# 生成式世界

通过 Fal Abot World 0 的实时 WebRTC 服务生成并探索世界。连接配置复用「工作流 · 3D · 画质」节点中的 Fal 专用创作工具。密钥只保存在服务端。

手动开始会话后等待首帧，点击画面获得键盘焦点；WASD 移动，方向键转动镜头，松开或离开画面即释放。更新和重置需等待服务端确认；刷新、关闭节点或切换画布会结束连接，重开不会自动启动按秒计费会话。

支持工作区图片作为起点；截图保存为图片输出，录制片段保存为视频输出，可继续接入现有生成和剪辑节点。

接口依据：[Fal Abot World 0](https://fal.ai/models/alibaba/abot-world-0/api)。实时协议使用官方 SDK 的固定 alpha 版本。
