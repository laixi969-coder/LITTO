# 梦境与志怪空间

东方梦境不等于无逻辑。**超现实靠"一处不对"，不靠处处乱**。画面里只有一个规则被改变，其余全部真实，读者才会觉得"这里不对"，而不是"这是拼贴"。

## 1. 只改一条规则

| 被改的规则 | 具体做法 | 其余部分必须照常 |
|---|---|---|
| 重力 | 山石与楼阁倒悬在上方，水向上流 | 云、雾、人物衣摆的下垂方向仍向下 |
| 尺度 | 人物身边的器物巨大，人只有器物高 | 器物结构完整、投影正常 |
| 空间深度 | 门后是一片海，门框大小与室内一致 | 门框、地面、光线方向不变 |
| 时间 | 同一画面里一半是落雪一半是夏叶 | 光源只有一个，色温统一 |
| 材质 | 衣服下摆化为烟、发丝化为水 | 面部、手部保持真实皮肤 |

- 一条规则只能改一次。同时倒悬 + 巨物 + 材质渐变，画面会散成特效堆。
- 改动要**落在具体构件上**：写"水榭的檐角朝下、瓦当向上"，不写"世界颠倒"。

## 2. 光的逻辑

梦境最常见的废片原因：光是假的。

- 主光必须有位置：窗、门、月、灯、云缝。哪怕画面是被压缩过的，光源方向仍要能画出来。
- 一个画面一个主光方向。超现实组合（比如雪与夏叶同框）不能带两个太阳。
- 逆光、侧逆光、漫射三选一，写清落在哪个表面、结果是什么。
- 不写"神秘光""氛围光""梦幻打光"，这些词模型会给你均匀发亮的塑料感。

## 3. 人物

- 只做一件事：望、听、行、执灯、抬手触。动作越少，人物越立得住。
- 服饰写形制与面料：交领、圆领、直裾、大袖；真丝、棉麻、纱罗。写垂坠与褶皱方向，不写"华美古装"。
- 表情写到方向与停顿："视线落在画面右侧的远处，停住"，不写"神情哀伤"。
- 人物与奇境的接触点要写实：手指压在石栏上的压力、脚踩在苔面上的下陷、衣摆被水托起。

## 4. 色彩

- 主调一个色，点缀一个色，其余中性。东方梦境常用：青灰主调 + 朱红点缀、墨黑主调 + 石绿点缀、月白主调 + 赭石点缀。
- 主色由环境承载（天、水、雾、石），点缀由人造物承载（灯、衣、器）。
- 肤色不参与主调：环境再冷，皮肤也要有血色。
- 不写"高级灰""莫兰迪"这类命名，直接写主色占比与位置。

## 5. 志怪的分寸

- 恐怖靠**认知错位**，不靠血腥与扭曲。写"器物数量对不上""影子方向不一致""水面倒影里少了一个人"。
- 不出现尸体、伤口、血污、腐烂；不出现儿童形象被置于威胁中。
- 异类只用一个特征：多一只眼、关节反向、皮肤半透明。不叠加多个特征。

## 6. 常见错误

- 同时改三条以上规则，读成特效拼贴。
- 光没有来源，全画面均匀发亮。
- 人物动作过多（走、回头、抬手、笑），一帧里塞不进，模型会画出扭曲肢体。
- 用"残破、斑驳、风化、苔痕"堆古意——违反写实红线，除非明确要遗构。
- 服饰写成"华丽、飘逸、仙气"，模型给塑料纱。
- 手足数量与关节方向没写清，志怪题材尤其容易多指。
