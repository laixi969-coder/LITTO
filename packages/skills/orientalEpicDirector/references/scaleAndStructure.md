# 尺度与建筑结构

奇境画面的两个硬伤：**没标尺**（巨物读成贴纸）和**结构不自洽**（天宫读成积木）。本文件给可直接写进提示词的比例与结构条件。

## 1. 标尺换算表

按真实构件尺寸推算，写提示词时直接用相对关系，不必写数字单位：

| 构件 | 真实尺寸（参考） | 放大到"奇境"后的写法 |
|---|---|---|
| 台基须弥座 | 高 1.5–2 米，约到成人胸口 | 一级踏步高到成人膝盖，整座台基十二级 |
| 柱径 / 柱高 | 约 1 : 9 | 柱身看起来要十几个人合抱 |
| 斗拱一格 | 实际尺寸按建筑参考核对 | 整组斗拱只有飞鸟翼展大小 |
| 檐口出挑 | 约为柱高的 1/4 | 檐下阴影能停下一只小船 |
| 廊桥宽度 | 3–4 米 | 桥上并行的两人在画面里只有两个像素高 |
| 花瓣厚度 | 真实 1–2 毫米 | 奇境里写"边缘有半米厚"，并写出投影 |
| 叶脉 | 真实 1–3 毫米 | 奇境里写"宽到可以落脚"，有独立高光 |
| 藤蔓直径 | 真实 1–3 厘米 | 奇境里写"与人腰同粗"，缠绕有缠绕角度 |

规则：

- 明确标尺与主体的尺寸、距离及遮挡关系；不要把提示语序当作模型布局保证。
- 按观看需要选择相容的尺度参照，不规定标尺数量；人物、舟与鸟的距离必须可辨。
- 标尺应处在**可比较的空间关系内**，否则会读成两个空间贴在一起。远山上的小塔不能当近景巨物的标尺。

## 2. 建筑五层写法

以云上天宫为例，逐层落到可检验的句子：

```text
台基：汉白玉须弥座，十二级踏步，每级高度到成人膝盖，栏板望柱间距约三人宽，
      台基边缘在云海上投出清晰的水平阴影。
柱列：朱漆圆柱，柱径约为柱高的九分之一，柱距等距，柱头外露一段额枋。
斗拱：柱头上方四层斗拱逐层出挑，出挑方向朝向檐外，每格只有飞鸟翼展大小。
檐口：深出挑，檐下椽子等距排列，瓦面按顺序搭接，檐口边缘在逆光下成一条连续亮线。
屋脊：正脊与垂脊沿主体轴线对齐，脊饰位于正脊两端，位置对称。
```

- **仰视**：重点写斗拱层数与檐底椽子的排列，台基只露出边缘。
- **俯瞰**：重点写台基轴线、飞廊连接关系、院落进深，檐口只见轮廓。
- **平视**：选取必要结构描述，但只写面向镜头那一侧，不写背面结构。
- 建筑群写清实际存在的主体与连接关系；没有配殿或飞廊时不为模板补造。

## 3. 巨型植物的解剖

巨型植物需要检查结构是否符合本项目世界规则。结构比例按已定生物或幻想规则设计，不强制改造所有植物：

| 部位 | 放大后的要求 |
|---|---|
| 茎 | 表面出现纵向纤维与分叉节点，节点处有环状突起 |
| 叶 | 叶脉主脉凸起、有独立高光与投影；叶缘有厚度，能看到断面 |
| 花 | 花瓣有厚度与半透明层次，花蕊成簇可见，花下有投影落地 |
| 根 / 气生根 | 沿建筑构件缠绕，压强处有勒痕，方向自上而下 |
| 露水 | 水滴有独立球面高光与倒影，不是噪点 |

- 巨型植物与建筑相接处必须写清"谁压着谁"：藤压瓦、根穿栏、花遮檐，不能含糊。
- 植物受光与建筑一致：同一方向，同一时间，同一色温。

## 4. 常见错误

- 巨物没有标尺，或标尺被虚化到看不清。
- 建筑只有飞檐没有台基与柱列，读成"飘着的屋顶"。
- 斗拱被画成一排装饰线条，没有与柱头的连接关系。
- 同一座建筑在画面两侧出现不同层数（模型自造对称时最容易发生）。
- 云海盖住整座建筑，只露檐角，尺度反而读不出来。
- 用"斑驳、残破、风化、苔痕、锈迹"加质感——违反写实红线，除非用户明确要遗构。
- 写"电影感光影""史诗氛围"代替具体光源位置与介质。
- 人物与巨物不在同一景深平面，人物像贴上去的。
