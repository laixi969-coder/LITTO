# 导演色卡库

198 位导演的实测色卡，取自真实电影截图取色，按 10 个风格大类归档。**这是比例数据，不是滤镜预设。**

## 怎么用

1. 需要定调时，先读 `index.json`，按分类或导演名定位（10 类：黑色悬疑／霓虹赛博／大地暖调／极简冷构／巴洛克华丽／超现实／动作史诗／动画奇幻／浪漫柔光／东方留白）。
2. 读对应的 `palettes/<编号>_<英文名>.json`，拿到主色板、情绪色板、光影与构图关键词。
3. 把数据转成生成参数，而不是抄形容词：
   - `shotSpec.lighting` 写「主光 X，高光偏 Y，阴影偏 Z，对比 N%」
   - `styleReference` 指向该导演的剧照（需自备，库内不含图片）
   - `composeFilm.grade` 用主色板里占比最高的两三色反推色相与饱和倾向
4. 一镜只用一个导演的色板。混两个会得到谁都不像的中间色。

## 三条硬规则

**主色由环境承载。** 墙面、天空、大体积布景承担主色；人物服装、道具与反射承担连接色和强调色。肤色保持中性可读，不被环境综合色污染。

**占比是比例，不是清单。** 主色 35% 意味着画面里三成以上是它，不是"出现一下"。判断是否执行到位，看色块面积，不看有没有这个颜色。

**不要用全局滤镜替代美术。** 资料里的原话：全局青橙、统一高饱和、塑料材质都是跑偏信号。真正的高级感来自光源、材质与色块面积的组织。

`profile.avoid` 是该导演最容易被做坏的方向，生成前先读它。

## 和质检配合

`qc` 会返回每镜的 `luma / sat / hue`。选定导演后，可以用主色板的 HSL 手工推算期望区间，对比实际值判断「这一镜偏离目标色板多远」。

量化只能发现明显偏离，不能判断好不好。色彩对了但画面平庸，仍需人看。
