# 角色锻造与定妆

## 从聊天开始选角

若只有角色方向，先给 3–4 位可区分的文字候选，各写适演角色、年龄感、轮廓、三个辨识点、气质与服饰。可用同一试镜动作表现差异，例如同样听到门响，有人先转眼，有人先收住笑容。用户已在角色库选人时直接读取其角色资产、定妆图、固定特征及允许变化，沿用该演员。

## 从全身母版派生

用户要创建新演员时，默认先比较两张竖幅全身候选。自然站姿，头顶和鞋底完整，镜头保持水平，留足腿部画幅。两版保持人物辨识点，用细小的姿态或妆发差别帮助选片。按当前模型支持的规格选择标准质量与接近 2K 的尺寸。多个角色各自维护母版和资产。

用户选定一张母版后，所有派生图均绑定同一张身份图。若另有参考，把面部结构、服装、表情与光线的用途逐一标明。已授权采用某张图时直接沿用该选择。

| 资产 | 构图与核对 |
| --- | --- |
| 人脸近景 | 中性背景，从胸口以上取景，保留头顶。检查眉眼间距、脸部轮廓、发际线和年龄感。 |
| 九宫格表情 | 统一机位和光源，依次呈现平静、浅笑、认真、悲伤、惊讶、生气、困惑、委屈、沉思。 |
| 角色多视图 | 左侧全身正、侧、背面，右侧半身正面、四分之三侧面和侧面。比较身材比例、妆发、衣物结构和配饰位置。 |

画布制作时先连接母版与派生节点，核对节点的实际引用与提示词指向同一张图。换母版时更新所有后续引用。已有定妆图只需一张分镜时，直接以选中参考进入该镜头。完成后沿用 Mili Mili 的人物资产、定妆参考、采用和收藏流程，回读角色名称、参考图和资产 ID。
