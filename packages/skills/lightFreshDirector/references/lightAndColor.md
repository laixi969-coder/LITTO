# 光线与色彩方法

光感小清新题材的核心是"光"：每镜写清真实光源方向、软硬、受光位置与背景明暗；同一场次光源方向、曝光、肤色与背景亮度保持连续。本文件按光线时段与场景给出写法细则，按需读取对应部分。

## 1. 三个光线时段

### 晨光（日出后 1–2 小时）

- 色温偏冷偏柔，光从低角度进入；写清"清晨侧光，光线低角度从画面左侧进入，人物面部一半受光"。
- 湖面/露水产生低角度反光；空气中有薄雾感。
- 受光结果："光线：晨光侧照，人物面部左侧受光，右侧处于柔和阴影，背景水面泛起细碎反光。"

### 午后（10–16 点）

- 光线最强、影子最短；写清树影、格栅影、屋檐影的方向与形状。
- 避免正午顶光造成面部阴影过重；人物可站在树荫边缘，写清"树影边缘落在人物肩头"。
- 受光结果："光线：午后顶光被树冠柔化，人物站在树荫与光斑交界处，面部受光均匀，背景明暗层次清晰。"

### 日落（17–19 点）

- 色温转暖，光从低角度进入，影子拉长；写清金色反光落在水面、发丝与衣料边缘。
- 面部转向光源方向时写清"夕阳暖光勾勒侧脸轮廓，发丝边缘泛金色"；背光时写清剪影与轮廓光。
- 受光结果："光线：日落侧逆光，人物轮廓镶金边，面部处于阴影一侧但仍清晰可读，背景海面呈金色反光。"

## 2. 特殊光效写法

| 光效 | 写法要点 |
|---|---|
| 逆光 | 光源位于人物身后；写清轮廓受光（发丝与肩线镶光）、面部受光结果与镜头眩光程度（"镜头轻微眩光，光斑扫过画面边缘"） |
| 树影/格栅影 | 写清影子形状与落点（"条状树影落在榻榻米与人物手边"），影子方向与真实光源一致 |
| 水面反光 | 写清水面反光的颜色与形态（"水面泛起碎金色波纹反光"），反光方向与光源位置一致 |
| 纱与裙摆通透感 | 写清"薄纱在逆光下透出轮廓，布料纤维可见"，与实色衣料的受光区分 |
| 光斑 | 写清光斑落点（"竹叶间透下的光斑落在石面与水面"），大小与形状随遮挡物变化 |

## 3. 清透色彩规则

- 以浅色系为主：米白、浅蓝、淡绿、燕麦色服装；环境保留适度自然饱和，清透不等于灰蒙蒙。
- 默认中性或微冷的清透日光，高光与阴影服从实际光源；夕阳与暖灯场景才明确加入暖高光，不能每镜统一套暖色滤镜。
- 肤色保持中性可读，不被环境综合色污染；"人物肤色清透自然，高光在鼻梁与颧骨，暗部在颌下线"。
- 不使用全局高饱和滤镜；清透来自光源、材质与色块面积的组织，不是加饱和度。

## 4. 逐镜光线句模板

每镜第二段以"光线："开头，只写一句，不写色温数值：

- 常规："光线：延续本场自然光，曝光与背景亮度保持一致。"
- 特殊："光线：侧逆光从画面右后方进入，人物面部右侧受光、左侧落阴影，背景树影随微风晃动。"
- 时间变化："光线：光线随日落转暖，人物面部受光角度下移，背景阴影拉长。"

光线变化必须有原因：人物走近窗边、门窗开合、云层遮挡、时段推进或场景切换可以形成有原因的光线变化；同一场次内不无理由跳变。
