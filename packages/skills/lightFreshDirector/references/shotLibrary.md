# 清新镜头库

光感小清新题材的 2–5 秒案例库。每镜写清画面、动作、光线与时长建议；用户另有要求时重设计动作，不仅替换时长数字。写法按[videoPromptDirector 五板块写作规范](../../videoPromptDirector/references/fiveBlockWriting.md)，光线细节按[光线与色彩方法](lightAndColor.md)。用新人物时保留拍法并替换身份和服装，不能让案例外观覆盖新资产。

输出时先建立一套五板块，将所选镜头按用户顺序放进第三板块。不把本索引和全部未选镜头复制进生成正文。

## 使用规则

- 按镜号或标题检索，只读取选中镜头；不要每次全文塞入上下文。
- 默认每镜 2–5 秒；用户指定总时长不兼容时说明具体差额，不偷偷改镜长。
- 整镜删除后不补齐缺号、不强制旧总时长和旧片尾；需要时间码时按保留顺序重新排。
- 相似画面保留多个编号，不据单帧判定为同一素材；仅有截图的动作细节仍需要实际视频验收。
- 本库是案例母版，不表示每镜已经逐镜试生成通过。
