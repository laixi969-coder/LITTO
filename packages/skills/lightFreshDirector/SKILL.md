# 光感小清新导演

把夏日、湖光、树影、微风和细腻的日常动作写成清透、自然、有呼吸感的短片提示词。支持 5–30 秒短片、多镜头时间轴与光线说明，可直接复制使用。

五板块完整提示词的通用写作规范读取 [videoPromptDirector 五板块写作规范](../videoPromptDirector/references/fiveBlockWriting.md)，资产建立规则读取 [资产建立与绑定](../videoPromptDirector/references/assetBinding.md)，节点创建规则读取 [节点创建与写入](../videoPromptDirector/references/nodeSetup.md)。本技能负责清新题材的镜头库、光线色彩方法与默认选择，不重新定义通用规范。

本题材方法只补当前项目未确定的视觉与动作选择，已采用的时长、画幅、媒介、配乐及人物状态优先。正式镜头写入既有规格后编译；独立节点选择五板块时才遵循该格式，文字方案不自动创建节点。项目总时长不代表单次生成容量；不能因加载本技能把 MV 改为无配乐，或把既定动画改为真人。

## 1. 任务范围与默认选择

- 默认中文。默认时长 5–30 秒，多镜头按动作与光线节奏分配，不平均切分；镜数和时长由行动与声音容量决定。
- 默认画幅 16:9 横版；用户指定竖版（9:16）时按竖版重新组织构图。
- 默认自然光、清透色彩、有依据的摄影方式、无背景音乐、保留环境声；用户另有要求时覆盖。
- 侧重：真实自然光（晨光/午后/日落）、清透色彩（中性偏冷的干净肤色、明亮中间调、环境保留自然饱和度）、多镜头安排（环境—动作—情绪—收束）、细腻表演（目光、呼吸、指尖、裙摆）。
- 只交付提示词与必要分析；不自动生成图片、视频、音乐或发布内容。

## 2. 按请求选择交付方式

| 用户当前请求 | 工作方式 | 输出 |
|---|---|---|
| 一句话构想，写简单分镜确认 | 确定场景、人物、动作与光线意图 | 简单分镜；不提前扩成完整提示词 |
| 已确认，写完整提示词 | 继承已确认内容，补全可生成的状态、动作、摄影与光线 | 一份五板块提示词 |
| 挑镜头、删镜、换顺序 | 按选择顺序取镜，补单镜上下文 | 一份五板块提示词 |
| 只要某一镜的替换段落 | 保留母版，只改影响范围 | 可直接替换的文字 |
| 结果不对，修某一镜 | 对照目标和实际结果找最小修改范围 | 必要诊断及修订提示词 |

信息充分时继续完成当前交付。只有缺失信息会实质改变人物、场景、动作或交付范围时集中询问。

## 3. 按需读取配套资料

- 新写或全面整编完整提示词：读取 [五板块写作规范](../videoPromptDirector/references/fiveBlockWriting.md)。
- 挑镜、复用现有画面或按编号取镜：先检索 [清新镜头库](references/shotLibrary.md) 的镜号和标题，再读取选中镜头；不要每次全文塞入上下文。
- 人物清爽、清透妆面与自然表演：读取 [清爽人物方法](../videoPromptDirector/references/cleanPortrait.md)，保持身份、肤色与年龄，不套统一白肤女团脸。
- 涉及晨光/午后/日落光线、逆光、树影、水面反光、纱与裙摆通透感：读取 [光线与色彩方法](references/lightAndColor.md) 对应部分。
- 对照生成结果修复：读取 [生成问题与修复案例](../videoPromptDirector/references/failureRepair.md)。

主文件决定流程和优先级，配套资料提供细节。镜头库是可改写的案例母版，不要求每次使用全部镜头或全部场景。

## 4. 默认镜头节奏（多镜头时间轴）

可从环境、人物行动、反应与收束中选择本片需要的信息；下表仅作预算示例，不是必备阶段或镜数配额：

| 阶段 | 建议镜头数 | 时长参考 | 光线任务 |
|---|---|---|---|
| 环境建立 | 1–2 | 每镜 3–4 秒 | 交代时段与光感：湖面反光、树影、光线穿过纱帘 |
| 人物进入 | 1–2 | 每镜 3–5 秒 | 人物受光位置明确，面部清晰可读 |
| 细腻动作 | 2–3 | 每镜 2–4 秒 | 局部光影变化：指尖掠过水面、裙摆被风掀起 |
| 情绪反应 | 1–2 | 每镜 2–4 秒 | 面部受光方向明确，背景明暗连续 |
| 收束 | 1 | 每镜 3 秒 | 回到环境，光线与开场呼应 |

同一完整行动可以保持一镜；必要的信息变化再切镜。示例时长不能证明实际模型能执行，按真实生成时长与剪入时长分别安排。

## 5. 影像判断

- 光线是本题材的主角：每镜必须写清光源方向、软硬、受光位置与背景明暗；同一场次光源方向、曝光、肤色与背景亮度保持连续。
- 清透色彩不等于高饱和：以浅色系服装与低饱和环境为主，高光色偏暖、暗部色偏冷灰，保留空气感。
- 表演由当前人物任务、触发与回应组织；克制是可选风格，不强加慢眨眼、微动作，也不删除剧情要求的大幅行动。
- 环境动态（风、树影、水面涟漪、花瓣）作为低存在感背景，不遮挡面部与对白动作。
- 人物旋转不要求摄影机环绕；固定观察时保持所选支撑方式，仅人物动作。
- 剪影、遮纱、极近局部允许读不到完整五官；需要读表情的近景则把人物转向光源或写清环境补光。

## 6. 输出前检查

在内部用实际镜头检查，不给用户重复附长清单：

1. 当前交付是简分镜、完整稿还是局部替换，是否越界新增内容。
2. 镜头数量、时长总和是否与确认规格一致，时间码是否连续。
3. 每个镜头动作因果与摄影路径是否清晰，动作能否在分配时长内完成。
4. 光线是否逐镜写清、同场次连续，特殊光影是否有真实依据，固定光线也可成立。
5. 表演是否由目光、呼吸、指尖等可见行为承载，没有抽象情绪词替代。
6. 五板块是否各司其职，镜头选择与用户确认的母版一致。
7. 实际生成能力未核实，不承诺全部镜头能一次调用生成；未生成的稿件不宣称试生成通过。

## 原创例与反例的使用

适用与输入：清新自然光题材；输入既定人物、场地、天气和当场任务。

写法示例：人物在树荫下读信，听到门响抬眼；摄影机固定，树影只随已有风变化。

反例：为‘清新’强加慢眨眼、手持摇晃、飞鸟和五个切镜。

约束与例外：本例只说明组织方法，人物、时长、数量与媒介须换成当前项目；不自动加入案例剧情。已有有效方案直接复用。

验收与修复：查动作触发、受光和声音；去掉无依据装饰，保留有意静止。 本例未实际生成，不作为效果证据。
