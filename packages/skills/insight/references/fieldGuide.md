# 消费者洞察判断标准

## 区分不同层级

| 层级 | 回答的问题 | 示例（均为教学构造，不是研究发现） |
| --- | --- | --- |
| 画像 | 谁 | 经常网购的上班族 |
| 观察 | 做了什么 | 下单前反复打开退货说明 |
| 需求/痛点 | 想要什么、哪里不方便 | 想买到合适的尺码；担心退货麻烦 |
| 洞察假设 | 为什么在这个情境下这样选择 | 第一次买陌生版型时，用户可能愿意尝试新风格，却不愿承担买错后的处理成本，因此先确认退出是否容易，再考虑是否下单 |
| 策略机会 | 可以改变什么 | 在尺码选择处清楚呈现真实退换条件，降低决策不确定性 |
| 创意表达 | 怎么让人记住 | “先看能不能退，再想要不要买” |

洞察的价值是解释行为并帮助决策，不是给普通事实换一个漂亮说法。观察也有价值，证据不足时停留在观察比强行解释更好。

## 五个核心标准

| 标准 | 通过依据 | 常见失败 |
| --- | --- | --- |
| 证据可追溯 | 可定位材料；推断与原话分开 | 编造引语、把 brief 的设定当研究 |
| 情境具体 | 知道谁、何时、要完成什么、面临什么条件 | “当代年轻人都……” |
| 机制有解释力 | 说明任务、阻力或取舍如何影响行为，并考虑其他解释 | 只说“需要情绪价值”，或凭空读心 |
| 选择与决策相关 | 影响购买/不买、使用、转用等，能指导具体决策 | 只是一句生活哲理或品牌自夸 |
| 可验证且有边界 | 有支持/推翻条件、适用范围和未知 | 用任何结果都能证明的空泛说法 |

缺直接证据的条目不能成为“已支持洞察”，但可作为值得研究的假设；未通过机制或决策标准时退回观察/需求。没有意外反转、事故感、画面或金句，不构成淘汰理由。

## 示例：同一行为，多个解释

以下为**虚构练习材料**，E 编号仅在本例内有效，不可引用为真实消费者证据：

- E01：受访者 A 描述第一次买陌生品牌裤子，先查上门取件；她说：“工作日没空跑快递点。”
- E02：受访者 B 的操作记录显示，查看退换条件后仍放弃；B 解释预算已经用完。
- E03：受访者 C 购买熟悉品牌同款时没有查看退换条件。

**观察**：A 与 B 都看过退换条件，但后续选择和原因不同。

**可推进的假设**：对工作日难以寄件、首次尝试陌生版型的人，买错后的处理成本可能限制尝试意愿；便于退货可能是他们愿意尝试的条件之一。

**状态**：待验证，低信心。A 提供直接的自述支持，但样本有限，缺少实际选择变化证据；B 提示预算解释，C 提示熟悉度边界。

**不能声称**：“消费者不在乎价格，只在乎退货”“提供上门退货就能增长销量”。

**行动与验证**：先访谈最近试买/放弃者，核对真实过程及预算、尺码、信任因素；若服务确实支持上门取件，可测试在决策处呈现退换条件。观察购买完成率，同时看实际退货、服务成本和投诉。文案测试只检验信息干预效果，不足以证明处理成本是唯一动机。

## 常见误判与修复

- **“年轻人需要情绪价值”**：追问哪种情境、实际行为和替代方案；不能仅用“年轻人”解释心理。
- **“用户嫌贵，所以降价”**：区分支付能力、相对价值、现金流、价格公平感和不信任；追问真实比较与放弃过程。
- **“她反复比价，是怕输给别人”**：先检查预算和习惯解释，除非材料支持社会比较。
- **“三条差评证明大家都……”**：限定为这些评论中出现的线索，记录平台、筛选方式、时间和偏差。
- **“广告获奖，所以洞察成立”**：执行表现不是原始研究；区分创作者主张、受众证据和结果归因。
- **“一帧拍不出来，所以不是洞察”**：复杂决策机制仍可能有用；可拍性只用于创意转译。
- **“品牌有某功能，所以消费者一定需要”**：先独立确认需求及阻力，再判断功能是否解决它。
