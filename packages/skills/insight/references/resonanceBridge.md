# 共鸣转译：洞察到内容

用户要海报、短视频、选题、脚本时使用；先读取洞察的机制、证据状态与边界，再写表达。现象 + 半步等具体手法见 [创意转译](../../adfilm/references/creativeTranslation.md)。

## 开始前

确认对象与情境、核心取舍、产品实际作用。已有支持的洞察可以转译；待验证假设也可生成明确作为探索的文案，不得通过转译变成研究事实、消费者原话或虚构证言。对外主张仍须符合已知产品事实。

文案不需要说明全部因果，但不能删掉与本条有关的核心张力，只剩卖点清单。可拍性适用于画面任务，转发意愿适用于分享目标；海报、转化信息或服务提示不必全部通过“想转发”测试。

## 共鸣四问

内部检查：谁会认出自己？哪个具体瞬间？这句话替他表达了什么？品牌提供了什么真实帮助？需要分享时再考虑转发理由。这些问题帮助选择表达，不是每次必须交付的字段。

避免默认用内疚、身份焦虑或控诉激发反应。情绪应来自材料，安静、务实的表达也可以有效；不用机械凑情绪种类。

## 按请求交付

- 只要文案：仅给文案，数量及编号对应原洞察。
- 约 20 字：正文 18–24 字为默认目标（不计标点），优先自然通顺，不堆抽象词凑数。
- 选题：一句主题 + 具体场景 + 必要时的载体；数量按用户要求。
- 完整内容方向：可展开对象、瞬间、文案、形式与测试方式，不默认每条三个钩子。

## 示例（虚构练习）

洞察假设：想与父母同住的夫妻，可能希望父母住好，又不愿牺牲自己的居住舒适。

海报探索：“想把好的留给自己，也想让父母住得舒舒服服。”

必须另行检查全套房是否真的提供舒适空间；不能由独卫推导面积相同。这个例子是练习，不是实际人群发现。

## 验证

认领、完播、收藏等检验内容反应；预约、咨询或购买检验特定行动效果。点赞不能独自验证动机，转化不佳也可能来自价格、投放对象或产品体验，先诊断再决定是否修正洞察。
