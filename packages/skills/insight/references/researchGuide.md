# 研究与验证指南

在资料不足、需要访谈/评论分析或设计验证时使用。研究力度按决策风险安排，不用固定样本数量冒充研究充分性。

## 证据台账

推荐列：`id | 来源与定位 | 日期 | 样本/招募方式 | 原话或行为 | 情境 | 局限`。

记录访谈匿名编号与段落/时间戳、评论链接或材料行号、行为数据的指标定义/时间窗/分母。缺项写未知。使用完成分析所需的最少个人信息，输出引语去除无关身份信息。

同一人的多条反馈、转载和重复评论不能算多份独立证据。矛盾资料单列，不因不符合主张而删掉。行为日志说明发生了什么，访谈提供自述解释；两者都不自动证明因果。

## 按问题选择方法

| 不确定性 | 合适的下一步 | 能回答 / 不能直接回答 |
| --- | --- | --- |
| 为什么买或放弃 | 最近真实事件访谈、决策过程回溯 | 机制线索 / 全体占比 |
| 说法与行动不一致 | 情境观察、日记、获准使用的操作记录 | 实际过程 / 全部内心动机 |
| 某种模式有多普遍 | 定义人群后的调查或覆盖明确的行为数据 | 样本内分布及有条件推广 / 无偏代表性保证 |
| 改变服务是否有效 | 对照实验或分阶段试点 | 干预对指标的影响 / 唯一心理解释 |
| 只有 brief | 列少量假设、缺口和最省成本的取证动作 | 研究方向 / 已证实洞察 |

## 访谈：最近一次，而非理想中的自己

围绕最近一次相关事件，按过程追问：

1. 当时发生什么，让你开始考虑？谁参与或付款？
2. 你先看了哪些方案？还考虑过不买、继续用旧的或其他办法吗？
3. 哪一步犹豫了？可以回忆当时看到的信息或做的动作吗？
4. 最终选了什么、放弃什么？为了这个选择接受了哪些不方便？
5. 使用后发生什么？最近有没有一次做了相反的选择，条件有什么不同？

避免“你是不是因为焦虑”“如果我们推出你会买吗”等诱导或意向替代行为的问题。受访者无法解释时保留未知，不能连续追问直到得到预设答案。覆盖购买者、放弃者、流失者和相关反例，不只访问品牌拥护者。

## 评论与材料分析

先说明材料如何取得、时间范围及筛选规则，再编码情境、任务、触发、替代方案、阻力、取舍和结果。同一评论可有多个主题。给出支持原文和负例，不只提炼情绪词。

需要报告数量时说明统计单位、去重方式和分母；仅代表提供的材料，不能转换成总体比例。材料太少或未覆盖不买的人时明确盲区。

## 验证卡

- 假设与适用人群：具体到情境和行为。
- 关键未知：动机解释、覆盖范围还是行动效果？
- 方法与对象：为什么这个方法能够回答这项未知？
- 支持观察：预期看到哪些行为与解释相互印证？
- 推翻/收窄观察：什么结果使假设失效或仅适用部分人？
- 决策规则：何时继续、修改或停止；数值阈值需结合基线和业务约束设定，未知时不编造。
- 行为指标与约束指标：例如完成购买，同时查看取消、退货、投诉和成本。

报告未执行的研究为“计划”，不能把预期结果写成发现。
