# 营销选择推导

洞察负责解释具体情境下的选择，营销选择负责"品牌接着做什么"。本层在用户需要行动建议时启动；只要洞察或文案时不自动扩展。

## 资格检验

给任何营销选择前过三问：

1. **品牌和这个现象有什么真实关系？** 是它的产品、渠道、用户或能力自然触及的地方，还是八竿子打不着？
2. **产品或服务能真实参与吗？** 能做出一个真实的产品、服务、规则或内容动作，还是只能贴一句标语？
3. **消费者会怎么看？** 说完这句话、做完这件事，消费者觉得品牌懂他，还是觉得被教育？

三问有答不上的，说明缺什么。**不为让品牌有话可说而修改洞察**；品牌能力不足不降低洞察本身的有效性；注明该品牌暂无合适动作。

## 推导链

从洞察到选择按顺序推导，不跳步：

**洞察的张力 → 品牌能扮演的角色 → 一个具体动作 → 消费者能感知到什么**

例：洞察是"收藏越多，决定越少——缺的不是方法，是先做哪一件的确定感"（张力）→ 品牌可以是帮人缩小选择的角色 → 动作：把教程做成"第一步只做这一件"的引导 → 消费者感知到：不用再囤方法，今天就能动手。

## 五类选择

| 类型 | 含义 | 正例 |
|---|---|---|
| 产品动作 | 产品成为洞察中已有动作的下一步延伸 | 照顾者习惯"多检查一步"：新品类产品要设计成她原有照顾动作的延伸，而不是额外的一堂健康课。 |
| 服务动作 | 服务补齐洞察里的摩擦或代价 | 收藏多决定少：减少答案堆叠，帮用户缩小选择，说明什么情况下先做什么就够了。 |
| 规则机制 | 让消费者经历自己的判断，而不是听品牌宣讲正确价值 | 标签先替动作打分：先暂时拿掉标签让观众判断，再揭示标签如何影响了自己。 |
| 传播内容 | 可拍的画面；把数据或痕迹变成用户的自我表达 | 年度听歌：不做数据账单，把数据组织成用户能认领、回忆和表达"这一年的我"的叙事。 |
| 场景渠道 | 出现在洞察发生的真实场景里 | 洞察发生在洗衣流程里，就进洗衣流程，而不是进电梯海报。 |

## 把选择写足

一句话的营销选择是目录,不是选择。每个动作写到"下周就能开会讨论"的程度:

- **传播内容**:给出形式与载体,至少列 2 个具体内容或话题示例;话题要设计到"用户能接话"——可复述、可拍同款、可发自己的朋友圈。
- **服务动作**:写清触发环节、动作流程、消费者在哪一步感知到什么。
- **产品动作**:写清改变的是哪个已有动作的哪一步。
- **规则机制**:写清规则文本、谁监督、违反了怎样。

### 传播内容形式库

| 形式 | 适合 | 要点 |
|---|---|---|
| 单支品牌片 | 一个可拍画面撑得起 60 秒 | 从 `shootable_scene` 长出来,不靠旁白讲道理 |
| 系列短内容(15–30 秒 × N) | 现象有多个变体场景 | 一集一个场景,攒成"说的就是我"合集 |
| 话题运营 | 洞察自带自我指认("我就是这样") | 话题名直接借洞察句,让用户晒自己的版本 |
| 海报/文案系列 | 一句话洞察足够锋利 | 文案保留洞察核心取舍，画面按需演绎，不把演绎当证据 |
| 数据内容 | 品牌手里有真实用户数据 | 把数据组织成用户能认领的自我叙事,不做账单 |
| 纪录片式长内容 | 品牌有真实的人、工坊、服务过程 | 拍过程不拍口号,真实感即差异化 |
| UGC 挑战/模板 | 洞察中的动作可被模仿 | 给模板和样例,降低参与门槛 |
| 联名/跨界内容 | 洞察指向另一品类场景 | 对象必须是洞察场景里的真实存在,不为联而联 |

## 与共鸣转译层的衔接

当选择类型是「传播内容」，或用户明确要选题/脚本/话题时，在定形式与叙事引擎之前，先完成 [resonanceBridge.md](resonanceBridge.md) 的共鸣四问与内容钩子。叙事引擎回答「怎么讲得动人」；共鸣转译回答「谁会认领、为什么转发」。两者都过，才写入 `marketing_choices.move`。

## 传播内容的叙事引擎

形式解决"发在哪、长什么样",叙事解决"凭什么被点开、被转发"。每个传播内容方向在定形式之前,先过三问:

### 三问定叙事

1. **谁的故事?(视角轮换)** 同一个洞察可以换主语形成内容变体，但不能当作新洞察。可考虑:用户本人、隐性受害者、隐性受益者、沉默的大多数、产品视角(让物件/系统开口说话)、十年后回看的人。爆点常藏在隐性受害者和沉默的大多数;同一洞察的多个内容方向,主语不得完全相同。
2. **打中什么情绪?** 情绪出口(替一群人说出憋着的话)、身份焦虑(怕落后、怕被看不起)、认知错位(表面与真相不一致)、代价感(输掉的不是输赢本身)、共鸣、荒诞。默认克制,不默认热血;只有洞察本身支持时才升档,禁止空话(燃、史诗、赋能)。
3. **转发时配哪句话?(转发语测试)** 想象读者转发这条内容时配的那句话("太真实了""转给老板""这就是我""离谱")。分享是目标时，配不出自然转发语就重新考虑切口；仅用于信息呈现或转化时不以此淘汰。

### 接近性折算

远的东西必须折算成"离我近"的表达才有传播力:大数字 → 一个人的账单;行业趋势 → 我下个月哪个动作变了;to B 概念 → 某个具体职位的某个具体深夜(如"云计算"折算成"IT 经理续费前的三秒")。折算不出来的,降级处理或改走趋势判断型。

### 内容方向十型

象征细节型(一个动作或物件讲整件事)、命运转折型(哪一刻变了)、代价揭示型(看似结果,实际谁在付代价)、身份投射型("这说的就是我")、情绪宣泄型(替人说出憋着的话)、认知反差型(表面与真相相反)、关系撕裂型(谁和谁不再站在一起)、现实避坑型(可收藏可转发的提醒)、趋势判断型(个体事件映射时代)、倒计时型(时间快没了)。

### 方向纪律

- 内部检查切入视角与情绪；分享目标适用时考虑转发语。只有用户要完整内容方案才展示这些字段。
- 多个方向不得只换壳:至少换掉视角、情绪、冲突、利益关系中的两个变量。
- 可以尖锐,不可以失真:切口必须能反推回洞察的证据,不硬造社会议题。

## 好选择自检

- 它是消费者已有动作的延伸，还是额外的一堂课？
- 能不能一句话说清，不借助"赋能 / 打造 / 引领"？
- 资格三问都过吗？
- 是否守住了洞察的人群与场景边界，没有偷偷扩到"所有消费者"？
- 消费者能具体感知到什么变化？
- 传播内容给形式和至少两个具体示例了吗？整个选择写到"下周能开会讨论"了吗？

## 坏选择清单

- **贴标语**：只堆标语却不说明实际产品价值。用户明确只要海报时，短文案本身就是有效交付，不强制额外服务动作。
- **价值观倒写**：品牌想占某个价值，就宣称消费者正在追求它。
- **上课**：借洞察批评消费者"你们其实需要……"。
- **改洞察迁就品牌**：为了品牌有话说，把"一部分人"扩成"所有人"。
- **承诺结果**：保证声量、爆款或销量。
- **扩成方案**：从一句营销选择膨胀成完整 campaign、媒介与预算规划。用户要进一步展开时，走 [strategyBridge.md](strategyBridge.md)（策略）与 [productForge.md](productForge.md)（产品）层，不在本层偷偷膨胀。

## 事实与效果边界

公开文案不添加无法证实的产品能力、功效、价格或稀缺性承诺。用户 brief 的说法与独立核实的事实分开；“唯一”等主张需要时间、区域、品类和来源范围。需判断具体法规时查证适用的现行权威资料，不用单一词表代替法律判断。

每个动作补充作用机制与最小验证；行为指标同时配体验/成本指标。内容共鸣不等于购买，购买变化也不自动证明心理动机。

## 数量与口径

每条洞察给 1–3 个营销选择，宁少而真。没有合格选择就写明：

> 这条洞察暂无合格的品牌承接：缺的是……（例如产品与该场景的真实接触点）
