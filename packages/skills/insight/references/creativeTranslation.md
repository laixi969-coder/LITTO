# Hiccai 创意转译：现象 + 半步

仅在需要广告/传播表达时使用。先有消费者洞察或明确标注的假设，再进行表达；创意本身不新增证据，也不能把假设升级为事实。

## 保留的表达方法

从洞察的真实场景中，提炼一个能被认出、能被复述的观察。标题可以只推进“半步”：重新命名、设置对照、补一个动作或物件，把解释留给支撑文字。这里可以避免标题使用“因为、本质上、这说明”等说理措辞，但消费者洞察陈述应保留必要解释。

需要探索时先形成少量候选，再按真实感、表达新意和品牌适配选取；不用为了数量制造假现象。

可尝试五种视角：交换观察者、对照不同时间、从被忽视角色出发、转换计量单位、反转品类惯例。它们是创意手法，不是研究方法，不能为了反转扭曲原始行为。

## 可选交付字段

- `source_insight`：所承接的洞察及其证据状态。
- `title`：现象 + 半步的表达。
- `evidence_scene`：原始场景，引用证据编号；无证据则标为构造场景。
- `half_step`：添加的命名、反差、动作或物件。
- `shootable_scene`：拟拍画面，明确是创意演绎。
- `accident_sense`：适用时写小冲突、误解或尴尬；安静的真实也可以成立。
- `psychological_driver` / `insight_value`：沿用消费者洞察中的解释与不确定性。
- `brand_fit` / `creative_proposition`：品牌能力、消费者收益和具体行动。
- `risk_note`：是否夸大、刻板化、冒犯，或承诺了品牌无法兑现的服务。

若用户需要旧版 JSON，保留旧字段，并将证据状态、替代解释与验证计划一并交付。无法判断的质量项用 null 并说明；不为凑齐字段全部填 true。

## 示例（教学构造，无真实研究）

假设：首次尝试陌生版型且寄件不便的人，可能先考虑买错后的处理成本。

现象表达：“先看能不能退，再想要不要买。”

拟拍画面：光标在尺码表和退换说明间往返，消费者查看真实取件安排后才做决定。

品牌行动：在确实具备相应服务时，将退换条件呈现在决策位置。画面是对假设的演绎，不证明消费者普遍这样做，也不能暗示未提供的服务。
