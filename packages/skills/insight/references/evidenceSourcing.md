# 证据检索

检索服务于理解真实选择，不能只搜能支持金句的帖子。需要研究设计时同时读 [研究指南](researchGuide.md)。

## 路由与查询

先界定决策问题、情境、购买/使用/付款/影响角色以及消费阶段，再选择平台。生活帖子提供自述线索；电商追评和退换讨论提供使用及选择叙述；日志和交易记录提供行为；报告提供覆盖范围内的分布；品牌官网用于核对产品事实。平台不固定，不能以性别标签代替渠道判断。

围绕问题检索正向选择、行为代价、反例与替代方案。例如“首次买 / 为什么选”“怎么比较 / 谁决定”“放弃 / 后悔 / 不买 / 继续用旧的”。不只搜焦虑、身份或委屈，也不为情绪丰富度补造温暖故事。

用户明确要求搜索时实际检索；需要核对当前售价、在售状态、区域唯一性等也要查证。只有 brief 且用户要脑暴时，可以先给标注的假设，不将研究计划称为搜索结果。

## 记录与判断

每条实际材料记录 E 编号、原文/转述、页面链接或文件定位、日期、样本/来源及限制。评论同源转载去重，多个报道引用同一帖子不算独立来源。搜索摘要不能代替未读正文，不补写不可见评论。

区分四类主张：
- 产品事实：有什么、多少钱、何时可用。官网或销售页面也只能支持其实际记载范围。
- 行为事实：特定样本做了什么。付款量不说明是谁买、买来怎么用，也不证明复购或满意。
- 态度自述：某人说了什么，不自动等于他如何行动。
- 动机解释：由上述资料推断的机制，需要与其他解释比较。

**多源一致提高特定事实的可信度，不自动验证因果或心理动机。** 一个原始页面只支持那个来源中的主张，不能推广人群。采用“观察有支持 / 机制部分支持 / 待验证假设”等分开表述，信心附理由。

## 不可访问与偏差

登录墙、限流、超时出现时，可做有限重试或换同问题的可访问来源；同一故障重试一次仍失败就换路径，全部不可用则使用现有材料并说明未完成检索。不要把无法访问说成没有反例。

只能读取媒体转述时注明转述，降低结论范围。检查发声者、算法、评价激励、幸存者、角色代述和关键词偏差；材料中多少条提及某主题，只代表该材料及统计口径，不等于总体比例。

竞品宣称与消费者证据分别存放。案例的获奖、销量或传播结果不能独自证明所声称的消费者机制。
