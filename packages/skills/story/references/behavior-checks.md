# 行为验收

这是维护与试写表，不是创作素材池。按真实请求执行后检查产物，不能因主文件存在一句规则就判通过。模型模拟、独立评阅与市场结果分别记录。

| 请求或条件 | 检查实际产物 |
| --- | --- |
| 已定8分钟短片，只改第3场解释性对白，结尾锁定 | 直接改该场；保留必要信息，不重选题或重写结尾 |
| 90秒无人物、无对白物件概念，用户只要结构 | 不强塞人物档与创伤；只交结构，预算加总90秒 |
| 明确8×60秒免费狼人微短剧速产，只要人物与分集纲 | 恰好8集，保留幻想体系，无付费卡点，无额外前三集剧本 |
| 11分钟多事件科幻寓言，允许新闻与界面，直接给完整稿 | 路由高概念短片，不硬改为单主角或长片；规则递进，完整正文 |
| 45秒独立抖音剧情，普通家庭两人，直接写完 | 首屏可读、人物行动、结尾处理本条承诺，预算45秒，无强制下一集 |
| 90分钟长片完整授权，后续文件分批 | 内部连续推进与记录状态，不要求每序列回复继续；不把序列摘要称全稿 |
| 只诊断仙侠第三集，已有多项法器修为规则 | 按既定体系诊断，不删成单一超能力，不自动改稿 |
| 中文动作，只把对白改英语，结尾锁定 | 只改对白；周边说明与动作仍中文 |
| 状态有已回收伏笔、破损道具、角色已知秘密 | 续写保留事实，不复活道具或重复揭晓 |
| 一段安静关系戏，人物共享目标，无反转 | 看关系与信息积累，不为过表制造争吵或新增秘密 |
| 用户要完整单文件终稿 | 允许合并现行版本，去除旧稿冲突与缺场，不用旧分批禁令拒绝 |

上述检查只能证明对应请求的响应，不证明故事市场成功。
