# 世界规律与秩序故事

本方法移植自 hiccai-host-story，供 story 技能按作品意图选用。用户要求、已有采用版本与故事工作台的保存和交接流程优先；本文的交付格式仅用于适用的创作任务，不覆盖用户指定格式。讨论写作方法时直接回答，不强制创作完整故事。

# 故事

动笔前读 本文「世界观」。世界观以那份文件为准。

当下被改写：片子的主角是一条规律。人是它的证据。秩序即世界：片子的主角是一个不肯承认的人。秩序是他逃不掉的世界。

动笔前先定三件事。

快感，四选一，整支片子先把这一种给满，再收回来：

- 爽：观众先痛快
- 笑：观众先笑出声
- 亲近：观众先想靠近某个人
- 旁观：观众先觉得自己只是在看

骨架和世界观成对：

- 当下被改写，且要七到十一分钟：新闻日。读 本文「九步」。
- 当下被改写，且是两个人、一个地点、或明确要短：一间房。读 本文「一间房」。
- 秩序即世界：只用 本文「世界观」 里的五步行程。不读九步。
- 长篇、万字、一万字：不走上面的短篇骨架。读 本文「长篇」。

契约，二选一。三条一起生效，不混用。

认账：

- 观众要承认自己刚才参与过
- 规则必须一眼看见。讲一段才懂的，换掉
- 结尾留着，让人拿不准自己站哪一边

拼上：

- 观众要把结构拼上。前面的细节得到结尾才归位
- 规则可以由人讲清楚。复杂本身就是戏
- 结尾扣死，让人重新看懂前面

认账必须配当下被改写。拼上必须配秩序即世界。用户说诺兰、烧脑、时间、记忆、因果、谁先知道、结构反转、结尾揭晓时，用后者。其余用前者。

## 让观众走进去

默认观众在手机上观看，可以随时离开。开头尽快给出正在发生的具体局面：有人想做一件事，规律或秩序使这件事遇到阻碍、出现机会，或产生意料之外的后果。让观众能看懂眼前发生了什么、对谁有影响，并想看下一步。世界背景和人物履历放进后续行动里，不先讲一段设定。

第一口就给选定快感：爽、笑、亲近或旁观中的一种。紧张、危险、秘密、尴尬和反差都可以用，但不是必选；安静的场面也要有具体的情境和正在变化的关系。不规定必须几秒内发生什么，不靠喊叫、突发灾难或密集反转强行抓人。

只给一个奇怪现象或谜面不算过关。开头至少让观众在意一个具体问题：这个人接下来怎么办、会失去什么、关系会变成怎样。谜底不必立刻揭晓，但眼前局面要能跟得上。若使用先给后果再回到原因，后续必须兑现这个后果；不能借它绕开所选骨架，也不能借用已有作品的情节。

从开头到结尾，人物的行动尽量接住上一步的结果：他试着解决眼前问题，新的后果改变处境，迫使他再做选择。让选择和代价落在具体的人与关系上；不要用无关事故或不断加新规则维持刺激。每场主要戏看一眼：结束时人物的处境、关系、目标或认识是否有变化；没有变化且不能承担必要铺垫，就删掉或并入别处。

悬念要有兑现：适时回答一部分，让答案改变人物处境或观众的理解，再由此生出下一步的问题。不必每场都反转，也不为了拖延而藏住人物自然会说出的信息。结尾兑现开头建立的核心期待，同时遵守认账的留白或拼上的扣死；不靠解释代替最后的事件或动作。

## 输入

用户给一句睡不着的感受，或一个生活里的错位。感受已经说清时，原句保留，只把它收成规则和装置。用户给的是题材时，先替他找到那盘醋，再写。

用户明确说先看设定：只交片头六行、传述一句，和该世界观的每步一行。

用户要剧本、拆成剧本，或故事和剧本一起要：先交完整故事，再按 本文「剧本」 拆。对话里已经有写定的故事时，只拆那一篇，不另写一篇。

其余情况交完整故事，不附剧本。

## 写作顺序

内部按这个顺序做完。不过关的步骤就地重写。

### 1. 锁醋

按下面深度第 1 条写成一句。

### 2. 锁装置

当下被改写的规律必须同时满足四条：

- 一句话能说完
- 判的是心意或注视，不只是撞上了什么
- 没有人从高处解释它为什么存在
- 人们会找到一个办法，这个办法是后半场

它要能被一个日常物件看见。讲一段才懂的，换一个更笨的物件。新闻日的第一口只让它碰冷开场的那个人。一间房里它出不了这间房。

秩序即世界不套这四条。秩序是什么，按 本文「世界观」 写。它可以被讲清一次。

### 3. 砍到一部片子装得下

短篇只有一种世界观、一条规律或一套秩序、一盘醋、一种快感。第二套世界规律出现时，删掉它。新闻日的切片超过五个时，删到五个，并按 本文「九步」 的连贯条写回同一个人。长篇的篇幅和分程以 本文「长篇」 为准，同样不另加第二条规律。写完用 本文「世界观」 的原创检验再看一遍。

### 4. 回看

认账用深度第 5 条和第 6 条回看结尾。拼上用契约的第三条回看结尾：结构要扣死，并且早先一场因此改了意思。不过就重写结尾。

再遮住作者的设定说明，只看故事正文的开头：观众能否看懂此刻谁在做什么、什么正在改变，以及接下来为什么值得看？选定的快感是否已经发生？如果只能回答「有点奇怪」或必须等后文解释才有兴趣，重写开头。接着沿主要场面检查行动、后果和选择是否相连，悬念是否有兑现；不要为了通过检查增加额外情节。

## 深度

当下被改写时六条都过，才交稿。秩序即世界只保留第 1 条和第 3 条，其余改为契约的三条，外加 本文「世界观」 里那件已经发生、他不肯承认的事。

1. 醋是一个矛盾。听的人会愣一下。马上说「对」的，换成更拧的一句。
2. 冷开场的那个人自己用过一次规则，而且用得很顺手。结尾的动作要交出他靠规则得到的那点舒服。
3. 能被起名字的画面，本身就是整部片子的论点。别人只转述这一个画面，也等于看过片子。
4. 后半段那个看似体面的办法，正好是这个人私下想要的。
5. 观众至少有一次和这个人同罪：痛快过、笑过、心软过，或把目光移开过。
6. 金句遮住以后，最后一个动作仍然扎人。它使用冷开场的同一个物件，观众因此重看第一场。只剩下温暖，就重写。

## 声音

人说话像话被切断，不发表观点。选定的那种快感要在前半段真的发生。

主播只属于新闻日。在那里，新闻腔把局部说成全球，一次说完。金句由这个主播说，整片一句。宣布办法的人语气温和，像值得信任的人。

一间房和秩序即世界不设主播。一间房没有合适的外部声音时，不要金句。

## 交付

用中文。用户用英文提出时，故事用英文。检查过程不交出来。

片头六行：

- 世界观：
- 契约：
- 快感：
- 规律：
- 醋：
- 可见的载体：

然后写成一支完整故事。完整，是指读者不用听解释也能跟着走完，并且故事正文里已经有：这个人、他这一程要做成的那件事、规律或秩序第一次落到他身上、他因此做的事、后半的转折、结尾的动作。缺一件，先补上再交。

当下被改写的新闻日，这个人从头走到结尾，九步写进这一天。一间房不换人、不换房。秩序即世界按 本文「世界观」 的五步写，不写成新闻日。长篇按 本文「长篇」 分程写，全篇约一万字。

人话嵌在故事里。新闻日的金句只出现一次，单独成行标出。认账的结尾不把题答完。拼上的结尾用事件把结构扣死，不另加解释。单片不硬加彩蛋。用户要系列时，才在结尾留一个不解释的物件。

故事结束后另起一行，只写传述：用一句话讲那个能被转述的画面。

用户要剧本时，读本文「剧本」，按那里的格式把这篇故事拆开。剧本不承担发明情节的工作。

分镜、镜头号、生成提示词和模型名，只有用户另外明确要时才写。

## 交稿前

当下被改写对照 本文「九步」 或 本文「一间房」，以及第 2 步的四条和深度六条。秩序即世界对照 本文「世界观」 的行程、契约三条，以及深度第 1 条和第 3 条。长篇改为对照 本文「长篇」。三类都再过 本文「世界观」 开头的原创检验。交的是剧本时，再对照 本文「剧本」。有一条不过，改完再交。

对着正文逐项检查，不以片头六行、作者想表达的意思或场景摘要代替已经写出来的证据：

1. **规律或秩序**：从开头到结尾追踪关键触发、结果和人物所知。相同条件下是否一致？结尾物件的变化是否真的由已建立的规律和人物当时的心意或行动产生？需要区分“心里想要”和“决定怎么做”时，不把两者写成同一件事。不为解释矛盾临时增加一条规律。
2. **题材落地**：用户明确要求的活动、环境或关系，在这篇中如何影响人物行动、选择、相处或后果？换成无关的活动或场地，关键情节是否仍完全一样？若是，补出与本故事有关的具体作用；不为每个题材强造冲突或额外支线。
3. **关系过程**：挑出重要关系的变化，核对变化前后有没有可见的行动、互动或事件支撑。生气变为原谅、喜欢变为放手都不能只靠时间跳过或一句说明；若人物没有和解或仍有矛盾，也要让读者看得出当下的关系。
4. **主角的决定**：他具体想做什么、为什么想做、为何犹豫，正文是否提供足够线索？他的关键选择是否由他自己作出并带来后续，而不只是被别人推着走？不必解释全部前史，也不把每个决定写成高风险两难。
5. **开头冷读**：遮住片头六行和作者说明，只读开头。能否跟上眼前的人、行动与变化，感受到选定快感，并说出一个值得继续看的具体期待？允许暂时不懂全部规则或原因，但不能只剩一个没有分量的谜面。

发现问题先在授权范围内改正文，再检查受影响的规则、人物知情、前后因果和结尾；若改动影响剧本，按工作台版本流程同步对应场次。重复核对直到适用项过关，再交付。用户锁定内容及局部修改范围优先，范围外的问题说明即可。不把可修的问题留到交稿后的解释中，也不为了通过清单硬加事件；检查过程不交出来。仅凭内部冷读不能声称真实观众一定会被吸引。

## 边界

用户要垃圾站那种固定工位、把观众评论写进下一集的连载：停。长篇不是这一类。长篇只是同一个世界里的几程。

用户要的是一般剧本、短剧或广告，手里没有「世界被一条规律改写」或「秩序本身就是世界」这层意思：停。不要把骨架套上去。

# 世界观

先定世界靠什么运转，再写一个人怎么过完这一程。盖住角色名之后，如果还能被认成某部已有电影的某一段，就重写。只换掉原片里的物件，故事还是那一段，也算没过。

不从已有电影里借情节。路牌成真、天上的光标、观看使新闻成真、作恶变成食物、把人送去月球、请非人上车，都不要再写。记忆倒放去找凶手、进入层层梦、把亲人写成穿越一个家具、爆炸之后才听见声音，也都不要再写。

## 当下被改写

配认账，用新闻日或一间房。

世界就是现在的街道、医院、手机和家里。一条人与人之间的行为变成看得见的后果。人照上下班。没有人从高处解释这条规律为什么存在。人们会想出一个办法，这个办法把同一条行为又做了一遍。

世界要问的是：当内心变成后果，人还怎么相处。

不发明帝国、神话和天选之人。

## 秩序即世界

配拼上。不用新闻日的九步。

世界的时间、记忆、因果，或谁先知道什么，本身就是这套秩序。秩序不是怪兽，也不是一句标语。一个人要在里面面对一件已经发生、他不肯承认的事。每场戏都是这套秩序被使用一次。换房间、换年份，只有秩序需要时才发生。

世界要问的是：知道全部之后，他还肯不肯承认那件事。

不靠新闻主播把世界粘起来。后半不写成一项政府新政策。

行程只有五步：

1. 他已经在秩序里。观众先看见一个后果，还不懂原因。
2. 秩序被讲清一次。只讲这一次。
3. 他用秩序去够那件不肯承认的事。每够一次，代价落在一个具体的人身上。
4. 先前散开的细节在这里碰头。
5. 结尾扣死。开场那个后果就是这件事。

# 九步

只服务「当下被改写」的新闻日。一间房见 本文「一间房」。秩序即世界见 本文「世界观」，不用这九步。

每步只有一个验收句。验收句不过，改这一步，不要靠后面的步骤补。

新闻日里，主播的那一句整片只有一句，放在第 6 步之后。它问的是观众会怎么选，不是复述剧情。

连贯：九步是同一天里的同一条因果。冷开场的那个人要活到第 8 步，第 8 步发生在这个人身上。第 3 步的其他人只在这个人看见的新闻、橱窗或窗外闪一下，每条一个动作，随即回到这个人。每一步使用上一步留下的结果。

| 步 | 验收句 |
|---|---|
| 1. 冷开场 | 一个具体的人做一个日常动作，规律在他身上生效一次；此时观众还不知道这是全球的事 |
| 2. 新闻升格 | 主播用两句把这件事说成全球的事，给出的解释来得太早 |
| 3. 切片 | 三到五个生活片段，每片一个日常动机，结果由这条规律产生；片段从属于这个人看见的世界 |
| 4. 可见后果 | 规律长成一个能被叫出名字的后果，这个后果本身就是论点 |
| 5. 旧办法失败 | 人们用原本就会的办法处理，办法失败 |
| 6. 新办法 | 人们推出一个听起来体面的办法，并给它一个公文名字 |
| 7. 同构 | 这个办法与原来的规律是同一种行为，由一张容易被信任的脸宣布 |
| 8. 人话 | 冷开场的那个人用一个很小的动作把醋交出去；遮住金句仍能感到这盘醋 |
| 9. 系列物件 | 单片没有这一步。用户要系列时，才留一个不解释的物件，且这个物件不来自已有电影 |

# 一间房

只服务「当下被改写」。两个人，一个地点，三到五分钟。规律只在这两个人之间生效。没有主播，没有全球新闻。关系本身就是那套办法。

秩序即世界不用这五步，行程见 本文「世界观」。快感、契约、装置四条、深度六条以 本方法正文 为准。

| 步 | 验收句 |
|---|---|
| 1 | 一个日常动作里，规则在其中一个人身上生效一次 |
| 2 | 另一个人用这次生效换到一件具体的舒服，而且用得很顺 |
| 3 | 被生效的人付出一个看得见的代价 |
| 4 | 想补救的那一下，正好是用规则的人本来想要的 |
| 5 | 他把那件舒服交出去。动作使用第 1 步的同一个物件，观众重看第一眼 |

不换人，不换房。金句可以没有。有的话只一句，从门铃、广播、语音这些外部声音里出来。

# 长篇

用户要长篇、万字、一万字时用这一档。短篇骨架不要拿来写长篇。

全篇八千到一万二千字。分成四到六程。每一程一千五百到两千五百字。

全篇只有一种世界观、一条规律或一套秩序、一盘醋、一种快感。不在中途换世界，也不另加第二条规律。

每一程自己完整：有一个能跟着走完的人，有他这一程要做成的一件具体的事，规律或秩序落到他身上，他因此做事，有转折，有结尾的动作。下一程使用上一程留下的后果，不把世界重置。

新闻日的九步和一间房的五步不要在每一程里重演。主播最多在全篇出现一次。体面的办法也只推出一次，放在后半，而且正好是这些人私下想要的。

当下被改写：每一程换一个人，或回到前面的人，但都活在同一条规律里。最后一程用第一程的那个物件做结尾。认账的问句只在最后一程出现一次。结尾不把题答完。

秩序即世界：秩序只讲清一次。前面的程先给后果。后面的程让人用这套秩序去够那件不肯承认的事，每次代价落到一个具体的人身上。最后一程扣死。第一程那个看不懂的后果，就是这件事。

单篇不硬加彩蛋。写完用 本文「世界观」 的原创检验看全篇。某一程单独拿出来像另一部电影的某一段，就重写那一程。

# 剧本

剧本是把已经写完的故事拆成一场一场能拍的戏。不新加情节，不换结局，不换世界观。

拆之前，故事里要已经有这些。缺任何一件，先补进故事，再拆：

- 一个能跟着走完的人
- 他这一程要做成的一件具体的事
- 规律或秩序第一次落到他身上
- 他因此做出的事
- 后半的转折
- 结尾的那个动作

一场戏只做一件事。下一场使用上一场留下的结果。短篇里，当下被改写不换主角。长篇按程拆，一程之内不换这一程的主角，程与程之间可以换人。秩序即世界只有秩序需要时才换地点或年份。

新闻里闪过的别人，如果只有一个动作，写进这个人正在看的那一场。不另开一支故事。

主播、广播、电话和语音都写成对白。对白用故事里已经有的话。可以补一句短的、像被打断的话。不能补一段讲主题的话。

每场只写这些，不写镜头号，不写模型：

第 1 场
地点：
时间：
人物：
动作：
对白：

没有对白就写「无」。

拆完对照原故事读一遍。多出来的情节删掉。故事里有、剧本里没有的转折或结尾，补进对应的场。
