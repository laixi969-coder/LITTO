# 核心编剧方法

目录：创作地基；反庸俗；试奏与音叉；完整开发流程；戏剧动作与人物；信息与讲法；对白与文本；节奏与时长；冷读与修订；交付与连续性。

## 创作地基

电影从已运行的世界切入。先知道人物的来路，再选择观众何时看见什么；不从出生机械讲起。生活、职业、地域的细节来自已给材料或可核实来源；想象明确为创作，不伪装调查结果。

现实偏移通常改变一条规则，幻想体系可以有多种已建立设定。统一检查触发、效果、范围、成本与信息边界，不用新设定解旧死局。可拍包含动画、特效、文字与声音，不等于所有信息只能由摄影机直接看见。

故事先行、结构后置，但讲法从创意时参与。先写具体的人在具体处境里做了什么，再检查因果与观看体验；允许从结尾、台词、物件或形式起步。结构是可选择的诊断工具，不能声称所有故事必须通过同一模板。

体验可以是愉悦、惊讶、担忧、亲密、恐惧、悲伤、荒诞或安静的认识。主题可以是明确判断，也可以是始终无法消除的问题；不把人物写成论点代言人，不把开放结局当未完成，也不因结尾温暖就视为庸俗。

## 反庸俗

内部检查第一反应方案，关注：
- 议题像贴纸，换议题仍是同一个空故事。
- 人物只代表立场，语言没有自己的来路。
- 精巧镜像或身份反转，没有过程与情绪。
- 临时绝症、事故、独白替代已累积的关系。
- 黑屏金句代替结尾行动。
- 后果完全平铺，观众早早知道全部走向。
- 只有裁员、算法、焦虑等抽象热点，没有具体切口。
- 空泛命名与空间，没有生活细节。
- 靠新能力或新规则不断加码。
- 讲法未经选择，入口没有观看理由。

不是一命中某个常见元素就删除；诊断它是否在本故事中被具体化。经典、顺叙、可预期的告别都可以有力量。公共题材不等于公共表达。

内部先比较2—5个可能方向，再问：
1. 当前真实候选之间，差别在哪里？各自弱在哪里？
2. 哪个细节具有具体来路，不能只由概念公式自动填出？它如何影响人物或体验？

不得为“生命迹象”随机塞装饰。细节不必与主题一一对应，但应属于人物、地方或处境。没有市场样本就不给排名或成功率。

用户探索时可简述被舍弃方向与原因；用户要剧本时不附大量废案。不把内部自审链条写成冗长交付。直出只是少展示过程，仍执行质量底线。

## 试奏 音叉与素材

素材优先：用户给的具体材料、已授权项目事实、合理想象。缺少素材可以邀请一件真东西，但不要求用户揭露私人经历；没有就继续创作。

方向探索用微缩试奏：直接示范故事被怎样讲起来，通常每方向一小段；按用户要的数量交付。可以附一句概念、一个具体细节和适合体量。直接成稿任务内部选择，不停下来让用户再选。

方向过开时可用6—10个碎片碰撞：画面、台词、人物动作、空间、物件。碎片无需提前形成完整因果；选中后再长成故事。不要把碎片阶段也变成全套填表。

先试写一场有热度的“音叉场景”，通常约200字，用于校准情绪和语言；不强制每次输出，也不以字数压坏关键动作。它不是全文最高效的唯一标准，更不能使其他场景都模仿同一种强度。

## 完整开发流程

### 入口与推进

明确模式 autonomous / guided / fast。完整交付授权后内部连贯推进；共同探索才在真实创意选择处停顿。续写接已有阶段；局部修改不重走全部流程。用户已定的集数、结尾、语言与产物范围优先。

### 故事展开 treatment

按选定观看顺序把故事讲完整，不把treatment误称剧本。人物与前史融在叙述里，关键时刻有可见行为；引少量必要台词，不铺成全部场次。复杂时序另建时间顺序表，用于核对事实，而不强迫观众也按时间顺序观看。

一般参考：概念超短300—600字、短片600—1500字、长片1500—4000字，剧集先季纲再分集。只是信息预算，不是所有语言的硬字符上限；用户所需详细程度优先。结尾必须有明确可呈现的落点，开放也应具体。

### 人物或规则开发

人物型：明确目标、策略、资源、顾虑、关系与行为矛盾。
规则型：建立规则卡、社会应对与共同情绪，不强加完整人物档。
形式型：建立形式单元、信息进入方式和变化。
观察型：追踪时间、关系、缺席、重复中的差异。

长片与群像可组合；每种材料只做必要工作。

### 整形

产出适用的序列或节拍、场景表、信息安排与估算预算。内部中间表无须全部给用户。

逐项问：核心观看问题是什么？什么在变化？人物为何采取下一步？重要选择是否有代价？对抗是否有效？知识与情绪如何转移？类型承诺是否有回报？

可以参考四段式、Save the Cat、McKee、Story Circle、章节、观察型或自定义结构。缺某模板标签不等于缺戏；出现动机断裂、重复、无推进等实际问题才改故事。比例可变，记录改变的作用即可。

### 写作

写实际行动与完整对白，不只写场景功能。每场检查进入局面、即时目标、策略、阻力、退出局面；变化也可发生在关系、知识或观众理解中。安静、闲聊、环境与重复可积累体验，不能被效率原则一律删除。

写出新走向时核对后续、时长、规则与伏笔。若授权覆盖就修改并同步；若改变用户锁定方向且未授权，提出具体变更方案。不要写完后仍让旧大纲冒充现行版本。

## 戏剧动作与人物

“想被爱”是欲望，“今晚让对方留下”是任务。人物用邀请、试探、拒绝、隐瞒、交换等策略行动；对手有利益、资源与自己的选择。

Want / Need / Ghost / Lie / Flaw是可选分析工具。人物可成长、堕落、坚持、获得理解或保持状态而改变他人。不要给所有人补童年创伤，不把每段关系都当治疗。多个角色可以共享外部目标，冲突仍可来自策略、信息、风险承受和不可说的感受；无须每场都意见对立。

次要角色应是活人，同时承担推动、镜照、关系、对抗或节奏作用。避免功能重复，但不能只按功能名称拼人物。群像允许多条有自身结果的线，只要与全片组织有关。

## 信息与讲法

区分：事实、角色所知、角色误信、观众所知。记清重要证据何时出现、何时被重新解释。悬念来自知道风险但不知道结果；谜题来自可理解的问题和证据；反讽来自观众与人物的知识差；重估来自新信息改变旧事件意义。

公平反转要与已确认事实相容，有可事后识别的前文支撑，并改变行动或感受。不借故遮住所有必要证据，不让叙述层说谎再称高级。

非线性、界面、并置、伪纪录、循环等服务本作。去掉讲法会失去什么？它是否改变信息、时间体验、可信度或情绪？有帮助即可，不要求证明宇宙中“只能如此”。形式可稳定重复，不强迫结尾打破形式。

## 对白与文本

台词先问对谁做什么，付出什么，来自怎样的人生。可透露信息，同时争取、安慰、回避、威胁或协作。必要解释应在角色确实需要知道时出现，并产生后续作用。

允许新闻、采访、教学、实验、书信、内心声和旁白承担信息；检查视角、情境、精简与声音，不一概禁止。避免双方明知却故意给观众复述。

动作描写以可呈现结果为主；“他意识到真相”应改成足以表现变化的行为，或使用本作已经选择的内心声形式。括号可用于必要语气、对象或画外来源，少用且不替演员表演；不是看到括号就一票否决。

口语化不等于所有句子都短。保留有归属的长句、打断、改口、沉默与日常粗糙。生活细节不按配额发放；一场戏可以有情节不需要、体验需要的物件或声音。参阅对白审美。

## 节奏与时长

双轨记录：外部事件密度与内部情感重量。安静场景可以情感很重，追逐也可以轻快。起伏服务作品，不规定三分钟或三集同情绪必失败；若持续，要看内部是否有变化和足够的投入。

时间预算以可见动作、口播、停顿和同步关系拆解。对白按目标语言和表演速度估算；同一时间的对白与动作不机械相加。描写字数不等于屏幕时长，转场不默认一律占2—5秒。只在确有朗读、预演或成片记录时写实测。

阶段时点与比例是开发参考，不是平台算法。总预算应覆盖目标范围，不把中点另加一遍。高概念切片要留观众辨认现象和因果的时间；信息流要查首屏、最低背景与兑现距离。

## 模拟冷读与修订

具体执行主技能的[起稿、审读与改稿](../SKILL.md#起稿审读与改稿)，按初稿、证据审读、实际修改、完整复读的顺序完成。下列问题用于辅助判断，不另设一套过关标准。

完成初稿后模拟首次阅读，记录：哪里想继续、哪里走神、哪里不理解、哪里预测被满足或改变、哪里像真人、哪里想多停留、读完留下什么。明确“模拟冷读”，不虚构陌生评审与观众。

先作证，再用一致性与体裁标准定位问题。共同指向的问题优先修；只有形式清单不符而没有实际损失，不为改而改。修订要具体到场次、问题、修改动作和连锁影响。评分仅辅助，不能替代修改。

检查承诺兑现、伏笔处理、规则边界、人物作用与原创性。原型相似要同时比较具体机制、人物关系、场景、转折顺序与解法，不只查词。少量方法可迁移，标志场面不可拼接。

## 交付与连续性

完整剧本包含全部场景、动作、对白与必要声画线索。长片分文件时保持稳定序列编号和全稿索引；最终允许生成合并稿或用户要求的单文件，不以旧“不得合并”规则拒绝。

单次输出可按自然场景拆批，但autonomous模式连续完成。环境硬限制中断时写入现行稿与待续位置，说明剩余，不假装完成；不要把普通分批变成索取授权。

持续项目记录锁定事实及来源、世界规则、时间、人物位置与知情、道具状态、伏笔、稿件版本与修改。未确认提议不登记为已确认。已发生的回收、死亡、损坏和揭晓不能因清表消失。

## 从点子到执行稿：目标、信息与采用版本

开发新故事时用“当前能完成的任务 → 直接阻力 → 失败代价 → 策略改变 → 可视听结果”检查因果；已有定稿只补当前缺口。目标“证明自己”须落实为本场行动，证据怎样支持结论、观众何时看清或听清也要成立。候选在行动、关系或信息释放上有实质差异，不固定输出十个点子、三人两景或指定反转数。

需要反转时分别写事实、人物所知、观众所知；追踪旧理解、前置线索、揭示触发、新理解及其对行动的影响。可从人物目的、动作用途、物件功能、声音信息、观看范围选择一种方法，不要求配齐。已展示的空桌面不能后来无解释出现录音器；隐藏答案留在故事意图中，不提前编译成必须入画的信息。

可复用的场次写法：{人物}在{当前条件}要完成{任务}，因{直接阻力}改用{行动}，使{关系/物件/知情}从{起态}变为{终态}；观众通过{可辨认的画面或声音}获得{本场信息}。这是补写工具，不给纯表演或观察式作品强加冲突。

采用方向后沿同一版本展开完整分场，复用 goal/obstacle/change/knowledge/causes 和 canon/threads；场次摘要不能代替正文。估时纳入真实台词、动作、反应及必要停留，不用字数或固定每镜秒数认证容量。删掉物件、改结尾或替换动作时，同步受影响场次、分镜、资产、声音和后续状态；保留旧稿和未改部分。

## 原创例与反例的使用

适用与输入：需要把点子转为可拍场次；输入采用故事、人物目标及已知信息。

写法示例：门卫要在交班前核实来访者身份，对方拿出的证件缺少照片，他改向值班室核对，来访者因此停在门外。

反例：只写‘紧张的对峙，最后反转’，却没写谁获得什么信息。

约束与例外：本例只说明组织方法，人物、时长、数量与媒介须换成当前项目；不自动加入案例剧情。已有有效方案直接复用。

验收与修复：检查阻力是否改变行动、证据是否可见；缺因果先修场次，不用旁白补未发生的事。 本例未实际生成，不作为效果证据。
