# 题材与观众体验

以用户指定的体验为准，题材可以混合。以下是创作与检查时可选的观察点，不是统一结构，也不保证读者一定有对应反应。

- 喜剧：辨认人物、关系或处境中的喜感，让笑点由已建立的情境、反差和时机产生。可温暖、讽刺或荒诞，不要求每次都有惩罚或说教。
- 爱情、亲情、友情：看关系中各方的感受和行动怎样影响彼此；靠近、错过、陪伴或分离都可成立。重要变化需要适合本篇的铺垫，不强制和解或圆满。
- 现实题材：用具体生活处境和人物选择承载冲突；阻力可以来自人际关系、制度或人物自己。场景要发生具体转折，不必把平凡处境写成灾难。
- 悬疑、推理：确定观众想知道的问题、人物与观众分别掌握的信息。推理解答应由已建立的事实和线索支撑；悬疑可以保留有意的开放问题，不靠人物无理由隐瞒来拖延。任何题材需要紧张紧迫感时读 [thriller.md](thriller.md)，用行动与阻力推进，而非仅靠悬念说明。
- 动作、冒险：明确此刻的处境、空间、行动目的和限制；行动改变局面，解决方式要有前提。按作品需求安排节奏，不以不断升级的危险代替人物与故事。
- 科幻、奇幻、寓言：选择与故事有关的设定及其后果，保持必要的一致性；可以探索奇观、思想、冒险或情感，不必强制一条规则、一种解释或寓意。
- 实验、意识流：围绕用户希望的视角、语言、感官或形式组织材料，允许断裂和歧义；每个独立场景仍需有可辨认的冲突和转折，不要求按传统时间顺序收束。

混合题材时，以主要期待和用户要求为先，例如浪漫喜剧同时需要可信的关系与有趣的情境。恐怖不在本技能的重点设计范围内。
