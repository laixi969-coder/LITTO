# 来源与版本边界

- 名称：hiccai-story 2.0；内部调用名 hiccai-story。
- 基础方法署名 @山音；输入为用户提供的 shanyin-screenwriting-master-v2-universal 2.0本地维护包，保留其主要方法、对白参照、叙事工具、格式资料与状态模板。
- 此版为用户定制融合与修订，不是原作者正式发布声明。原包的海外短剧章节与时间手术条目包含既有维护补写，继续明确其身份。
- 融合材料：用户当前项目的35个作品结构案例与编剧方法研究。研究原文：https://chatgpt.com/space/page_83f5b7cbdbb881919dc592c02aca3b79 。参考文件保留公共来源入口。
- 新增：15—90秒信息流剧情、高概念规则与社会切片、案例库、故事引擎、分体裁评价与实际行为验收。
- 规则统一：故事类型和观看环境优先；模板、次数与固定时点改为开发启发；必要解释与声音叙事合法；用户授权后连续推进；快模式不关闭质量底线。
- 经典案例是结构判断，不声称本次逐页读取全部原剧本；DiDi_OK案例依据采访和作品资料，非逐镜数据库；不得生成未核实时间码或成功率。
- 类型与对白中作者名只作方法参照，不模拟在世作者独特措辞，不复用台词或标志性情节。
- 本版尚未获得市场表现验证。机械检查、模型模拟试写、独立人工审阅与真实发布测试属于不同证据，须分别记录。
