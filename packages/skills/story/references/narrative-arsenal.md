# 叙事武器库（所有格式通用·编剧武器）

目录：一、视角类；二、形式类；三、时间类；四、并置类；五、尺度与语调类；长片讲法原型；剧集讲法原型；短片讲法原型；超短片讲法原型；适配速查；最终检验（任何武器/原型交付前）。

> 本版使用范围：本文件的结构比例、时点、次数、人数与集数均为可调整的开发启发，不是普适规律或市场数据。用户任务、既定事实与主文件工作模式优先；静态弧、群像、多事件、观察型按其组织方式检查。


**定位：** 这里的每一件武器都是**叙事层面的选择**——决定"这个故事用什么方式讲"，而不是镜头层面的执行。编剧落下的是叙事结构和信息控制；具体的镜头方案、运镜、构图交给导演阶段（山音超级导演大师）。创意阶段以正文示范讲法；用户需要导演交接时，在独立交接备注中记录视角与信息边界，不强制往剧本正文插入标签。

**本库的定位是破题与创意阶段的内部调色盘**：AI生成方向时内部取用其中的手法与讲法原型，让讲法直接长进微缩试奏和创意文本里——不作为流程节点被引用，不以"本方向采用XX手法"的字段形式外显。次序、入口、视角是艺术判断，不是问卷答案；试奏骗不了人，字段可以。线性平铺也是一个合法讲法，但必须是被选择的，不是缺省剩下的。

**本文件结构：**
- Part I：武器条目（单件手法，可单用可组合）
- Part II：讲法原型启发库（按格式分区的完整讲法范式，对标导演风格库的用法——不是模仿对象，是校准质感的参照系）
- Part III：选择与检验

**使用原则：**
1. 武器服务作品。已有故事时选择更合适的讲法；用户从讲法起步时先做微缩试奏，再让人物与素材补足它，不要求必须先有完整故事。
2. 通常先聚焦少量主要方法，避免无关形式堆叠；数量按故事需要。
3. 武器需要递进——检查稳定手法是否持续产生新的内容、理解或感受，不强制形式自身变形。
4. 一种可选用法：结尾时形式参与新的理解——形式即内容。
5. 武器方案照过反庸俗层——"这个题材+这个手法"的第一反应组合往往也在公共池里。

# Part I：武器条目

## 一、视角类

### 视角置换
用一个不可能的视角讲述——物、动物、抽象存在、事件中的边缘者。
**编剧落笔：** 视角决定信息边界——这个视角能看到什么、永远看不到什么。看不到的部分就是留给观众的想象空间；视角的物理限制（不能移动、不能说话、会被丢弃）就是结构。
**何时用：** 熟悉题材需要陌生化；或视角本身即主题（边缘者视角=边缘处境）。
**递进方式：** 视角的处境随故事变化（被珍视→被遗忘→被丢弃）；或视角在结尾获得一次"越界"。
**死法：** 视角只是解说机位，换成正常视角信息量不变；视角的限制被随意打破。

### 限制视角
观众只知道某个角色知道的，信息与角色严格同步。
**编剧落笔：** 剧本里不出现任何该角色不在场的场景；悬念全部来自"他不知道的事"；观众和角色一起被骗、一起发现。
**何时用：** 悬疑、代入感优先、结尾靠认知翻转的故事。
**递进方式：** 角色获得的每块新信息同时推翻一块旧认知。
**死法：** 中途为了方便叙事偷偷切出该视角（哪怕一场戏，契约即破）。

### 多视角 / 罗生门
同一事件从多个视角讲述，版本互相矛盾或互相补全。
**编剧落笔：** 先写一份"客观事件底稿"（不给观众），再写各版本的变形；每个版本自洽且带有讲述者的利益或盲区；版本间设计2-3处关键差异点供观众对照——差异本身就是人物塑造。
**何时用：** 主题涉及真相不可达、记忆不可靠、立场决定叙述。
**递进方式：** 版本的排列顺序即信息设计——后一个版本要重写观众对前一个版本的判断。
**死法：** 版本差异只是细节装饰，没有立场含量；最后给出的"真相版"让前面的版本全部作废（好的罗生门里每个版本都留下点真的东西）。

### 不可靠叙述者
叙述者在撒谎、自欺或认知受限，观众在某个时刻发现"讲述本身不可信"。
**编剧落笔：** 提前埋叙述与画面的细微矛盾（说"我们很幸福"时画面里她坐得离他很远）——揭穿时观众能回想起"早就露馅了"。
**何时用：** 翻转型故事；主题涉及自我欺骗、记忆篡改。
**递进方式：** 矛盾从"可以被解释"逐渐走向"无法被解释"。
**死法：** 叙述者不可靠得毫无规律（不可靠也要有一致的动机——他为什么这样骗自己/骗观众）。

## 二、形式类

### 形式模拟
借用非叙事形式装故事：说明书、搜索记录、监控画面、聊天界面、验收报告、庭审笔录、客服对话、使用条款。
**编剧落笔：** 剧本直接以该形式的文本结构写作；故事信息全部通过形式内部的合法元素传递——一条搜索、一次已读不回、一条被撤回的消息、条款里的一个星号注释。
**何时用：** 形式与内容有本质关联时（用"产品验收"讲人的标准化；用"使用条款"讲一段关系的不平等）。
**递进方式：** 形式内部的异常逐渐累积——格式开始出错、系统提示越来越频繁、正式文体里渗入不该有的私人语气。
**死法：** 换掉形式故事照样成立（形式只是包装）；形式的规则被随意违反。

### 伪纪录 / 伪文档
假装是真实的纪录片、档案、采访、新闻调查。
**编剧落笔：** "正经"的形式让荒诞更荒诞——受访者一本正经地陈述离谱事实；镜头外提问者代表观众的常识，他的沉默或追问就是节奏工具；素材的"缺损"（丢失的片段、被打码的脸）是资产不是缺陷。
**何时用：** What-if概念需要严肃的壳来反衬；题材需要"这是真的"的错觉。
**递进方式：** 纪录的客观性逐渐失守——拍摄者被卷入、被摄者开始表演、素材开始互相矛盾。
**死法：** 机位出现在不可能有人拍的地方；受访者说出纪录片里没人会说的解释性台词。

## 三、时间类

### 时间压缩
把长时间跨度压进短篇幅——一生压进两分钟、十年压进一场戏。
**编剧落笔：** 选取重复出现的锚点（同一张饭桌、同一个街角、同一句问话），锚点不变而内容剧剧变，时间感从对比中产生；每次重现只改变2-3个关键元素，观众自己完成补间。
**递进方式：** 重现的间隔越来越短或越来越长——压缩的节奏本身有表意（越来越快=失控；越来越慢=凝滞）。
**死法：** 均匀切片的编年史（每段等长等重=流水账）。

### 时间拉伸
把一瞬间拉长——一秒钟里发生的一切。
**编剧落笔：** 写出这一秒内的全部感知层次，按主观重要性而非物理顺序排列；拉伸段的文字密度要远高于常规段落。
**何时用：** 全片围绕一个不可逆瞬间（事故、告白、扣扳机）。
**死法：** 拉伸的内容只是慢动作描述，没有主观信息增量。

### 循环 / Loop
起点→发展→看似解决→回到起点。第二次看到起点时，观众的理解已经不同——起点从"开始"变成"牢笼"。
**编剧落笔：** 两次起点的文本几乎一字不差，差异只在观众的认知；可在第二次循环开始处收尾，让观众自己完成"又来了"。多轮循环时列**轮次表**：每轮的变量、主角的认知增量、规则的新面向。
**递进方式：** 轮次是递进不是重复——每轮必须消耗设定的一个新面向。
**死法：** 轮与轮之间只有量变（这就是重复）；循环规则中途漂移。

### 倒叙揭示
先给一个不可理解的结果，全片回答"这是怎么发生的"。
**编剧落笔：** 开场画面必须精确设计——它要在结尾被重新理解时含义完全翻转；每步回溯让画面更合理，同时更荒诞或更恐怖。
**死法：** 结果不够怪（观众没有"怎么回事"的钩子）；揭示过程是平铺直叙的补课。

### 逆时序
整体倒着讲：从结局开始，一段段回到起点。
**编剧落笔：** 先按正序写完整时间线，再切段倒排；每段的结尾要与时间上的后一段（叙述上的前一段）咬合；越往回走，越接近"一切还来得及"的时刻——宿命感来自观众知道结局而角色不知道。
**何时用：** 主题=追问"怎么走到这一步"、无法挽回。
**死法：** 正着看信息量一样（倒序只是顺序游戏，没有认知收益）。

### 双线时间交汇
两条时间线并行推进（过去线+现在线；正放的早晨+倒放的夜晚），在某个点交汇，交汇瞬间产生揭示。
**编剧落笔：** 交汇点先定，两条线反向铺设；每次切线都要有信息或情绪上的理由（在语义呼应处切，不在随机处切）；两线的节奏做成互补（一线紧时另一线松）。
**死法：** 一条线明显弱，观众只想快进到另一条。

## 四、并置类

### 双线并置
两条看似无关的线平行推进，观众在某个时刻意识到它们是同一件事的两面、或一方的美好建立在另一方的残酷之上。
**编剧落笔：** "意识到"的瞬间不需要角色说出来——并置的顺序和节奏本身完成揭示；两线要有形式上的呼应点（同一个动作、同一句话在两线各出现一次）。
**死法：** 关系在开头就被观众看穿（并置失去揭示功能，沦为对照示意图）。

### 前景 / 背景叙事
前景在做一件事，背景在发生另一件事，两者互相注释。
**编剧落笔：** 同一场景描写里写清两层信息；背景信息不被角色注意、只被观众注意——观众因为"看到了角色没看到的"而产生优越感或恐惧感。
**死法：** 背景信息喧宾夺主，或角色对背景的无视不合逻辑。

### 叙述与呈现错位
说的是一件事，展示的是另一件事——旁白讲体面，画面全是狼狈；嘴上原谅，动作在收拾行李。
**编剧落笔：** 两层信息的缝隙就是潜台词，错位必须精确设计；本型可让旁白与画面产生距离；其他作品允许必要的同步解释，不作普遍禁令。
**递进方式：** 缝隙逐渐加大，直到某一刻两层彻底撕开（旁白说不下去了/画面终于和话一致了——一致反而成为最重的一拍）。
**死法：** 错位变成随意的不一致；旁白开始解释剧情（违反写作红线）。

## 五、尺度与语调类

### 尺度跳跃
在极大与极小之间跳跃——一场家庭争吵/切到外太空的地球/切回争吵。
**编剧落笔：** 跳跃的两端必须有语义关系（对照、讽刺、消解），不是炫技变焦；跳回来之后，原场景的意义必须已经改变。
**死法：** 跳出去又跳回来，什么都没变。

### 零度表达
灾难越大，语气越平。情感顶点用最克制的方式呈现。
**编剧落笔：** 删掉顶点处所有情绪化台词和动作，只留一个日常动作照常进行——照常本身成为最大的冲击（家里出了大事，她把菜炒完了，装盘，摆筷子）。
**何时用：** 任何格式的至暗时刻；黑色幽默的核心语调。
**死法：** 全片都零度（没有温差就没有冲击——零度只在观众期待爆发的位置才成立）。

### 规则限制叙事
给叙事加一条自我限制：全片单一空间、全程无对白、只有声音没有画面、全片一个视点。
**编剧落笔：** 限制是压力锅——正是"不能用常规手段"逼出非常规讲法。选限制时问：这个限制与主题是否同构（困在一个房间=困在一段关系；失去画面=失去看见彼此的能力）？列出限制下还剩的全部叙事资源，戏全部从这些资源里长。
**递进方式：** 限制在结尾可以被打破一次——打破的那一下就是全片最重的一拍（全片无对白，最后说了一个字）。
**死法：** 限制与主题无关（纯技术挑战）；中途偷偷违反限制。

# Part II：讲法原型启发库（按格式）

**用法（与导演风格库同构）：** 每个原型是一种被验证过的完整讲法范式。锚定作品是**质感参照系**，不是模仿对象——借它的机制，不借它的情节；"像某某那样"的第一反应方案照进反庸俗禁区。阶段1-2构思时翻阅寻找"这个故事有没有更锐利的讲法"；阶段3整形时按原型的"死法"逐条检查。原型可杂交（罗生门×伪纪录、循环×限制视角）。

## 长片讲法原型

### 原型F1：多视角罗生门型
锚定质感：《罗生门》《英雄》《最后的决斗》
- 机制：同一事件N个版本，每版本自洽且带讲述者的利益。
- 结构特征：版本排列即信息设计；版本间2-3处关键差异点是观众的对照锚。
- 适用信号：故事的核心是"真相取决于谁在讲"；一个事件、几个当事人、各有不可告人处。
- 编剧落笔：先写客观底稿再写变形；每个版本用该讲述者的语言质感写（用词、节奏都不同）。
- 死法：版本差异无立场含量；"真相版"让前面全部作废。

### 原型F2：逆时序 / 结果先行型
锚定质感：《记忆碎片》《不可撤销》《薄荷糖》
- 机制：从结局往回讲，每回溯一段，已看内容的含义被改写。
- 结构特征：段与段的咬合点（时间断口）是结构支柱；越往回越接近"还来得及"的时刻。
- 适用信号：主题是宿命、无法挽回、"怎么走到这一步"。
- 编剧落笔：先正序写完整时间线再倒排；每个断口留一个悬置元素供下段（时间上的前一段）解答。
- 死法：正着看信息量一样；断口切在随机处。

### 原型F3：网状群像型
锚定质感：《撞车》《通天塔》《疯狂的石头》
- 机制：多条线因一个事件/物件/巧合交织，线与线的碰撞点是结构支柱。
- 结构特征：先设计碰撞点时刻表，再往回铺各线；每条线独立成立、各有小弧光。
- 适用信号：主题需要横切一个社会截面；一个物件/事件天然会经过很多人的手。
- 编剧落笔：可先控制少量线索，4条只是规划参考；碰撞必须由各线自身的逻辑推出，不是编剧的手在推。
- 死法：碰撞靠硬巧合；某条线只为服务碰撞而存在。

### 原型F4：单一空间 / 实时型
锚定质感：《十二怒汉》《活埋》《狙击电话亭》
- 机制：空间或时间被锁死，限制即压力锅。
- 结构特征：信息只能通过有限渠道进入（一个电话、一扇门、一份文件），每次新信息进入就是一个结构节拍。
- 适用信号：核心冲突足够浓、人物足够少、赌注足够大。
- 编剧落笔：开工前列出空间的全部资源和信息渠道清单——戏全部从清单里长；人物的进出（如允许）要严格管制。
- 死法：靠回忆闪回逃出限制；空间资源用到一半开始重复。

### 原型F5：章节体
锚定质感：《低俗小说》《杀死比尔》
- 机制：分章讲述，章序不必线性，章与章的错位制造揭示。
- 结构特征：每章有独立小高潮和自己的语调；章标题参与叙事；章序设计=信息释放设计。
- 适用信号：故事天然分块（几组人物、几个阶段）；线性讲会平淡但错位讲会互相照亮。
- 编剧落笔：先线性排出全部事件，再实验章序——好的章序让某个普通场景因为位置而变得惊人。
- 死法：分章只是分段（没有错位收益）；章与章语调无差异。

### 原型F6：介入式叙述者型
锚定质感：《大佛普拉斯》《大空头》
- 机制：旁白或角色打破第四墙，叙述者的态度是第二层内容。
- 结构特征：旁白与画面错位即潜台词；叙述者对人物的态度（怜悯/嘲讽/无奈）给全片定调。
- 适用信号：题材沉重需要一层反讽的缓冲；或素材琐碎需要一个声音串起。
- 编剧落笔：旁白不解说画面，与画面互相拆台；旁白有自己的口头禅和盲区；在最重的一场戏让旁白沉默——沉默处即真心。
- 死法：旁白在解释剧情或总结主题（双重违反写作红线）。

### 原型F7：循环型
锚定质感：《土拨鼠之日》《恐怖游轮》
- 机制：时间循环，每轮消耗设定的一个新面向。
- 结构特征：轮次表（每轮变量+主角认知增量）是骨架；循环规则从头到尾稳定。
- 适用信号：主题是困境的重复、逃不出的模式、"重来一次会不会不同"。
- 编剧落笔：第一轮要完整且看似普通；破局方式必须在前面轮次中埋过。
- 死法：轮次只有量变；规则中途漂移；破局靠规则外的力量。

### 原型F8：伪纪录 / 拾得录像型
锚定质感：《中邪》《女巫布莱尔》
- 机制：假装是真实素材，信息缺损是资产。
- 结构特征：拍摄行为本身要有剧情理由（为什么一直有人在拍）；素材的断裂处让观众自行脑补最可怕的部分。
- 适用信号：低成本高沉浸的恐怖/悬疑；题材需要"真实感"背书。
- 编剧落笔：写剧本时同步写"拍摄者是谁、为什么拍、素材怎么留下来的"三个答案。
- 死法：机位出现在不可能有人拍的地方；素材过于完整流畅。

### 原型F9：双时空互文型
锚定质感：《你的名字。》《触不到的恋人》
- 机制：两个时空的角色互相影响，互文规则前置且稳定。
- 结构特征：两线节奏交替设计；规则的每次使用消耗一个新面向；交汇/错过的时刻是情感支点。
- 适用信号：主题是错过、连接、时间对情感的作用。
- 编剧落笔：规则优先由事件验证，必要时也可通过符合情境的解释传递（角色试错中让观众理解规则）；规则的限制比规则的能力更重要——不能做什么决定了戏在哪。
- 死法：规则随剧情需要变化；两线人物有一边不立。

### 原型F10：极简对话型
锚定质感：《爱在》三部曲《完美陌生人》
- 机制：对话即全部——事件密度极低，语义密度极高。
- 结构特征：话题的选择与回避即叙事；每次话题转移都是一次微型结构节拍；时间/空间的限制（一晚、一顿饭、一次散步）制造亲密和紧迫。
- 适用信号：核心是两三个人物之间的关系精确观察。
- 编剧落笔：对话模拟真实交谈（跑题、绕回、忽庄忽谐）；人物通过"聊什么、躲什么、在哪个话题多停了一秒"暴露内心；高潮是一句对了的话。
- 死法：对话变成观点交锋（图解式人物）；台词金句化。

## 剧集讲法原型

### 原型S1：双时间线互文
锚定质感：《漫长的季节》《真探》第一季
- 机制：过去的案与现在的人互相注释，答案在两线的缝隙里。
- 结构特征：两线各自有独立牵引力；切线点选在语义呼应处（同一个动作、同一句话跨时空出现）。
- 适用信号：罪案只是入口、真正要写的是时间对人的作用。
- 编剧落笔：过去线不是闪回是平行叙事——它有自己的完整戏剧结构；每集两线的比重有节奏地变化。
- 死法：一条线明显弱；切线沦为机械交替。

### 原型S2：单集形式实验
锚定质感：《9号秘事》《爱，死亡和机器人》
- 机制：单元剧框架下，每集换一种讲法——一镜到底集、无对白集、倒叙集、实时集。
- 适用信号：轨A单元剧；框架的可变维度包含"怎么讲"。
- 编剧落笔：形式应对该集信息或体验有具体作用（过形式检验）；一季的形式清单先行规划，避免后期重复。
- 死法：形式炫技与内容无关；观众开始预测"这集又要玩什么"。

### 原型S3：瓶装集
锚定质感：《绝命毒师》"Fly"一集
- 机制：一集锁死空间和人物，把多集积累的关系压力煮开。
- 适用信号：季中疲劳点；两个人物之间攒了很多没说的话。
- 编剧落笔：瓶装集的表面事件越小越好（抓一只苍蝇），真正的戏是压力的释放；本集必须消耗一个积累已久的秘密或情绪。
- 死法：没有积累就上瓶装集（没压力可煮）；表面事件抢戏。

### 原型S4：循环 / 规则集
锚定质感：《开端》《俄罗斯套娃》
- 机制：设定即牵引——每集/每轮消耗设定的一个新面向，一块新拼图。
- 编剧落笔：轮次表先于分集大纲；规则边界稳定；每轮的认知增量兼作集末钩。
- 死法：中段轮次注水（增量为零的轮）；结局靠规则外力量收场。

### 原型S5：视角轮换
锚定质感：《我们与恶的距离》《难以置信》
- 机制：每集或每段换一个视角看同一事件系统——加害者家属、受害者家属、辩护律师、媒体。
- 适用信号：题材是复杂社会事件，任何单一视角都是偏见。
- 编剧落笔：每个视角有自己的信息边界和盲区；视角之间的信息差本身制造悬念；观众最终拼出的全貌比任何角色知道的都多。
- 死法：视角轮换但语调不换（换汤不换药）；某个视角明显是"正确答案"。

### 原型S6：冷开场闪前
锚定质感：《绝命毒师》的粉色泰迪熊
- 机制：季首给未来的碎片画面（不可理解的结果），全季回答"怎么到那的"。
- 编剧落笔：闪前画面必须精确设计——足够怪但不剧透；每次重现多给一块碎片；真相到来时观众发现自己一直理解错了方向。
- 死法：闪前只是预告片式的悬念噱头，兑付时没有认知翻转。

### 原型S7：伪纪录剧
锚定质感：《办公室》《摩登家庭》
- 机制：角色知道镜头存在。采访位=人物内心的合法出口（不违反红线的"心理描写"通道）；看镜头的一眼=与观众的私下结盟。
- 适用信号：喜剧；人物的表里差是核心笑点来源。
- 编剧落笔：正戏与采访位互相拆台（正戏里嘴硬，采访位里露怯）；镜头的存在偶尔被剧情利用（躲镜头、抢镜头）。
- 死法：采访位沦为剧情解说；角色忘记镜头存在。

### 原型S8：实时 / 倒计时剧
锚定质感：《24》
- 机制：叙事时间=现实时间，时间表即结构。
- 编剧落笔：先排物理时间表（几点几分发生什么），戏往表里填；每集的钟表刻度天然是节拍器；"来不及"是永恒的压力源。
- 死法：为凑实时注水（角色在赶路的戏占一半）；时间流速偷偷作弊。

## 短片讲法原型

### 原型D1：精密反转机械
锚定质感：《调音师》（2010短片版）
- 机制：全片每个细节都为最后一击服务，一刷是故事、二刷是机关图。
- 编剧落笔：从结尾倒着设计；每个关键细节双义（一刷读表面义、二刷读机关义）；揭晓后只保留必要反应与余波，不硬规定一秒切黑。
- 死法：为反转牺牲过程的可看性（前面只是机关的铺设，本身不好看）。

### 原型D2：桌面 / 屏幕叙事
锚定质感：桌面电影语法（《网络谜踪》的短片化应用）
- 机制：屏幕即世界——输入又删除、已读不回、光标的犹豫都是戏。
- 编剧落笔：把全部戏剧动作翻译成界面行为；"打字-删除-重打"是屏幕叙事的潜台词三连；时间戳和电量是免费的时钟与压力条。
- 死法：屏幕只是取景框（内容与屏幕媒介无关）。

### 原型D3：一镜到底短片
锚定质感：一镜语法的短片应用
- 机制：不可逆的时间感；调度即剪辑——信息靠人物和视点的移动进出画面。
- 编剧落笔：写剧本时同步写"视点的行走路线"；每个空间转换点安排一次信息或情绪的换挡；结尾停在哪里=全片最后一句话。
- 死法：一镜只是技术挑战，切成普通剪辑毫无损失。

### 原型D4：静观型
锚定质感：小津式固定视点的短片化
- 机制：固定视点看一段生活，变化极小但不可逆。
- 编剧落笔：选一个"东西会自己经过"的视点（窗、门口、摊位）；在近乎重复的日常里埋一条单向的变化线（一个人的位置每天空一点）；结尾不解释，让缺席自己说话。
- 死法：静观变成静止（没有那条单向变化线）。

### 原型D5：双线并置短片
锚定质感：并置蒙太奇的短片形态
- 机制：两条线互照，交汇即翻转（Part I双线并置的整片化）。
- 编剧落笔：两线篇幅不必对等——一条主叙事线、一条切片线也成立；交汇点按信息与情绪需要安排。
- 死法：开头就被看穿关系。

### 原型D6：独白 / 伪访谈型
锚定质感：《听见她说》
- 机制：一个人对镜头说话，说的内容与说的方式错位——语言在体面，微表情和停顿在崩溃。
- 编剧落笔：独白文本要写两层（说出的话+话与话之间的裂缝）；道具和空间是第三个演员（她一边说一边卸妆）；打断独白的一次外部声音（门铃、电话）可以是结构转折。
- 死法：独白变成朗诵（只有第一层）；文本金句化。

## 超短片讲法原型

### 原型U1：界面 / 文档模拟系
- 机制：整片是一份文档、一串搜索、一个界面的演进（Part I形式模拟的整片化）。
- 编剧落笔：形式的最小单元（一条记录）对应故事的最小节拍；异常渗入的速率就是节奏；最后一条记录承担翻转。
- 死法：记录之间没有递进，只是罗列。

### 原型U2：递进崩塌系
- 机制：规则一级级升级，人们一级级适应，崩的可以是系统也可以是观众的认知（所有人已完全适应最荒诞的状态）。
- 编剧落笔：每级升级用同构的画面呈现（同机位、同构图，内容更荒诞）——同构放大荒诞；"适应"比"反抗"更恐怖，多写适应。
- 死法：升级是量变不是质变；结尾靠画外音点题。

### 原型U3：循环系
- 机制：起点即牢笼（Part I循环的超短片化——通常只走一轮半）。
- 编剧落笔：第二次起点保留足够理解时间；重复或变奏按本片作用选择。
- 死法：怕观众看不懂而加提示。

### 原型U4：伪广告 / 伪宣传系
- 机制：用最正经的商业语法（产品广告、招商片、宣传片）卖最荒诞的东西。
- 编剧落笔：严格遵守该广告类型的全部套路（金句、笑脸、价格闪现、免责声明）——套路越标准，内容越惊悚；免责声明的小字是翻转的黄金位置。
- 死法：广告语法学得不像（形式破功，荒诞就只是胡闹）。

### 原型U5：时间手术系
- 机制：压缩、拉伸、倒放的整片化——一生两分钟、一秒三分钟、一个街角一百年。
- 编剧落笔：先选不变的锚点（地点、物件或重复问话），再列每次重现改变的元素，如时间、人物年龄、物件磨损或回应。压缩时保留可辨认的变化；拉伸时增加这一瞬间的感知层次；倒序时先建正序因果表，再倒排呈现顺序。此句为维护补写，非恢复的作者原文。
- 死法：均匀切片流水账。

### 原型U6：数据可视化系

- 机制：用图表、数字、统计的冷语言讲一个滚烫的悲剧——数字越冷静，内容越震撼。
- 编剧落笔：数据的呈现顺序即叙事结构（从宏观数字逐级下钻到一个具体的人）；最后一个数据点必须落在一个可拍的具体画面上。
- 死法：全程停在数据层，没有落到人。

# Part III：选择与检验

## 适配速查

| 需求                       | 优先考虑                                                     |
| -------------------------- | ------------------------------------------------------------ |
| 概念超短片需要形式即内容   | U1-U6任一原型 / 形式模拟、循环、倒叙揭示                     |
| 短片结尾要punch            | D1精密反转 / 倒叙揭示、双线并置、不可靠叙述者                |
| 长片题材太熟需要陌生化     | F1罗生门、F5章节体、F6介入叙述者 / 视角置换                  |
| 长片局部段落要标记"不一样" | 时间压缩、尺度跳跃、伪纪录（只在特定段落用，全片用就不特别了） |
| 剧集某一集要出圈           | S2形式实验、S3瓶装集、S5视角轮换                             |
| 剧集季级悬念骨架           | S1双时间线、S4规则集、S6冷开场闪前                           |
| 高潮情感过满               | 零度表达                                                     |
| 题材沉重需要缓冲           | F6介入叙述者、伪纪录、零度表达                               |

## 最终检验（任何武器/原型交付前）

- [ ] 去掉这个讲法，用常规方式讲，冲击力是否丧失？（若没有具体作用，考虑简化形式；有帮助即可，不要求绝对不可替代）
- [ ] 讲法有没有递进设计？（内容递进、理解变化、变奏或打破均可，稳定形式也可成立）
- [ ] 讲法的规则从头到尾稳定吗？（中途违反=契约破裂）
- [ ] "这个题材+这个讲法"是不是第一反应组合？（是→进反庸俗禁区，再推一层）
- [ ] 用户要求导演交接时，是否另附讲法、视角信息边界与现行故事版本？未要求交接时不增加正文标签。
