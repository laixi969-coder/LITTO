# 一间房：可选骨架

当用户指定原系列的一间房形式，或选择用有限空间呈现“当下被改写”时参考。人数、空间和时长按用户要求；没有指定时可用两人一室形成集中的交锋。规则触发和后果以 [world.md](world.md) 为准。

可从下列步骤挑选或调整：一个日常举动触发规则；一方尝试利用或应对，另一方受到影响并反击；应对产生意外代价或暴露关系；人物调整策略并作出选择；用行动落到当前关系或处境。

场景冲突与转折按 [scenes.md](scenes.md) 检查：两人的诉求、具体阻力、尝试及局面变化应能在正文中看见。对方有自己的理由和策略，不只是规则的受害者或解说员。首尾同一物件、交出好处、外部广播和固定五步均是工具，不是必须；用户明确要求时保留。
