# 长片格式指南 v2

目录：Reference Language Scope；两个体量：院线长片 / 网大；序列发明（长片的核心工作）；类型库（按口碑作品锚定）；人物深挖件（长片级）；体检表（阶段3整形、阶段5医生使用）；Subplot、伏笔、暗线、世界观（阶段3规划，阶段5审计）；长片常见陷阱。

> 本版使用范围：本文件的结构比例、时点、次数、人数与集数均为可调整的开发启发，不是普适规律或市场数据。用户任务、既定事实与主文件工作模式优先；静态弧、群像、多事件、观察型按其组织方式检查。


## Reference Language Scope

遵循主文件与language-policy.md的语言范围和工作模式。中文例子是方法参照，不固定输出语言、闸门、次数或字符配额。

## 两个体量：院线长片 / 网大

|  | 院线长片 | 网大 / 平台电影 |
| --- | --- | --- |
| 时长 | 90-120分钟 | 60-75分钟 |
| 观看场景 | 买票入场，退出成本高 | 可随时退出，较早建立观看理由 |
| 结构耐心 | 建置长度随类型与兴趣维持方式确定 | 建置服务当前行动，时长由项目确定 |
| 成败核心 | 完整性与后劲 | 前置钩子 + 类型元素兑付率 |

### 网大子型规则

- **较早建立类型兴趣与观看承诺**（见 format-series.md 短剧思维）：开场直接进冲突或奇观，人物与设定溶解在事件里交代。
- **类型元素前置**：观众为哪个类型点进来，较早给予该类型的具体回报，时点按作品调整（喜剧要先笑、动作要先打、怪兽要先露一爪）。
- **节奏检查**：在实际停滞处增加有后果的行动或信息；没有项目数据，不声称6分钟、30分钟是固定流失位。
- **结构预算（70分钟参考）**：建置10分钟 / 发展前半20分钟（含中点相关段落）/ 发展后半20分钟 / 高潮15分钟 / 结局5分钟，总计70分钟。按具体作品调节后仍需核对总和，中点不另加时长。
- **压缩纪律**（从长本压网大时）：砍支线不砍主线层次；合并功能重复的角色；检查场景是否推进事件、关系、信息或体验；按核心承诺分配时间，不用统一两项配额。

## 序列发明（长片的核心工作）

**观众记住一部电影，靠的是段落，不是节拍。** "中点在第55分钟"没人记得，"浴室那场戏"所有人记得。长片"差点意思"的病根几乎总在这里：结构全对，但没有一个段落是有发明的。

### 规则

- 可从8—12个序列试排，每个包含若干场戏；数量随故事、类型和片长调整，有自己的小型"建立→冲突→结果"。
- **每个序列立项时必答：这一段的发明是什么？** ——一个观众没见过的情境、机制、玩法或画面。答不出的序列是"过场"，不能仅以发明数量判定段落存废，关系与体验的必要过渡也可成立。
- 序列之间的衔接借用集末钩逻辑：序列结果可自然引出下一次行动，也允许阶段性完成和余波。

### 发明的来源（构思序列时的内部工具）

- **处境极端化**：把一个日常处境的某个参数推到极限（谈判是日常，人质脖子上有炸弹倒计时的谈判是序列）。
- **规则碰撞**：让两套互不兼容的规则在同一场景运行（葬礼上必须完成的商业谈判）。
- **空间即戏**：一个自带限制或含义的空间决定这场戏怎么打（只能容一人通过的走廊、正在下沉的房间、隔音的玻璃两侧）。
- **道具机制**：一个物件带着自己的规则进入场景，所有人围绕它重新排布（一把只有一发子弹的枪在桌上）。
- **误会机器**：信息差被结构化——观众全知，场上每个人各知一部分，每句话在不同人耳中是不同意思。
- **反着演**：这类场景的常规演法是什么？取反（分手戏两人全程在笑；追杀戏杀手和目标不得不合作干一件小事）。

### 序列自检

- [ ] 说得出每个序列的发明吗？（一句话说不出=没有）
- [ ] 发明是否长在故事上？（换个故事这个发明照用=贴上去的炫技）
- [ ] 高潮序列的发明是否是全片最强的？（高潮不必是最大奇观；它应回应本片的主要行动、关系或情绪承诺）

## 类型库（按口碑作品锚定）

每个类型：观众来看什么（核心快感）、必备兑付（不给观众会骂）、常见死法、体检重点。类型确定后，阶段2的剧情创意就要保证核心快感的原料在故事里；阶段3整形时按"必备兑付"检查。

**1. 犯罪 / 黑色**（《杀人回忆》《白日焰火》《周处除三害》《烈日灼心》）
来看什么：真相的重量与人性深渊；调查者被案件本身改变。
必备兑付：调查递进链——每条线索真实改变方向；真相的代价——知道真相的人回不去了。
死法：为反转牺牲人物逻辑；凶手动机靠独白说教；黑色只是滤镜和雨夜、不在人心里。
体检重点：McKee鸿沟（每次以为接近真相，现实给出更深的落差）。

**2. 悬疑惊悚**（《看不见的客人》《误杀》《控方证人》）
来看什么：信息差游戏的智力快感。悬念的类型由"观众和角色谁知道更多"决定——观众多知是煎崖（炸弹在桌下），角色多知是谜题。
类型参考：可以使用使前文被重新理解的信息揭示；使用反转时要有前文证据，不强制每片反转。
死法：靠隐瞒关键信息作弊式反转；结尾用超长解释性闪回还账。
体检重点：把全片信息列成表——每条信息谁在何时知道；翻转后重放前文是否全部自洽。

**3. 荒诞 / 黑色喜剧**（《驴得水》《大佛普拉斯》《年会不能停！》《抓娃娃》）
来看什么：体面的崩塌、系统的自我打脸；笑着笑着不敢笑。
必备兑付：一台越描越黑的谎言/制度机器——每次补救让窟窿更大；笑点从人物处境里长出来，不是段子。
死法：段子拼盘；结尾强行温情收编（前面骂了一路的系统突然被原谅）；讽刺对象含糊。
体检重点：零度表达检验——最惨的时刻是否用了最平的语气；每个笑点删掉后情节是否受损（不受损=贴上去的段子）。

**4. 现实主义剧情**（《我不是药神》《隐入尘烟》《奇迹·笨小孩》）
来看什么：具体的人在具体系统里的挣扎；真实的质感本身就是内容。
必备兑付：行业/地域细节的可信度（这是生死线）；两难而非好坏对立——对面不是坏人，是另一种合理。
死法：苦难展览；议题贴纸（对照反庸俗清单第1条）；用一个善人解决系统性问题。
体检重点：偏移检验反向用——这个故事是否足够扎根，扎根到不需要任何设定帮忙。

**5. 家庭 / 亲情**（《步履不停》《饮食男女》《你好，李焕英》《乘船而去》）
来看什么：说不出口的爱与亏欠；饭桌上的战争。
必备兑付：日常仪式作为战场（做饭、过节、搬家、扫墓）；一次迟到的表达——迟到本身是痛点。
死法：催泪杠杆（绝症车祸失独按需取用）；和解来得太便宜；父母角色只有慈祥或只有严厉一种声调。
体检重点：潜台词浓度——这类片的台词表面content与真实含义的距离应是全类型最大的。

**6. 爱情**（《花束般的恋爱》《爱在》三部曲《前任3》）
来看什么：关系的精确观察——观众在里面认出自己那段。
必备兑付：具体到扎心的细节（歧义的聊天记录、逐渐分岔的口味、谁先睡着）；关系每个阶段的质感差异。
死法：误会驱动、巧合驱动；金句化台词（对照写作红线）；把"合不合适"简化成第三者。
体检重点：把两人的对话单独抽出来读——第一次约会和最后一次吃饭的说话方式必须能盲分。

**7. 动作 / 冒险**（《疾速追杀》系列《碟中谍》系列《怒火·重案》）
来看什么：动作段落的发明 + 身体的真实代价。
必备兑付：每个动作序列有独立创意（空间/规则/道具，见序列发明）；主角会疼、会累、会怕。
死法：动作场面无发明只堆量和预算；文戏沦为动作之间的填充物；主角无敌导致零悬念。
体检重点：列出全部动作序列，各自的发明一句话——有两个说不出就砍掉合并。

**8. 科幻**（《流浪地球2》《降临》《月球》《宇宙探索编辑部》）
来看什么：概念最终砸在一个具体的人身上的重量。
必备兑付：偏移型科幻集中推演关键规则；多设定科幻保持既定能力、限制与成本稳定。概念通过具体人物的行动和生活呈现。
死法：设定堆叠；世界观讲解替代故事；概念很大、落点没有人。
体检重点：偏移检验——拿掉科幻设定，人物的情感困境是否依然成立。

**9. 恐怖**（《遗传厄运》《咒》《中邪》）
来看什么：恐惧的形状——每个立得住的恐怖片核心都是一种真实焦虑的具象（家族宿命、失控、被窥视）。
必备兑付：恐惧规则的一致性（它什么条件下出现、能做什么不能做什么）；日常空间的污染——最熟悉的地方变得不对。
死法：Jump scare依赖；规则随剧情需要漂移；结尾把恐惧解释光。
体检重点：写出这部片的"恐惧规则表"并逐场检查有没有违例。

**10. 成长 / 青春**（《狗十三》《阳光灿烂的日子》《过春天》）
来看什么：世界第一次露出真面目的时刻。
必备兑付：一次不可逆的祛魅（一件事之后再也回不到之前的看法）；成人世界作为持续的背景压力而非台词。
死法：怀旧滤镜堆砌；青春疼痛套餐；用旁白总结成长（对照写作红线）。
体检重点：找出那个祛魅时刻——它必须是被拍出来的一场戏，不是被叙述的一个结论。

**11. 历史 / 时代**（《霸王别姬》《活着》《一秒钟》）
来看什么：时代碾过个人的具体方式。
必备兑付：大事件永远在画外或背景，前景是个人的一顿饭、一件衣、一场戏；时间跨度有结构方案（分段？锚点重复？一物贯穿？）。
死法：编年史流水账；人物成为时代传声筒；用字幕卡扛时间转场。
体检重点：每个时代节点是否都通过前景人物的具体损失/获得来呈现。

### 类型杂交（方法，不是类型）

（《寄生虫》《周处除三害》《宇宙探索编辑部》）

- **类型是承诺，杂交是惊喜。** 单一类型保证观众知道自己买了什么；杂交在承诺兑付的基础上给出没预期的东西。
- **换轨点设计**：前后半可以是不同类型（《寄生虫》喜剧→惊悚），换轨点本身必须是一场强戏，且换轨后前半的元素要在新类型下重新结账。
- **杂交检验**：两个类型是否共享同一个核心焦虑？共享 → 化学反应；不共享 → 缝合怪。
- 杂交方案照常过反庸俗层——"A类型+B类型"的第一反应组合往往也在公共池里。

## 人物深挖件（长片级）

以下是变化弧人物的可选诊断工具；静态弧、负向弧、群像与观察型不强制套用：

- **Ghost**（前史创伤）→ **Lie**（错误信念）→ **Flaw**（行为外化）。链条：Ghost → Lie → Flaw → Want（错误的追求）→ 考验 → 面对Need → 关键选择 → 新常态。
- Ghost不必完整展示，可以只通过反应暗示（从不在雨中站着的人）。
- **伪变化**：有些长片可使用一次“看起来变了又退回去”，角色不能在第30分钟就到达真相。
- **用法：** 诊断工具。在创意先行工作流里，这些层次应已在阶段2的故事叙述中显形——本节用来检查它们是否存在、是否自洽，缺了再回去补故事，不是先填这张表。

### 次要角色四功能

镜像（走了主角没走的那条路）/ 催化（推动变化的外力）/ 主题（具象化主题的某个立场）/ 节奏（喜剧relief）。每个有台词的角色至少一个功能，功能重复的角色合并；台词风格与主角可盲分。

## 体检表（阶段3整形、阶段5医生使用）

**声明：以下模板全部是诊断工具。禁止用它们生成故事。**

### 体检表A：Save the Cat 15节拍（商业类型片）

逐项对照（分钟数按100分钟等比缩放；网大按70分钟缩放）。每个功能位在结构对照表中单列一行：

```
第一幕（约25%）
1. Opening Image 开场画面——角色的"旧世界"，与Final Image对照。
   必须本身是一段精彩的视听内容：商业片用高密度场景同时展示
   角色能力/性格/世界规则；文艺片用风格化段落锚定全片气质。
2. Theme Stated 主题陈述（约5%处）——某个角色（通常非主角）无意间
   露出主题张力，主角此时未必接住；可以用动作或对白完成，不强制宣讲主题。
3. Set-Up 建置（前10%）——主角的日常、缺陷、世界；铺设后面会用到的
   所有人物关系；让观众开始关心主角。
4. Catalyst 催化剂（约12%处）——打破平衡的不可逆事件。
5. Debate 犹豫（12-25%）——要不要接受挑战？正是Lie让主角抗拒改变。

第二幕前半（约30%）
6. Break into Two（约25%处）——主角主动选择进入新世界，不是被推着走。
7. B Story——新关系线（爱情/友情/导师），承载主题论点。
   A线问"能否达成目标"，B线问"能否成长"。
8. Fun and Games（30-55%）——预告片段落。主角用旧方法应对新世界，
   有胜有败，整体轻快。
9. Midpoint 中点（约55%处）——A/B线交汇；伪胜利或伪失败；
   赌注从个人升级到更大层面。

第二幕后半（约30%）
10. Bad Guys Close In（55-75%）——内外压力同时收紧：外部阻碍升级，
    内部团队分裂/自我怀疑；Flaw开始产生真实代价。
11. All Is Lost（约75%处）——最低点，失去最重要的东西，"死亡气息"。
12. Dark Night of the Soul（75-85%）——主角自己在废墟中看到真相
    （不是被人点醒），弧光转变的临界点。

第三幕（约15%）
13. Break into Three（约85%处）——想通了：不是旧方法升级版，
    是全新方式；A/B线认知融合。
14. Finale 高潮——五步：集结→执行计划→计划失败（高塔惊魂）→
    挖掘内心（用新自我应对）→执行新计划。
15. Final Image 终场画面——与开场对照的"新常态"，不解释学到了什么。
```

诊断问法：哪个功能位缺失或偏弱？中点是否真的改变了赌注？至暗时刻是自己想通的还是被人点醒的（后者⚠️）？高潮是否包含"计划失败后靠新自我翻盘"？

### 体检表B：Story Circle 八步（成长/冒险/变形记）

```
1. YOU——角色在舒适区。建立常态（可以是痛苦但熟悉的状态）。
   开场要求同STC：常态展示本身必须精彩。
2. NEED——角色意识到（或被迫面对）自己缺什么。
3. GO——跨过阈值，不可逆地离开舒适区。
4. SEARCH——新环境试错。旧方法时灵时不灵。遇到盟友与阻碍。
5. FIND——得到想要的东西（对应中点），但"得到"自带代价。
6. TAKE——为所得付出代价。圆环底部，离舒适区最远，旧自我瓦解。
7. RETURN——（物理或心理上）回到起点，但旧舒适区已不再合身。
8. CHANGE——新常态。与Step 1同一个人、同一个地方、不同的状态。
```

诊断价值在对称性：3↔7（出发/回归）、4↔6（寻找/代价）。诊断问法：FIND得到的东西与TAKE付出的代价配吗？把RETURN时的角色放回YOU的场景，观众能看出区别吗？

### 体检表C：McKee（深度剧情片）

**适用限定：控制性理念仅用于明确立场型作品，其余按具体功能选用**（判定见 core-methodology.md的结构与信息部分）。开放问题型不强制通过第1项“控制性理念”检验，改用命题式体检（核心命题+翻面检查+余味检验+悬置纪律）；其余项目按作品类型适用，不要求每一场价值极性翻转。

```
1. 控制性理念——全片一句可论证的判断：[价值]+[原因]。
   它决定结局——结局是这句话的最终论证。
2. 价值转变——每场戏有一个核心价值（生/死、爱/恨、希望/绝望），
   检查场景是否改变事件、关系、知识或观众理解，也允许有意义的积累；不要求每场正负翻转。
3. 鸿沟——角色做A期望B却得到C。落差层层加深：每次角色以为
   自己学会了，下一个鸿沟比上一个更深更意外。
4. 激励事件——彻底打破生活平衡；创造全片核心问题，
   这个问题在结局前不能被回答。
5. 进展纠葛——冲突逐步升级，每次失败代价更大；外部困难和
   检查外部行动与内部关系是否相互影响；不以固定分钟数要求单调变难。
6. 危机选择——不可逆的真两难：两害相权或两善不可兼得。
   一边明显更好就不是危机。
7. 高潮——危机选择的行动化，不可逆。
8. 结局——新秩序，控制性理念获得证实或证伪。
```

诊断问法：控制性理念一句话写得出来吗？随机抽三场戏做价值转变检验；危机选择的两个选项是否真的都有分量？

### 体检表D：文艺片内在节拍 + 导演风格变体

内在节拍：常态与裂缝 → 扰动（无法继续假装正常的微妙瞬间）→ 游走与回避（间隙时刻展示角色在回避什么）→ 对峙（被迫面对）→ 选择或接受（文艺片高潮通常是"接受了什么"）→ 余震（结局是新的问题）。

风格变体（用于校准每一步的质感、留白比例和信息方式）：

- **是枝裕和式（日常流）**：情节藏在生活细节里；没有明确激励事件，裂缝靠日常积累渗出；对峙是平淡瞬间泄漏的情绪；结局落在一个极日常的动作上。
- **王家卫式（情绪流）**：场景以情绪而非因果连接；重复的母题制造时间质感；旁白与画面错位，缝隙即潜台词；没有传统高潮，情感饱和后安静收尾。
- **小津式（静物流）**：冲突来自代际间无法弥合的理解鸿沟；场景间的空镜制造沉淀；克制本身是最大的潜台词；结局是安静的"确实如此"。
- **Linklater式（对话流）**：对话就是故事本身；节奏模拟真实交谈（跑题、绕回、忽庄忽谐）；人物通过选择聊什么、回避什么暴露内心；高潮是一句对了的话。
- **奉俊昊式（类型杂交）**：商业结构骨架里塞社会批判与黑色幽默；空间即隐喻（上/下、里/外）；同一物件前半是喜剧道具后半是悲剧道具；结局是被讽刺覆盖的情感炸弹。

变体可混用（是枝的节奏+王家卫的旁白错位）。诊断问法：安静场景是否都在传递内心状态？变化是否由内部而非外部事件驱动？是否有统一母题贯穿？

### 通用体检三件套（按已选类型与弧光适用）

任何长片都过一遍（详见 core-methodology.md的结构与信息部分）：核心问题 / 不可逆节点 / 逐场价值转变。

## Subplot、伏笔、暗线、世界观（阶段3规划，阶段5审计）

### Subplot交织

- **A Plot（主线）**：主角的外在旅程。**B Plot（副线）**：通常是一段关系，承载主题论点，进展反映主角内心变化。**C Plot（可选）**：节奏调剂或主题的另一角度。
- 交织原则：A/B通过后果互相影响；交汇时点按故事决定。群像可有自身结果的支线，但应与全片组织有关，避免无关填充。

### 伏笔与回扣

四个层次：**道具伏笔**（日常物件后段变关键）/ **台词伏笔**（闲话后段获得新含义）/ **行为伏笔**（习惯动作暗示Ghost）/ **结构伏笔**（看似无关的场景后段被证明是关键信息）。

规则：首次出现必须有合理的表面理由；承诺解决情节问题的伏笔必须有回扣，余味或开放问题可以保留，但须记录有意保留的理由；回扣要改变观众对前文的理解；按故事需要安排，不强制3—5对或层次配额。

**伏笔登记表（阶段3填写，阶段5逐条核销）：**

```
伏笔内容 | 层次 | 首次出现位置 | 回扣位置 | 回扣如何改变含义 | 已回扣？
---------|------|------------|---------|----------------|--------
```

### 暗线

观众一刷注意不到、二刷发现"从一开始就在铺"的线。设计方法：先定终点（浮出水面时揭示什么）→ 反推需要多少暗示 → 每个暗示都有表面含义（一刷读表面，二刷读暗线）→ 浮出时机通常在高潮或结局段。可先控制少量暗线，数量由理解负担与篇幅决定。

### 世界观分层（世界观有复杂度时）

```
表层规则（前30%展示）——这个世界的基本运行方式。
运行逻辑（第二幕展示）——为什么世界是这样的。通常通过角色深入
  探索或B线角色的视角揭示。
底层真相（高潮段揭示）——世界真正的面目。如有这个揭示，应实际影响理解或行动，不强制全世界观都藏有反转。
```

每层的揭示通过角色的行动和发现自然呈现——避免脱离行动的设定讲课，必要解释遵循核心方法；用户选定旁白、字幕或界面叙事时，它们可以承担信息，但必须符合人物声音、视角边界和该形式的规则。阶段3做一份信息释放时间表：哪一层在哪个段落、通过什么事件揭示。

## 长片常见陷阱

- ❌ 结构全对但没有一个序列有发明 → 这就是"差点意思"，回序列发明节
- ❌ 第二幕松垮 → 关键转折应有实际后果；时点与数量按故事判断
- ❌ 弧光太线性 → 如采用伪变化，需有动机与后果；不强制所有弧光回退
- ❌ 高潮只是更大的打斗 → 高潮回应主要承诺，不强制最大奇观
- ❌ 类型承诺不兑付（喜剧前20分钟没笑点）→ 按类型库"必备兑付"检查
- ❌ 网大用院线节奏 → 适应可退出观看环境，较早建立兴趣；不硬套6分钟
- ❌ 世界观一次性倾倒 → 分层释放；必要说明参与行动与判断，不作脱离处境的讲课
- ❌ 伏笔埋了忘收 → 连续性档案逐条审计
- ❌ 两个高情感场景之间没有呼吸 → 双轨节奏检查
