# 剧本写作与故事改编

用户直接要求剧本时，直接写剧本；用户要求拆解已有故事时，以该故事为依据，保留重要事件、角色关系、设定和结局。可补足实现既有情节所需的可见行动、必要衔接与自然对白，不擅自创造改变原情节的事件。若原文存在妨碍改编的关键缺口，说明采用的最小假设或按用户允许的范围补足。

## 改编依据与取舍

读取本次约定范围的原文，沿用已确认的人物、事实、时长与改编幅度。长材料记录实际读到的位置和未读范围；补细节时用人物、物件与具体事件定位，再回读对应段落，不凭摘要或后文片段改写当前人物所知。原文无法取得时说明限制，不宣称完成忠实度核验。

先辨认关键段落在原作中承担什么：促成哪次选择、建立哪条关系、提供哪项行动条件，或安排谁先知道什么。简单故事在上下文核对即可；复杂改编复用现有资料位置、场次、canon/threads 与简报记录对应关系及实质删改，不新建必填台账。人物的立场、动机、做事方式和结局含义也属于保留范围，不能只保留姓名与事件外壳。

压缩或删段前，反查后文是否仍依赖其中的信任依据、线索来源、道具交接、能力或权限；依赖仍在，就把必要条件落实到保留场面，不能让结果无缘无故成立。合并人物时检查双方原有的秘密、立场、关系与同时行动是否兼容，避免合并后人物自己瞒自己，或支持者变成施压者。重排事件时区分真实发生顺序与观众看到的顺序，核对前因、时间定位及原位置是否重复兑现。上述调整均服从已授权范围；会改变锁定事实的取舍另行说明，不以补衔接为由悄悄改写。

## 把叙述写成戏

按用户指定格式呈现；没有格式要求时，以场景标题交代地点和时间，用能拍到或听到的行动、对白和必要声音构成戏。每个独立戏剧场景依据 [scenes.md](scenes.md) 检查冲突与转折。无对白可以不写对白；不为镜头号、设备、生成提示词或场记格式添加用户未要求的内容。

心理变化从它引发的下一次行为反推：人物如何改变策略、交出决定权、拒绝原先的安排或重新对待另一人。用场内已有条件写出触发、选择与回应，不把“想通了”统一换成攥拳、望窗或摸旧物，也不为外化一句心理凭空新增资金、证据或帮手。画面能够承担的信息落到行动；言行反差、跨时认知或用户指定的主观表达可保留必要旁白，不机械删成沉默。

## 对照原文与成稿

拆稿后先从原文查剧本：重要事件、关系、关键选择及结尾是否有实际承载，压缩后是否仍能理解行动条件与信息顺序；再从剧本查原文：新增的事件、关系、资源和解局办法来自哪里，是否属于已授权补充。发现偏离时同时指出来源位置与剧本场次或原句；来源未读或含糊时标为待核对，不把模型推断当作原著事实。

最后连读受修改影响的前因与后果，核对人物所知、时空、持物和场尾状态是否接续；不能只检查相邻一句，也不能因为原文已有一句概述，就假设观众能从画面中理解。每场的转折须在正文中实际发生，字段、映射与审稿通过都不代替戏剧效果。以上是内部写作与审读方法，不默认交检查表或增加确认轮次。
