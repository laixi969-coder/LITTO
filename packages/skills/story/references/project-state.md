# 项目接入、状态与变更边界

## 从已有材料进入

| 用户材料／请求 | 当前动作 |
| --- | --- |
| 从零找方向 | 新项目默认配置后进入素材／选题 |
| 已选方向 | 进入剧情创意，不重选 |
| 已确认剧情创意／结尾 | 进入用户要求的人物、结构或场景工序 |
| 已有大纲／分集纲 | 对照已定事实进入指定场／集 |
| 已有正文，指定局部修改 | 只改指定范围，必要时读相邻场景 |
| 只要诊断 | 给原文位置、问题、影响与修改建议，不自动重写 |
| 跨会话续写 | 先读取现行状态和必要稿件，接上已记录下一步 |
| 明确短剧速产 | 按速产和用户指定输出项工作 |

缺失信息只补当前任务必需的部分。没有上下文的续写只请求最后一段或现行状态，不声称记得未提供的决定。

## 状态记录

持续项目使用 assets/project-state.md 的简明模板；支持文件时保存到用户项目目录，不写入 Skill 安装目录。无文件能力时输出同等信息的摘要。单次小改只记录本次改动，无需空填整份模板。

每个事实标来源：用户明确给定／稿件已经写出／参考事实／AI 提议／待核实假设。提议、默认值和推测不能写成用户已确认。字段展示可按交互语言本地化，稳定 ID 与内部状态值保持不变。

状态包含项目配置、模式与开关、当前阶段、锁定决策、世界规则、时间线、角色状态与知情、道具、伏笔、现行稿件版本、修改日志和下一步。只写当前相关的记录，不强迫用户逐项填表。

## 修改分级与同步

- **局部修整**：语句、动作、节奏或衔接变化不改变锁定事实，可直接处理并记录。
- **方向性变更**：改变主角、目标、核心关系、世界规则、讲法或结尾等锁定项，交付具体前后方案、因果理由、影响位置，等待该项决定。用户明确授权改变此项时执行；结合既有授权和当前任务判断；用户已明确允许重构时连续执行，不重复索取授权。
- **受影响稿件**：确认变更后同步剧情创意、结构、场景、正文与档案；尚未同步的版本标“待同步”，旧稿保留版本号，不并列当现行稿。

无人物、静态弧、回归常态或非传统高潮等类型例外记录为“不适用＋原因”。通用检查为故事服务，不以补表为由改作品。

## 更新与恢复

第一个已确认决策即开始记录；每序列／每集或影响后文的修改后更新。恢复先看项目、阶段、锁定决策、现行版本和下一步，再读本次必要的角色、规则与稿件。

已回收伏笔转为简明索引：保留埋设／回收位置及已经发生的结果。已死亡、已损坏、已揭晓等事实继续约束后续，不能随清理活跃清单消失。

## 类型与结构适配

- 有变化弧的角色检查正向或负向变化；静态弧检查立场经受压力并产生结果；情景喜剧检查单集事件解决与必要的跨集痕迹。
- 无人物概念片检查物件、规则后果或观众理解的递进，不强加 Want/Need 和 Ghost。
- 现实偏移型通常聚焦单一偏移；用户指定的幻想作品检查既定体系的一致性，不以现实世界作为设定上限。
- 各段估算必须加总；实测朗读、预演或成片时长另记来源。文字预算与媒体实测是不同记录。
