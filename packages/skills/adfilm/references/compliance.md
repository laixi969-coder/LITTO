# 广告合规清单（写作提醒）

这是帮助写作时避坑的清单，不是法律意见。正式投放以平台审核和法务意见为准。发现命中项时：列出原句、说明原因、给 1–2 个替代写法，由用户决定。

## 1. 绝对化与极限用语

避免：最、第一、唯一、首个、首选、顶级、极致、至尊、国家级、世界级、全网/全国第一、史无前例、永久、万能、100%、绝对、完美、无与伦比。

替代思路：改成可验证的事实或具体描述。
- 「最好用的保温杯」→「保温 12 小时的保温杯」（需要用户提供测试依据）
- 「行业第一」→ 删除，或写有来源的具体数据并标注来源与时间。

## 2. 功效与承诺

- **医疗与保健**：不暗示治疗、治愈、预防疾病，不使用「根治、特效、无副作用」。普通商品不涉及医疗功效。
- **化妆品与护肤**：不承诺改变皮肤结构或「永久」效果；描述使用感受而不是医学结论。
- **金融**：不保证收益、不使用「稳赚、保本、零风险」，不暗示无风险。
- **食品**：不夸大营养功效，不使用「治病、降三高」类表述。
- **教育培训**：不承诺通过率、录取、提分幅度。

## 3. 数据、对比与证明

- 不虚构数据、销量、排名、认证、实验结果、用户评价。
- 用户提供了数据：标明来源与时间，请其确认可公开；没有来源就不写具体数字。
- 对比广告：不贬低竞品、不点名；比较需有可公开的依据。
- 「用户好评」「专家推荐」需要真实来源，不由你编造台词冒充。

## 4. 人物、代言与素材

- 不使用明星、公众人物肖像或相似度极高的形象，除非用户有授权。
- 不使用影视角色、动漫形象、他人商标；音乐、字体、素材需要有授权。
- 出现儿童的画面、医疗人员形象、专家形象，谨慎处理，需要用户确认授权与合规。
- 涉及特殊品类（药品、保健食品、医疗器械、酒类、烟草、金融投资等）必须提醒用户这类广告有专门规定与审核。

## 5. 检查流程

1. 通读脚本、字幕、口播、画面中出现的文字与数字。
2. 对每一条，判断是否属于：绝对化用语 / 功效承诺 / 无来源数据 / 未授权人物或素材。
3. 命中则列出，附替代写法；没有命中的不做无依据的指责。
4. 记录处理结果在文本节点中，随脚本一起交付。
