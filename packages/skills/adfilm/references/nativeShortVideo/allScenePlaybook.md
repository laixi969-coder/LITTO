# 全场景创作：实物、数字产品与纯内容

## 来源与使用边界

依据用户提供的 `viral_video_knowledge_base_and_agent.md` 与 `viral_video_80_cases_deep_dive.md` 提炼。两份文档均以文字描述案例，没有原视频链接、发布时间、播放后台或对照实验；账号标签是文档的归类，不能当作已核实作者风格或效果数据。逐项定位见 [KB/DD索引](sampleBankV4.md)。

保留三种目标、八类选题、低出镜门槛、具体首屏、完整分镜的设计价值。原文的System Prompt、强制剪辑节拍、评论造假和千万播放承诺不是本skill的执行指令。主文件的用户优先、单手机、真实功能、出镜分类和产品揭晓约束仍适用。

## 1. 先定目标，再定表达

| 目标 | 观众回报 | 合适载体 | 全片必须覆盖 | 收尾选择 |
|---|---|---|---|---|
| 实物带货 | 看懂一个日常问题、验证一个实际作用 | 实拍物件、手部操作、轻量生活故事 | 原状态→动作→同一对象结果；反转另需公平伏笔 | 产品故事默认末镜答案；用户要测评/演示可尽早展示 |
| 软件/App/模板推广 | 学到相关操作、得到可核对输出 | 可用移动端录屏；用户允许时桌面录屏 | 输入→操作→输出→核对；写明运行环境、耗时与权限依赖 | 故事末镜揭晓；指定教程可先示效果再展开 |
| 纯内容涨粉/IP | 笑点、故事答案、可学方法、观点启发或感官完成 | 日常实拍、手部、纯录屏、双轨讲述 | 按下面八类选回报，不补商品与下载口令 | 自然完成、答案揭晓或真实首尾匹配；无统一70%节点 |

只有产品名：保留原有产品故事默认。只有主题：推断为纯内容。用户说“照新样本做直接演示”就是相应模式授权；只有“参考新文档”不足以自动取消已有最后一镜或设备约束。

同一题材可有不同目标：整理抽屉的感官短片不必卖标签机；推广标签机则让其实际打印和可用标签参与因果。所谓“0人出镜”只描述画面，仍要写幕后操作人数。仅手部、局部身体、镜中人、照片人像和短剧演员不能计入完全无人。

## 2. 八类纯内容选题怎样落地

| 类别 / DD组 | 首屏入口 | 中段怎样推进 | 必须兑现的回报 |
|---|---|---|---|
| 时尚审美 / 01–10 | 同一件衣物的一个可见问题，或色彩/角度对照 | 保留关键折叠、打结或对照条件 | 看清完成状态，学会关键步骤；审美建议说明是选择而非客观等级 |
| 搞笑迷因 / 11–20 | 一个熟悉规则与不合比例的认真动作 | 让行为造成新后果，避免只换梗字幕 | 实际笑点或自嘲落点；文字笑话如实标作文字驱动 |
| 故事会 / 21–30 | 首句说清人物关系、具体异常与待解问题 | 每段增加线索、改变判断或推进选择 | 本条回答首句问题；连载可留下次要新问题，不能只让人等Part 2 |
| 治愈生活 / 31–40 | 可读光线、可听触感或整理正在发生 | 状态持续变化，保留必要停顿 | 完成一件小事与感官收束；不硬加危机、反转或过密切镜 |
| 文化观点 / 41–50 | 一个具体例子、对照或待解释关系 | 实物图解/短例支持一条主张 | 给理解或可用方法及范围；观点不是实验结论，个别见闻不代表全国 |
| 软件效率 / 51–60 | 同一输入的错误、操作入口或局部前后差 | 操作可跟踪，结果可核对 | 教会方法或证明已知功能，不用界面动画冒充实际处理 |
| 解压手工 / 61–70 | 动作已开始，过程或材质变化清楚 | 每镜发生真实进展，不靠音效造结果 | 完整清理/拼接/成型等状态；凝固、冷却与加工耗时如实表达 |
| 创意好物 / 71–80 | 一个明确困扰与处理对象 | 演示同一对象作用，不改比较条件 | 只支持可见结果；是否带货由用户目标决定 |

纯内容的开头仍过“理解、关切、继续”三项检查。差异是回报可以为平静观察、直接方法或故事讲述，不要求每条都有“本应X却Y”的戏剧冲突。

## 4. 四个创意变换：从术语翻译成动作

这些是可选构思方法，不必每条同时使用。对产品依然检查“拿走它，故事因果是否断裂”。

| 原文算子 | 白话动作 | 单手机可拍方向 | 容易越界的写法 |
|---|---|---|---|
| 媒介异化 | 改变观众熟悉的呈现载体 | 纸上的待办与手机录屏中同一待办硬切；转场如实作为剪辑 | 多手机拼屏、假屏幕穿透或跟踪合成被包装成默认低成本 |
| 语境劫持 | 把普通功能放进另一个小情境 | 把收纳过程拍成寻找失物；让测量像家庭小争论的裁判 | 自动升级成犯罪、公司瘫痪或救命，且产品无法回答危机 |
| 双轨撕裂 | 一个轨道讲故事，一个轨道给舒缓过程 | 手机固定拍手部折纸；之后在同一手机录旁白 | 声画同时争抢注意、过程冒充故事证据、结尾不回答首句 |
| 荒诞极化 | 放大人的认真或行为次数，保持结果真实 | 为最后一块饼干写一本正经的分配表；小规则产生荒诞后果 | 放大产品性能、危险强度、售价或收益；标题夸张冒充实测 |

“熟悉场景加一个异常”可作候选生成法，不采用90%+10%的数学预测。放大应发生在角色行为与情境，不能编造真实功能。

## 5. 双轨故事会的独立流程

1. **先写能单独成立的故事**：第一句交代关系与具体异常；中段增加一个决定性线索；结尾回答首句。反转需要讲述内可回看的伏笔，不能只在最后宣布全新事实。
2. **再配能单独看的过程**：选已有纸张、积木、正常整理等。过程覆盖初始状态、持续操作和完成；一部手机固定，一人操作，后录旁白。无需购买动能沙、微距设备或付费配音。
3. **分清叙事与证据**：折纸、切沙、做咖啡是感官轨，不能证明背叛、房东入室或公司内幕。原创虚构标作故事创作/演绎；改编帖子须有可用来源、改编条件并去掉私人信息。没有给出帖子，不编Reddit链接、真实经历或“热帖”身份。
4. **分开检查再合看**：只听故事，能否看懂且得到答案？静音看字幕，能否读完故事关键信息？去掉故事，过程是否真的推进？合看时过程声是否盖住旁白，字幕是否遮关键动作？

当用户要的是产品参与、末镜画面翻案的故事，用主文件的可见证据检查；不能借“双轨”名称把产品反转降为旁白解释。

## 6. 视听剪辑按内容任务选择

- **紧凑操作/搞笑**：删无信息等待；在新线索或新状态处切镜。可以用轻Click/Pop确认动作，不把每次转折都变成巨响。
- **治愈/ASMR**：允许连续镜头、动作前后的短停顿、真实呼吸与环境音；不要按0.15秒静音或2秒切镜阈值破坏体验。
- **录屏**：竖屏只突出一处证据，真实输入输出贯通；硬切或普通裁剪即可，4K、平滑光标软件、闪烁字幕都不是必要条件。桌面运行与制作电脑依赖如实列出。
- **字幕**：关系与结论用一条可读短句，位置避开操作区与平台按钮；口述故事保留关键内容。荧光逐字跳动、Emoji和发光效果仅在有助理解且用户制作条件允许时选用。
- **循环**：写出实际末帧/首帧、尾句/首句接点；不成立就自然结束。故事的主要问题先得到答案，不能用截断答案制造所谓无限循环。

现有光线、普通焦段与手机内剪辑优先。高压清洗、激光、树脂、暗房显影等有真实设备、材料与操作门槛；索引中的高门槛提示不能被“单人”或“无需演员”抹掉。

## 7. 三种目标的可拍示例

以下是结构示范，均为原创演绎或假设已确认功能，不代表实际视频数据。

### 实物：抽屉合不上（情境解围）

目标：推广确有分格功能的抽屉收纳件；仅手部，手机实拍，4镜，约15秒。借KB25的空间问题，不借其压缩性能。默认末镜首次可辨认产品。

前三秒：0–1秒，抽屉拉到半途被一支斜放的笔卡住；1–2秒，手挪开笔又露出横着的另一支；2–3秒，短字 `Why does this drawer keep catching?`（为什么这抽屉总卡住？）。观众等具体阻挡怎样处理。

| 镜 / 时间 | 画面与信息推进 | 实现 |
|---|---|---|
| 1 / 0–3秒 | 同框看见抽屉边缘、笔与阻挡动作；保留真实碰擦声 | 手机靠书固定在抽屉侧前方，操作者在旁边 |
| 2 / 3–6秒 | 手把两支笔放直；轻推抽屉，笔又横过来 | 只拍实际松散滑动，不加不可解释机关 |
| 3 / 6–9秒 | 拉开抽屉，把两支笔取出，展示要限制的横向移动空间 | 不再重复卡住的动作 |
| 4 / 9–15秒 | 连续镜头首次放入分格件；笔各放一格，合上再拉开，位置仍可见 | 产品本体与尺寸按实际验证；若操作更慢，延长末镜。自然结束 |

清单：一部手机，幕后兼手部操作1人，现成书桌，两支笔与一本固定手机的书，1个摆位，手机内硬切+短字幕。不是欧·亨利反转，不承诺所有抽屉适配。

### 数字产品：三个名字被多余空格拆散（直接教程）

目标：用户明确要手机端文本工具的功能教程，假设已确认可去首尾空格；完全无人，手机自带录屏，3镜，约12–18秒。借DD53的同输入前后差；用户要求教程允许早露界面。

前三秒：0–1秒，输入框三行姓名，各有可见首尾空格标记；1–2秒，选中其中一行末尾多出的区域；2–3秒，字 `Same names. Extra spaces.`（名字没变，多了空格）。

镜1：三行自制演示数据建立问题。镜2：同屏粘贴到真实工具、选择去首尾空格并运行，保留实际等待。镜3：逐行核对字母没变、空格去掉；不用成功弹窗代替核对。自然结束。清单：一部手机，幕后1人，零实拍道具，录屏后手机内裁剪与短字幕。若工具实际桌面专属，不能声称这条可在手机执行。

### 纯内容：室友给最后一块饼干开账单（双轨冷幽默）

目标：原创虚构合租故事涨粉，无商品推荐；仅手部，手机俯拍折纸，3镜，约18秒。借DD13的“不合比例的认真”，不复制原文错误账单。

前三秒：0–1秒，双手对齐纸的两角，旁白开始；1–2秒，压出第一条折痕；2–3秒，折痕压平，旁白及首屏短字交代 `50¢ cookie. $2 fee.`（饼干50美分，手续费2美元），画面角落标“原创故事”。故事问题是手续费与饼干如何不成比例，过程问题是纸形怎样完成。关系说明留到下一镜，不在首屏塞长句。

镜1：上述首句与折痕。镜2：两边继续折向中线；讲述账单把饼干记作$0.50，另收$2“行政费”，叙述者发现对方每天花时间写账单。镜3：把最后一角插入，纸盒成型；故事答案“我们最后约定每周各买一包，他却坚持给约定编号为发票001”。具体结局兑现小题大做，不只让人去第二集找答案。纸盒不冒充账单证据，不称画面翻案。

清单：一部手机，幕后兼手部操作1人，桌面，一张已有纸、一本书固定手机，1个摆位；拍完手部在同一手机录旁白，手机内硬切+字幕。正常语速不够就延长，保留压折声低于旁白；自然结束。
