# 反转质量判定

用于产品故事及用户明确要求的欧·亨利式反转，不套用到教程、治愈、ASMR。规则能筛掉明显失效的结构，不保证观众必然惊讶或平台效果。

## 两种不同的答案

- 原因揭秘：“袋子湿了，因为冷饮冷凝”“数口数，因为等对方碰杯”。开头事实仍成立，结尾只是把问号填上。
- 判断翻案：观众把某人当作被偷者，结尾连续动作证明他拿走的是别人的东西；先前护食因此变成抢食。必须在实际脚本中给出归属证据，不能仅写这个结论。

“以为坏人，其实善良”不是自动不合格，但不能用善意动机替代矛盾证据。给整罐而收走空杯、等待一起开罐等熟悉答案，不能贴上欧亨利标签交付给要求强意外的用户。

## 四个实际检查

1. 截断在3秒：写下已经发生的损失、阻挡或相互矛盾的动作，以及观众自然形成的判断。没有可见冲突就先修开头。
2. 遮住解释语看末镜：列出哪个镜头事实使原判断不可能继续成立。只有新品亮相、台词宣布身份、纸条补规则、镜外背景故事，都不充分。
3. 回看伏笔：标出具体镜号、可辨识细节及两种解释。结尾第一次才出现的决定性规则不算伏笔。别靠角色为了镜头不合理地不看、不说或不行动。
4. 比较整组：归属翻转、责任倒置、胜负反噬等可拉开方向，但按实际因果去重，不按标题或人物去重。静态谜底、原因说明和功能演示不能补足强反转数量。

## 已收到的失败反馈

| 被否定方案 | 为什么未达到本次要求 |
|---|---|
| 数吃饭口数，最后一起开罐 | 控制动作没有被反证，只补充了等待理由；结尾易预测 |
| 拿走两个空杯，最后给对方整罐 | 常见的先抑后扬，赠饮没有足够强的认知翻转 |
| 纸袋湿，最后出现冷饮 | 物理原因解答，不是角色、事件或结果的翻案 |

这些方案可作普通日常小片或原因揭秘，不能作为“强反转已通过”的示范。历史回归中的格式、露出和拍法合格，不等于意外程度合格；记录两者，不用通过总数抹掉用户的质量反馈。
