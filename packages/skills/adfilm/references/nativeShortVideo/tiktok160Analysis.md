# 新版 tiktok.docx：160 条文字样本分析与 v3.2 更新依据

## 1. 材料范围与证据等级

本次分析对象为用户新提供的 `tiktok.docx`，SHA-256：`0e1b2a4f962247be8c5d39027054181a8aa2606363c222ca82f0186b4837dfb1`。正文含 2383 个 XML 段落节点（含空段），三组编号各自重置：KOC 30 条、数字工具与 Faceless 50 条、实体商品 80 条，共 **160 条文本方案**。文档无嵌入媒体、无外部超链接关系；其中账号名、播放量与“真实爆款”是来源自述，本次未核验。没有原视频供逐帧检验，也没有后台数据支持留存结论。

这份文件替换了上一份同名、90 条案例的文件；不是在原文件尾部增加 160 条，也不应相加宣称“250 条独立爆款”。旧分析与 A/B 编号保留为历史材料，新索引用 K/D/P 避免歧义。部分商品和结构重复，160 不代表去重后的产品数或创意机制数。

分析中分三层：**原文观察**（文档怎样写）、**案头判断**（结构和因果是否成立）、**新增方法**（为改善输出制定的创作规则）。后两层不冒充平台研究或实测。逐条取舍见 [160 条索引](sampleBankV3.md)。

## 3. 前三秒：真正新增的是证据，不是更大声

原文几乎统一列出第一帧、顶部文字、音效、停留机理。这种拆分有用，但“根本不可能划走”“阻止90%”没有数据支持。创作可保留四个通道，评价仍回到一个具体问题。

**可用结构：可读证据 → 眼前利害 → 待揭晓的结果。**

- **临界状态**：K12 的时钟、P09 的导出进度与电量，把“马上发生”放在画面里。借其临界关系，不复制强行断电或虚构损失金额。
- **同一对象的矛盾**：D13 的现价与历史价，必须同一规格、渠道、时间口径。若两张表不是同一对象，冲突只是剪辑制造。
- **输入输出落差**：D02 的粗略输入与精细输出，吸引点是转化过程；要给观众看出对应关系，不能直接换成无关成品。
- **反复发生的小麻烦**：P64 清理梳子比梳毛更费事，比先拍手指流血更贴近实际使用。一个被卡住的毛团足以表达问题。
- **来源未明的结果**：P20 床下亮点可误认，揭晓必须在同一空间出现；不允许结尾空降另一个对象。

0–1 / 1–2 / 2–3 秒是注意力节拍，不是三次切镜配额。录屏可固定一个窗口：先看到错误，再看到受影响的一行，最后光标停在可疑差异上。可读性优先于塞满动作；三秒同时读长聊天、长字幕和小数字，案头再刺激也拍不成立。

**声音的作用**是确认动作、制造节奏或提示临界点。声音作为主要线索时，要有对应的可见反应、指示灯或波形。关闭声音后允许短文字补关系，但不能让异常彻底消失。

## 4. 中段需要增加信息，而不是继续着急

原文经常把 3–13 秒写成重复失败、尖叫、准备赔钱，随后工具一次解决。这只是在推迟结果。更新后，每个中段镜头必须至少完成一项：

1. 加深一个有根据的误判；
2. 展示已有办法为什么在当前条件下不够用；
3. 增加可回看的公平伏笔；
4. 让相同任务进入可见的新状态。

例如软件稿：文件无法导入 → 找到被标记的那一行 → 看似删掉重要字符 → 导入成功后确认数值未变。每一步在回答同一问题。若写成“老板再次催促—主角更慌—倒计时更大”，删到一个镜头即可。

不能先制造无法兑现的承诺：开头说“原漆磨穿”，清洁剂只能去掉附着物；开头说“重量超标”，压缩体积没有回答重量问题；开头说“龋齿”，冲出食物残渣没有回答疾病问题。P12、P19、P39 是对应反例，迁移前应重建问题本身。

## 5. 拆开三个常被混淆的时刻

**商品/界面第一次出现、功能或身份被解释、商业意图变明显**，是三个不同事件。

- P33 的卷发带、P54 的塑身衣，首镜已出现商品；没有品牌大字也不是零产品。
- D01 若中途展示特定生成器，其界面可能已经可辨认；把 Logo 裁掉不必然隐藏产品。
- P46 书形收纳盒可以外观早露、用途晚揭，但只能在用户允许该模式时用，不能偷偷突破最后一镜要求。

保留本 skill 的默认“最后一镜首次可辨认”。软件若难以兼容，就用通用任务文件、错误状态或输出证据建立前段，最后连续镜头揭示实际工具。若仍然看不懂，改故事；只有用户允许演示或提前露出时切换模式。不要为藏产品连问题都藏起来。

## 6. Faceless 是拍摄条件，不是无人认证

本次新增两个独立标签：**出镜**（完全无人 / 仅手部 / 有人）与 **载体**（实拍 / 录屏 / AI / 混合）。

K01 有教师，K09 有会议人像；D03 有数字人，D07 有照片人像，D48 有会动的名画人形。即使拍摄者不露脸，也不符合“画面完全无人”。录屏还要检查头像、视频缩略图、反射、桌面壁纸和嵌入的人物素材。

无人优先用真实物件状态、真实机械过程、无人物内容的录屏。不能为了满足两条无人，自动编“冰块逃跑”“商品排队”等定格动画。动画可以做，但它增加制作负担，运动来源也必须说清；并且不能把动画里的功能当实测。

## 7. 产品因果要诚实到品类层级

分三级检验：

- **品牌或型号特有**：已有证据支持该外观、交互或功能，并且故事确实依赖它。
- **品类相关**：气泡饮料的分享、开罐声与冷凝水可能适用多品牌。可以构成饮料故事，但不能冒称可口可乐独占能力。
- **任意商品可替换**：只在结尾递出一件商品，前面的笑话照常成立；这是弱融合，需要重写。

D48 的名画动画末尾喝可乐就是检查对象：人形动画本身不是品牌因果。要么承认它是品牌贴片，要么让可确认的产品交互参与前面的行动。不能靠最后给包装特写就给反转通过。

## 8. 不迁移的原文模式及替代方法

| 来源问题 | 为什么结构上不能照抄 | 保留吸引力的替代 |
|---|---|---|
| “制造专业漏洞引战” | 故意错误破坏效果证据，假争议不代表真实互动 | 用户需要互动时，问实际选择：节省步骤还是保留手动控制 |
| 数字工具秒变收益/升职 | 完成输出与商业结果之间缺少因果证据 | 展示一个明确任务、实际输出与核对动作 |
| 所有结尾都接“因为” | 语句未必连贯，问题已解决却无故恢复 | 匹配构图/动作/声音；不能自然衔接就结束 |
| 危机远超过产品能力 | 工具无法兑现救命、治病、百分百防护承诺 | 换成小损失、轻微不便、有限误会 |
| 用破坏、动物受惊证明强度 | 风险代替了证据，且未必低成本 | 使用正常使用过程、离体样片或明确模型 |
| 两物件/两状态偷换 | 观众被隐瞒关键新设定，非公平反转 | 提前出现区分线索，前后跟踪同一个对象 |

P43 的红点从报警器跳到猫项圈，P58 的翻面被写成换项链，P80 的胶带撕掉后孔仍不漏，均需修正空间或物理因果。可以保留“误认来源”“拿错物件”“堵住泄漏”的结构，不能复制其断裂。

- 主文件 v3.2.0：新的资料路由、双轴出镜标签、软件任务证据、三种曝光时刻、每镜信息增量、产品因果层级。
- 前三秒方法：增加证据载体、临界状态、阅读负担与静音检查，不删除原有独立钩子验收。
- 新增录屏/Faceless 拍法：输入—操作—输出—验证，明确模拟界面与效果实录边界。
- 新增本分析与 160 条逐项索引；90 条资料标为历史快照，不混号。
- 补回归请求：人像录屏、提前露出、屏幕阅读、假效果、伪反转、完整五条交付与评论争议。

这些更新完成的是文字方法与结构验证；真实停留率、完播率、品牌转化仍需实际制作与数据，不在此次分析中声称已验证。
