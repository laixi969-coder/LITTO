# 创意转译：现象 + 半步

用于 [adfilm](../SKILL.md) 第 3 节写标题、口播和画面构思。先有消费者洞察或明确标注的假设，再进行表达；创意本身不新增证据，也不能把假设升级为事实。

## 保留的表达方法

从洞察的真实场景中，提炼一个能被认出、能被复述的观察。标题可以只推进“半步”：重新命名、设置对照、补一个动作或物件，把解释留给支撑文字。这里可以避免标题使用“因为、本质上、这说明”等说理措辞，但消费者洞察陈述应保留必要解释。

需要探索时先形成少量候选，再按真实感、表达新意和品牌适配选取；不用为了数量制造假现象。

可尝试五种视角：交换观察者、对照不同时间、从被忽视角色出发、转换计量单位、反转品类惯例。它们是创意手法，不是研究方法，不能为了反转扭曲原始行为。

## 可选交付字段

- `source_insight`：所承接的洞察及其证据状态。
- `title`：现象 + 半步的表达。
- `evidence_scene`：原始场景，引用证据编号；无证据则标为构造场景。
- `half_step`：添加的命名、反差、动作或物件。
- `shootable_scene`：拟拍画面，明确是创意演绎。
- `accident_sense`：适用时写小冲突、误解或尴尬；安静的真实也可以成立。
- `psychological_driver` / `insight_value`：沿用消费者洞察中的解释与不确定性。
- `brand_fit` / `creative_proposition`：品牌能力、消费者收益和具体行动。
- `risk_note`：是否夸大、刻板化、冒犯，或承诺了品牌无法兑现的服务。

若用户需要旧版 JSON，保留旧字段，并将证据状态、替代解释与验证计划一并交付。无法判断的质量项用 null 并说明；不为凑齐字段全部填 true。

## 示例（教学构造，无真实研究）

假设：首次尝试陌生版型且寄件不便的人，可能先考虑买错后的处理成本。

现象表达：“先看能不能退，再想要不要买。”

拟拍画面：光标在尺码表和退换说明间往返，消费者查看真实取件安排后才做决定。

品牌行动：在确实具备相应服务时，将退换条件呈现在决策位置。画面是对假设的演绎，不证明消费者普遍这样做，也不能暗示未提供的服务。

## 叙事广告、产品展示与生活推广模板

| 类型 | 组织方法 | 提交前检查 |
| --- | --- | --- |
| 关系驱动广告 | 已有关系任务 → 产品引发/承接行动 → 可辨认的反应 → 品牌记忆 | 产品为何参与，动作/声音暗号是否足够辨认，不靠解释旁白补因果 |
| 原料或制作过程 | 同一空间内可操作的制作步骤 → 产品使用 → 感受 | 容器承水、工具用途、时间省略及工艺成立；微距是否提供新信息 |
| 产品运动展示 | 产品结构参考 + 白模构图/路径 + 当前材质光线 + 停靠结果 | 白模不能作为最终材质；底部接地、反射、标识与结构逐项可读 |
| 动画家庭广告 | 产品状态与人物误会/照顾关系共同推进 | 动画保留自身媒介；开盖、放置、坐站和台词在同一采用版 |
| UGC 使用分享 | 交流对象 → 展示/使用产品 → 有依据的反应 | 自拍镜像与实际手位分清，产品切换有来源，不新增功效或填充台词 |
| 餐厅带看 | 实际门店空间 → 菜品/服务 → 真实信息对应的口播 | 菜名、食物、店址与素材逐项相符，未提供事实不靠生成画面证明 |

将选定方法写入 adDirection 的 concept/productRole/brandRecall/emotionalArc，再落实本镜 advertising.productRead/cutToNext/sound。旧稿删除第二件产品或改变认人方式时，同步数量、道具状态、表演、参考与声音，不能保留旧动作的幽灵指令。

落版先保证包装/产品与准确文案可读，再选静态覆盖、文字动画或首尾帧方式；稳定读字时间包含动画完成后的停留。后期配乐意图留在声音/剪辑层，生成无声素材时不再要求供应商生成同一音乐。真实粗剪决定声音卡点，不把初稿时码当成最终时间。

用户明确要求多场景、运镜或人物对口型时，逐镜记录真实空间、景别、摄影机起点/路径/终点和口播发声窗口。换裁切不算换场景，人物移动不算摄影机运动，旁白覆盖或人物张嘴不算口型同步。按实片核对产品结构、口播音节和可见嘴部，观察模型漏听或无法确认时保留未验证状态，与真实音频检查交叉核对；不能因生成成功就采用。仅重做具体失败镜头并保留前后候选，用户明确指定静态落版、单场景或旁白时尊重该选择。

教学示例（不自动加入用户项目）：某次赠予动作在多年后以产品再次出现，角色通过同一动作认出对方。应先建立暗号、再拍识别反应、最后展示产品；若没有前置铺垫，单独敲瓶盖不能证明认人。

## 原创例与反例的使用

适用与输入：广告、产品展示、UGC或餐厅；输入准确产品事实、受众、传播任务和采用资产。

写法示例：店员将实际菜单中的热汤端上桌，镜头看清同一碗和已提供菜名；消费者反应作为创作演绎。

反例：通过生成画面新增‘百年配方’或不存在的菜品。

约束与例外：本例只说明组织方法，人物、时长、数量与媒介须换成当前项目；不自动加入案例剧情。已有有效方案直接复用。

验收与修复：核对商品、包装、操作、口播与落版；虚构事实删掉，结构错误修资产。 本例未实际生成，不作为效果证据。
