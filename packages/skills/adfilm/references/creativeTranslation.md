# 创意转译：从依据到创意成品

用于 [adfilm](../SKILL.md) 的商业构思、脚本与重做。运行时会预读本文件；以下流程是共同入口，详细方法按需加载。创意探索不等于消费者研究，不能把假设升级为事实，也不能靠生成画面证明产品功效。

## 先找值得表达的东西

- 现有材料有访谈、评论或购买行为：用 [insight](../../insight/SKILL.md) 区分观察、解释与假设，再取与本次广告有关的发现。完整研究留在 insight，不让一支短片被研究报告淹没。
- 只有品牌与产品：整理已知的形状、使用动作、声音、品牌资产和任务，缺失的型号与功效留空。可以从产品事实或媒介表达入手；不要为了写故事捏造“大家都这样”的洞察。
- 已有有效方向只需改句、改镜头：保留核心，只修用户指定范围。

## 先完成品牌承接，再选手法

洞察路线先接收 insight 的情境与选择、依据状态、替代解释、品牌承接和传播任务。没有具体行为后果的“渴望自由、追求不同”退回观察或需求，不靠贴“假设”标签通过。其他路线写明已知产品事实、感官特点或品牌资产，不虚构深层心理。

内部保留：**依据或假设 → 消费者取舍（适用时）→ 品牌作用与传播主张 → 创意机制 → 实际作品**。先明确希望谁改变哪个认识、品牌凭什么回应，再选表现手法；不能先想笑点再补心理解释。删掉所称洞察后创意完全不变时，检查洞察是否只是装饰；可以诚实改为产品/媒介路线，但不能借此回避用户明确要求的洞察。

品牌承接分三项判断：

| 层次 | 必须说明 | 不能代替它的东西 |
| --- | --- | --- |
| 品牌识别 | 通过哪个真实标志、形状、声音或其他资产认出品牌 | 仅贴品牌名不证明产品价值 |
| 产品关联 | 产品在行动、体验或证明中起什么作用 | 出现使用场景不等于只能由该品牌承接 |
| 品牌意义 | 观众对品牌/产品新增或强化了什么理解、感受或选择理由 | 一段“为什么适合品牌”的策划说明不能替作品传达 |

共同品类利益可用，但需品牌资产与有辨识度的表达，不编造独家功能。品牌片可通过真实立场与资产成立，不强求功能演示；短提醒等窄任务按既定目标审核，不强行创造全新品牌定位。

## 开放创意先分路，再成稿

读取[创意机制](creativeMechanisms.md)，内部探索通常三个不同方向：它们应在主张、因果、观察者或表现规则上不同。不是同一误会换三个场景，也不是三个品牌都套一个生活片公式。用户要一个成稿就精选一个；用户要求多方向才展示差异。每条交付应能具体想象成品：

1. 一句话核心想法：明确对象、动作与发现，不能只有主题词。
2. 第一眼/第一耳：准确画面、声音、首句；说明观众为何在意。
3. 关键发展与回报：动作怎样升级，最终发生什么；反转需前置线索与翻案证据，其他形式可用演示、节奏或感官完成兑现。
4. 品牌作用：产品引发或完成动作、提供可信证据、贡献独特视觉/声音资产，或承担与其有关的立场。
5. 实际结尾：写出最后动作及准确台词/落版。无台词就明确无台词，不把包袱留成占位。

需要脚本时继续写完整时间段与分镜，核对总时长、表演和阅读时间；只要创意时不扩成制作任务。用[品牌文案](brandWriting.md)处理口播与品牌语气；仅在玩梗、UGC或社交传播目标下读取[社交脑洞](socialPlay.md)。原生手机短视频才继续应用[原生方法](nativeShortVideo.md)的制作默认值。

## 开场钩子与结尾回报

每支完整广告在开场尽早建立值得继续看的理由，结尾兑现开场的期待，并留下相关品牌记忆。钩子可以是悬念、关系冲突、异常动作、直接利益或感官吸引；按渠道与调性安排，不把所有品牌片强压成同一种前三秒套路。不要用与后文和品牌无关的猎奇片段骗停留。只改局部文案或已采用方案时保持用户范围。

开放构思时优先探索一个有伏笔的欧·亨利式反转候选，与适合当前主张的非反转方向比较。它应让观众在意外揭晓后重新理解此前的行为及品牌价值，而不只是知道一个新身份、看见产品或听见原因。若需要扭曲洞察、隐藏正常可见的信息或编造产品能力才能成立，就放弃该候选；不要求每支广告反转，也不要求每个候选都交给用户选择。

选择反转时须满足：

- **有前置线索**：初看合理，回看能找到依据；结尾不能突然增加解决一切的陌生人物、规则或产品功能。
- **行为自然**：人物在其所知情境下有合理动机；超现实设定也遵守自身规则，不能为瞒观众反常行动。
- **意义改变**：写清观众先前可能怎样理解，哪项可见证据改变理解，此前哪个动作因此有了另一层含义。身份揭晓本身不足以证明反转成立。
- **品牌参与兑现**：产品、使用动作、真实品牌资产或立场参与结尾的意义，不能只在故事结束后贴标。

非反转结尾可采用情绪回报、视觉完成、事实证明或幽默收束，同样检查开场承诺是否兑现、品牌为何在场；事实证明须有真实依据。感官片可以兑现观看与聆听体验，无须捏造谜题。交付脚本时把钩子、伏笔（若采用反转）、兑现动作及准确落版写进作品，不另堆自评表；若用户只要开头或结尾，就只交对应部分。

## 两遍审稿：先受众，再广告任务

第一遍暂时遮住策略、作品外标题和“为什么适合品牌”，只读实际画面、台词、字幕与声音：发生了什么，为何值得继续，人物为什么这样行动，结尾是否兑现期待？保留成片本来就有的标题/字幕；声音作品不要求静音也成立。以下是案头审稿，不冒充独立评审或真实受众反馈。

特别检查：隐藏信息是否公平？人物可以知道观众暂时不知道的事，但不能为了藏谜底做反常行动；摄影机也不能无缘无故一直躲开正常可见的关键物件。超现实前提可以成立，前提下的动机与规则仍须一致。需要时提前露产品、改变开场或放弃反转，而非不断增加遮挡。

中段每个节拍应增加信息、改变局面、提高代价或深化意义；只换场景重复同一笑点不算发展。想法撑不起指定时长就发展结构或换方向，不靠慢镜和重复填满；用户未锁时长时可建议更短版本，不能擅改已指定时长。

第二遍回到广告任务，分别检查品牌识别、产品关联和品牌意义，再核对以下项目：

| 检查 | 看什么 | 不成立时怎么修 |
| --- | --- | --- |
| 对题 | 受众能获得哪项相关价值，是否满足当前任务 | 回到主张，不靠更华丽的镜头补救 |
| 换品牌 | 竞品原样使用有何损失 | 加入已知品牌资产或独特表达；不能捏造独家功能 |
| 拿掉产品 | 动作因果、证据或品牌意义失去什么 | 让产品参与机制；品牌片可由独特立场/资产成立，不要求每镜露出 |
| 去掉解释 | 只看画面、计划内字幕与声音，能否接住意思 | 修改作品，不用策划说明替观众理解；无需强迫声音广告静音也成立 |
| 回报兑现 | 开场期待在何处以什么动作、证据或台词完成 | 补足真实结尾；原因揭秘不冒称强反转 |
| 可执行 | 动作、因果、时长、产品事实与制作条件是否相容 | 改相关镜头，不把 AI 可生成当作可验证功效 |

按失败层级修正，不以自评高分放行：洞察空泛回材料或降级为观察；证据不足但机制清楚则标探索假设；品牌意义缺失重选主张或承接方式；核心因果失败淘汰方向；动机不自然或中段重复则重构；关键台词/结尾未写出视为未完成；仅措辞拗口就局部润色。不能一边承认核心缺陷，一边把它标为可制作的推荐方案。

用户说“没创意”时先指出具体失败层级，保留有效 brief 和事实，再修对应部分；不一律换手法或只加“大胆、国际大奖、电影感”等形容词。用户要求的数量先努力完成，仍有方向不成立则如实标明缺口，不用弱稿凑合格数量。两轮仍无有效新方向时给最值得补的资料或有边界的探索稿，不无限改稿，不擅自换品牌、增加片长或启动生成。

用户要求效果比较时，固定 brief、模型、时长与交付条件，隐藏版本请用户比较观看意愿、作品记忆与品牌归属，并记录具体理由。模型案头审稿与真实用户反馈分开；未实际比较不宣称新版更好。

## 可选：现象 + 半步

从洞察的真实场景中，提炼一个能被认出、能被复述的观察。标题可以只推进“半步”：重新命名、设置对照、补一个动作或物件，把解释留给支撑文字。这里可以避免标题使用“因为、本质上、这说明”等说理措辞，但消费者洞察陈述应保留必要解释。

这一方法适合生活观察文案，不限制其他方法的戏剧幅度。没有生活洞察时，可从已知产品细节、品牌立场或媒介结构开始，不能先编观察再伪装成研究。

需要探索时先形成少量候选，再按真实感、表达新意和品牌适配选取；不用为了数量制造假现象。

可尝试五种视角：交换观察者、对照不同时间、从被忽视角色出发、转换计量单位、反转品类惯例。它们是创意手法，不是研究方法，不能为了反转扭曲原始行为。

## 可选交付字段

- `source_insight`：所承接的洞察及其证据状态。
- `title`：现象 + 半步的表达。
- `evidence_scene`：原始场景，引用证据编号；无证据则标为构造场景。
- `half_step`：添加的命名、反差、动作或物件。
- `shootable_scene`：拟拍画面，明确是创意演绎。
- `accident_sense`：适用时写小冲突、误解或尴尬；安静的真实也可以成立。
- `psychological_driver` / `insight_value`：沿用消费者洞察中的解释与不确定性。
- `brand_fit` / `creative_proposition`：品牌能力、消费者收益和具体行动。
- `risk_note`：是否夸大、刻板化、冒犯，或承诺了品牌无法兑现的服务。

若用户需要旧版 JSON，保留旧字段，并将证据状态、替代解释与验证计划一并交付。无法判断的质量项用 null 并说明；不为凑齐字段全部填 true。

## 示例（教学构造，无真实研究）

假设：首次尝试陌生版型且寄件不便的人，可能先考虑买错后的处理成本。

现象表达：“先看能不能退，再想要不要买。”

拟拍画面：光标在尺码表和退换说明间往返，消费者查看真实取件安排后才做决定。

品牌行动：在确实具备相应服务时，将退换条件呈现在决策位置。画面是对假设的演绎，不证明消费者普遍这样做，也不能暗示未提供的服务。

## 叙事广告、产品展示与生活推广模板

| 类型 | 组织方法 | 提交前检查 |
| --- | --- | --- |
| 关系驱动广告 | 已有关系任务 → 产品引发/承接行动 → 可辨认的反应 → 品牌记忆 | 产品为何参与，动作/声音暗号是否足够辨认，不靠解释旁白补因果 |
| 原料或制作过程 | 同一空间内可操作的制作步骤 → 产品使用 → 感受 | 容器承水、工具用途、时间省略及工艺成立；微距是否提供新信息 |
| 产品运动展示 | 产品结构参考 + 白模构图/路径 + 当前材质光线 + 停靠结果 | 白模不能作为最终材质；底部接地、反射、标识与结构逐项可读 |
| 动画家庭广告 | 产品状态与人物误会/照顾关系共同推进 | 动画保留自身媒介；开盖、放置、坐站和台词在同一采用版 |
| UGC 使用分享 | 交流对象 → 展示/使用产品 → 有依据的反应 | 自拍镜像与实际手位分清，产品切换有来源，不新增功效或填充台词 |
| 餐厅带看 | 实际门店空间 → 菜品/服务 → 真实信息对应的口播 | 菜名、食物、店址与素材逐项相符，未提供事实不靠生成画面证明 |

将选定方法写入 adDirection 的 concept/productRole/brandRecall/emotionalArc，再落实本镜 advertising.productRead/cutToNext/sound。旧稿删除第二件产品或改变认人方式时，同步数量、道具状态、表演、参考与声音，不能保留旧动作的幽灵指令。

落版先保证包装/产品与准确文案可读，再选静态覆盖、文字动画或首尾帧方式；稳定读字时间包含动画完成后的停留。后期配乐意图留在声音/剪辑层，生成无声素材时不再要求供应商生成同一音乐。真实粗剪决定声音卡点，不把初稿时码当成最终时间。

用户明确要求多场景、运镜或人物对口型时，逐镜记录真实空间、景别、摄影机起点/路径/终点和口播发声窗口。换裁切不算换场景，人物移动不算摄影机运动，旁白覆盖或人物张嘴不算口型同步。按实片核对产品结构、口播音节和可见嘴部，观察模型漏听或无法确认时保留未验证状态，与真实音频检查交叉核对；不能因生成成功就采用。仅重做具体失败镜头并保留前后候选，用户明确指定静态落版、单场景或旁白时尊重该选择。

教学示例（不自动加入用户项目）：某次赠予动作在多年后以产品再次出现，角色通过同一动作认出对方。应先建立暗号、再拍识别反应、最后展示产品；若没有前置铺垫，单独敲瓶盖不能证明认人。

## 原创例与反例的使用

适用与输入：广告、产品展示、UGC或餐厅；输入准确产品事实、受众、传播任务和采用资产。

写法示例：店员将实际菜单中的热汤端上桌，镜头看清同一碗和已提供菜名；消费者反应作为创作演绎。

反例：通过生成画面新增‘百年配方’或不存在的菜品。

约束与例外：本例只说明组织方法，人物、时长、数量与媒介须换成当前项目；不自动加入案例剧情。已有有效方案直接复用。

验收与修复：核对商品、包装、操作、口播与落版；虚构事实删掉，结构错误修资产。 本例未实际生成，不作为效果证据。
