# 商业广告：方法发想与案例对照

用于开放构思、Big Idea、多方向与创意重做；局部改句、已采用镜头的制作与修复不重开策略。承接 creativeTranslation 的品牌、证据与因果检查，用户的数量、载体、预算与交付范围优先。

## 先对齐任务层级

区分长期品牌主张、一次活动主张和单条执行。用户要短片，就在短片内创造机制差异；滤镜、装置或拍摄手法本身不等于活动创意。不擅自把促销升级成品牌重塑。确认本次要改变的认识或行动、真实产品依据、受众阻力和可用承接入口。

## 按问题选择方法

以下根据来源方法目录改编，选能解决当前问题的少量方法，不规定必须三种、必须产出十二条或淘汰最先想到的方向。

| 任务 / 方法 | 操作 | 商业边界 |
| --- | --- | --- |
| 产品特点不突出：SIT | 列出产品、用户与环境中已有元素；尝试减去一个元素、拆分重组、让已有元素承担第二个表达任务，观察什么价值变得可见 | 表达可减法，真实功能和交易条件不能删改；沿用准确产品结构 |
| 旧表达同质化：SCAMPER | 对现有表达尝试替换视角、组合场景、借用其他形式、放大细节、改变用途、删减或颠倒顺序；保留有效主张 | 不把创意中的新用途写成真实适用范围，不为枚举而凑数 |
| 预算或信息矛盾：TRIZ | 写清“需要 X，但 Y 妨碍”；试分段、提取关键属性、局部变化、反向表达或随情境变化 | 解决传播矛盾，不宣称创造了产品没有的能力 |
| 多方向总是相似：形态分析 | 将主角、证明方式、情绪、机制列为几列，从不同列组合；先固定用户指定的渠道与片长 | 每个组合都要说清品牌作用，不能只换布景 |
| 想法缺乏新联系：双重联想 / 类比 | 从产品真实特点出发，找另一领域相同的动作、结构或规则，将共同关系变成可见画面 | 借关系而非借结论；比喻不能冒充功效证据 |
| 品类惯例难突破：逆向发想 / 挑衅 PO | 列出一个理所当然的惯例，暂时反转，提取能改善理解或选择的部分，再恢复事实与执行约束 | 不强求冒犯、悬念或反转；明确演绎与真实承诺的界限 |

## 案例检索与迁移

读取 [案例索引](campaignIndex.md)，按当前行业、形式、预算标签选 2–4 张完整卡片；用一个异业案例寻找机制新联系。必要时通过 skillOperator 的 read 读取 adfilm 下 references/campaignCases/ 的对应文件。只读了索引就不能声称分析过完整案例。

从卡片提取：它回应什么问题 → 用什么机制表达 → 品牌在机制中做了什么 → 当前产品有什么真实条件支持迁移。卡片中的 Insight 和 Why it worked 是来源作者的解释，不是本次消费者研究或因果效果验证。保留案例原始链接；正式提案引用奖项、年份、效果数据时回查原始来源。

每个借鉴方向内部记录来源、借用机制、当前品牌依据和实质差异；展示借鉴时附来源。不直接复刻口号、角色、分镜或标志性构图，不暗示案例素材已获得商用授权。索引中的机制标签仅帮助检索：案例多不等于创意差，库里没搜到也不等于原创；明确原创性要求时补查当前市场。

## 保留商业转化标准

- 曝光 / 品牌片：受众能认出品牌、复述与需求相关的价值；不强塞购买号召。
- 成交 / 留资：需求情境、核心利益、真实证据、关键异议、准确交易条件与一个可用行动入口连得上；缺价格、资质或服务事实不编造。
- 制作：产品参与表达因果，所需素材、时长和预算相容，用户指定的成稿完整交付。
- 效果：模型审稿只提出待验证判断；播放、品牌记忆、合格线索和成交分别记录真实反馈，不用热闹代替转化。

继续使用 creativeTranslation 的对题、换品牌、拿掉产品、去掉解释、回报兑现和可执行检查。推荐前简短预演最可能失败的原因及修正：看懂却记错品牌、相信不了证据、行动入口不通、制作无法兑现。只修失败处；两轮仍无有效方向，按原流程说明缺口并交有边界的探索稿。

不引入 Cannes / HumanKind / Grey 评分、9 分退出阈值、情绪等级、案例饱和度扣分或获奖预测。简单情绪、清晰演示与促销表达同样可用，以当前商业任务验收。
