# 社交脑洞、原创梗与二创

改编自 hiccai-wild 主技能、creative-mechanics 和 distribution，并吸收 hiccai-72 的参与与传播视角。只用于年轻化、脑洞、玩梗、事件或二创任务；不因用户要求商业创意就自动套用。来源见[研究记录](creativeSources.md)。

## 有锚点的荒诞

从品牌/产品独有的形状、名称、使用姿势、声音或场景规则出发，连接一种具体处境。区分生活阶段、关系与圈层，不把年轻人写成统一人格。品牌可以是道具、角色、场地或自嘲对象，但必须解释它为何在场。

| 方法 | 具体生成动作 | 退回原因 |
| --- | --- | --- |
| 一本正经处理小事 | 用严肃制度办理一件极小的私人事项 | 只有公文语气，没有具体的荒诞事项 |
| 规则错位 | 把另一场景的完整规则搬过来 | 两套规则没有可理解的对应 |
| 物品人格化 | 让物品产生与其用途有关的诉求或冲突 | 只有眼睛和卖萌，没有行动 |
| 低配宏大仪式 | 隆重呈现一个极有限的成果 | 只有夸张口号，没有仪式动作 |
| 字面执行 | 让一句日常比喻成为可见事件 | 无聊谐音、危险操作或产品假功效 |
| 身份/评价反转 | 让平时被评价者反过来评价 | 靠羞辱用户而非情境产生笑点 |
| 一条怪规则 | 建立前提后始终一致执行 | 每镜随机换规则，观众无法理解或续写 |
| 情绪实物化 | 用一个物件承接不可见的小情绪 | 生硬贴“情绪价值”，品牌可随意替换 |

轻量是生活观察的一处偏差，中量是看一个示范就能理解的荒诞规则，高量可能依赖圈内语法；根据目标选择，不假定越怪越好。当前热梗需查来源与日期；原创设定不必硬找热点。

## 交作品，再说为何好玩

每个方向给准确首句、关键画面/动作、品牌作用和具体结尾。若目标是分享，说明“谁发给谁，借此表达什么”；不能只写“引发共鸣”。不看解释就完全接不住时，先改作品。多个方向在笑点或参与动作上不同，不只换名字。

**教学构造，非实测案例**：袜子失物招领被写成招聘：“急聘左袜一只，搭档已到岗三天。”对象失散与招聘找搭档有结构对应；泛泛的“衣起发疯”只有谐音。迁移到具体品牌时仍须建立真实资产联系，不把这个例子自动放进广告。

## 需要二创时才提供参与结构

给一个可直接使用的母版，明确固定识别点、可替换槽位和最低动作；再示范同圈自用、朋友调侃或相邻圈改编。数量遵从用户需求，示例不能冒充网友真实作品。写清参与者表达了什么，而非只靠奖品驱动。

保留可回应的角色、命名或结局入口；避免伪造错误事实骗纠错。提供无需购买、到店或复杂剪辑的低成本版本，若不符合品牌任务则不强加参与玩法。

## 全案才扩到传播与验证

围绕“谁先看到 → 如何第一次改编/转发 → 官方如何回应 → 哪个相邻圈层接得上 → 品牌留下什么”安排内容，不默认达人铺量。给具体首发作品与回应示例，预算未知就说明假设，不联系达人或发布内容。

案头检查只能筛明显问题。实际验证按目标看理解、分享、独立二创、品牌归属或商业动作；排除官方示例和委托作品冒充自然传播。没有数据不写效果结论：看懂却不分享查关系表达，二创多却忘记品牌查识别点，不用曝光代替品牌记忆。
