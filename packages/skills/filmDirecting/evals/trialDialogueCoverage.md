# 试跑：狭窄走廊对峙要钥匙

状态：simulated。2026-11-10。未付费生成，只检验技能是否改变镜头判断。

## 输入

短剧。女主角林夏要回自己公寓的钥匙。男主角周宇堵在狭窄走廊里，背靠唯一的门。对白：

林夏：把钥匙给我。  
周宇：现在不是时候。  
林夏：你挡住门了。  
周宇：你出去就回不来。

空间：宽约 1.2 米的内廊，尽头一扇门，侧墙不能拆。夜间，门缝一条暖光。时长目标约 12 秒，16:9。不要生成媒体。

## 不用本技能时的典型草稿（对照）

平均正反打，每句一切，两边都短焦平视，相机随说话人左右摇，走廊墙在反打里消失。

## 技能改变的判断

导演思维（丹西格）：钥匙等于回家的控制权；走廊是单向通道，门是唯一出口。摄影必须一直让门作为地理答案存在。

空间（诺兰）：墙不拆。相机不得退到侧墙外。反打仍在走廊内部。

平面图（贝格莱特 / 卡茨 I 形态）：

```
门（画深）
  周宇 背门 面林夏
  林夏 走廊近端 面周宇
相机A 林夏侧过肩，低，看周宇+门
相机B 周宇侧略高、更长焦，看林夏
相机C 同侧双人中景，I 形态
轴线：两人视线，工作区在廊的同一侧
```

选用技巧：卡茨 I 面对面 + 过肩；肯沃斯 1.1 力量对比（周宇短焦略仰，林夏平视更长焦）；10.2 L 形隔离用在林夏拒绝退让、镜头从她身后推过；覆盖用主镜头加一对过肩，不按四句切四镜。

## 产物（ShotSpec 摘要）

### S1 建立 · 双人中景

- technique: I-pattern two-shot, locked
- purpose: 先让观众看见门在周宇背后、林夏无退路
- start: 林夏在廊近端，周宇堵门，钥匙在周宇右手
- subjectPath: 两人未移动
- cameraPath: 锁定，眼高，35mm 量级，轴线 A 侧
- narrativeFunction: 建立
- invariants: 门在画面深处；两侧墙可见；不拆墙
- acceptance: 不靠台词也能看出他挡住唯一出口
- fallback: 若纵深塌缩，改稍高固定，仍含门

### S2 力量对比 · 周宇过肩

- technique: power contrast, low OTS on aggressor
- purpose: 看他用身体占门，林夏的拒绝发生在压迫透视里
- start: 周宇肩在前景左下，林夏在走廊中段
- subjectPath: 周宇上半身略前倾，不离门
- cameraPath: 锁定，略低于周宇胸，短焦微仰
- 对白: 「现在不是时候。」「你挡住门了。」
- side: A
- acceptance: 林夏被压在门与身体之间；门缝暖光仍在
- fallback: 做不到短焦压迫则保持 S1 距离，切林夏反应

### S3 L 形推近 · 林夏

- technique: L-block push isolating resistant character
- purpose: 她不退，镜头从她身后超过去，读出抵抗
- start: 林夏背对相机一小部分，周宇在门前脱焦
- subjectPath: 林夏静止
- cameraPath: 从她左后缓慢推到眼睛特写，停在最后一句结束
- 对白: 「你出去就回不来。」她不接话，只伸手
- timing: 推近贯穿整句，句末停止
- invariants: 周宇仍在门前，不交换位置
- acceptance: 主角不动而镜头超过她，抵抗可读
- fallback: 固定特写 + 伸手

覆盖：三镜同一轴线。不按四句切四次。声音：S2 两句画内周宇/林夏；S3 周宇画内，林夏伸手无口型。
