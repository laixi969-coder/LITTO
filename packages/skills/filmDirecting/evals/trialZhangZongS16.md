# 试跑：张总·同学会 S15–S16 包厢对峙

状态：spec-compile。2026-11-10。项目 `张总·同学会`（租户工作区已有成片、走位板、覆盖表）。未改项目文件，未付费生成。用 LITTO 的 `shotInput`、`cameraDirectionIssues`、`creativeDirectionIssues`、`checkAxis`、`blockingText`、`coverageCheck` 验收。

## 输入（项目原文）

单场景酒店中餐包厢，夜。圆桌，吊灯暖黄，门缝冷白。李伟求张强放过公司；张强要他把「混成这样」再说一遍。

原分镜：

- S15 双人侧面，镜头几乎不动。四句同镜。
- S16 双人正面，镜头几乎不动。七轮对白塞进一镜。后来实验拆成六镜正反打（S16a–f）。

原提示词共性：首帧锁定 +「镜头几乎不动，只有极轻微的手持呼吸」+ 对白散文。没有 `subjectPath` / `cameraPath`，没有焦段对比，S16 正面有肥皂剧叠脸风险。

## 技能改变的判断

导演思维：这场不是打脸，是张强拒绝变成李伟。摄影要一直让「求情的人没牌、坐着的人掌握出口」可读。

空间：包厢墙不拆。门是走廊冷白的入口。相机不退到墙外，不绕桌穿墙。

平面图（沿用项目 `assets/blocking.json` 的圆桌坐标）：

```
门 (6.9, 5.4)
  张强 (3.6, 4.6) 面李伟
  圆桌 (3.6, 3.2)
  李伟 (3.6, 2.0) 面张强
K15  桌侧双人中景
K16a 张强右肩过肩 → 李伟
K16b 李伟肩、低、32mm → 张强
K16c 张强左后推近
轴线：李伟–张强，四机都在同一侧
```

选用：S15 肯沃斯 10.3 分享镜头 + 10.6 余光；S16a 卡茨 I 过肩建立；S16b 肯沃斯 1.1 力量对比；S16c 肯沃斯 10.2 L 形隔离。放弃环拍 2.1、绕圈 11.1、按七句拆七镜。

## 编译验收

| 镜 | schema | camera.design 缺项 | 创作缺项 | 路径分离 | 肥皂剧/拆墙 |
| --- | --- | --- | --- | --- | --- |
| S15 同框求情 | 通过 | 无 | 无 | 是：人微倾、相机锁定 | 无 |
| S16a 建立条件 | 通过 | 无 | 无 | 是 | 无 |
| S16b 力量对比 | 通过 | 无 | 无 | 是：人略前倾不离椅、相机锁定 32mm 微仰 | 无 |
| S16c L 形隔离 | 通过 | 无 | 无 | 是：人静止、相机推近 | 无 |

走位板 `checkAxis`：`crossing: false`，K15/K16a/K16b/K16c 全是 side -1。

覆盖表：level `warn`，不是 `block`。S15 四轮、S16b 三轮记为 overloaded，规则原文是「能完整执行的持续镜头可以保留，不强制拆镜」。生成门禁只拦 `block`。

编译进提示词的字段（节选）：

- S15 `Camera technique: shared two-shot, I-pattern, glance not locked eyeline`；`Camera path: 锁定`
- S16b `power contrast, low OTS on controlling character`；`32mm`；`below chest`
- S16c `L-block push isolating resistant character`；`Subject path: 张强静止`；`Camera path: 从张强左后缓慢推到眼睛特写`

对照原 S16 提示词：原句没有 technique、没有两条路径、没有 32/85 焦段差、没有「门在画深」不变量。

## 回到书里

S16c 用的是 10.2「主角必须静止」。张强若在推近时起身，抵抗会被动作吃掉。可接着在 `masterShots1.md` 第 10 章读 10.1 双人同速推近：这场短句打断要不要改成一对匹配速度的推近，而不是一锁一推。
