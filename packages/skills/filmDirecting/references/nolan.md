# 诺兰：空间与制作纪律

来源：汤姆·邵恩《诺兰变奏曲》引言、结构、空间；《盗梦空间》拍摄剧本开场；黑暗骑士三部曲剧本+分镜为对照材料。cinema 的 shotLanguage 已有 ASC/BAFTA 访谈转译，这里只补本书正文里的方法，不重复色板或模仿其影片外观。

## 空间

「我不会把场景里的墙壁移开。如果摄影机往后退到观众所认知的墙壁位置之外，他们就知道你作弊了。」箱子型房间里，退到墙外会感觉身在房外。诺兰要的是房间的局限：密室内的神秘案件。

建筑按叙事顺序进入。吴哥窟必须从正面入口走，从后面溜进去等于把电影放反。场面调度、组合镜头、为故事创造地理，都与建筑有关。

环境必须回答或挑战人物。封闭世界（哥谭、汽车旅馆、木屋、监狱、拖网渔船）困住身体，反派常在其中用计谋超越限制。主角要在封闭里学习接受或找到出口。

## 结构

结构是他真正放纵的地方。人物像艾雪图形那样分裂：对外顺从、对内反叛。先在结构里找到救赎，再被结构背叛。时间顺序可以打碎，但情感节奏仍按观众能懂的惯例推进。《记忆拼图》若按时序讲会让人看不下去，必须让观众与失忆主角共享乐观和无知。

## 制作纪律（引言，转为工作约束）

自己拍每一帧，不用第二组。拒绝先做概念图再找故事。剧本和水印影本留在片场。看演员，不盯监视器。能实拍就不把关键动作交给 CGI（《黑暗骑士崛起》约 3000 镜 / 430 VFX）。这些是诺兰的现场选择，不是 LITTO 必须模仿的工时制度；可执行的是：关键动作优先写进可拍空间，不把「拆墙、第二视点、后期补环境」当默认。

## 《盗梦空间》开场的覆盖含义

餐厅：齐藤背对观众；桌上枪与锡锥；镜头移向旋转的陀螺。揭示从背后开始，道具桌面驱动推近。对象驱动的 push 写进 `cameraPath` 和 `visualPayoff`，不要开场就给陀螺特写。

## 接到 LITTO

`invariants` 写明不可拆的墙、入口方向、观众已知的房间边界。`cameraPath` 不得穿过这些边界。需要更大视野时改切到已建立的外部，或让人物把门打开，不把相机放到墙外。
