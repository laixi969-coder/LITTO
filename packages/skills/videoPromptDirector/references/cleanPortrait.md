# 清爽真人：身份、妆面、成像分开控制

用于清爽、清透、精致且像真人的人物资产及视频。沿用已确认的年龄、肤色、体型和身份；不把清爽等同于漂白、幼态化、瘦脸或统一女团妆。与 workflow 的 characterStyling.md 共用妆造方法。

此方法已作为真人剧情、商业广告和 MV 的默认人物质感。用户已认可的样片确定的是清爽程度与真实纹理的平衡，不是固定人物长相、浅蓝衬衫、窗边场景、回眸动作或统一模型。沿用项目的具体角色、商品、故事与音乐设计；不新增每次选择肤质的询问。既有合格资产优先复用，模型与生成预算继续沿用用户选择。

## 先锁定，再动起来

已有合格参考直接复用。新角色在人物资产的正面特写中检查眉眼比例、鼻唇、发际线和肤面，再检查全身造型；同一张设定板可完成这些检查，不自动追加收费图片。脸部参考只约束身份，不能凭头肩图猜全身服装。变更妆发或服装时保持面部身份，废弃候选不能和采用版本一起传入。

设定板作为多参考身份输入；单首帧模型需要真实剧情构图的关键帧。视频正文分别写清人物、服装、场景参考的职责，不继承设定板白底、并排人物或中性站姿。

## 五项正向控制

| 项目 | 写什么 |
| --- | --- |
| 身份 | 具体脸型、眉眼关系、鼻唇比例、发际线与已确认记忆点；新人物先定协调结构，不分别堆“最大眼睛、最小下巴” |
| 肤面 | 既定肤色下均匀自然，眼周与嘴唇有适度血色，微细纹理只在对应景别可辨；轻薄半哑光底妆与颈部衔接，额鼻控油、颧骨和唇部克制高光 |
| 妆发 | 眉色和毛流、睫毛分束、眼影边缘、颊部落色、唇色和润泽程度；发根蓬松、轮廓整齐、少量位置明确的碎发 |
| 光线 | 资产使用正面偏上大型柔光与反光板，眼下明亮、鼻侧和下颌有柔和体积；视频改按场景光源布光，逆光时用真实环境反射保持脸部可读 |
| 表演 | 明确视线对象和触发，再写一个主要动作与细微反应；呼吸、发丝和衣料随动作变化，不机械堆眨眼、歪头和对镜甜笑 |

清爽不要求所有脸哑光。明确要水润唇妆时保留局部透亮高光；明确要纪实时允许少量自然肤色变化，但不主动加黑眼圈、干皮、粗大毛孔、胡茬或疲态。完整头部在资产中清楚，剧情里不强求背景和面部同样锐利。

## 可改写样例

> 保持已采用人物的面容、肤色与年龄。肤色均匀自然，近景保留细微纹理与眼周血色；轻薄底妆平顺衔接颈部，额鼻反光克制，面颊与下唇受光处有柔和光泽。眉毛与睫毛清晰分束，唇色服从已定妆面。发根清爽蓬松，耳侧两缕碎发随微风轻动。左后方窗光勾出发丝边缘，正面白墙反射光补起眼下，鼻侧保留浅淡体积阴影。

这是方法示例，窗户、风与妆容必须按实际项目替换。只选当前镜头需要的内容，不每镜重复全部五官。负面段仅保留实际风险，例如整脸油亮、蜡状磨皮、过度锐化、身份漂移。

## 模型与验收

先查已授权模型的实际能力，不为某模型凭空加入权重语法或摄影参数。自然语言按身份、妆发、构图、布光、质感排序；模型不执行妆面时，只补强遗漏部位，不一并更换脸型与灯光。直接生成段在五板块的第二块写上述成像要求；正式镜头写入 look、lighting、realism.surface，再 compile 回读实际请求。

验收分别看原身份、脸部高光、眼周、发根、唇纹、皮肤与衣料区别，以及视频转头后是否保持一致。只看提示词或抽帧时标明未完成动态验收；无真实对照不能宣称提升已被验证。
