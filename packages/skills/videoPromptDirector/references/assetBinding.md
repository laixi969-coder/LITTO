# 资产建立与绑定

人物、场景与道具资产是身份、空间与结构的依据，不只是风格参考。本文件规定资产如何生成、命名与绑定，供视频提示词导演在项目前期确认后执行。

## 1. 人物三视图资产

### 1.1 生成顺序

```text
确认剧情核心角色 → 检查人物参考是否已上传 → 弹出角色面容与穿搭选择 → 用户选择后生成人物三视图 → 绑定为人物资产
```

- 没有人物参考时由导演直接设计角色；普通人物照片只作为面部身份与基础外貌参考，不直接作为视频起始画面。
- 多角色项目为每名核心角色分别设置一个单选问题；一个弹窗最多承载三个角色，超过时分批调用。每次调用后立即暂停等待用户选择。
- 人物参考存在时，三个选项只改变妆发、服装和角色气质，不改变人物身份与核心五官。

### 1.2 面容与穿搭选择

问题标题固定为"你希望【角色名】使用哪种面容与穿搭？"。单角色弹出一个单选问题，提供三种根据当前剧情即时设计的具体方案，最符合剧情的一项排在第一位并标注"推荐"。每个选项必须明确：角色年龄感、脸型与五官气质、妆发、完整穿搭与身份记忆点；不使用"方案一/方案二/方案三"。

现代年轻女性、旅行、日常与青春题材优先使用日系小清新、韩系清透、日韩简约文艺三类方向，把上衣、外套、下装或连衣裙、鞋履、配饰、颜色和材质写具体；剧情没有运动需求时不使用普通运动套装。古装、职业、年代与特殊身份人物服从剧情身份，不强行套用现代穿搭。保留自由填写入口。

### 1.3 五段式提示词（图像节点必填）

调用图像生成前，先在内部展开完整五段人物资产提示词，再把整份提示词原样传入图像生成节点；不得把人物选择结果压缩成"人物三视图、白底、正侧背"的简写。提示词必须完整包含以下五个原样标题：

```text
【角色身份与外观】
【固定人物资产构图】
【肤质、布光与成像】
【一致性要求】
【负面约束】
```

内容要求：

- **身份与外观**：明确具体脸型骨相、下颌、眉形、眼型、虹膜、鼻型、唇形、肤色、妆容、发型、身材、完整服装和身份记忆点。
- **构图**：左侧 60% 为正面、90 度侧面、背面三张全身图；右侧 40% 为独立正面头颈面部细节图，面部占右侧高度 55%–60%，下方裁切至锁骨。
- **肤质与成像**：按 [清爽人物方法](cleanPortrait.md) 明确轻薄妆面、细微纹理、受光部位与柔和体积，不强制套未提供的“原句”，不凭真实感增加毛孔、黑眼圈或干皮。
- 缺少任意一项时禁止调用图像生成。

创建或写入人物图像节点后，必须重新检查节点提示词输入框：输入框内容必须与完整五段提示词一致；如果只显示一段简短概述，立即覆盖为完整提示词再开始生成。

### 1.4 生成不可用

图像生成不可用时，输出完整五段中文提示词并暂停，不得假称资产已经生成。

## 2. 场景与道具资产

按资产范围选择执行：

- "人物"：只建立人物三视图节点；
- "人物和场景"：建立人物三视图节点，并为剧情中的核心场景建立场景资产节点；
- "人物和道具"：建立人物三视图节点，并为剧情中的核心道具建立道具资产节点。

场景资产写清：空间结构、当前时间、天气、主光来源与方向、材质与反光、门窗入口、道路或车辆朝向、人物活动区域。道具资产写清：结构、材质、颜色、尺寸、初始持有人、佩戴或摆放位置。

## 3. 绑定编号与职责

资产生成完成后按实际生成顺序绑定：

```text
图片1＝角色一的人物身份、面部、发型、身材、服装与三视图参考
图片2＝角色二的人物身份、面部、发型、身材、服装与三视图参考
图片3＝核心场景的空间结构、时间、天气、光线与环境参考
图片4＝核心道具的结构、材质、颜色、尺寸与状态参考
```

规则：

- 图片编号按照实际生成顺序连续排列，不输出未生成资产的空编号。
- 后续分镜和视频提示词使用对应图片作为人物身份、服装、场景结构或道具外观参考；不把人物或道具资产的纯白背景、设定板排版和道具展示板排版继承到剧情画面中。
- 只在聊天中出现过的图片，不等于本次视频生成已实际接入。实际接入才使用原始资产标签并说明职责；未接入时把需要的信息写成可独立理解的画面，不造图片编号或写"看原图即可"。
- `{{ref N}}` 是本平台原生引用标记。先连接资产，再调视频节点 getConfig，按 references 的 marker/source/ready 绑定，不能猜 N 或只输入 @角色名。
- 三视图只在模型支持多参考模式时作为身份与服装参考；首帧模式使用单幅剧情关键帧，不能把白底设定板当开场。
- 资产锁定的面容、发型、体型和服装在最终提示词【故事前提与资产绑定】中只作简短绑定，不在每个镜头重复。

## 4. 资产一致性

- 场景、服装、道具的状态必须跨镜头连续：谁持有、放在哪里、是否穿着、是否在容器内、是否启用。
- 道具完成任务后写清去向，不让它突然消失或重新出现。
- 容易串用的情况必须正面声明：独立服装图可能被穿到人物身上；道具与人物服装属于同一品类；多张人物图可能交换身份或服装；场景图与人物图的光线、站位或服装不一致。
