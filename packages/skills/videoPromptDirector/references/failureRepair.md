# 生成问题诊断与修复

用户上传生成截图、视频或描述生成错误时，先对照目标与实际结果找到最小修改范围，再输出修订内容。本文件规定诊断顺序、常见问题与修复写法。

## 1. 诊断顺序

1. 查看完整视频和关键帧，按时间线比较"预期画面 — 实际结果 — 提示词歧义"。
2. 先区分：用户想保留的目标、实际生成了什么、哪些只是失败结果。不能把偶然串装或错误物件自动纳入规范。
3. 先用一小段说明直接原因，再输出最小范围的替换镜头。
4. 先修正文中的正向空间、动作和道具状态，再补充必要的局部负面约束。
5. 不因一次失败重写全部视觉设定，也不要用不断增加禁止项掩盖动作结构问题。

## 2. 常见问题与修复写法

| 问题 | 修复写法 |
|---|---|
| 人物身份、年龄、服装漂移 | 强化资产绑定与角色名锁定；写清年龄版本与当前服装；必要时锁定"身份、脸型、五官、肤色、发型和当前基础服装由人物资产确定" |
| 道具增减、变形、错位、瞬移 | 绑定道具初始持有人与准确位置；写清来源 → 持有人 → 位置 → 使用动作 → 下一镜状态；道具完成任务后写清去向 |
| 人物朝向、左右位置与空间边界错误 | 明确入口、目标方向、视线落点和确认速度；锁定位移方向与画面左右；写"队伍沿门外横向街道向画面左侧离开" |
| 背景人物重复、影子和虚影 | 正面声明已离开人物不再出现；写"背景仅保留空庭院"类唯一结果 |
| 动作失控、表演空泛 | 补人物目标、手上任务、触发、听者反应和回答前停顿；把抽象情绪转译为可见行为 |
| 接触后僵持 | 补完成态、松手和重新站位；不得让接触动作保持僵硬姿势继续长对白 |
| 对白错位 | 减少同镜说话人，明确一句一人、非说话者闭口倾听；写清说话者、准确台词、语气、音量和发生时间 |
| 物理状态夸张 | 限制滴水、抖动、奔跑、争抢等强度；写"衣物潮湿、有重量感，但不滴水""动作急而不慌乱" |
| 镜头单调/漂移 | 根据新观察内容增加必要切镜，不靠持续运镜制造变化；明确固定状态、运动幅度、方向和停止点 |

## 3. 局部修改范围

- 只修改导致问题的片段，保留未被新指令覆盖的剧情、对白、时长和资产。
- 分镜已经转换为视频提示词时，只更新受影响的分镜行与对应视频生成段，只输出受影响的替换时间段。
- 重新生成后必须回读节点输入框核对五板块标题与资产引用，确认替换已写入节点。

## 4. 修复案例沉淀

每次成功修复后，把"问题现象 + 直接原因 + 最小修复"记录为该题材的知识资产（题材包 references/repairCases.md 或本技能维护的案例清单），供后续同型问题直接复用；记录时注明该案例的生成模型与版本，不跨模型假定同样有效。

## 按证据定位原因，保留有效结果

“预期—实况”有证据才能确定缺陷；提示词歧义、错参考、适配器丢输入、动作容量和随机生成是不同候选原因。未取得请求或完整动态时标为待核，不把一次失败断言为某词触发模型机制。

| 现象 | 先查 | 最小修复与复核 |
| --- | --- | --- |
| 肤面蜡感/细节污染 | 原参考、光泽、景别、锐化/压缩与提示叠加 | 修对应来源，保年龄肤色和材质；不全局清除纹理 |
| 换机位房间重搭 | 母图覆盖、地标、世界坐标、实际构图输入 | 优先有效裁图/全景投影，补未知视角只作新设计并核对 |
| 反打换光、重光后换脸 | 光源坐标与当前朝向、编辑参考 | 保原身份结构，只改需要的光；调色不能修投影 |
| 交接未完成、物件瞬移 | 起态、手部占用、承托/松手、实际终态 | 修改对应接触阶段与依赖镜，不能仅写“更自然” |
| 深度/故事板变灰或成拼板 | 参考用途、适配器通道、裁切与输入顺序 | 用实际支持的控制/单幅参考，普通参考不承诺硬控制 |
| 声音或音乐接缝 | 原句、声音身份、实测时长、源入点与轨道重复 | 修音轨或同步路径，不无故重生已合格画面 |
| 局部修复后其他区域漂移 | 当前修复工具是否真支持蒙版 | 无蒙版参考编辑会重绘整帧，产出新候选并比较，不能称区域外绝对不变 |

同原因反复失败先改变有依据的方案，在原授权额度内修受影响素材。保留原图、成功镜头和版本关系；修复记录包含请求版本、模型参数、具体变化、观察结果及未验证项，多变量修改不宣称某一句话单独提高成功率。

## 原创例与反例的使用

适用与输入：已有可见缺陷时；输入失败媒体、原规格、实际请求和已采用版本。

写法示例：发现右手穿过杯壁，先定位接触区间并检查握持规格；按可用编辑能力修这一段。

反例：未看结果就把所有问题归因于模型，整片更换seed重跑。

约束与例外：本例只说明组织方法，人物、时长、数量与媒介须换成当前项目；不自动加入案例剧情。已有有效方案直接复用。

验收与修复：保留旧候选，对照修复前后及邻镜；未覆盖的声音或全段不能填通过。 本例未实际生成，不作为效果证据。
