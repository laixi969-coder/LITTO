# 节点创建与写入

用户已要求在画布制作且分镜与提示词已就绪时，直接配置所需节点，不重复询问；仅要文字提示词时不创建节点。本文件规定节点创建的循环、字段配置与回读核对规则。

## 1. 执行顺序（固定）

```text
确认生成段数量
→ 在节点外完成并校验 final_video_prompt
→ 对生成段循环创建视频节点，禁止对剪辑镜头逐行循环
→ 按顺序命名节点
→ 设置已确认或平台默认模型、画幅与该段实际支持的生成时长
→ 连接本段实际使用的人物、场景和道具资产
→ 支持 @ 提及时，通过资产选择器把对应资产作为原生引用实体插入第一板块
→ 将带有原生资产引用的 final_video_prompt 写入节点提示词输入框
→ 保存为可生成状态
→ 检查节点内容并报告结果
```

MILI MILI 执行：先 connectNodes，再 nodeTools 调 getConfig，核对 references 的 source/sourceHandle/dataType/ready；按返回 marker（`{{ref N}}`）调用 setPrompt。promptInput 会将有效标记显示为实体。再次 getConfig 回读 prompt 与 references；未连接标记会被拒绝，不能猜序号或只键入 @人物。

已有正式镜头 shotId 时沿用 productionSpec → compile → productionFingerprint，把人物、光线、表演和时间设计写入镜头规格；不能用 standalone 绕过正式镜头。五板块直接提交用于独立生成段，正式编译器不承诺原样保留五板块。

使用画布工具（`addNode` 创建、`connectNodes` 连接资产、`nodeTools` 调用节点注册函数、`getCanvasNodes` 回读）完成上述步骤。优先创建空白视频节点，再逐项设置模型、时长、画幅、资产与提示词字段。独立节点不再由代理另写内容；正式镜头必须使用 productionSpec 的真实编译请求，不把编译格式变化误判为非法改写，也不绕过规格生成。

## 2. 数量断言

```text
expectedNodeCount = 视频生成段数量
生成段划分同时检查时长、参考、声音与动作容量，规则见 segmentPlanning.md
实际创建次数必须等于 expectedNodeCount
```

- 一个视频生成段对应一个视频节点，节点数量不得少于或多于生成段数量。
- 10秒五镜可以合段，但须满足已选模型与当前设计的全部容量要求，不能只按时长断言节点数。
- 节点按"视频段01｜核心事件""视频段02｜核心事件"顺序命名。

## 3. 字段配置

- **模型**：沿用用户已选模型；未指定时回读平台默认和已授权能力，记录实际解析的模型与参数，不能自行改选“最高规格”，也不能把未解析的空白选择当作已确认请求。
- **时长**：使用该生成段的建议生成时长。
- **画幅**：使用项目已经确认的画幅。
- **资产**：只连接该段实际使用的资产；人物三视图作为身份、面部、发型、身材与服装参考，不把纯白背景和设定板排版带入视频画面。
- **@资产引用**：平台支持 `@` 提及时，必须点击或调用资产选择器，依次选择本段实际使用的人物、场景和道具；不得只键入普通文字"@名称"，不得只连接参考字段而省略提示词中的原生引用。每项原生资产引用只在【故事前提与资产绑定】的对应资产行出现一次；人物时间线继续使用角色名，不重复插入 `@人物`。
- **提示词**：整份带有原生资产实体的 final_video_prompt 写入节点提示词输入框，不压缩、不翻译、不改写、不拆散到聊天说明中。

## 4. 写入后回读

- 重新读取节点字段，检查每个资产引用的实体类型与目标资产 ID；界面只显示普通"@名称"文字、引用无法点击或目标 ID 不符，均判定为绑定失败。
- 独立五板块节点回读时核对五个固定标题；【镜头01｜时间｜内容】属于第三板块子标题。该协议下出现额外【正文】时合并回时间线。正式镜头核对编译请求及 productionFingerprint，不把它覆盖为五板块。
- 回读内容出现标题替换、板块增减、镜头摘要、正文重复或时间码丢失时，立即覆盖为 final_video_prompt 并再次回读，最多修正两次；仍不一致时停止，不启动生成，并明确报告节点写入失败。
- 确认节点名称、模型、时长、画幅、资产与提示词均已保存。

## 5. 边界与失败处理

- 用户只要求配置时停在可生成状态；已经授权生成则继续执行，不重复索要启动确认。未授权生成时不提交视频任务。
- 如果平台把"创建节点"和"开始生成"绑定为同一个不可分离动作，在调用前暂停并向用户说明会直接开始生成，获得明确许可后再执行。
- 如果当前平台没有视频节点创建或配置能力，不能假称节点已经建立；在对话中交付每段完整提示词，并明确说明节点未能自动创建。
- 部分节点创建失败时保留已经成功的节点，只重试失败部分，并逐项报告成功与失败状态。
- 全部节点配置成功后，只用简短结果说明已经建立的节点数量、名称、所用模型与节点状态；除非用户要求，不在聊天中重复粘贴已经写入节点的长提示词。
