# 视频制作的画布转换

本文件只说明如何把已确定的制作内容落实到画布。创作与生成路线统一遵循 [视频制作工作流](../../workflow/SKILL.md)，资产遵循 [资产制作](../../workflow/references/assets.md)，镜头与衔接遵循 [摄影与剪辑](../../cinema/references/shotLanguage.md)。工具调用见 [画布操作手册](../SKILL.md)。

## 0. 逐阶段协作

沿用用户已授权的范围，先完成可审阅成果；只询问未知且影响结果的事项，不重复确认已授权动作。生成、人工采用、批量扩展分别如实记录，沉默或工具失败不表示验收通过。

默认先保存镜头规格，检查并采用主关键帧，再生成视频候选。只有用户采用多镜片段且实际模型支持时才合并执行，保留各镜规格、起止状态与可剪区间。画布操作不另设默认模型、固定镜数、板式或时长，不绕过领域验收。

## 1. 读取现状

用 `getCanvas` 查看概览，用 `findCanvasNodes` 定位目标。已知 ID 时直接调用 `getCanvasNodes`，连接关系用 `getCanvasEdges`，节点能力用 `getNodeTools`。遵守分页与截断，按需查询，不读取整图详情。不猜节点类型、ID、端口或函数。

复用当前画布及已有合格素材，只补本次范围的缺项。不要为每一步都创建一个节点，也不要先批量建空节点。

## 2. 内容落位

| 内容 | 画布用途 |
| --- | --- |
| 剧本、镜头表 | 可编辑文本；不整段连接到每个生成节点 |
| 身份、服装、场景、道具参考 | 真实媒体输出，按当前镜头用途选择 |
| 关键帧候选 | 对应图片生成节点；实际采用通过制作入口完成 |
| 视频候选 | 对应镜头或已确认多镜片段的视频节点 |

创建节点后记录返回 ID，查询该节点实际函数，再填写内容和参数。已有节点直接修改。只有当前函数清单包含时才调用 `node:setPrompt`、`node:setConfig` 等函数，不将示例当固定接口。

文字已完成时直接写入，不必再次调用语言模型。已有媒体从真实文件或已有输出导入，名称和路径字符串不能冒充媒体。节点尚未初始化时保留节点，处理独立工作后再尝试，不删除重建。

## 3. 连接实际素材

先读两端真实端口，再连接兼容输入。连线表示媒体依赖，不表示审批或自动调度。生成前核对最终实际输入及编号，分清身份、服装、空间、构图、光色和动作参考。

角色展示板不等于单镜有效参考。需要裁脸或单格时，确认实际发送的是裁切图片。静态表情图不当作 PERFORMANCE 视频；普通多参考图不宣称为供应商原生首帧约束。容量不足时明确处理，不静默漏掉锁定参考。

独立片段不因时间先后连边。依赖前镜状态的后镜须核对已采用前镜的实际结尾，不能只沿用计划中的姿势。

## 4. 生成与交付

账号电影制作使用 `productionSpec` 保存并编译规格，带 `shotId` 和 `productionFingerprint` 生成。节点文本不替代领域规格和人工验收。工具缺失时说明实际能力缺口。

生成中不切换或删除可能中断任务的节点。任务 ID 只表示已提交，保留旧结果，通过实际状态查询确认完成；修改提示词不会改变已经发出的请求。不能把旧输出当作新版本。

完成后只核对受影响节点、引用与输出，按需 `fitCanvas`。只有用户要求整理整幅画布时才使用 `arrangeCanvas`。

分别报告已写入、已提交、已生成、已审看、已采用与已合成的内容。真实感检查须看实际输出；剪辑须播放接点前后并听音，不能用静帧或“电影感”词汇代替验收。
