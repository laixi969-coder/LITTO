# 顶级 CG 电影质感

## 单帧与系列

先写一个能直接拍出来的镜头，依次交代景别、人物、光源位置、主体运动、材质、环境和点缀色。银黑是这份风格的底色，冷白边光勾出轮廓。余烬橙、琥珀金、暗红、冷青择一，面积约占一成。已经采用的项目色板优先。

例如，雨夜高台的侧逆光半身像，人物向画面右侧回望。左后方顶灯穿过雨雾，湿发边缘亮白；一枚琥珀扣针映在衣领上。前景一片虚焦黑曜石移出画面，人物眼睛仍在焦内。用这种具体的光和材料描述代替只写「顶级画质」。

同角色系列可取正面半身、低机位半身、情绪近景、眼部特写、逆光全身、材质细节六镜。沿用定妆参考、脸型、年龄、发型、服装与标志物，每镜只改观察角度或动作。批量出提示词时给镜头编号；按编号返修。用户只要一张时交付一张。

## 从图片接到视频

读首帧并记录人脸朝向、头发或碎片的运动、主光位置和强调色。30 秒示例可分为 0–8 秒静中蓄势、8–22 秒展开动势、22–30 秒留余波。每镜安排一个主运镜，再写演员或环境的运动。举例，先缓推到眼睛，切远景让银色碎片沿首帧风向展开，最后拉远留出静止的人物剪影。

分段时逐段保留末帧构图、运动方向与声桥。画面过亮先缩小发光体面积，动作读不清先减少同镜运动，脸漂移则回到定妆近景并实际绑定身份图。导出给具体模型时只填写该模型支持的参数；分镜图、提示词和实际生成按用户指定的阶段交付。
