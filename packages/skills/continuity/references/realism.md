# 真实感：写行为，不写形容词

「8K、超写实、电影感、完美、高清大片、大师级」不是真实感方案，它们没有可执行的信息，还会让不同镜头各自「理解」成不同样子。提示词里删掉它们，换成下面这些可见的行为。

## 改写示例

| 空话 | 改成 |
| --- | --- |
| 电影感画面（夜/内） | 低照度夜景，台灯为主光从画左来，脸部侧光，背景自然暗下去，高光不过曝 |
| 电影感画面（日/外） | 天光为主光，按时段定色温，脸部顺光或侧光，背景保留层次与色彩，高光不过曝 |

改写示例按场景时段取光：电影感不等于低照度夜景，日景、室内白昼和清晨按当时段的实际光源写；单一暗调影调只在项目 Look 明确限定时用于对应时段的镜头。
| 超写实皮肤 | 皮肤有毛孔和细小纹理，高光处有自然油光，不磨皮 |
| 高清细腻 | 布料能看到织纹和自然褶皱，金属有克制的高光，木头为哑光 |
| 完美构图 | 人物在画面左三分之一，视线方向留白，机位在胸口高度，平视 |
| 动作流畅自然 | 先微蹲蓄力，重心移到前脚，起身时手臂略滞后，落地时膝盖缓冲 |
| 逼真光影 | 窗光从右侧进入，在地面形成斜长的光斑，人物脸另一侧有柔和补光 |

## 分层清单（按需取用，不要全塞进一个提示词）

**表面**：皮肤（毛孔、油光）、头发（发丝飘动与受光）、布料（织纹、褶皱方向）、玻璃（反射与透射）、金属（高光与环境反射）、木材（纹理与哑光）、水（折射与波纹）。

**成像**：曝光依据（以肤色为准还是保护高光）、动态范围（高光是否允许过曝）、暗部处理（保留细节还是压黑）、焦平面与景深（谁清楚、谁虚）、光学特征（轻微暗角、镜头呼吸、灯光眩光）、噪点（暗部可见细噪）。

**世界**：重力与接触（脚踩地、物体有落点与影子）、遮挡关系、物体恒常（物件不凭空增减）、比例（人与门、桌、杯的相对大小）、空间因果（雨落在哪、风吹向哪）。

**运动**：起势与收势、重心转移、加减速（不匀速）、惯性（松手后物体继续运动一小段）、二次运动（衣摆、头发、围巾晚于身体）、相机惯性（推拉摇平滑起止，手持有重量感）。

**镜头语言**：表演（情绪强度与视线）、站位（前中后景）、机位动机（为什么在这里）、镜头职责（这一镜负责交代、揭示还是反应）。

## 使用方法

- 每镜只挑 3–5 条与该镜相关的行为写进提示词，其余靠参考图和设定约束。
- 景深、光线、运动这三类最影响一致性：同一场戏的光线与焦段保持一致，写进每镜。
- 不确定某个效果模型能否做到，先查 `node:getConfig` 的能力；做不到的写进文字描述，并告诉用户。

## 手机自拍视频与生活感：有动机的不完美

仅在用户明确需要手机自拍、生活记录、UGC 或相似质感时使用；不把这套成像特征默认施加到电影、产品精修、动画或所有真人视频。

1. **先分清参考用途**：角色图锁五官、发型、衣服与饰品；场景图锁空间。外观参考不等于首帧，不能顺带固定参考图的姿态、构图和背景。实际绑定方式以模型能力为准，文字声明不能取消供应商的首帧输入约束。
2. **动作与机位形成因果**：写清谁持机、哪只手可用、起始距离、动作、构图变化及结束状态。例如“手持手机从胸前抬到面前，构图短暂偏移，对焦稍迟后恢复”。避免同一只手同时持机、拨发和拿道具。人物自然表演用视线转移、呼吸、重心变化等少量可见动作表达，不堆抽象情绪形容词。
3. **连续运动与剪辑分开**：拿起、放低手机是镜内运动；硬切、跳切是剪辑。明确采用哪种，不能既要求全程一镜到底又要求跳切。镜内变化保持人物、服装与空间连续；真实切点在剪辑阶段落实。
4. **成像瑕疵必须有触发与上限**：快速抬机时短暂拖影或失焦，低照暗部少量颗粒，恢复稳定后五官仍可辨。每镜选择 2–3 项即可；滚动快门、曝光/白平衡变化、磨皮、彩噪与压缩不全部叠加。把“保留轻微自然变化”写清楚，避免模型把手机质感理解成持续变形、闪烁和严重模糊。
5. **声音与动作对应**：衣料声、拨发声、脚步和室内底噪按画面动作选择；无对白不等于静音，也不等于人物跟背景歌曲做口型。音乐、音效、口型分别声明。已有音乐时沿用用户音轨，不擅自换成新歌。
6. **区分外观描述与真实参数**：“720p 手机观感”不是输出分辨率设置，“踩鼓点”不是准确时间码。查实际模型的分辨率、音频、多参考和多镜能力；不支持时用后期缩放、配音或剪辑实现，不能声称提示词已保证精确卡点。

编译顺序可用：参考用途 → 场景与光线 → 持机与表演 → 分段动作/切点 → 有条件的成像特征 → 声音 → 少量必要限制。沿用当前模型的提示词格式，不另套一套强制模板。不要复制案例里的性别、服装、亲密程度、音乐类型或固定 BPM 到其他项目。

验收看实际输出：身份是否稳定，手和手机是否合理，失焦是否及时恢复，轻微瑕疵是否仍保留可读性，音画事件是否对齐。可用相同参考和参数做基础版与少量成像特征版对照；未生成或未审看时，只报告提示词设计判断，不宣称质量提升已被验证。
