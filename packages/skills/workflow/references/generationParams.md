# 生成参数手册

生成媒体时的六个参数决定成片质量的底线。全部为工作区相对路径，缺省即不使用。

## 1. `shotSpec` —— 镜头规格

把一句散文拆成可执行字段。填了它，模型不必猜景别和运镜；留空则完全依赖 prompt。

| 字段 | 写什么 | 反例 |
| --- | --- | --- |
| `shotSize` | 大远景／全景／中景／近景／特写 | 「电影感镜头」 |
| `lens` | 35mm 浅景深／24mm 广角深焦 | 「专业镜头」 |
| `cameraMove` | 缓慢横移跟随，动机是人物走动 | 「运镜流畅」 |
| `blocking` | 人物在画面左三分之一，侧身朝窗，前景有桌角遮挡 | 「构图好看」 |
| `action` | 抬手把电笔贴上外壳，停两秒再收回 | 「他在检查机器」 |
| `performance` | 目标是想早点收工，听到异响先停手再抬头，反应慢半拍 | 「表情疲惫」 |
| `lighting` | 顶部荧光管做主光，冷白 5600K，右侧管壁反射暖金补光 | 「有氛围」 |
| `startState` | 首帧他背对镜头站在柜前 | — |
| `endState` | 本镜结束时他转身朝向走廊深处 | — |

一镜只承担一次动作转折。需要「推门→进门→看见仪器」三个转折时，拆成三镜或改用 15 秒长镜。

## 2. `cast` —— 角色档案

`assets/cast/<角色名>.json`：

```json
{
  "name": "陈砚",
  "identity": "26 岁东亚男性，短黑发，偏瘦，眉骨清晰，眼神疲惫但清醒",
  "wardrobe": "磨得发白的深灰工装，左胸口袋，袖口卷起",
  "references": ["assets/cast/陈砚-正面.png", "assets/cast/陈砚-全身.png"]
}
```

生成时传 `cast: ["陈砚"]`，服务端自动把参考图并入 `images`，并把身份说明拼进提示词。

**人物镜头没有 `cast`、`images`、`firstFrame` 或 `continueFrom` 时直接拒绝生成**——纯文本等于每镜重新选角，跨镜必然换脸。只有空镜、环境、流体、光效可以用纯文本。

## 3. `styleReference` —— 影调参考

传一张图，只借色彩、对比与质感，不借人物与地点。服务端会在提示词尾部追加 `STYLEONLY` 说明，并把这张图放在参考序列最后。

一张对的参考图胜过一万字描述。定一部片的调子，先找三张画面，不要写形容词。

## 4. `continueFrom` —— 续拍

传上一镜的视频路径，服务端抽真实末帧作为 `firstFrame`，下一镜继承空间、光向、人物站位。

同一场景的连续镜头默认用它。跨场不要用，会带着上一场的空间跑。

## 5. `composeFilm` —— 合成

镜头全部采用后再合成，参数 `{clips[], output, grade, targetLufs, headTail}`。

- 默认 `grade` 给 `contrast 1.05 / saturation 0.9 / grain 4`，目标是电影感，不是做旧；`grain` 超过 12 会明显噪。
- `targetLufs` 默认 −16，峰值压在 −1.5 dB，避免手机外放破音。
- 片头片尾的黑场用 `headTail` 豁免，否则自检会把它报成缺陷。
- 合成后自动跑整片自检，结果在返回的 `qc` 字段。

## 6. `qc` —— 体检

两种用法：

- 合成前 `{clips}`：逐段查黑场、削波、静音、时长偏差、画幅不一致、相邻镜亮度与冷暖跳变，以及饱和度／色相偏离全片均值的镜头。
- 合成后 `{file, headTail}`：查段间黑闪与响度。

**质检只报告，不自动重生成。** 黑闪、削波、冷暖跳变都能靠合成参数修，重跑镜头是浪费。只有身份不一致、动作没完成、构图跑题才需要重做，且每镜最多一次、全片不超过镜头数的 10%。

## 参数之间的顺序

`cast` → `images` → `styleReference`。影调图必须最后，`STYLEONLY` 的「最后一张」才指得准。

## 7. 导演影调：先推荐，再绑定

**不要让人从 198 位里挑。** 先调 `POST /api/ai/media/director`，默认走 `mode: "smart"`：
规则先粗筛 20 位 → 语言模型按剧本再选一次，给出「为什么是他」和「为什么不是他」，并指出像哪位导演的哪部作品。

只有明确要求快、或语言模型不可用时才传 `mode: "rule"`，退化为纯规则排序。

传一句创作意图即可：

```json
{ "brief": "2140 年，一座把最痛记忆当能源的城市，地下库廊里两派交火", "tone": "冷峻、高对比", "setting": "夜景" }
```

返回三位导演，每位带 `why`（这位导演的哪套影像语言适配本片的哪个具体条件，落到光与空间）、`likeFilm`（最像他的哪部作品）、`technical`（主光/高光/暗部/对比）、`palette`、`avoid`；另有 `excluded`（最接近但不该选的两位及原因）与 `ruleRanking`（规则排序，用于核对模型有没有跳出粗筛范围）。
把这三组连同理由呈给用户选，不列全库。

选定后写 `assets/look.json`：

```json
{ "director": "021_RidleyScott", "note": "全片影调：冷暗未来与霓虹暗金对冲" }
```

之后每次生成自动带上该导演的主色与占比、主光、高光与阴影偏色、对比度、avoid 清单，不用逐镜重复。

**一镜只用一个导演。** 换导演就换 look，不要在同一个镜头里混两套色板。
