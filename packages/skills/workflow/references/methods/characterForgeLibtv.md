# character-forge-libtv v1.4 · 角色创作

Mili Mili 主创作 Agent 负责这个流程。制作方法与派生图构图来自 [Character Forge LibTV 原稿](characterForgeLibtvSource.md)。执行使用当前项目的画布、模型和角色资产工具；原稿中的 CLI 示例和交付链接属于 LibTV 的宿主实现。

## 两次选片

第一次选择的是人设。只有文字方向时，在对话给 A–D 中的 3–4 位文字候选。每位交代姓名、用途、年龄感、三个面部辨识点、发妆、衣装和气质，并说清与其他候选的区别。此时不建节点或生图。已有选定人设可直接进入母版；已有库演员则沿用其定妆与项目资产 ID。

把选中人设的脸部结构、发际线、年龄、身材比例、衣装与三个辨识点写入各节点提示词。指定多份参考时区分主脸、肤质、表情、服装与光线。多个演员分别维护身份源。人物信息留在对话与资产中。

第二次选择的是实际生成的全身定妆图。首轮在画布建两列纯图片生成节点，左列默认两张 9:16 母版，明确要求更多选项时可做四张。头顶至鞋底完整，镜面竖直，A、B 只改变姿态、微表情和构图。右列同时预建下表三个节点。通过 getCanvasNodes 查端口，用 connectNodes 将母版 01 连到这三个节点。只在左列启动生成，右列等待选片。返回实际画布入口、母版结果及待选项；默认连线不代表用户已经选了 01。

| 右列节点 | 构图及内容 |
| --- | --- |
| 人脸近景 | 3:4 竖幅，头肩或胸上，大脸占幅；模型缺少此比例时可用 4:5。对照眉眼、鼻翼、发际线、皮肤与年龄。 |
| 九宫格表情 | 整张 3:4 竖幅，3×3 等格，每格都是同机位的大脸近景，浅色背景。从左到右依次为平静、微笑、认真、悲伤、惊讶、生气、困惑、委屈、沉思。 |
| 转面设定板 | 横幅，优先 16:9。左侧全身正、侧、背三视图，右侧半身正面、45°、侧面及辅助角度；逐格核对身材、衣缝、配饰与面部。 |

原版预设为 Image2、标准画质、2K。实际用 node:getConfig 确认平台已选模型和可用档位；node:setConfig 只传工具支持的模型、尺寸和比例。缺少单独的画质开关时如实说明。用户仅要求提示词或单张设定图时执行指定阶段。

## 换母版与交付

用户选 02 时，先读 getCanvasEdges，定位三个派生节点上来自 01 的边；用 deleteEdges 移除这些边，再用 connectNodes 接入 02。复查每个派生节点只有选中母版作为身份来源。母版有实际输出后，读派生节点的 node:getConfig，按 references 的真实顺序在 node:setPrompt 中使用对应的 {{ref N}}。同时核对实际连线、引用编号和母版输出。只改提示词不算换图。

派生图使用 node:generateImage 的 purpose=asset，查询 node:getGenerationStatus。单个节点失败时保留其他结果。用户指定的定妆和产出的派生图按本项目已有采用、角色资产和收藏流程保存；回读资产 ID 与定妆参考后，后续分镜沿用该身份。
