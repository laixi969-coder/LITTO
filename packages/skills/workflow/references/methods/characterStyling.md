# 妆造：按剧情与表演形式设计

用于角色妆发、服装搭配、换装、卸妆及持续外观状态的设计与修订。与[视觉设计](visualDesign.md)、[色彩与用光](colorAndLight.md)、[表演指导](../../../cinema/references/performanceDirection.md)共用现有资产和镜头规格，不另建制作流程。已有适用造型直接复用；仅做提示词时直接交付，不要求先生成资产。

部分参考分工、穿戴顺序与装饰层次方法经 GitHub 项目筛选后改编；固定版本及许可见[来源](characterStylingSources.md)。这些方法不代表模型能力或效果保证。

## 1. 从角色处境推导造型

先读本场人物要做什么、想让谁如何看待自己，以及已确认的年代、地域、环境与穿着条件。分开记录原文事实、参考图可见信息和设计提案。缺少考据时明确“风格化提案”，不把网络风格标签当历史事实。

需要选择方向时，给两套在轮廓、穿着方式或妆发重点上有实质差别的简短方案，说明各自如何支持人物；已选定或明确托管时直接细化，不强迫每人三套造型。每个方案只写本次有用的部分：

| 部分 | 可执行描述 | 检查 |
| --- | --- | --- |
| 妆面 | 肤面质地；眉、眼、颊、唇的颜色、边界、落点与轻重 | 保留实际肤色、年龄纹理与五官结构；不以修容重画骨相 |
| 发型 | 长短与分缝、收束位置、蓬松或贴合、固定方式及饰件 | 是否挡住要读的眼神，是否妨碍转头、奔跑、戴帽等动作 |
| 服装 | 内外层、轮廓、领袖衣摆、闭合方式、面料与主要色块 | 动作范围、承重与穿脱顺序可执行；不只写“高级礼服” |
| 鞋与配饰 | 必要物件、数量、身体侧别、固定点与取用方式 | 不自动要求成对；沿用既定单耳饰、缺件等不对称设计 |
| 观看重点 | 本场首先要认出的脸、动作、衣物或线索 | 装饰密度服从叙事；服装展示时也可让衣服成为重点 |

妆造能表达人物如何准备、保护或呈现自己，不凭性别、职业或性格规定唯一脸型与身体。相同世界使用相容工艺与媒介，不默认所有角色古风、浓妆、瘦身、露肤或做旧。同一角色换造型保持身份；不同角色的差异不能靠每帧换脸实现。

中性光主参考用于辨认本色和结构；正式镜头另查当前光源下的肤面反光、唇色、衣料高光及人与背景的区分。不能为显妆而擅改全片 Look；角色默认三视图按[资产制作](../assets.md)执行，全身图看不清眼妆时只补有用途的近景，近景不替代三视图。

## 精致写真人像：皮肤、妆发与搭配

用户选择精致写真人像、现代时尚人物展示，或提供此类参考图时使用；已选方向直接执行，不重复要求选风格。现代真人 MV 未指定其他人物质感时，可采用细腻肤面、设计完整的妆发与当代搭配作为初始提案；既定身份、年代、剧情状态及用户的纪实、粗粝或其他画风要求优先。不把精致等同于年轻、白肤、瘦身或固定服装。

| 部分 | 写进生成描述的控制 |
| --- | --- |
| 皮肤 | 肤色均匀但保留面颊、眼周与唇部的自然色差；细微纹理与景别匹配。额头、鼻梁、面颊高光柔和过渡，控制油亮与过硬反差；不刻意放大毛孔、皱纹或胡茬，不凭电影感增加粗糙、污损或颗粒。允许局部修饰临时瑕疵，保留既定年龄、肤色与身份特征，避免蜡感、塑料感及锐化颗粒。 |
| 妆面 | 明确底妆的薄厚与质地、眉毛边界和毛流、眼周层次、颊部颜色与唇色及润泽程度。轻妆同样有具体设计，不以修容重画骨相，不将疲惫、苍白或浓妆当作清冷的默认表达。 |
| 发型 | 写清长度与分缝、顶部和侧面的蓬松度、发束走向、鬓角及碎发；自然不规则有轮廓控制，避免整片油亮、贴头或机械排列。不把参考模特的脸混入发型要求。 |
| 穿搭 | 先定整体轮廓，再写肩线、腰线、内外层长度、衣摆处理、裤型、裤脚与鞋履关系；补充面料厚薄、垂坠、主要色块及少量配饰。职业或音乐类型不直接决定唯一套装，不只列衣物名称或写“年轻时尚”。 |
| 摄影 | 展示图使用可辨认本色的柔和光线，保留脸部体积、暗部信息和衣料层次；控制额鼻强反光、过深眼窝阴影与过度锐化。背景明度按肤色和衣物轮廓选择，不强制白底。正式镜头按当前场景重建光源，不复制展示板的灯光。 |

参考图先实际查看，分别提取上述可见关系；仅改变用户允许的部分。风格、妆发或穿搭参考不自动授权复制参考人物的脸、年龄、肤色和体型。按实际模型能力传入参考并注明用途；纯文本模式只说明已转译为文字，不能称已传图或已视觉锁定。

把本次有效的肤面、妆发与服饰控制写入现有资产属性和实际图片提示词；镜头制作沿用本文件的保存、编译与检查规则。不得只在聊天中描述审美而遗漏生成请求，也不把可更换的妆造写成永久身份锁。

验收分开看脸部与全身：脸部检查肤色过渡、纹理尺度、高光、眼周、唇部、发际线及身份；全身检查轮廓、搭配、面料、鞋饰与各视角一致性。用户选择“大幅面部特写＋三视图”时，特写和全身应保持同一身份与造型，各全身等高、头脚完整；全身图看不清的脸部细节不能宣布通过。实际图片未生成或未查看时，不能宣称质感已提升。

## 2. 先区分连续剧情与唱跳表演

| 内容类型 | 造型变化依据 | 一致性范围 |
| --- | --- | --- |
| 短片、电影、MV 的连续剧情段落 | 故事事件、合理时间经过或已定设定；不必每次拍出穿衣过程 | 同一时空内妆发服饰和持续痕迹接得上，时间或事件改变后使用相应状态 |
| 唱跳、舞台、时尚展示型 MV 段落 | 音乐段落、舞蹈编排、舞台概念、色彩对比或指定剪点 | 同一人物身份稳定，每套造型在指定镜头/时间块内稳定；段落或剪点可直接切换 |
| 剧情与唱跳交错的 MV | 两条线各自采用对应规则 | 叙事线按剧情接戏，表演线按造型编排切换，回到某条线时恢复它应有的状态 |

唱跳 MV 的多套衣服、妆容和发型是可以主动设计的表现手段，不要求编造换衣事件、补穿戴过程或用遮挡证明变化合理；造型数量与切换频率由音乐、舞蹈和用户方向决定，不设每镜换装配额。可在动作匹配剪接中直接换造型，保持舞姿或动作相位的设计意图；同一连续时间块内仍不能未经安排随机变衣、串妆或换脸。段内有意瞬变也须写清切换点及前后状态。

用简短编排表记录“音乐段落或剪点 → 造型名称/参考 → 妆发服饰差异 → 舞台/舞蹈任务 → 适用镜头”。先确定每套造型的职责和相互关系，不把同一套只换颜色当作必然足够，也不要求套套都完全不同。已定多造型方案不是未决候选，不应因一致性检查被退回统一一套。

### 连续剧情的状态继承

按故事顺序记录“入场状态 → 触发事件 → 可见变化 → 延续范围”。不同时间线、闪回与演唱舞台分别标明适用状态，不能按剪辑顺序把后来的湿发、伤痕提前带进回忆。

- 日常动作只产生局部褶皱或发丝运动；持续湿透、脱衣、改妆等才形成状态变化。流泪不必花妆，雨中不自动换妆容；是否变化及程度来自已定故事与材质方案。
- 换装不自动消除身体伤痕；卸妆不改变五官、年龄与肤色。无换装或修整事件时，不能在反打或切镜后自动恢复干净、完整。
- 剧情 MV 可用同一件衣物或妆面变化强化人物选择；叙事线的变化有故事依据。剧情开头仍要有可读的行动或问题；唱跳开头可通过鲜明造型、舞步、舞台与音乐落点吸引人，不强加剧情悬念。
- 演唱造型与剧情造型不同，先明确这是独立舞台、主观空间还是同一人物的另一时刻；不要让演唱切入抹掉叙事线的状态。

**教学例（非默认剧情）**：已定故事中，角色一边挽留对方，一边擦掉准备赴约的唇色。开头从“手已拿起纸巾却停住”进入问题；收到明确回应后才完成擦拭。妆造记录唇色的前后状态，表演记录试探、停顿与决定，后镜保留擦拭结果。不能只写“伤感红唇”，也不能让角色从第一帧就像已经听到结局。

## 3. 换装与穿戴动作

画内实际穿戴时，按衣物结构安排先内后外、先承重件后附属件；明确物件来自哪里、由谁抓握、在哪里接触或扣合、何时松手及最终位置。鞋、扣件和细小饰品动作过多时减少单段负担，拆分须符合用户镜头要求和模型实际时长。

剪辑换装可用有动机的切点或遮挡，不强制固定遮挡秒数、固定机位或每次都物理穿衣。明确允许超现实变身时沿用其规则。变化前禁止后态衣饰提前出现，变化后只继承仍有效的前态细节；衣物、头发和饰品的次级运动应由真实动作引起。

把造型与表演一起检查：厚领是否限制低头、长袖是否遮住关键手势、面纱是否遮挡口型、鞋履是否支持所需步态。调整服饰、景别或行动中最小的必要一项，不用增加表情数量弥补看不清。

## 4. 参考图各管什么

身份参考管五官、年龄、体型与肤色；妆发参考管指定部位的形状、颜色与质地；衣服参考管剪裁、面料与结构。绑定时用现有 role 和 notes 说明对象及边界：服装用 WARDROBE；妆发可用 LOOK 并限定到对应人物，不能覆盖项目全局影调。没有 MAKEUP / HAIR 专用 role，不虚构接口字段。

同一模特的服装照片不等于角色身份参考。实际使用的每个 referenceId 都说明用途；身份图中的旧妆旧衣与新造型冲突时，明确旧图只管身份，新图管当前造型。必要时制作并采用整合后的单一状态主参考，不能把所有套装作为当前造型同时喂给模型。

编译后核对真正送入的图片、用途及 degradations。超输入上限、模型不支持多参或图片缺失时不能声称已视觉锁定；文字描述可保留意图，但不是等价的像素约束。

## 5. 写入现有资产与镜头

不新增资产类型或 API。先用 productionSpec(read) 读取真实对象 ID：

- Character 的 invariants 只写适用的身份不变量；当场表情、临时妆容和将会更换的衣物不能写成永久锁。造型状态可写入现有 attributes.styling，内容为当前状态的 makeup、hair、costume、accessories 和适用场次说明；这些是属性约定，不是新增工具参数或自动校验器。
- 已独立成实体、需要复用或单独引用的服装使用 Wardrobe，attributes.wornBy 指向真实 Character 资产 ID。普通衣饰可留在角色当前造型中，不为每枚纽扣建资产。角色与服装两处出现同一信息时必须一致。
- 每套造型资产的 attributes 只保留该套有效造型，不把多套候选或全片编排表塞进去：编译器会将 attributes 全部送入提示词，不会按场次自动筛选。已定多套造型分别保存并按镜头选用；单段需要切换时，参考 notes 和 musicVideo.timeline 明确各套的适用时间，不能把它们写成同时成立的外观。
- 持续造型按现有变体/版本机制保存，保留旧态给此前场次使用。当前 productionSpec 的 asset 只创建草稿，不支持更新或 variant 操作；没有可用变体入口时，创建独立状态草稿并在描述中回链原角色和场次，不声称已设置 parentAssetId。Approved 对象不可覆盖。
- 镜头 assetIds 选本镜实际状态；画内变化明确起始与目标用途，不把两套状态当两个角色。action、performance.gesture/timing 写动作与反应，MV 同时写进 musicVideo.timeline；constraints 写禁止提前出现或无故复位的边界。
- intendedStateDelta 记录计划结果，不自动替代镜头动作：衣着归属用 characters[角色ID].wardrobeId，局部状态可用对应人物或衣物条目的 note；改变归属时使用已保存的 Wardrobe ID。起始状态由前镜继承，不能把本镜结束变化误当入场状态。以实际输出观察并采用的结果核对后镜。

当前状态引擎按 sequence 逐镜继承，sceneId 改变不会自动清除妆造。互不连续的舞台/造型单元或叙事时间线使用独立 sequence，再在成片时间线按歌曲编排交错；连续动作匹配与原曲位置另外明确，不拿叙事线尾帧硬锁新舞台的开场。单个生成段内切造型则写在本段 timeline，编译器不会仅凭“MV”自动解除造型约束。

保存并 compile 后逐项检查：当前造型在 ASSETDETAILS 或 Visual direction、参考分工在 referenceIntent、表演在 PERFORMANCE 或 Visual direction、变化时序在 ACTION / Timeline。起始状态不能成为全程冻结指令；明确变化也不能覆盖仍有效的身份锁。冲突时回到规格修正，不在自由 prompt 中偷偷覆盖。

## 6. 对抗式检查

逐项尝试让方案出错：只换唇色是否换脸；旧身份图是否抢回旧衣服；后态配饰是否提前出现；多套造型是否未分时段而同时生效；连续剧情的反打是否自动复妆；舞台装是否污染剧情时间线；变体是否忘记旧伤；面纱是否让口型要求不可见；把“克制”写成全程无反应；身份锁是否禁止已计划的卸妆；唱跳 MV 的计划换妆是否被误判为穿帮或强制补拍穿衣。

分别报告文字规格、真实请求和媒体效果的检查结果。静图只证明可见造型，不能证明动作、演技、口型或跨镜连续性；没有实际视频就保留未验收状态。

## 按作品与镜头用途核对造型

此入口覆盖电影、短片、广告和 MV，不以“现代真人 MV”作为读取妆造方法的唯一条件。先沿用原稿、已采用人物和用户视觉目标；肤面、眉眼唇、发型收束、服装轮廓/剪裁/面料及配饰分别设计，缺项仅作提案。下面是检查重点，不是强制风格或换装配额。

| 当前用途 | 优先核对 | 避免自动追加 |
| --- | --- | --- |
| 叙事电影、短片、剧情广告或剧情 MV | 年代与场合、角色准备程度、动作范围、同场造型连续性 | 以职业、悲伤或生活压力推出胡茬、疲态、旧衣或污渍 |
| 美妆、时尚与人物宣传 | 已选肤面质地、妆色落点、发际线与整理方式、服装廓形；近景与全身相容 | 把精致等同于年轻、白肤、瘦身，或每次都加浓妆和礼服 |
| 产品使用与生活方式广告 | 穿着便于操作，袖口、手部与配饰不遮产品；人物与品牌色层级清楚 | 为真实感做旧，或让人脸、衣服、环境同时变成品牌色 |
| 舞台、演唱与概念展示 | 用户已选的造型重点、段落/镜头适用范围及本套身份稳定 | 因允许多造型而随机换脸、串妆；把舞台光色当作肤色和衣物本色 |

身份参考、妆发参考、服装参考分别注明只控制什么；全局色调参考不负责重画五官，衣服照片里的模特也不替换角色。正式镜头结合[色彩与用光](colorAndLight.md)复核肤面反光、面料高光、背景分离与产品可读性；不把资产三视图的中性展示光照搬到剧情镜头。

采用前分别核对实际人物图中的身份、妆发、服装结构、材质状态和正/侧/背视角，再核对当前镜头所用造型。发现偏差时定位是身份、造型、受光还是后期色偏，修正相关描述与参考用途；不能用“更高级”掩盖不明问题。只有真实图像或视频可验证效果，规则齐全与请求已发送均不等于结果合格。
