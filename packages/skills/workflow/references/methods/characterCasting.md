# 选角、人物生成与摄影呈现

用于电影、MV、广告及独立角色设计。与[资产制作](../assets.md)、[妆造设计](characterStyling.md)共用现有资产和镜头入口，不创建第二套人物档案。已有角色直接复用，只补本次缺项；不强迫用户填写完整小传或手动选择 Skill。方法来源与取舍见[来源记录](characterCastingSources.md)。

## 全局默认：干净、完整、清晰

人物、服化道和场景默认整洁、完好、符合年代与用途；曝光让重要人物、动作和物件可读，成像无额外重颗粒、噪点和浑浊。不从电影感、悲伤、曲风、历史、职业或社会地位推导脏旧、破损、疲态、伤疤、阴暗或失焦。自然纹理、指定年龄和正常衣褶保留，不以磨皮、去龄、过锐或全画面同焦换取清晰。

例外只能来自用户明确要求或已确认的剧情/状态，说明对象、属性和生效范围。“旧皮箱”不做旧人物衣服；“夜景”不改成白天，也不默认压黑人脸；“老人”保留年龄，不附加邋遢。仅借参考图的构图、妆发或光线，不自动继承其污损和颗粒。已成立的损伤连续状态不自动复原，明确换装和状态变化也不被默认规则阻止。用户纠正时修改冲突的原描述，不在末尾追加相反形容词。

## 1. 从用途提炼选角依据

先沿用已有设定，把角色在作品中的任务变成可见要求，不用好坏、性格或职业规定唯一脸型。只处理与本次角色有关的世界、时代、行动与关系，不为一张人物图编造创伤史。

| 用途 | 选角依据 | 按需验证 |
| --- | --- | --- |
| 电影、剧情 MV、剧情广告 | 已定目标、关系、外在表现与内在矛盾，人物需要完成的行动 | 具体台词的潜台词、倾听、反应与动作；沿用原文，不擅加对白 |
| 演唱、舞台、概念 MV | 歌曲情绪、视觉意象、轮廓、身体表现与造型编排 | 指定动作、表情转换与服饰运动；按音乐段落换造型，身份保持 |
| 品牌、时尚、产品与生活方式广告 | 品牌气质、受众和真实使用场景，人物与产品的观看层级 | 穿戴、拿取或使用产品是否自然；手、袖口和配饰不遮关键结构 |

混合项目按段落调整重点；不把广告一律做成华服写真，也不把电影一律做成粗粝人物。二维、动画与特殊物种沿用指定媒介，不强制真人摄影。

## 2. 候选比较与面部设计

用户需要选角或方向未定时，先提出少量有明确差异的文字候选，各写“适合的原因、可见区别、需要验证的点”。已有明确形象直接设计，不自动增加候选图片或试镜费用；数量、模型与生成范围沿用现有授权流程。

候选差异从脸部长宽与颧颌关系、眉眼间距、鼻唇比例、体型轮廓、姿态和造型中选择。不靠同一张脸换衣色，不为记忆点强加伤疤、污迹、衰老或夸张缺陷。多人同框并看身份锚点与轮廓，亲属关系按设定保留，不机械要求所有人毫无相似处。

有参考时实际查看并记录用途：面部结构、妆发服装、场景摄影分别控制什么。原创人物可综合不同来源的可见结构，不让一张风格图中的模特主导所有候选；指定同一人物时不再重组其脸。没有素材可以先交设计提案，不能声称已完成参考锁定，也不强制用户搜齐固定数量的素材。

选定后只把采用的身份锚点、当前造型与真实参考写入资产。候选比较留在制作说明，不塞进会全部编译的 attributes。沿用[资产制作](../assets.md)的一张四视角设定图约定；候选预览按批准范围执行，不为每个未选候选自动生成全套资产。面部细节由同张图的正脸特写呈现，不自动追加生成。

## 3. 身份、造型、摄影、当场状态分开

| 层次 | 现有保存位置 | 边界 |
| --- | --- | --- |
| 人物身份 | Character.invariants、描述及已采用的身份参考 | 稳定面部结构、年龄、肤色、体型；不锁死表情和姿态 |
| 当前造型 | attributes.styling 的 makeup/hair/costume/accessories；独立服装用 Wardrobe，wornBy 指向真实角色 ID | 每套只保存当前有效状态；换装不换脸，不把全部候选同时发给模型 |
| 摄影呈现 | Look、camera、lighting、realism；参考 binding 的 role/notes | 明确只借光照、构图或成像，不覆盖已定身份、服饰、场地与时段 |
| 当场表现与变化 | action、performance、musicVideo.timeline、intendedStateDelta | 表情来自事件，变化在指定时点生效；计划结果不是已观察结果 |

道具按现有 Prop 资产和状态记录持有人、位置、尺寸及固定方式，可在人物间传递；广告产品沿用 Product。不为普通饰品新增实体，不虚构新 API、造型自动筛选器或变体字段。具体读写、已采用资产保护与不同 sequence 的状态边界依[妆造设计](characterStyling.md#5-写入现有资产与镜头)。

## 4. 摄影参考转成可执行方案

先拆出光源位置、方向、曝光、反差、色温、高光、焦点、景深和构图层级，再写人物动作。身份参考只负责稳定五官，当前事件决定眉眼、视线、嘴角、呼吸和身体反应，不复制中性定妆表情。妆发、衣饰、场景、摄影参考各注明允许改变的部分。

系列画面共用已定身份和摄影原则，每张只写当前机位、动作与场景差异。换机位时保持光源在世界空间中的位置，重新推导受光和遮挡；背景有丰富元素不等于每层都清晰。皮肤纹理与妆面反射分别描述，允许明确选择的高光妆面或直闪，不以真实感强制磨砂皮肤。

局部修改保留已采用资产；修正身份或风格漂移时回看原始身份主参考及本次摄影参考，上一轮失败图只作问题证据，不能悄悄升级为身份母图。连续动作仍使用实际首尾帧接戏，同时用原始身份参考核对累积漂移，不禁止用户明确要求的局部图片编辑。

## 5. 试镜与验收

试镜只在任务需要且生成范围已授权时进行，不为单张人物图额外生成视频。先明确这次要验证的能力，再用简单场景、可见动作或已有台词观察；电影查反应与潜台词，MV 查身体与造型运动，广告查产品互动。声音和动作习惯仅在有依据时沿用，不强加眨眼、哭泣、口吃或粗粝颗粒。具体表演使用已有[表演指导](../../../cinema/references/performanceDirection.md)。

生成前核对实际 prompt、参考编号与用途、输入上限及降级；缺失图片不能以文字宣称视觉锁定。出图后分别看身份、多人区分、身高比例、妆发、服装结构、道具归属和摄影可读性。未经要求的破损、脏旧、暗黑人脸和重噪点均记为偏差；例外按对象与时间范围对照，不把自然年龄、合理夜景、景深或已确认剧情状态误判为缺陷。

失败时先定位身份、造型、参考串用、受光或成像中的问题，只改受影响项，保留其他已采用资产。不以更清晰的错脸替换正确身份，不通过全批重做掩盖局部问题。静帧不能证明演技、声音、运动和跨镜连续性；没有实际媒体观察就保持未验收。
