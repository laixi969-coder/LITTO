# 按镜头选择光照方案

需要把窗光、逆光、道具光、舞台或产品布光落实到具体镜头时读取。通用设计与检查沿用[色彩与用光](colorAndLight.md)，已有合适布光直接继承；每镜只提取有用的关系，不把本表整段送入生成模型。

依据用户提供的《20套光照参考.doc》独立归纳，结合[第 2899 课](https://www.super-i.cn/info-2899.html)的既有正文研究；摄影术语核对 [ARRI 照明手册](https://www.arri.com/en/learn/lighting/lighting-handbook)。这些是可选设计，不是经过当前模型验证的预设参数。

## 五种打光先拆维度

正文的侧逆光、轮廓光、侧光、硬光、近身道具光可以组合：方向、职责、阴影软硬和光源距离分别决定画面。侧逆位置可以形成轮廓，近身道具也可以从侧前方投出硬影；不做互斥五选一。

| 想控制什么 | 本镜需要写清什么 |
| --- | --- |
| 侧逆方向 | 光源在人物侧后哪一处，照到发丝、肩或透光衣料的哪些区域；暗侧是否需要环境反射 |
| 轮廓分离 | 需要与背景分开的边界及其宽度、强弱；允许边缘被遮住，不给全身贴恒定发光线 |
| 侧向塑形 | 脸朝向、主要亮面与暗面、必要可读信息；侧前光不必刚好半脸明暗 |
| 硬光投影 | 投影方向、边界与遮挡物；产品标签和玻璃高光分别处理，硬光不等于加大亮度 |
| 近身道具光 | 发光物的高度、距离、照亮范围及移动后的变化；靠近人物不等于从下照 |

## 20 个方案的选用条件

先读当前时段、天气、空间和已经存在的光源，再从对应行取需要的控制。没有剧情依据时，不为套方案新增雨、雾、湿地、灯具或人物动作；情绪不能直接决定光色。

| 方案 | 适用条件与受光设计 | 本镜要防止的偏差 |
| --- | --- | --- |
| 窗边柔光 | 已有窗户提供较大有效光面；按窗与脸朝向安排亮面，室内墙地反射回填暗侧 | 窗位置随反打翻转；人物转身后脸仍按原方向受光 |
| 顶部天光 | 露天或真实顶部开口；上方天空照亮头肩，眼窝受光按遮挡与周围反射判断 | 在封闭室内凭空加天窗；上方有光就要求眼睛必有高光 |
| 阴天漫射 | 已定阴天，天空形成广域柔和照明；保留轻微形体层次与材质差别 | 把低反差误判为假，擅加硬太阳、暗场或强描边 |
| 黄金时刻逆光 | 低角度直射暖阳仍可到达人物；受光边缘与环境反射分别设计 | 太阳已落或被挡仍保留直射；把所有皮肤和衣物染金 |
| 清晨薄雾 | 已确认清晨有雾；按入射方向、散射和远近关系组织空间 | 为显示光束新增雾；薄雾让近景身份、道具全部失去细节 |
| 月光夜景 | 已有月光能经过开口或露天到达主体；选择必要亮区与剩余环境光 | 把冷蓝当月光固定本色；无窗密室凭空照亮整张脸 |
| 烛光 | 蜡烛在近处且未被挡；局部照亮靠近火焰的脸、手或纸面，远处逐渐变暗 | 小烛火无衰减地照亮全屋；烛台位置与鼻影方向矛盾 |
| 灯笼光 | 已有灯笼的位置、罩材与开关状态明确；透过灯罩的光覆盖附近区域 | 灯笼在背后却直接照亮正脸；手提移动后亮区固定不动 |
| 火光 | 火堆、火盆或火把真实存在；邻近表面受光有相容的局部明暗变化 | 整个画面随机闪烁；自动加入烟尘或改变剧情火势 |
| 霓虹侧光 | 已有招牌或彩色灯源；不同朝向表面接收对应色光，保留人物与商品识别 | 无依据增加湿路面；衣服本色随彩光永久改变 |
| 雨夜路灯 | 已定下雨与路灯；按灯位、伞的遮挡和湿材质分别安排受光 | 伞下脸无来源地自亮；被屋檐遮住仍全身淋湿 |
| 车灯逆光 | 车灯的高度、朝向、人物距离和遮挡明确；按实际入射范围设计边缘与地影 | 低车灯自动勾亮整个发顶；无雾空气中强行画实心光柱 |
| 舞台追光 | 已定舞台灯位与照射区；需要跟随时说明灯斑如何随表演移动 | 人物离开灯斑仍全身同亮；为追光必加烟雾 |
| 聚光硬光 | 小有效光面或明确的硬边设计；分别确定光束覆盖区和投影软硬 | 把聚光范围、亮度和硬影混为一项；高光吞掉关键物件 |
| 轮廓剪影 | 需要隐藏面部、保留姿态或身份轮廓；决定全剪影还是少量暗部可见 | 一边要求全剪影一边强填五官、肤质和双眼高光 |
| 高调棚拍 | 明确需要明亮、低反差展示；大面积柔光与背景曝光共同保留形体和本色 | 把高调等同纯白过曝；为了去 AI 感改成强侧光暗背景 |
| 低调暗场 | 需要控制观众能看见的信息；限定脸、手或关键道具的亮区与允许隐藏处 | 把整帧压黑；剧情要求辨识的表演与线索不可见 |
| 反射补光 | 已有入射源与墙、地或反光板；从反射面方向柔和回填指定暗部 | 补光凭空产生、强过主光或投出冲突的反向硬影 |
| 水面反射 | 入射光、水面与接收面确有可达路径；需要动态纹理时与波动相容 | 只因场景临水就给脸加流光；让水反射同时负责互相矛盾的主辅职责 |
| 双色分离 | 两处光源或明确的风格化设计已确定；按各自位置控制照射区和主辅层次 | 机械左右各半染色；双色覆盖人物肤色、标签与品牌识别 |

补光、眼神光、背景虚化、雾与光晕都按当前镜头需要选择。眼神光取决于光源、视角与遮挡；有意剪影或背向光源时可以消失。不要从某个名称自动添加固定眼神光、45° 主光或正面补光。

## 合入现有镜头与提示词

正式镜头继续使用 productionSpec 的既有 lighting 字段，不新建光照协议：

- `worldSource`、`motivatedLight`、`practicals`：说明实际光源、世界位置与可见灯具；`keyDirection` 只记支持的粗方向，细节写入 `key`。使用 `directionSpace` 区分世界与屏幕方向，反打后不移动世界光源。
- `key`、`fill`、`negativeFill`、`exposure`：写主要受光区、阴影过渡、暗部信息和主体与背景关系；材质响应进入 `realism.surface`，综合色彩沿用 Look。
- 开关灯、遮挡或持灯移动写入已有动作与唯一时间线；`intendedStateDelta.lighting` 记录必要末态。静态 `lighting` 不得与这些变化相反。

普通素材的 `shotSpec.lighting` 用一段相容描述；独立五板块写进「画面质感与光影」，动态变化放进原有时间线，不再贴一份方案库。

**原创示例**：既定夜间书桌上，烛火位于人物左前方，照亮靠近火焰的手和信纸；脸暗侧只接到桌面微弱反射。手移到烛火与信纸之间时，纸面出现相应遮影，移开后恢复；背景保持夜间层次。是否需要看清面部按本镜信息任务决定，不额外补一盏正面灯。

生成前核对实际编译请求与参考分工；生成后看实际光源动机、投影、材质和邻镜方向，视频还须看遮挡与移动过程。上述示例未运行生成，不代表效果已验证。
