# Seedance 镜头执行

仅在用户或实际节点已选择 Seedance 后读取；不替用户选模型。当前供应商的模式、时长、参考容量与声音能力以 listMediaModels / 真实节点为准，不把版本名称等同于固定上限。切换模型保留创作规格，按新能力重新编译。

本文件只负责把已定创作转成当前镜头请求。表演用 [performanceDirection](../../cinema/references/performanceDirection.md)，摄影用 [shotLanguage](../../cinema/references/shotLanguage.md)，MV 的故事与音乐编排用 [musicVideoDirection](../../musicfilm/references/musicVideoDirection.md)；按本镜缺口读取，不整包叠读。画布执行沿用 [canvasExecution](canvasExecution.md)。

## 1. 先完成可拍的戏，再编译

事实源是用户最新明确要求、已采用剧本与资产，以及明确托管范围内形成的创作方案。只有梗概时，在既有授权内完成场景、对白和调度；不要直接把梗概做成旁白加微动图片。未经采用或授权的旧提示词不能升级成剧情事实。

剧情事实包括事件因果与结果、人物关系与知情、重要道具归属，以及明确锁定的动作、位置和声音。导演可以为既有目的设计未锁定的表演策略、倾听反应、距离、走位与摄影覆盖；不必要求原文逐字写出这些执行动作。不得借此新增前史、关键道具、角色动机或改写结局。新增对白或改变因果先回剧本修订，生成请求不临时加戏。明确沉默、画外、静止、一镜到底或固定站位时沿用。

每个节拍明确“谁想对谁做什么 → 阻力或触发 → 可见行动/真实对白 → 产生的变化”。普通剧情按实时行动设计，停顿保留倾听、判断或悬念的作用；慢戏、静态作品及非线性叙事服从已定意图。镜头时长由观众读懂行动、信息与反应需要决定，不靠慢推、呼吸、眨眼、衣发微动填满时长。旁白只执行原定功能，不能接管本应看见的冲突。

## 2. 全片记录与本镜执行分开

制作记录保留完整源节拍、剧本版本、知识状态、场次与时间变化、角色档案、资产库和全片段表。长片可以分批交付，但全局节拍映射和呈现顺序不能每批重置。检查覆盖时区分同一节拍的连续拆镜与重复事件；合镜不跨越需要保留的时空边界，不为最少段数挤掉对白或动作过程。

当前生成只取本镜实际可见/可听的内容：

- assetIds 记录本镜关联资产；visibleAssetIds 指定本镜某时刻实际出镜的资产，包含稍后入镜者，排除只发声者。旧镜头省略时沿用 assetIds，空数组表示没有这些资产出镜。
- camera.design.start 单独写第一瞬间已在画内的人物、姿势、位置、朝向、持物和接触；稍后入镜写进 action / timing，不能预先站在首帧里。
- 只在对白出现的人保留原句和声音来源，不附全身造型、站位或身份图片。画内说话与画外说话按该句实际安排填写 lipSync。
- 角色 attributes.characterDirection 是导演参考：从长期习惯选出适合当场目标的行为，再写入 performance；声音习惯只为正在发声的人写入 delivery。不整段贴人物小传、关系和未来知情。
- 全量状态账本可以保留离场角色。请求只继承当前资产的起始状态与相关服装；不把本镜计划结果或下一场状态当作起点。历史状态中的 present 不等于当前画面出镜。
- 参考库、研究分析、候选方案、验收标准、修订理由与备用方案留在制作记录，不发给媒体模型。只引用本镜需要且真实存在的参考 ID，不能写“同上”或编造句柄。

同一事实只找一个主要承载字段。action 写行动链，performance.gesture 写人物策略与身体证据，performance.timing 写反应触发与先后；已有 musicVideo.timeline 承载时序时，不在其他字段逐段复制。删掉旧的冲突句再写正确方案，不在尾部追加例外。

## 3. 空间先于摄影

先锚定门、窗、桌等既有场景位置，再写每个出镜者的位置、身体朝向、目光对象和必要的持物/接触。人物路径与摄影机路径分别设计，谁从哪里到哪里、为何移动、何时停下要读得清。允许有目的的静止，不能靠摄影机移动冒充人物行动。画外人物何时入镜由节拍决定，不自动补齐合照。

世界方位与画面左右分开：反打可改变屏幕方向，但门窗、光源和人物在世界中的关系不跟着镜头翻转。越轴通过可见的移动或重新建立空间完成；body facing、gaze 与 screen direction 不混作同一方向。

摄影选择跟随观众需要获得的信息：写观看距离、主体占比、背景关系、焦点与景深的可见结果。焦段附带意图，不把器材数字当精确模拟。运镜写起点、触发、路径、速度变化和停点，推轨、摇镜、变焦分清；一个关键反应已能成立时可以固定机位。

主光锚定世界中的窗或灯，屏幕光向由机位和人体转向产生。沿用当前 World/Look、时代、维护状态与造型。自然皮肤、材质粗糙度、接触阴影和合理曝光支持真实感；不自动加脏损、衰老、烟尘、暗噪，也不以清楚为由消灭阴影、磨皮或要求所有景深同锐。已设计的逆光、剪影与风格化媒介保留。

## 4. 表演、对白和物理过程

按角色分别写当场目标、策略与可见证据，听者在收到线索后反应，背景人物保留自己的注意对象。反应尺度适合景别；不要求每人同步点头，不机械规定微表情数量，不把强势等同安静、情绪等同低语。持续倾听、目的明确的等待也可推进戏，不额外给每个人塞道具或秘密。

对白原句、说话人、顺序和既定声音通道保留。声音身份稳定，语速、停顿与语气服务当场目的；尽量按真实录音安排时长，未录制时说明估计。字幕不是发声，也不能证明口型同步。模型不能原生发声时落实已有后配音/对口型路径，不删掉台词规避能力限制。

因果动作保留接近、接触、施力与反馈；可以省无关准备，不能只写两个终态让人物或物体瞬移。持物要有真实入口、抓握与支撑，攻击要有接触点、受击位移和后续选择。紧张动作按有效攻防推进，不轮流等待或每击回中性姿势；也不把所有戏都拍成打斗。实时是默认速度，重量不自动等于慢动作。

换装、卸妆、损坏与道具消耗只在既定节拍发生；锁定身份和未变化细节，不能把整个起始状态锁死。MV 已定的舞台/造型转换可按音乐或剪点发生，不补换衣前史、不把上一个舞台服装和尾帧强锁进下个舞台。原曲区间、音乐与声音方案沿用已定意图，不能用普通剧情的无额外配乐默认值静音 MV。

## 5. 保存、编译与实际投喂

账号制作复用 productionSpec：

1. read 已有 World/Look、资产、镜头与参考。新增或修改镜头时写入 action、visibleAssetIds、performance、blocking、camera.design、lighting、creativeBrief 和 intendedStateDelta；source 保存所依托的已采用剧本来源。已有可用设计直接复用。
2. camera.design 保存 technique/purpose/start/end/subjectPath/cameraPath/timing/cut/invariants/acceptance/fallback。起始画面用于静帧；行动、表演、路径和时间用于视频；跨镜剪点、验收标准和备用方案只供制作流程使用。静帧不执行未来动作列表。
3. 用 reference / binding 保存实际参考及用途。身份图约束身份，衣装图约束衣装，位置图约束空间，不带入参考中无关的人或物；脸部裁剪不决定身材。文字与节点名不能替代真实图片输入。
4. compile 使用实际模型与模式；读取真实发送的 references、warnings 与 degradations，generate 使用同一请求与 productionFingerprint。不要复制导演分析作为另一份自由 prompt 覆盖编译结果。

视频从已采用本镜主帧开始；原生首帧与普通外观参考有不同能力，不把后者说成精确首帧控制。单镜生成、素材长度与最终剪辑长度分开：按实际接口选择足够时长，并为剪接保留有用余量，不把生成上限当每镜固定长度。数值轨迹、声音和尾帧仅在实际接口支持时使用。

动作参考视频只能在当前供应商和模式实际支持时发送，逐项指定只借动作、机位或视觉属性；参考视频本身不证明首帧接续、身份一致或逐帧复刻。接口只支持首帧图时，沿用实际图像和文字动作，不伪造视频引用句柄。角色、身体、兵器或镜头发生互相覆盖时，先定位是编排、摄影还是参考的问题；保留其他条件，优先改动最相关的一类并对照新输出。没有可信样本时，不按固定的每秒动作数或固定镜数声称模型容量。

所有时间为本段局部时间，从 0 到 generationDuration 或 duration；跨镜衔接读取前镜真实末态。跨场返回可用 continuityFromShotId 指定同序列更早镜头，时间跳跃不自动继承最后一个同名场景。只有计划时须标明待实测，不能把 planned state 称为观测结果。

## 6. 模型文本组织

Seedance 2.0 使用简明的本镜资产/空间、按时间的画面与动作、光线和声音描述。Seedance 2.5 可用下列自然语言组织；它是提示词结构，不代表供应商提供对应的硬控制接口：

Objective: 本段可见任务。
Reference binding: 实际输入句柄及简明用途；没有参考就省略。
Immutable locks: 身份和本段真正不能变的条件。
Target duration: 实际选定秒数。
Timeline: 每个局部时间块一段连续画面描述，包含该时刻必要的动作、反应、对白、物理反馈和显式切镜。
Visual direction: 当前机位、空间、光色和材质关系。
Audio direction: 原文对白、环境、拟音及已定音乐/无声方案。
Preserve / Avoid: 本段最容易漂移的少数内容，不重复锁定项或堆通用负面词。

时间块数量随剧情，不按秒平均填满、不强制固定镜数。对白与节拍只需出现一次；编译路径已在 DIALOGUE 保存原句时，时间线以动作与说话时点定位，不再抄整句。对用户直接交付完整文本时把原句放在发生的时间块。正式请求不包含全片总览、知识账本、E## 审计表或“下一镜将会”。

后期字幕和标题留给剪辑；实体文字、产品包装文字按已采用资产呈现，不能擅改品牌或声称文字绝对不出错。不开额外配乐、慢动作、字幕或切镜，除非当前方案已要求。

## 7. 精修与交付

先判断是剧本/表演/调度问题、图像局部缺陷、剪辑接点还是声音问题，复用对应的现有修订、入出点和声音工具。剧情不成立时先修规格，不能靠反复补画脸和手解决。

图像局部精修通过 image 请求 localRepair{keyframeId,kind,target:{assetId?,region},note?}，同时传 shotId：先 compile，generate 复用同一请求与指纹。region 写实际对象及部位，例如“画面左侧角色握杯的右手”，不能写“所有手”。原图作为唯一图像输入，提示只写 CHANGE 与其余 PRESERVE，不重讲整场戏；每次处理同一明确缺陷，不扩大到其他人物。必须使用能接收原图的编辑模式，纯文生图不可替代。无蒙版时明确属于参考图编辑，区域外可能漂移，不能承诺像素级不变。

精修产物保留为新候选，原图保留。实际对照后复用关键帧检查与采用流程，不自动顶替 Hero。视频须看完整动作、剪点和声音；抽帧、静图、文字符合和接口成功都不等于演技、口型或成片质量通过。批量生成与付费重跑服从已有授权，不因方法清单自行加轮次。
