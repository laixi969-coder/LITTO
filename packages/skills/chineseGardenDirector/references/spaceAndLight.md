# 空间取景与光线

园林画面的问题几乎都出在两处：**空间读不出来**（观众不知道人在哪、离镜头多远）和**光没有来源**（每处都亮，皮肤发灰）。本文件给出可写的具体条件，写提示词时按当前镜头取用，不整篇套用。

## 1. 取景装置（一镜只选一个）

| 装置 | 边框来源 | 适合的观看距离 | 常见误用 |
|---|---|---|---|
| 月洞门／门洞 | 圆洞或方洞的完整轮廓 | 中景到全景，人物穿过洞口 | 洞口只露出一部分、边缘不成形 |
| 漏窗 | 花格的重复图案 | 中近景，人物在窗外活动 | 窗格变形、数量不一致、格心挡住整张脸 |
| 游廊柱列 | 柱与柱之间的竖直分割 | 中景跟拍或固定，靠柱距读纵深 | 柱子随手增减、柱距忽宽忽窄 |
| 桥栏／石栏 | 横向栏板与望柱 | 近景到中景，人物扶手或凭栏 | 栏杆高度到腰或到胸不一致 |
| 假山缺口 | 不规则石体之间的缝 | 中景，人物从缝里出现 | 石头形状与上一镜不接 |
| 檐下一角 | 瓦檐、梁枋、挂落构成的上缘 | 近景，人物在檐阴影里 | 瓦面排数混乱、梁枋结构不成形 |

规则：装置在镜头开头就要交代完整形状，后续运动不得破坏它的边界。需要换装置时切镜，不推拉换景。

## 2. 三层纵深

| 层 | 作用 | 写法 |
|---|---|---|
| 前景 | 建立「我在园子里看」的视角 | 檐角、竹叶、栏柱、垂下的枝条、虚焦的灯笼，占画面一侧 1/4 以内 |
| 中景 | 人物与动作 | 人物全身或腰上，动作朝向清楚 |
| 背景 | 交代空间延伸到哪 | 水面对岸、另一重门、院墙与天光的交界、远处的树冠 |

- 前景虚焦程度写清楚（轻微虚／明显虚），不要「前景朦胧」这类模糊词。
- 背景必须与人物同一天气、同一时段、同一光向；不能人物在阴影里、背景却在直射阳光下。
- 人物走远时，三层结构不变，只是中景变成背景——此时补一个新的前景，否则画面会散。

## 3. 光源位置与结果

| 位置 | 光怎么来 | 画面结果 | 写法示例 |
|---|---|---|---|
| 檐下 | 顶光被瓦檐挡住，光从前方地面与水面反射上来 | 面部均匀、下巴与眼窝有柔和填充，地面比人脸亮 | 人物站在檐阴影中，正前方水面反光把下颌和颈侧提亮 |
| 廊内 | 侧光从柱间切进来一条 | 一半脸受光一半在暗部，柱影落在地面与身上 | 午后斜光穿过廊柱，在青砖地面拉出等距亮带，人物侧脸被亮带扫过 |
| 开口处 | 逆光或侧逆光，光源在人物背后 | 人物成半剪影，发丝与肩线有轮廓光，背景过曝 | 人物背对院门，门外亮部把发丝边缘和肩线勾出细亮边，正面靠地面反射 |
| 窗内 | 光从花格透进，形成图案 | 身上与地面出现花格光斑 | 光透过漏窗在人物袖口和地面留下重复的花格亮影 |
| 夜间廊灯 | 廊下单一灯源，位置低 | 人物一侧暖亮、四周暗、地面有光池 | 廊灯在人物左侧齐胸高度，照亮半张脸与手，脚下一圈光池，其余靠夜色 |

- 一镜只有一个主光源；补光只能来自已有的反射面（水面、白墙、地面），不能凭空加柔光箱。
- 不写色温数值，写「偏冷的漫射」「傍晚的低角度暖光」这类可观察描述。

## 4. 时段

| 时段 | 光的特点 | 适合的画面 |
|---|---|---|
| 清晨 | 低角度、光弱、有薄雾、反差低 | 水面平、雾气在院墙与树冠之间、人物走动带起轻微衣料声 |
| 上午到午后 | 方向明确、树影清晰、光斑锐利 | 廊内亮带、漏窗光斑、地面树影移动 |
| 阴天 | 漫射、无直射、色彩干净 | 人像最稳，白墙与水面成天然反光板 |
| 雨后 | 表面湿润反光、空气透 | 石面与瓦面的湿润高光、水面有细密涟漪 |
| 傍晚 | 低角度暖光、影子长 | 门洞形成逆光、水面泛暖、人物成半剪影 |
| 夜间 | 只有人工灯 | 廊灯、窗光、水边地灯；其余靠夜色，不补假月光 |

## 5. 常见错误（提交前对照）

- 同一镜里出现两个取景装置（先门洞后漏窗），观众会读成两个空间。
- 人物站在完全空旷的平地上，只有背景一堵白墙——这不是园林，是影棚。
- 光斑铺满整幅画面、位置不随人物移动——变成滤镜噪点。
- 建筑构件数量每镜都变（柱子三根变五根、窗格图案换样式）——模型会把它当新空间。
- 用「斑驳、剥落、霉、青苔、泛黄、昏暗、污渍」写质感——违反本项目的写实红线，除用户明确要求遗构外必须删除。
- 夜景里出现月光轮廓光、蓝色环境光或星点灯串——园子里没有这些光源。
- 人物动作写成奔跑、扑倒、回头狂奔——与含蓄表演的默认值冲突，除非剧情明确要求。
