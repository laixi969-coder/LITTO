# 摄影与剪辑

每镜先写「观众为什么需要看到这一镜」，再选摄影方案。景别、焦段、运动和光线必须能在镜头规格里解释，并由真实模型配置执行。

换机位由信息、动作或视点变化驱动，不要求每次切镜同时改变景别与运镜方式，也不以固定的远中近循环制造变化。相邻镜头可以保持相同摄影风格；切点要让观众接得上行动，不能把外部模板的风格偏好当作模型必须遵守的技术限制。

## 镜头职责

| 职责 | 判断问题 | 设计重点 |
| --- | --- | --- |
| 建立 | 人物在哪、彼此和环境是什么关系？ | 空间锚点、走位、出入口与行动轴线 |
| 揭示 | 新信息如何进入观众视野？ | 遮挡、焦点、构图变化或有动机的移动 |
| 反应 | 人物如何理解刚发生的事？ | 视线、停顿、呼吸、重心与微表情 |
| 对比 | 两个状态或人物的差别是什么？ | 景别、距离、色彩或空间关系的受控变化 |
| 过渡 | 时间、地点或情绪怎样衔接？ | 明确的时空依据与声音桥 |
| 匹配 | 切前切后什么保持连贯？ | 动作相位、视线、方向、形状或声音 |

镜头职责也可以是展示产品外形、证明真实卖点、建立品牌识别、提供感官体验或留出准确落版的阅读时间。按当前商业目标判断它是否有用：品牌片关注品牌记忆，效果广告还要让利益、证据和行动入口可理解；不要求每镜推进冲突或露出产品，也不用漂亮画面代替真实证据。静物、留白、停顿和建立氛围都可承担观看任务，不能仅因没有动作而删除。

## 摄影方案

先规划整场的观看层次，再定每镜。按当前信息需要组合空间/全身关系、人物交互、关键接触细节和后果反应：全景让位移与退路可读，中景承载动作交互，近景/特写突出改变局面的信息。选择需要的覆盖，不套固定的远→中→近循环，也不要求每场必须具备所有景别。相邻镜头持续使用相近景别时，检查它是否服务连续动作、压力或明确视点；仅由草稿默认值或复制上一镜造成的重复需要重设计。换景别同时复核轴线、持物手、动作相位和画内对白口型，不能靠换焦段数字冒充新的观看关系。

动作量来自同一事件中有因果的层次：身体目标→尝试→阻力→调整→可见结果。安排有用的走位、交接、支撑、攻防及环境互动，允许可并行的行动自然重叠；保持既定人物、道具、胜负和对白。一个动作链可以由多个景别覆盖，也可在有动机的连续跟拍中完成；不为丰富而添剧情或把一镜塞满招式。写清主体路径与构图变化，摄影机运动不能代替人物行动，微动不能替代已计划的身体动作；明确要求的静止与细腻小动作照常保留。

镜头之间的剪点写在分镜记录；需要单段视频内部切镜时，明确保存进执行时间线并复核各段的起止构图和动作接续。没有内部切镜计划时，生成模型只执行当前镜头；景别丰富由整场镜头组合承担。用户要求一镜到底时，通过主体远近变化、调度或有动机的跟拍形成观看层次，不强插剪切。

- 先用场景锚点确定人物位置、身体朝向、视线与接触，再安排前中后景、遮挡和深度。visibleAssetIds 只含本镜出镜资产；camera.design.start 写第一瞬间，不把之后的走位终点提前画进首帧。构图不只说「三分法」。
- 焦段与拍摄距离共同决定透视关系；选焦段时说明空间压缩或人物与环境关系的意图，不把某个焦段当电影质感万能参数。
- 机位高度、角度和主观视点由叙事关系决定。焦点转移用于注意力变化，必须写明对象和时点。
- 推、拉、摇、移、跟随都写起点、终点、速度变化与动机；手持只在确有视点与情绪依据时采用。
- 主光与实景灯有来源；补光、负补光、背景亮度与高光保留服务人物可读性。跨镜保持光源方位和时间关系。
- 真实感用具体约束：受力与接触、自然皮肤纹理、材质反射、焦平面、高光过渡；不堆叠「高清、超真实、完美」。

## 连续性与输出检查

规划时检查 180° 轴线、视线和屏幕方向；改变轴线必须有可读的建立镜头或过渡。动作接点检查动作阶段、持物手、接触与结果，不仅检查服装颜色。

需要顺畅接视线时，先判断切点前观众注意的对象及其画面位置，再确定下一镜需要先被看到的对象，用构图、运动、焦点或声音引导注意；检查产品、人物或线索是否有足够时间被认出。人物的目光目标与观众的注意点分别记录，不把人物看向某处等同于观众一定看向那里。视线匹配是选择，不是必须让主体永远处于同一画面位置；悬念、惊跳或有意错位可打断接续。规划是预期，实际观看剪接后再核对，未审看时不声称视线已顺畅接上。

出入画边缘不能机械写成相同或相反：先确定两镜的世界路径、机位方向和是否省略时间，再判断屏幕运动方向及人物进入哪一边。例：同向横移且新镜在行进方向前方，人物向右离开前镜后通常从下一镜左边进入；反打、运动机位或有意越轴可能改变画面左右。接点以实际两镜动态核对，计划图不证明结果。

生成后查看实际镜头，检查摄影机是否漂移、人体是否穿透、环境是否变形、焦点是否无故跳动、表演是否只有机械眨眼或摆动。没有查看输出就不评价这些项目；发现问题记录镜头和实际依据。

## 专业电影摄影：从意图到可执行规格

这是电影镜头规划前的必读方法。专业摄影不等于固定设备品牌、宽银幕、浅景深或橙青调色；手机也可以服务电影中的特定视点，但不能因上一项目用了自拍就继承前摄、720p、自动曝光泵动与压缩块。先沿用当前 Look 和用户锁定项，再做下面的取舍；Look 按时段与场景分档，日景与白昼室内按当时段光源组织光色，不套夜档影调。

### 1. 确定摄影方向

| 当前意图 | 摄影选择的起点 | 不应自动带入 |
| --- | --- | --- |
| 受控的叙事电影 | 有来源的布光、明确焦点、稳定的影调和轴线；按情绪决定静止或运动 | 随机失焦、白平衡跳动、手机美颜 |
| 纪实或主观紧迫感 | 有重量感的手持与现场光，保持主体和空间可读 | 无规律剧烈抖动、持续模糊 |
| 风格化电影 | 沿用已确认的色彩、光学与运动规则，解释本镜为何例外 | 每镜独立换滤镜、无依据辉光 |
| 剧情内手机自拍 | 人物持机逻辑、近距离视点及有限成像瑕疵 | 把整部影片都变成手机风格 |

同一影片可包含多种摄影方式，但变化须有场景、视点或叙事依据。方向已明确就直接应用；模糊时给一项具体提案，不让用户逐项填写摄影术语。

### 2. 镜头、距离与焦点

- 先选观众的位置：和人物靠近、隔着空间观察，还是与人物共享视点。再结合景别和环境占比选择距离与焦段；透视主要由观察位置决定，不能说仅在原地换长焦就改变了透视。
- 焦段数字必须有画幅语境。画幅未知时优先描述视野与空间关系，不把 35 mm、50 mm、85 mm 当通用效果按钮。比较两种焦段时说明是否移动机位保持人物大小。
- 景深是选择注意力的手段：对白可保留必要环境，前后景同时承载信息时需足够景深；只有明确要隔离主体时才减浅。不默认最大光圈，不要求“背景完全模糊”又要求背景线索清楚。
- 拉焦写清起始对象、触发事件、目标对象与落点；固定焦点也是有效方案。跟焦必须服务走位，不能将持续焦点漂移当专业质感。
- 数值和品牌若无模型原生支持，属于视觉意图描述；不宣称模型真实使用某摄影机、镜头、光圈或胶片。

### 3. 机位、支撑与运动

选择一种主导方式，并写进 camera.motion 与 camera.motivation：固定机位用于观察和让表演发生；轨道推近用于逐步改变观看距离；横移用于跟随或揭示遮挡后的信息；有支撑的跟拍用于连续穿越空间；手持用于具体的身体视点或不稳定情绪。它们都不是必选项。

每个运动写“起点 → 触发 → 路径/速度变化 → 终点”，不要一镜同时要求环绕、推近、摇镜、升降和快速变焦。推轨改变空间视点，变焦改变取景范围，不能互相冒充。表演已经足够承载情绪时优先保留静止方案。

摇镜是在原机位转动视线，横移或跟拍会改变机位；环绕接触点时分别说明相机路径与双方实际动作，避免让人物为了制造旋转背景无故自转。先验证运动路径能否到达所需落幅：小幅推进不能在主体不动的情况下自然从全景变成大特写。先选一个主导运动；确有两个阶段时写清触发、先后与终点，不把能否复现视为模型保证。

### 4. 布光、曝光与色彩

- 先写世界中的光源：哪扇窗、哪盏实景灯、何时何地；再写人物相对光源的位置。反打改变屏幕上的光向，不应让世界里的窗户换边。
- 分清作用：主光建立面部与物体形体；补光控制阴影可读性；负补光减少环境反射、保留层次；实景灯提供画内依据。轮廓光不是每镜必需，夜景也不等于一律欠曝或全片染蓝。
- 用可见结果描述软硬、方向与层次，例如“窗侧柔光包裹面部，背光侧保留阴影，背景比人物略暗”。不机械要求所有灯都柔、所有高光都压平。
- 曝光服务本镜重要信息：人物表情、窗外线索、金属高光的优先级可能不同。肤色可读不等于抹掉所有皮肤纹理；专业布光不等于无影、无反差。
- 色温对比必须有光源理由。调色保持场景和肤色逻辑，颗粒、光晕、镜头耀斑仅在 Look 明确需要时选择，不堆成“高级感套餐”。同场对白覆盖继承同一曝光与色彩逻辑。

### 5. 表演、声音与剪辑承接

让演员有具体对象和任务，描述触发、反应及行动的先后；不让每句话都伴随眨眼、微笑、点头。呼吸、衣料、脚步等声音按动作选择，保持环境声底，是否配乐沿用用户方向。

对白、倾听和群像的具体设计读取[表演指导](performanceDirection.md)。人物调度与摄影机运动分开描述：谁从哪里移到哪里，摄影机保持、跟随还是退让，分别因何发生。构图应让本镜主要表演证据可见，不在远景要求无法辨认的微表情。

**逐句交代声音归属。** 画内发声须保留真实口型；有依据的画外声、同框多轮和持续镜头可以成立。依据调度可读性、实际声音容量和模型能力选择正反打或连续覆盖，不按轮次、字数硬切，不靠反应镜掩盖嘴型错位。具体规则见[对白覆盖](coverage.md)。

参考按用途裁决，不设所有素材通用的优先级：角色身份服从已采用资产，本次动作衔接服从上一镜实际输出，影调服从当前 Look 的对应时段档位。参考互相冲突时指出具体冲突；不能把上一镜变形的脸当成新身份，也不能为了复用中性资产把上一镜真实姿势和情绪清零。固定世界设定与当前镜头变化分开维护，编译时确认关键约束仍进入实际请求，不能靠省略来假定模型记住上一镜。

同场反打保持世界中的主光来源、阴影层次、肤色和环境声底。镜头换了方向不等于光源换位；没有故事依据不添加灰尘、烟雾或雨。沿用已有环境声、对白、配乐选择，不将“电影真实感”自动等同于禁用背景音乐。以上调度、模块化设定与参考分工改编依据见[来源与许可](performanceDirectionLicense.md)。

为剪辑保留必要的动作前后余量；反打保留视线关系和动作阶段。动作模糊应随运动出现，稳定段保持关键面部与道具可辨。帧率、快门、慢动作和音画同步若无原生控制，只能作为意图或后期计划，不能靠写入提示词保证。

### 6. 应用到 MILI MILI，而不只写在分析里

1. 读当前 World/Look、资产和已锁定镜头；选择本场摄影方向。只对本次需要的镜头设计，不重写整片。
2. 用当前工具 schema 落位：camera 的 shotSize、position、height、angle、lensMm、focus、depth、motion、motivation、side、screenDirection；lighting 的 motivatedLight、key、fill、negativeFill、practicals、exposure、keyDirection、timeOfDay、colorTemp。字段不存在时不得伪造，额外意图写入已有可用文本字段。
3. 每镜至少留下叙事职责、一个明确的摄影选择及其理由、光源与焦点、动作起止和衔接。参数不是填满即专业；与当前镜头无关的效果不添加。
4. 经 productionSpec 保存后 compile，检查最终请求是否保留摄影意图、参考用途与邻镜一致性；核对 warnings/degradations。不能绕过已锁版本、人工采用或当前授权。
5. 模型缺失相应能力时减小并发复杂度或提出后期方案，不把品牌名与负向词当补救。先验证一个能代表身份、布光和运动的小样，再在已授权范围扩展。
6. 审看真实视频后检查焦点是否落在目标、光向是否稳定、皮肤和物体是否可读、运动是否有起止、接点是否连贯。未生成或未观看时只报告设计完成。

### 同一场景的写法对照（仅为示例，不自动写入用户剧情）

意图：“人物读完信后意识到真相，观众注意到表情变化。”

专业摄影描述：“室内中近景，机位与人物视线接近，信件在画面下沿，背景仍可辨。窗侧柔光保持固定，背光侧保留阴影。人物读完后停顿并抬眼，焦点保持眼睛；机位静止，让表演完成信息变化。延续房间环境声，保留纸张轻响。”

若明确需要推进压迫感，可将静止改成“从读信到抬眼期间缓慢推近，抬眼后停止”，其余光线、身份和状态保持。不是同时再添加手持、跳切、自动曝光与极浅景深。

## 参考转译与可执行摄影模板

先区分源片可见事实、分析推测和本项目新设计。实际切点、人物位置、遮挡和结果可作为分析依据；单截图不能恢复完整路径、精确焦距、声音或原始提示词。转译只借所需观看关系，保留本项目身份、时段、天气与空间，分析时间线不另作一份执行稿。

填写现有 camera.design：观看目的；起幅主体/焦点/遮挡；subjectPath；cameraPath；事件触发与停止条件；落幅及剪点。高度、俯仰、距离、焦距和主体画面大小分开：透视依赖拍摄位置，换焦距并不自动改变前后比例。需要推轨变焦时同时说明主体大小目标与背景变化，须看视频判断是否真正执行。

纪实发现式镜头可从门框遮挡开始，主体先动后相机寻找并停稳；延迟和抖幅由当前设计决定，不默认半秒或全部手持。轨道、固定镜头与清楚开场同样有效。遮挡揭示须有可通行的相机路径，不能穿墙或让障碍自动透明。

正反打按固定世界地标核对每个拍摄方向；俯视图中的人物路径、相机路径和时间独立标清。场景母图只证明已展示空间，全景转向不提供平移视差，白模预演只约束所选构图/路径，不能证明生成器精确复现三维运动。

镜头检查分别记录起幅、关键事件、落幅及剪接；只看到人物放大不能认证推轨变焦，只有末幅到位不能证明路线和完整停靠正确。

## 原创例与反例的使用

适用与输入：需要摄影表达与空间揭示；输入观看目的、场地、人物路径及能力。

写法示例：人物从柜前走向门口；摄影机留在原位摇向门，直到门外来客可辨。

反例：同时写固定机位、向前推轨、主体大小永远不变，却没有对应距离与视角安排。

约束与例外：本例只说明组织方法，人物、时长、数量与媒介须换成当前项目；不自动加入案例剧情。已有有效方案直接复用。

验收与修复：检查透视、屏幕方向和揭示时点；修冲突的原字段，不堆运镜名称。 本例未实际生成，不作为效果证据。
