# 摄影与剪辑

每镜先写「观众为什么需要看到这一镜」，再选摄影方案。景别、焦段、运动和光线必须能在镜头规格里解释，并由真实模型配置执行。

## 镜头职责

| 职责 | 判断问题 | 设计重点 |
| --- | --- | --- |
| 建立 | 人物在哪、彼此和环境是什么关系？ | 空间锚点、走位、出入口与行动轴线 |
| 揭示 | 新信息如何进入观众视野？ | 遮挡、焦点、构图变化或有动机的移动 |
| 反应 | 人物如何理解刚发生的事？ | 视线、停顿、呼吸、重心与微表情 |
| 对比 | 两个状态或人物的差别是什么？ | 景别、距离、色彩或空间关系的受控变化 |
| 过渡 | 时间、地点或情绪怎样衔接？ | 明确的时空依据与声音桥 |
| 匹配 | 切前切后什么保持连贯？ | 动作相位、视线、方向、形状或声音 |

## 摄影方案

- 构图写出前、中、后景、人物位置、负空间、遮挡和深度，不只说「三分法」。
- 焦段与拍摄距离共同决定透视关系；选焦段时说明空间压缩或人物与环境关系的意图，不把某个焦段当电影质感万能参数。
- 机位高度、角度和主观视点由叙事关系决定。焦点转移用于注意力变化，必须写明对象和时点。
- 推、拉、摇、移、跟随都写起点、终点、速度变化与动机；手持只在确有视点与情绪依据时采用。
- 主光与实景灯有来源；补光、负补光、背景亮度与高光保留服务人物可读性。跨镜保持光源方位和时间关系。
- 真实感用具体约束：受力与接触、自然皮肤纹理、材质反射、焦平面、高光过渡；不堆叠「高清、超真实、完美」。

## 连续性与输出检查

规划时检查 180° 轴线、视线和屏幕方向；改变轴线必须有可读的建立镜头或过渡。动作接点检查动作阶段、持物手、接触与结果，不仅检查服装颜色。

生成后查看实际镜头，检查摄影机是否漂移、人体是否穿透、环境是否变形、焦点是否无故跳动、表演是否只有机械眨眼或摆动。没有查看输出就不评价这些项目；发现问题记录镜头和实际依据。

## 专业电影摄影：从意图到可执行规格

这是电影镜头规划前的必读方法。专业摄影不等于固定设备品牌、宽银幕、浅景深或橙青调色；手机也可以服务电影中的特定视点，但不能因上一项目用了自拍就继承前摄、720p、自动曝光泵动与压缩块。先沿用当前 Look 和用户锁定项，再做下面的取舍。

### 1. 确定摄影方向

| 当前意图 | 摄影选择的起点 | 不应自动带入 |
| --- | --- | --- |
| 受控的叙事电影 | 有来源的布光、明确焦点、稳定的影调和轴线；按情绪决定静止或运动 | 随机失焦、白平衡跳动、手机美颜 |
| 纪实或主观紧迫感 | 有重量感的手持与现场光，保持主体和空间可读 | 无规律剧烈抖动、持续模糊 |
| 风格化电影 | 沿用已确认的色彩、光学与运动规则，解释本镜为何例外 | 每镜独立换滤镜、无依据辉光 |
| 剧情内手机自拍 | 人物持机逻辑、近距离视点及有限成像瑕疵 | 把整部影片都变成手机风格 |

同一影片可包含多种摄影方式，但变化须有场景、视点或叙事依据。方向已明确就直接应用；模糊时给一项具体提案，不让用户逐项填写摄影术语。

### 2. 镜头、距离与焦点

- 先选观众的位置：和人物靠近、隔着空间观察，还是与人物共享视点。再结合景别和环境占比选择距离与焦段；透视主要由观察位置决定，不能说仅在原地换长焦就改变了透视。
- 焦段数字必须有画幅语境。画幅未知时优先描述视野与空间关系，不把 35 mm、50 mm、85 mm 当通用效果按钮。比较两种焦段时说明是否移动机位保持人物大小。
- 景深是选择注意力的手段：对白可保留必要环境，前后景同时承载信息时需足够景深；只有明确要隔离主体时才减浅。不默认最大光圈，不要求“背景完全模糊”又要求背景线索清楚。
- 拉焦写清起始对象、触发事件、目标对象与落点；固定焦点也是有效方案。跟焦必须服务走位，不能将持续焦点漂移当专业质感。
- 数值和品牌若无模型原生支持，属于视觉意图描述；不宣称模型真实使用某摄影机、镜头、光圈或胶片。

### 3. 机位、支撑与运动

选择一种主导方式，并写进 camera.motion 与 camera.motivation：固定机位用于观察和让表演发生；轨道推近用于逐步改变观看距离；横移用于跟随或揭示遮挡后的信息；有支撑的跟拍用于连续穿越空间；手持用于具体的身体视点或不稳定情绪。它们都不是必选项。

每个运动写“起点 → 触发 → 路径/速度变化 → 终点”，不要一镜同时要求环绕、推近、摇镜、升降和快速变焦。推轨改变空间视点，变焦改变取景范围，不能互相冒充。表演已经足够承载情绪时优先保留静止方案。

### 4. 布光、曝光与色彩

- 先写世界中的光源：哪扇窗、哪盏实景灯、何时何地；再写人物相对光源的位置。反打改变屏幕上的光向，不应让世界里的窗户换边。
- 分清作用：主光建立面部与物体形体；补光控制阴影可读性；负补光减少环境反射、保留层次；实景灯提供画内依据。轮廓光不是每镜必需，夜景也不等于一律欠曝或全片染蓝。
- 用可见结果描述软硬、方向与层次，例如“窗侧柔光包裹面部，背光侧保留阴影，背景比人物略暗”。不机械要求所有灯都柔、所有高光都压平。
- 曝光服务本镜重要信息：人物表情、窗外线索、金属高光的优先级可能不同。肤色可读不等于抹掉所有皮肤纹理；专业布光不等于无影、无反差。
- 色温对比必须有光源理由。调色保持场景和肤色逻辑，颗粒、光晕、镜头耀斑仅在 Look 明确需要时选择，不堆成“高级感套餐”。同场对白覆盖继承同一曝光与色彩逻辑。

### 5. 表演、声音与剪辑承接

让演员有具体对象和任务，描述触发、反应及行动的先后；不让每句话都伴随眨眼、微笑、点头。呼吸、衣料、脚步等声音按动作选择，保持环境声底，是否配乐沿用用户方向。

为剪辑保留必要的动作前后余量；反打保留视线关系和动作阶段。动作模糊应随运动出现，稳定段保持关键面部与道具可辨。帧率、快门、慢动作和音画同步若无原生控制，只能作为意图或后期计划，不能靠写入提示词保证。

### 6. 应用到 LITTO，而不只写在分析里

1. 读当前 World/Look、资产和已锁定镜头；选择本场摄影方向。只对本次需要的镜头设计，不重写整片。
2. 用当前工具 schema 落位：camera 的 shotSize、position、height、angle、lensMm、focus、depth、motion、motivation、side、screenDirection；lighting 的 motivatedLight、key、fill、negativeFill、practicals、exposure、keyDirection、timeOfDay、colorTemp。字段不存在时不得伪造，额外意图写入已有可用文本字段。
3. 每镜至少留下叙事职责、一个明确的摄影选择及其理由、光源与焦点、动作起止和衔接。参数不是填满即专业；与当前镜头无关的效果不添加。
4. 经 productionSpec 保存后 compile，检查最终请求是否保留摄影意图、参考用途与邻镜一致性；核对 warnings/degradations。不能绕过已锁版本、人工采用或当前授权。
5. 模型缺失相应能力时减小并发复杂度或提出后期方案，不把品牌名与负向词当补救。先验证一个能代表身份、布光和运动的小样，再在已授权范围扩展。
6. 审看真实视频后检查焦点是否落在目标、光向是否稳定、皮肤和物体是否可读、运动是否有起止、接点是否连贯。未生成或未观看时只报告设计完成。

### 同一场景的写法对照（仅为示例，不自动写入用户剧情）

意图：“人物读完信后意识到真相，观众注意到表情变化。”

专业摄影描述：“室内中近景，机位与人物视线接近，信件在画面下沿，背景仍可辨。窗侧柔光保持固定，背光侧保留阴影。人物读完后停顿并抬眼，焦点保持眼睛；机位静止，让表演完成信息变化。延续房间环境声，保留纸张轻响。”

若明确需要推进压迫感，可将静止改成“从读信到抬眼期间缓慢推近，抬眼后停止”，其余光线、身份和状态保持。不是同时再添加手持、跳切、自动曝光与极浅景深。
