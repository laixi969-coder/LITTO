# 叙事节奏

镜头的长度来自行为与观众理解所需的时间。先判断场景如何改变人物处境，再安排节奏；没有统一的每分钟镜头数、固定开场钩子或反转时间点。

## 场景节拍

- 目标：人物此刻想得到什么，观众需要知道什么。
- 阻力：对手、环境或内心冲突如何阻碍目标。
- 选择：人物听到或看到什么，何时改变行为。
- 结果：选择改变了哪种关系或状态，如何衔接下一场。

这些是分析维度，不是每场强制模板。用户定稿中的事件与顺序优先；改编提出调整时说明依据，未经同意不改核心事实。

## 剪辑决策

- 一镜可以容纳多个行为节拍；情绪转变常需要保留反应时间。
- 切点由信息、情绪、动作或视点变化推动，不按一句对白切一镜。
- 动作场面先建立方向与空间，再提高剪辑密度；保留动作起势、接触与结果的可读性。
- 对话覆盖包含说话者和听者，反应镜头服务潜台词；允许双人镜头或持续镜头，避免机械轮流正反打。
- 视线匹配、动作匹配、构图或声音桥可衔接场景；转场有剧情依据，避免装饰性炫技。
- 结束点可以是选择的后果、情绪余韵或必要悬念，不强制「未完待续」。

## 时长与生成分段

规划时长必须包含动作、对白、停顿及声音；不能用一套固定语速替代实际表演判断。严格总时长时先做预算，再删减覆盖或调整节拍。

模型单次时长限制是执行边界，不是创作切镜规则。按 workflow 拆为可生成片段，并保留分段间状态、视线、动作和声音衔接；不能声称多个独立片段已经自然连成完整场景。
