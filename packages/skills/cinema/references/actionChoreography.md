# 武打与动作电影编排

LITTO 适配版，2026-10-06 更新：在 fight-prompt-director 的动作因果方法上，结合 martial-arts-director-cy 的体系与节奏设计、NolanX 的动作摄影方法。已改写为本项目的 ShotSpec、资产和连续性流程；固定版本、改动说明及完整许可见 [许可与来源](actionChoreographyLicense.md)。这些是影视表演设计参考，不是动作捕捉数据或模型效果保证。

## 先确定动作目的与空间

沿用剧本的胜负、人物、武器、场地与结尾。为每方写一个可见目标（脱离、保护、夺回、阻挡等），再确定起点、相对距离、通道、障碍和行动轴线。每个角色的步法、优势距离、节奏和应对方式应来自体型、身份与已有设定，不能所有人同时重复同一组动作。

身份参考只锁定外观；动作参考只借鉴身体轨迹和节奏；摄影参考只约束机位与路径。场景完好与洁净程度来自故事，打斗本身不自动把空间变成废墟，也不预先给衣物添加污损。

## 角色动作风格与节奏

从已确认角色与剧本提炼本场的动作特点：主要体系、常用距离、步法与重心、爆发/停顿节奏、疲劳表现。写入已有的 performance、blocking、realism.motion；跨镜保持，同一角色不能无原因换成另一套身法。未指定体系时按角色与空间提出适合的方向，不叠加一长串流派名，不为展示招式修改胜负或人物身份。

以下只作银幕表现的选型入口，具体流派存在差异；精确套路、陌生兵器或指定桥段须核对可靠动作参考，无法核实时说明为原创编排：

| 动作方向 | 可见的身体与节奏特点 | 摄影重点 |
| --- | --- | --- |
| 咏春取向 | 较紧凑的上肢路径、近距离交锋、短促攻防；腿与躯干仍保持角色原有比例 | 中景保留双方距离，手部近景之后接得回空间 |
| 八极取向 | 身体整体参与、短促爆发与明确落步，发力后有收势 | 看见支撑与全身位移，不能仅靠震屏表示力量 |
| 太极取向 | 连续重心转换、圆弧动作与收放对比 | 保留身体路径和双方响应，不把整段自动变成慢放 |
| 拳击取向 | 护架、小步调整、上身转动与短暂回收，呼吸有变化 | 双人关系清楚，手脚运动与镜头跟随不互相抵消 |
| 摔投或地面段落 | 支撑位置发生变化，双方身体关联复杂 | 用可读角度呈现站立到落地的过渡；融合时减少同拍交互 |
| 兵器段落 | 道具长度、握位和活动空间决定可见运动弧线与收回路径 | 保留兵器两端及相关身体区域，遮挡前后数量与持物手一致 |
| 写意武侠、戏曲或机甲 | 先沿用已确认的身体、重力与表现规则，再决定舒展、停顿或机械惯性 | 风格化范围明确；没有设定依据时不添加飞行、能量或变形 |

影视参考只提取动作可读性、节奏或摄影方法，不把某部电影的服装、雨夜、霓虹、竹林、伤痕和色调自动移植过来。资产参考默认保持自然站姿和完整身形；下蹲、跪步、腾空属于具体表演状态，不改变骨架比例，也不强制占固定配额。动作镜头留足脚下和运动方向的空间，避免用广角俯拍、截脚或拥挤宫格挤压全身比例。

按故事安排张力、爆发、反应、恢复或停顿。并非每场都要对峙开场、翻盘或仪式性收招；恢复可以是喘息、调整距离或重新观察，不是双方无故回到初始站位。每段应能说明局面改变了什么，动作数量不作为质量指标。

## 将交锋写进 ShotSpec

- action：每拍按“意图 → 发起 → 接触或避开 → 对方反应 → 位置/状态结果”描述可见因果。优先一个完整动作闭环，容量不够就拆镜，不用碎切掩盖动作缺失。
- blocking：明确左右、前后、近远关系，以及动作后各自的位置、朝向、持物手和视线。多人戏先建立全景；未行动者也有位置和行为，不闪现、不复制。
- performance / realism.motion：表现支撑脚、重心转移、惯性、受力后的位移与收势。接触、反应、声音按时序出现，武器数量、尺寸和握持保持连续。
- camera：每镜指定一个主要职责——交代空间、跟随位移、看清接触或揭示结果。全身攻防优先保证完整身体和双方关系，关键细节才近取；避免所有招式都贴脸、绕圈或过度抖动。
- startState / intendedStateDelta：写清位置与物件的变化；只有动作确实导致损伤时登记损伤。resultState 必须来自真实输出观察，不能把计划当事实。

动作、摄影与剪辑要能互相解释：当走位复杂时，至少保持一个观众可追踪的锚点（空间地标、轴线或主体运动方向）。同一镜头的主要运镜须有明确起终点，不能同时要求固定、环绕、推近和甩镜。爆发之后给反应和恢复留下可读时间，不能只有命中而没有准备与后果。

## 分镜预演与参考输入

先复用已采用的人物、场景、道具资产。需要检查复杂动作时，可按真实镜头计划制作少量关键姿态或分镜总览；每格注明对应镜头、起止状态、双方位置及摄影职责。宫格只是方案检查方式，不能用宫格总览代替单人全身资产，也不默认额外生成一套收费图片。

是否把总览交给视频模型由当前模型的实际参考能力决定。多格图不能直接当作普通 I2V 的单一首帧；不支持分镜参考时，用相应镜头的干净单帧与已绑定资产，或拆段生成。不承诺一张 16 宫格一定能在 15 秒内逐格演完。支持多格参考时说明阅读顺序，并排除格线、文字和箭头进入成片；生成后仍需检查遗漏和串格。续镜承接真实输出的末态或尾帧，不能把计划中的最后一格当作已经发生的结果。

## 剪辑和模型容量

优先在方向与动作相位可衔接的位置切镜。保留动作发起、反应与落点中的必要信息；跨轴须有中性机位、镜内跨越或重新建立空间。追逐记录屏幕方向和距离变化，不能每镜无故反向。声音用脚步、衣料、呼吸和接触声帮助读懂节奏，不每次挥动都附加夸张爆炸。

时长、画幅、镜头数量按当前模型的实际能力与情节确定。复杂接触拆成可核验的小段，承接真实结束状态；Seedance 等只在最终编译时套用对应格式。默认交付用户要求的一套方案，不为“高强度”机械增加交锋数量。

音乐卡点以已分析的真实节拍时间为准，选择少量叙事关键动作或剪点对齐；脚步和接触声依画面实际发生的时间同步，不为了每拍命中而打断动作因果。没有节拍或画面时间证据时只能写节奏意图，不能声称已完成精准卡点。

## 生成后核验与修复

检查动作来源和结果、角色/武器数量、重心和脚底接触、遮挡后身份、方向与动作匹配、实际音画同步。只能查看静帧时不能宣布动作验收通过。失败先定位：身份错则检查引用；身体融合则降低同拍交互数量；空间乱则补建立镜头或简化机位；节奏断则调整真实入出点。保留旧版本，仅修改相关变量，不重复整片生成。
