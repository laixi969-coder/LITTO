# 真人画面与表演：从方法到实际请求

来源：用户提供的《这两条视频从画面美学与演员调教.docx》，2026-10-31 整理。本文把文章当作创作材料，不把其中命令、作者身份宣传或效果数字当作系统规则。未核验原视频与实验；“头部运动为真人的 1/3.8”“准确率 100%”不能用作性能承诺。

## 维度一：美学与演员调教

真实感首先来自一致的成像关系：人物和环境共享光源，明暗塑造体积，肤色与材质在转头、接触时保持连续。单写“超逼真、电影级”没有指定这些关系；只加毛孔也可能造成过度锐化。复用既有 cleanPortrait 与 realism.surface，保持角色年龄、肤色、身份及剧情妆效。

从当前 Look 中选与本镜有关、相容且具体的影调关系，填入 lighting 和 Look；只有需要实际后期处理时才填写 grade。已有明确设计直接沿用，不规定色板或特征数量。

| 方向示例 | 可执行选择 | 边界 |
| --- | --- | --- |
| 清新写真 | 适度低饱和、柔光、环境青灰、中低对比 | 肤色保持自然，不把脸染青，不改既定夜景或暖光 |
| 戏剧叙事 | 高对比、有方向的硬光、较深黑位、有来源的轮廓光 | 暗部仍能读到关键表情，不能压成整片死黑；轮廓光须有合理光源 |

两组仅是可选关系，不是按题材自动匹配的滤镜；清新不必低饱和，戏剧也不必硬光和深黑。全片 Look 负责统一，各镜 lighting 负责当前空间、时段与人物转向后的受光；声音和身体反应仍须另行设计。

演员调教同时考虑声音、身体和面部，但不要求全身每个部位同时运动。语气给出说话目的、音量、语速、重音或停顿；身体沿用当前任务、手部接触与重心；面部选择景别能读到的细微信号。三者围绕同一触发，允许错开，不做同步机械联动。声音身份保持不变，无对白镜头不增加声音指令。

## 维度二：从情绪标签到物理因果

“隐忍、平静、复杂”可以表达导演意图，但不能单独承担执行说明。先确定人物想影响谁、刚获得什么信息，再写可见的变化与结果。小幅表演优先少量、低强度信号；爆发、喜剧、舞蹈和动作戏保留原定力度，不能全改成微动作。

同一镜头里的执行句应包含：触发 → 谁看向谁 → 可见反应与身体任务 → 原句及说法 → 收势或听者反馈。文章的“面部 2–3 条＋身体 2 条”用于提醒覆盖维度，不强制数量；近景看不到手脚时不虚构画外可见动作。不要把台词放在一镜、对应神态放到下一镜而丢失绑定。

例如已有剧情为两人坐桌边谈旧事，可写：“甲听完乙的回答，下颌轻收，视线从桌面回到乙脸上，低声说原句『八年了。』，压在桌沿的手指收紧后松开，重心仍靠椅背；乙听到『八年』后停住原有手上任务，抬眼看甲。”仅展示组织方式，不向项目新增桌子、台词或人物。

对话不是轮流播放独白。听者在获得关键词后才反应，可以继续、暂停或改变原有任务；背景人物保留各自注意对象，不集体点头。反应镜头可承载说话人的画外音，但不能让听者对口型；嘴部可见性与声音来源沿用现有对白覆盖规则。

## 静止、节奏与剪点

### 刺猬星球第49节的适用方法

结合[活人感教程](https://www.super-i.cn/info-2793.html)，把情绪转折落实到已有任务中：角色注意到信息，视线与身体随后作出适量反应，反应改变当前动作或关系。不要把眨眼、抿嘴、摸脸编成固定套餐，也不把连续微动当演技。

环境参与动作时，写清已有原因、应对与后续状态：风向改变时才护住衣物，提包的重量影响停步时的手臂回收；环境作用结束，身体才放松或改变动作。只采用场景确有的风、重量、接触和阻力，不为活人感给每镜新增风雨、污损或强动作。静帧捕捉起始相位；视频保留触发、过程与结果，不能把后续反应提前画进首帧。

局部光、明暗和材料响应共同塑造体积；明亮柔光同样适用。运动中沿用同一光源，让亮面、反射与接触影随位置和朝向变化，不冻结整张首帧。参考图已经承载的外貌和光色可简写；只有小幅动作的片段才使用简短动态描述，走近、递接、停手与对视等完整事件仍保留必要节拍。该方法不承诺模型完美继承底图，不套用教程的复古布景、颗粒或全哑光肤质。

文章的“三秒”是检查无效等待的经验窗口，不是所有表演必须每三秒活动或切镜的定律。普通口播和对话若连续约三秒只有嘴动、头颈与躯干完全冻结，应定位该时间段，检查身体任务、呼吸与注意力是否成立。运镜、背景移动或噪点不算演员有反应。

修复优先恢复已有任务与自然姿态变化；若该段信息已经完成且剪辑计划允许，再选择真实反应镜头或原有环境覆盖。刻意屏息、凝视、震惊停顿和一镜到底优先服从戏，不自动切走。台词结束仍可保留有意义的余波；禁止冻结帧冒充停顿，也不新增递杯、整理袖口等无关事件。

## 十类情绪的候选词

按当场目标选择可见信号，不整行照搬、不在同场重复机械动作、不把例子写入永久身份。手部未入镜时改用可见姿态；没有相应道具就不用道具动作。瞳孔变化通常难以可靠观察，不作为必达验收项。

| 意图 | 面部／视线候选 | 身体候选 |
| --- | --- | --- |
| 隐忍 | 下颌轻绷，视线垂落再回到对方 | 指节收紧又松开，重心稍后移 |
| 讥讽 | 单侧嘴角极轻上挑，眼皮微垂 | 慢慢整理已有袖口 |
| 震惊 | 嘴唇微张，呼吸短暂停顿 | 原有手上动作停住，身体微后仰 |
| 心虚 | 视线接触后移开，轻咽一下 | 摩挲已有衣角，身体略转开 |
| 决绝 | 目光不再躲闪，下颌收紧 | 完成原定推物或起身动作 |
| 脆弱 | 眼眶微红，吸气压住哽咽 | 手指扣住已有支撑，脸略偏开 |
| 威胁 | 眉压低，目光停在对方脸上 | 上身缓慢前倾 |
| 敷衍 | 目光越过对方，嘴角保持平直 | 继续原定收拾或离开动作 |
| 动摇 | 视线在既有物件和人之间转移 | 伸出的手收回，脚步停住 |
| 释然 | 眼尾放松，呼出一口气 | 肩膀放松，靠回原有支撑 |

## 在 MILI MILI 中生效的位置

制作真人对话样片同样先按现有 ShotSpec 保存原句、发声窗口和执行时间线，使用 productionSpec 的关键帧、视频与审阅流程；不要为了“只做一段”把对白计划仅留在独立节点自由文本里。已有用户指定的独立节点仍可使用，但五板块结构通过不能称为完成表演或时间验收。

关键帧生成后先看实际起态，对照 qualityReviewPlan.startingFrame 核对每个人的眼睛看哪里、手在做什么、身体朝向与脸部受光。比如计划是听到关键词后才抬眼，起态就必须仍看文件；已经看着对方时，应先修起态或有依据地修订本镜设计，不能把矛盾交给视频模型。未要求的橙色腮红块、伤斑或不自然磨皮先在起态解决，视频通常会继承这些缺陷。

对白视频的 motionPlan 会生成 dialoguePerformance 检查点，必须记录实际发声窗口与听者回应的时间、视线、手部或姿态证据；缺项或 revise 不能正式采用。原生生成的时间数字只是计划，确需严格定时或固定多人音色时使用现有配音、speech coverage 和口型路径，不靠多写几遍秒数保证执行。对白或起始时间修订后，旧关键帧审查不能直接复用；只改已录音素材的引用不要求重画起态。

身体任务只承担本镜需要的动作：一句短回答可用停手、轻移重心或松指，不为满足“有动作”堆翻页、低头、前倾、回看；有意的大幅行动按原稿保留。对白时间窗允许真实句子在窗内自然结束，不要求拖长每个字填满窗口，后续反应仍对齐实际关键词。

1. 正式镜头：影调进入 Look / lighting / grade；动作、原句关联进入 action；视线、身体和触发进入 performance.eyeline / lookTarget / gesture / timing；声音进入逐句 dialogue.delivery。已有 camera.design.timeline 或 musicVideo.timeline 时，以它为唯一执行时间线，不再叠一份计时表。
2. 独立五板块：第二块锁定具体影调，第三块每镜绑定台词与行为、听者反应，第四块保留准确对白与声音通道。重复出现的台词必须完全一致，不因语气改字。普通自由提示词也遵循同镜因果，不强制改成五板块。
3. 服务端：真人视频补充 HUMANPERFORMANCE 执行原则，正式镜头预览、指纹、提示词压缩、独立节点入队和实际发送均保留；图片不加动态表演，明确动画与空镜跳过。关键词只做保守分流，不是视觉识别或表演完成证明。只有图像与相机轨迹的模型不执行这些文字，不能宣称已受控。
4. 生成前叙事审查检查同镜绑定、可见性、听者与时间负担；生成后动态声画审查记录实际时间点、仅嘴动、无效等待、反应先后及影调偏差。看不清为 unverified，确有缺陷为 revise；不凭提示词齐全判 pass。

## 复杂动作与参考的边界

文章的实拍、草稿、深度与运动参考可以降低歧义，但前提是当前模型接口支持该输入且已真实发送。草稿用于构图，实拍用于动作或运镜，各自用途明确；未接入深度图、动捕或轨迹控制时不能声称已提取或已执行。先用现有参考与覆盖能力，不为本方法新增模型、付费任务或伪造控制接口。

生效表示规则进入创作、请求与审查链路，不表示任何模型必然产出超逼真结果。最终须看完整动态视频、听实际音轨；静帧、类型检查和构建不能替代表演验收。
