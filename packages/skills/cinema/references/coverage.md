# 对白覆盖（Coverage）与正反打

对白戏拍坏的多数不是「表演不够」，而是**没给说话人一个镜头**。观众听到 B 的声音，画面还停在 A 的脸上——这在剪辑语法里叫覆盖不足，中文行业口语叫「没切过去」「对白没给反打」，成片上表现为声画主体错位。

单镜生成的模型不会自己切镜。它按首帧给的机位演到底，所以**覆盖必须在分镜阶段就排好**，不能指望模型在镜内完成"说完我，切给他"。

## 1. 三类症状与术语

| 观众看到的 | 专业叫法 | 根因 |
| --- | --- | --- |
| A 的画面里传出 B 的台词，B 从未出镜 | 覆盖不足 / 反打缺位（no reverse shot）；单边覆盖（single-sided coverage） | 一轮以上的对白被塞进同一个机位 |
| B 说话时画面停在 A，但 A 没有反应动作 | 缺少反应镜头（missing reaction shot） | 听者被当成背景板 |
| 上一镜末尾的声音延续到下一镜开头 | L-cut（声音后出）；反向是 J-cut（声音先入） | 这是**刻意的**剪辑手法，不是错误；滥用才成为错位 |

有意让人物在画外说话只有两种合法情形：**说话人在本场已有独立画面**，或**画外声源在剧情上刻意隐藏**（门后、电话里、看不见的人）。除此之外，说话人必须在本镜画面内，或紧邻的前一镜/后一镜里有他的独立镜头。

## 2. 拆镜判定（动手前先过一遍）

任一条命中就必须拆镜，不能靠提示词补救：

1. **一轮以上**的说话人交替（A 说完 B 接）——拆成 A 镜 + B 镜。
2. 单镜台词超过 **约 22 字**（按 3.5–4 字/秒的普通话语速，6 秒的容量）——拆，或砍。
3. 单镜内出现 **2 个以上情绪转折**（例如「愣住 → 冷笑 → 让步」）——转折点放在切点上，不在镜内。
4. 需要看清 **听者的判断**（这句话有没有击中他）——单独给反应镜，允许无台词。
5. 说话人从站立改坐下、从门口走到桌前等**大幅位移**——位移单独成镜，别和台词抢时间。

## 3. 正反打的基本件

一场双人对白至少需要下面四种镜头，按需组合：

| 件 | 画面 | 作用 |
| --- | --- | --- |
| 主镜（master / two-shot） | 两人同框，交代空间与距离 | 建立轴线，只用在开头或关系变化时 |
| A 镜（over-the-shoulder） | 越过 B 的肩拍 A，B 的后脑或肩在前景虚焦 | A 说话时用；前景的那半个肩就是「他在听」的证据 |
| B 镜（reverse） | 反向，越过 A 的肩拍 B | B 回答时用；与 A 镜成对，机位差 120°–180° |
| 反应镜（reaction / single） | 单人近景或特写，不给台词 | 台词落地后的判断、咽口水、移开视线 |
| 插入镜（insert / cutaway） | 手、道具、眼睛、桌面 | 换气、遮掉跳切、把信息交给观众 |

**180° 轴线**：A 在画面左、看向右；B 在画面右、看向左。整场不变。要换轴必须先给一个建立镜或运动过渡，否则观众会以为两人换了位置。

## 3.5 机器先算一遍（不用人工数轮次）

分镜台词一落定，先调 `POST /api/ai/media/coverage`：

```
{ "directory": "<工作区>", "shots": [
  { "id": "S16", "duration": 14, "visible": ["李伟","张强"], "lines": [
    { "speaker": "李伟", "line": "你能不能……" },
    { "speaker": "张强", "line": "可以。" }
  ] }
] }
```

它返回三样东西，并默认写入 `assets/coverage.json`：

- `shots`：每镜的轮次、汉字数、是否有人在画、判定（`orphan` 说话人不在画又没独立镜头 / `overloaded` 三轮以上 / `offscreen` 画面一个人却在和画外对答 / `multi` 两轮 / `crowded` 台词超容量）。
- `splits`：把多轮镜直接切成正反打，含建议镜号、时长、景别与过肩前景。
- `verdict`：整张表的结论。`orphan` 与 `overloaded` 判 block。

**block 的项目不能生成视频**——生成接口会直接拒绝并说明原因。`offscreen` 与 `multi` 只警告：同框长镜和画外手法是合法资源，但每一行都会被点名，避免整场都是「一个人在画里，另一个人在画外说」。

`offscreen` 是这条规则里最容易漏的一类：对方在别的镜头里有脸，观众知道是谁在说，但**这一句仍然该给他镜头**。有独立镜头只解决「知道是谁」，不解决「看得到他说」。一场戏里用一两处可以，用成主要手段就是覆盖不足。

## 4. 景别分配

对话不靠中景讲。中景（腰以上）脸只占画面 1/8，微表情读不到，模型也不会做。

- 多轮交锋：近景（胸以上，脸占 1/3）为主，关键句给特写。
- 只有交代两人距离、或一方起身/逼近时用中景。
- 一场戏里景别要有变化：中景建立 → 近景交锋 → 特写落点，不要整场同一个景别。

## 5. 声音归属

- 每句台词写明**说话人 + 是否在画面内**。画外句标注「画外」，并确认他有一镜独立画面。
- 单镜内的画外句不超过 **2 句**，否则就是拿画外音省镜头。
- 同一镜内换说话人时，听者必须有可见反应（抬眼、停手、呼吸变化），否则观众不知道声音换人了。

## 6. AI 单镜生成的三条硬约束

1. **首帧定表情。** 关键帧是什么脸，模型就演什么脸，只会微调。关键帧必须取「正在说这句」或「刚听到」的那一瞬间，不能给一张平静的正脸。
2. **一镜一个节拍。** 镜内只完成一个动作或一次判断。转折、换机位、换说话人，全部交给切点。
3. **表情写在能执行的东西上，不写在形容词上。** 「语气平静」「神情平淡」会把表演抹平。能演面部的执行器写在肌肉上（眉心、眼睑、嘴角、喉结）；只能演动作的执行器（H3 一类）写在首帧表情加手、头、呼吸、视线、重心上——判断依据见[按模型能力分工](performanceDirection.md)。

对照句式：

- 差：他平静地说：「我就是开店的。」
- 好：他抬眼看对方，眼皮没有跟着抬；说完嘴角往回收了一下，下颌仍松着；手掌压在协议上没有移开。

## 7. 编译进 ShotSpec

| 字段 | 写什么 |
| --- | --- |
| shotSize | 对话用近景/特写；中景只用于建立与位移 |
| blocking | A 在画面左看向右、B 在画面右看向左；前景是谁的肩 |
| performance | 本镜唯一的那次判断：触发 → 抑制或释放 → 残留状态 |
| action | 本镜谁对谁做了什么，台词归属写清 |
| startState / endState | 第一瞬间的脸与手在哪；结束时残留什么 |
| cameraMove | 对话镜默认不动；要动必须有动机（逼近、退让） |

一场戏的 coverage 表要先列出来再生成：`场次 | 镜号 | 说话人 | 是否在画 | 景别 | 前景 | 台词/字数 | 时长`。表里出现「说话人不在画且无独立镜头」的行，就是要在成片里翻车的行。

填表模板（每场一张，先填再拍）：

| 镜号 | 说话人 | 在画 | 景别 | 前景（谁的肩） | 台词 | 字数 | 时长 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 例 S16a | 李伟 | 是 | 近景 | 张强右肩 | 你能不能…… | 5 | 5" |
| 例 S16b | 张强 | 是 | 近景 | 李伟左肩 | 可以。／我有个条件。 | 9 | 5" |

三条自检：说话人列全是「在画=是」；相邻两行的前景互为对方；字数 ÷ 3.5 ≤ 时长。

## 8. 已经拍坏了怎么救（后期，不重生成）

覆盖不足的镜头，多数可以靠**已有素材重新排列**救回来，不必重跑模型。三种手段按优先级：

1. **补反应镜头（最常用）**：从同一场已经生成的镜头里，取说话人的那几秒插进来，声音仍用原片的整条音轨。对白时序一字不动，只是画面在说话人之间切。切点对齐台词的开口音。
2. **J-cut / L-cut**：把下一镜的声音提前，或让上一镜的声音拖过来，掩盖画外与跳接。适用于人物动作不匹配、但台词必须连续的段落。
3. **插入镜**：手、杯子、文件、门口，2–3 秒，把画外音变成合法画外。适用于找不到说话人可用素材时。

脚本 `scripts/coverageRepair.py` 做第 1 种：给一张剪辑表（每段用哪个文件、入点出点），输出重排后的片子，音轨取自 master。

```
python3 scripts/coverageRepair.py repair.json out.mp4 工作区目录
```

```json
{
  "master": "assets/generated/原片.mp4",
  "cuts": [
    {"from": "assets/generated/说话人镜头.mp4", "in": 0.0, "out": 1.9},
    {"from": "assets/generated/原片.mp4", "in": 1.9, "out": 5.9}
  ]
}
```

注意两点：补救只能补「谁在画」，补不了「脸不一样」——跨镜身份仍要靠关键帧锁；插入片段的景别与光向要接得上，否则观众会察觉是硬切。
