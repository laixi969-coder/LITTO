# 对白覆盖、持续镜头与声音归属

对白覆盖让观众理解谁说、谁听、谁在判断，并保留完整声音与动作因果。轮次、字数、景别数量都不能单独决定拆镜。本规则与[叙事节奏](pacing.md)、[摄影与剪辑](shotLanguage.md)共同执行，不再使用“一镜只许一个节拍”“换人必须切”“超过22字就砍”的旧规则。

## 先规划覆盖，再决定拆镜

制作表包含：镜头、原句、说话人、画内/画外与声源依据、观看对象和景别、实际声音时长/待探测、局部起止窗口。已有配音读取实际时长；未生成时可以粗估，但固定语速不能证明发声与口型能塞入时长。

后配音视频生成前用 productionSpec(planSpeech){shotId,bindings?:[{lineIndex,path}]} 实测已采用声音，复用返回的 audio:{mediaId,text}，再设计镜头；声音未确定时只做草案和预览。visible 的每句另存 coverage:[{start,end,description}]，完整覆盖发声区间；水下/海面切到座舱必须在该句开始前到位并保持嘴部可见至整句结束。本镜有角色、framing文字或未来会切回来不能代替完整区间。字段只是设计，成片仍须实看口型。容量下限不是自动慢放、定格或延长动作的许可；完整因果与原速声音共同决定分镜。

- 同框持续镜头可包含多个说话人和相连节拍，前提是调度、逐句可见性、倾听反应及当前模型能力足以执行；不得只按轮次拆镜。
- 电话、对讲、隐藏声源与有意反应镜均可成立，写清 lipSync:offscreen 和 framing 的实际依据；不要求先有角色正脸。
- 画内发声必须覆盖真实嘴部，并保持台词、说话人、实际声音与口型一致，不能让另一张脸说这句。
- 时间容量不足、行动被遮挡、人物关系变化或模型不能可靠执行时再调整覆盖。保留完整原句，不删词、加速、平均分秒或挪到无关镜头。
- 一镜到底优先用调度、视点和焦点组织信息。能力冲突须说明，不能偷偷加切镜。

## 按信息选择镜头

主镜/双人镜交代关系；过肩与反向机位看见说话或倾听；反应镜保留真实触发后的判断；插入镜突出已有道具、手部或线索。只取有用部分，不强制凑齐或轮流正反打，不默认慢推。

切点来自行动、信息、关系或视点变化。反应可发生在对方讲话期间，但不能先于触发。一镜可以完整呈现触发、尝试、阻力、调整与结果，不为“一镜一个节拍”切碎动作。

同场保持轴线、目光目标、屏幕方向、世界光源与环境声底。机位差异服务观看，不硬套固定角度；越轴须有可读依据。保留关键手部、接触和支撑，不在远景要求不可辨微表情。

## 本地覆盖检查

POST /api/ai/media/coverage 接收 {directory,shots,save?}，每镜可含 id,duration,visible,ownShot,lines；每句为 {speaker,line,lipSync?,framing?}，默认保存 assets/coverage.json。

- orphan：声源不在画且未交代画外依据，或明确visible却缺画面，阻止生成；先补覆盖，不删台词或关闭检查绕过。
- overloaded/multi：多轮同镜的能力与调度提示，不因轮次强制拆镜。
- offscreen：核对画外安排与听者反应是否有意，合法画外可保留。
- crowded：字数粗估提示，真实声音与窗口校验仍由配音/剪辑流程完成。

splits仅返回风险段落备选，不自动执行，不要求用户再次确认已选画面。不改原句，建议时长由真实音频与表演进一步核对。

## 真实声音与口型

首帧只规定开始瞬间，不提前放入尚未发生的说话姿态或结尾表情。多轮发声依赖已选能力与实际输出，不能一概断言模型会自动切镜或永远不会切镜。

原生声音按完整逐句计划生成并检查。后配音先读取真实时长；可见嘴部须走专用口型任务、真实输入输出检查和候选登记，随后完整看听。TTS混音、音轨一致或抽帧不能证明口型通过。

J-cut/L-cut须明确声源、目的、父镜头与源片余量，在真实时间线上执行。声音桥不能把可见嘴部错位变成合格，不能删句、改对白速度。当前校验不支持的跨镜同步不能改用自由FFmpeg绕过。

## 已有素材补救

先readEdit，复用已有且检查有效的镜头、原句和声音。通过previewCut、set_cut/trim_clip、soundBridge、soundCues完成授权修订。缺可用画面如实报告，不能凭调序声称修好了嘴型。

迭代用render options.draft:true；定稿走正常导出、实际成片检查和验收。自由拼接脚本不能代替时间线、完整对白与口型校验；不自动重生成付费素材。

## 声音与剪辑的执行模板

复用现有对白、音乐、sfx轨道，不为每个脚步重新生成素材。先听已有录音和源片，按需要保留或补齐环境底声、关键动作声、音乐与有意静默。当前没有音轨或工具不能听时明确未验证，风吹草的画面不证明已有风声。

每项声音写“真实来源/素材 → 对应事件 → 源入点 → 成片位置 → 增益/淡入淡出及对白让位”。事件在源片的时间为t、素材剪入点为in、时间线起点为start、速度为speed时，其位置为 start + (t - in) / speed；仅对实际剪入区间有效，具体仍以现有剪辑工具回读为准。剪辑或速度改变后重算关联，不沿用旧脚本秒数。对白与原曲保持既定原速，不能为了套公式随意变速。

角色音色身份固定，逐句语气由说话目的决定；语速/重音指令只有提供商实际支持并发送才算生效。环境声按空间与距离组织，不能每到“孤独”就加鸟鸣。现有增益、淡变、duck可直接复用；没有声像控制字段时不承诺左右声像关键帧。

剪辑选择实际可用入出点，保留关键接触与完整字音；共同端点处有停滞才考虑裁帧，不机械每段删1–2帧。整片试听检查音色跳变、重复原曲、声音桥、字句缺失和动作同步，抽帧与波形不代替听验。

## 原创例与反例的使用

适用与输入：对白、声音事件或剪辑变化；输入实测源音、说话者、剪入点与时间线。

写法示例：源片第4秒关门，剪入点1秒、时间线起点10秒且原速，关门声对应成片13秒。

反例：剪掉前一秒画面后仍沿用旧关门音点。

约束与例外：本例只说明组织方法，人物、时长、数量与媒介须换成当前项目；不自动加入案例剧情。已有有效方案直接复用。

验收与修复：回读剪辑并完整听接点；重排关联声音，保留完整字音，不用变速挤台词。 本例未实际生成，不作为效果证据。
