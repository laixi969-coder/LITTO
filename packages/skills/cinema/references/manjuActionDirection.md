# 武打导演专项：节拍、空间、兵器与法术

LITTO 于 2026-10-10 基于漫剧老李 Short-Drama Director Suite 改写。固定提交、采用文件与 MIT 许可见[来源与许可](actionChoreographyLicense.md)。先遵循[动作编排](actionChoreography.md)；本资料用于影视分镜和生成提示词，不把创作词库当作武术史料、真人动作教学或模型效果证明。

## 1. 先选表现尺度

从用户需求、已采用剧本及 world/look 判断；缺失时提出一个有理由的建议，不默认高燃。已有比例、分辨率、时长与模型选择直接沿用，生成前查询实际媒体模型能力。

| 方向 | 画面证据 | 不自动加入 |
| --- | --- | --- |
| 写实克制 | 支撑、重心、呼吸、距离、遮挡和反应清楚；停顿有观察或决策原因 | 能量气浪、巨大破坏、腾空和强制慢镜 |
| 商业动作 | 动作幅度与快慢对比更鲜明，关键转折有清楚的反应和落点 | 每镜翻盘、固定连击数量、所有动作配震屏 |
| 武侠/仙侠/动画 | 按世界设定设计轻功、法器、能量形态及环境反馈 | 所有角色都会飞、兵器自动变形、特效盖住角色 |

风格化不等于更血腥。烈度、胜负、伤情、环境损坏及结尾均服从故事和用户要求。不将上游“完播潜力”启发式当作真实完播率预测，不承诺提高某个百分比。

## 2. 攻防写成状态变化

每拍写明谁发起、谁响应、发生在哪里、如何结束。用可观察动作代替“快速交手”“打得很猛”，但不堆满一段模型无法表现的招式。

- 有效防守：明确视线、支撑、双方距离与当前持物状态。
- 防守受扰：只有前一动作实际造成干扰时，才表现重心、护持或位置的变化。
- 过渡与恢复：延续踉跄、调整、寻找支撑或重新拉开距离的过程，不能下一帧无缘由恢复原站姿。
- 下一拍继承：从实际位置、朝向、持物手和疲劳状态继续。未发生破防时，不强制走完上述三步。

允许有效的小幅反应，也允许有表演目的的静止、对峙和慢镜。若试片出现呆立，先补角色注意对象、呼吸、眼神或调整动作；需要继续移动时再把情绪放进走位，不认定所有模型都不能生成静止表演。

## 3. 多人、兵器与空间

多人镜头为每人记录“当前目标—起点—路线—终点—结束状态”。一拍只保留一个主要注意对象；其他人可观察、受阻、掩护或离画，必须有原因，不要求所有人同时攻击。主体发生遮挡后，重新出现的位置和身份须接得上。

换位说明谁从画面哪侧经过哪个地标，是否发生交叉或跨轴。追逐保留距离变化，腾跃保留起落点；轻功的借力或超自然移动由世界设定决定。镜头跟随可读路径，不用绕圈和频繁切镜掩盖位置跳变。

兵器或法器先核对资产：数量、长度、材质、握持端、持物手及收纳位置。展示挥动时留出活动空间；遮挡前后不得多出一把，换手或掉落必须有可见过渡。短兵器、长兵器和软兵器的画面范围各自规划，不能共用一条无差别运动路径。

流派名仅是沟通入口：优先延续角色已经选定的动作风格。上游词库混合了传统流派、影视招式和虚构名称；不把“独孤九剑”等虚构体系标为史实或正统套路。用户指定精确套路时需要相应参考，否则标为原创银幕编排。

## 4. 摄影与剪辑选择

先说明观众需要看清什么，再决定景别、机位、跟随对象和运动路径。

- 空间镜头交代距离、地标、出入口和运动方向；关系复杂时先建立空间。
- 接触或避让镜头保留必要身体区域，反应镜头说明局面变化。近景不等于必须展示伤口。
- 动作匹配切：上一镜已经完成的动作阶段不重演，下一镜接续其方向、速度与状态。
- 视线匹配切：记录剪点处观众正在注视的屏幕区域，让下镜的关键信息易于找到。
- 遮挡切：遮挡物有空间来源，遮挡之后仍是同一场地、身份和动作相位。
- 景别和运镜可以重复，只要承担明确职责；不强制固定景别阶梯、每几秒换镜或所有运动同向。

横屏可展开双方横向距离与环境，竖屏可利用纵深和前后层次；两者都要保留必要的脚下、兵器及运动空间。竖屏不自动添加升空和俯冲，不靠裁掉肢体容纳双人动作。

### 连续长镜头还是剪辑段落

用户要求一镜到底时，用一条连续摄影机路径组织动作节拍：明确开始位置、跟随对象、路径转折、焦点转移和结束构图。时间标注代表同一镜头内的阶段，不写成互相矛盾的“切到另一机位”。保持稳定资产、地标和光向。

多镜剪辑则明确每镜职责、入出点和邻镜承接。模型单次生成时长不等于最终剪辑镜头的最短长度；实际需要更短镜头时按可用生成时长制作素材，再按工具能力剪辑。复杂长镜头超出模型能力时说明限制，先验证关键一段；拆段或隐藏剪辑须标明，不宣称已实现真实连续一镜到底。

## 5. 仙侠法术的可见因果

仅在已有超自然设定或用户要求时使用。法术不强行套拳脚接触：分别写出媒介、施放动作、可见形态、运动方向、对方响应和结束状态。

1. 媒介：法器是什么、谁持有、从何处产生变化；无媒介施法须符合既定世界规则。
2. 形态：描述材质感、轮廓、尺度及生长方式，例如薄雾凝结的弧面或有纹理的光带，不只写“震撼特效”。
3. 路径：说明从何处到何处、相对主体如何移动；方向、速度变化与景深共同提供尺度。
4. 响应：防护产生、受扰或消退的顺序可见；只有故事需要时才转为反击，不默认每招破防。
5. 余态：结束时法器、人物、场地留下什么可见变化，下一镜继承。颜色服从已确认资产与 look，不把元素名称绑定成唯一配色。

关键动作期间保留轮廓和空间参照，减少遮盖面部、持物手和接触位置的特效。同一镜头不同时塞入多种无关法术。屏幕大规模群体只交代必要层次，不承诺模型精确控制每个个体。

先 read，再按工具实际 schema 保存并 compile；不新增臆造的 combatLevel、martialStyle 等顶层字段。MV 沿用 musicVideo.timeline 与真实音乐分析时间，不将预估节拍声称为精准卡点。分镜图沿用资产与干净参考帧规则，不把宫格当作普通首帧直接送给视频模型。

交付包含动作节拍、空间与摄影安排、邻镜承接及待核对项。用户只要方案时停止在方案；要求实际生成时复用已确认授权和规格。生成后检查身体/兵器数量、遮挡连续性、动作相位、角色反应、实际音画同步；未观看视频不得宣称动作验收通过。

### 小型编排示例：守住通道后脱离

沿用既定的两名角色和通道资产，写实、不新增武器或损坏。A 的目标是经过通道，B 的目标是阻挡，结局沿用剧本。

- 起点：中景看清通道口、双方距离及各自朝向。
- 行动：A 尝试移向通道一侧，B 对应调整；明确双方路线和注意对象。
- 变化：按剧本发生一次可读的接触或避让，B 的位置变化让出空间；给反应留下时间，不瞬间复位。
- 结果：镜头跟随 A 经过地标，B 保持上一拍结束位置并重新观察；下镜从真实出口方向接续。

这是动作因果的示意，不是固定四镜模板。时长、镜数、是否发生接触和最终胜负均按当前剧本与模型容量确定。
