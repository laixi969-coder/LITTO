# 打斗动作与镜头素材库

依据用户提供的「S音 / Seedance 打斗动作提示词合集」7份表格筛选、去重与改写。这里只提供创作选项，不继承来源中“全部适配官方规范”、难度评级或生成成功率的说法。原表留在用户提供目录，本库不改变其来源归属。既定世界、资产与动作因果优先；先读[动作设计](combatDesign.md)，有具体表达缺口再选下面一项，不把整张表拼进提示词。

## 动作按目的选

| 当前目的 | 可选表达 | 写成执行稿前补足 |
| --- | --- | --- |
| 争取距离 | 直刺、横斩、短促肘击、推进、后撤 | 谁向谁、攻击路径、对方躲避或接触、结束距离 |
| 改变来势 | 格挡、侧移、卸力、举盾、绕外侧 | 接触对象、支撑脚、偏转方向；格挡不自动造成反伤 |
| 近身争夺 | 扣腕、锁臂、肩背摔、拉扯、压制 | 双方接触点、空闲手、重心变化、释放与落点 |
| 刀剑交锋 | 点刺、反手斩、交叉挡、回收再刺 | 左右手、刀刃路线、回收过程；剑花不代替攻防 |
| 长柄控距 | 枪尖试探、横扫、勾挂、扫低位 | 场地能否容纳、握持点、杆身与障碍、近身后如何调整 |
| 软兵器 | 鞭甩、链缠、绳镖回收 | 锚点、轨迹、张紧或松弛、回收去向；不穿过人物 |
| 重兵器 | 斧劈、锤击、盾撞 | 预备、挥击惯性、落空后恢复，不能无过程反向连击 |
| 远程攻击 | 射箭、投掷、远程法术 | 发起点、目标、弹道、遮挡、落点；再次发射的来源 |
| 试探与反击 | 轻击试探、佯攻、格挡后进身、以退换位 | 对手因什么做出回应，露出的机会是什么 |
| 多人协作 | 前后夹击、侧翼封路、掩护撤离、交叉压迫 | 每人位置和介入条件；同伴不互穿、不同时抢一个接触点 |
| 受力反馈 | 后撤失衡、武器脱手、扶墙恢复、倒地 | 与击打强度、方向一致；伤情和失物继承到下一拍 |
| 疲惫与恐惧 | 支撑兵器喘息、格挡变迟、慌乱退步 | 由已发生事件引出，不用状态标签突然改人物能力 |
| 收束 | 击退收势、控住武器、脱离、收剑、僵持 | 当前胜负、持物、站位和下一步；压制不等于已安全脱离 |
| 玄幻表现 | 御剑、结印、护盾、剑气、瞬移 | 仅既定世界允许时选，落实来源、路径、范围、代价与终态 |

来源的流派、国别混合分类不作为武术知识使用；“瞬移、轻功、音波攻击”与写实动作分开。点穴、击飞、锁喉也不因原表写作“非致命”就保证无伤。这里只设计虚构影视场面，不提供真实训练或伤害教程。

## 32条运镜归并为12种用途

编号对应原《打斗运镜32条》行号，便于追溯；合并的是重复摄影机制，不自动合并不同剧情。

| 原编号 | 选用目的 | 修订后的摄影表达与边界 |
| --- | --- | --- |
| 1、32 | 建立或结束对峙 | 双人定镜交代距离、出口、武器和支撑；远景不同时要求眼部微表情 |
| 2、15 | 关键判断或持物细节 | 眼部或手部特写择一，交代前后空间；不靠特写掩盖缺失的接触 |
| 3、6、11、18、25 | 蓄力转行动、接触强调 | 静止或缓推后，在明确事件处短推；长时间等待不称“延时摄影” |
| 4、26 | 远处观察、远程发起 | 先确定相机距离、焦点和需辨认的目标，再选焦段；不同时虚化目标又要求看清命中 |
| 5 | 看对手逼近 | 过肩镜保留前景肩部；主观镜从角色视点观看，两者择一，不写“第三人称过肩POV” |
| 7、12 | 强调高度与进攻方向 | 低机位固定或跟随，保留必要落脚区域；仰拍不等于自动产生力量 |
| 8、21、29 | 交代高低差或战场范围 | 高位俯看、向下移动、升高揭示范围按目的择一，给起终构图与路径，不靠“百万军队”证明规模 |
| 9、13、19、20、24、31 | 跟随交锋或逃离 | 选择侧移、平行跟随或轻手持；动作涉及摔投时保留支撑与落地，不能只锁上半身 |
| 10、14、30 | 在原机位追踪方向 | 垂直摇镜或水平摇镜按运动选择，摇镜是转动而不是相机平移；不同时要求扫过全身与持续特写 |
| 16、17 | 主观失衡或空间压力 | 倾斜构图与推拉变焦是不同方法；后者需相机位移与反向变焦配合，能力不明确时用普通推镜 |
| 22、27 | 展示影响范围 | 从接触区后拉至已建立的环境，保留人物位置和破坏残留，不用强光把结果全部遮掉 |
| 23、28 | 交代环绕关系或多组位置 | 环绕与群像定镜择一；环绕明确起终方位，120度不是半圈；群战先分层，不要求所有交锋同等清晰 |

原表“禁止360度”“基础/低崩坏”等不作为通用限制或承诺。是否环绕、变焦、切镜取决于叙事与真实模型能力；实拍摄影术语也不等于供应商支持数值控制。

## 光影、天气与效果

沿用已采用的 Look，只补本场缺项。冷暖是可选表现，不按正邪或胜负自动配色。

| 类别 | 可选素材 | 与动作绑定 |
| --- | --- | --- |
| 持续光源 | 月光、阴天漫射、落日侧光、洞内烛火、火场光 | 写来源、方向、受光范围；烛火不因场景阴暗就变冷蓝光 |
| 短时光源 | 闪电、能量释放、爆炸闪光 | 只在事件发生时影响照明，写消退后的基底光 |
| 天气 | 雨、雪、风沙、薄雾、浓烟 | 改变可见性、脚下条件和衣物状态；下一镜保持湿度或残留 |
| 碰撞 | 火花、兵刃震动、碎屑、溅水 | 接触先成立，效果与材料相容；不是所有碰撞都出火花 |

| 能量 | 光刃、符文、护盾、气浪、粒子 | 依据世界规则选；发起、传播、作用、消散与残留连续 |

## 三类分镜练习

改编自原表三套脚本的组织用途，不沿用固定30秒、人物、画幅或必杀结尾。

1. 双人兵器：建立距离与出口 → 试探改变防守 → 一次有效交锋 → 反制迫使换位 → 结果接下一镜。原武侠例的剑气只适用于已允许法术的世界。
2. 仙侠空战：建立高度与相对方向 → 迂回攻防 → 蓄力时对手仍有行动 → 能量交锋 → 显示冲击后的双方状态。御剑、停悬和能量传播必须已获世界规则支持。
3. 巷道追杀：建立潜伏位置 → 突袭与回应 → 近战阻止脱离 → 逃跑改变距离 → 巷口交锋与结果。原例“瞬移”不迁入写实场；负伤后保持同一伤情，不默认以濒死收尾。

## 从词组到提示词

原例“1.5秒内击中、倒飞三米、撞墙、跪地”压缩了接触、飞行、撞击和恢复，不能直接当合法时长方案。按实际可辨事件估时，再按模型档位计划；需要拆段时保持前段结束状态。具体数值由当前动作与预演决定。

改写示范：甲右手持短棍，乙从画面右侧挥棍向甲肩部。甲向左移步，抬棍挡住来势；两棍接触后，甲退半步重新站稳，右手仍握棍，乙停在甲右前方。相机在两人侧前方保持中全景，使接触和落脚都可辨认。地面沿用已定雨后湿石面，脚下溅起少量水；没有新增伤情、慢动作或法术。

正式制作写入现有 action、blocking、camera、lighting、startState/intendedStateDelta；独立视频提示词按当前交付格式转写。模型参数、声音、参考编号另按实际能力填写。编译后回读请求，动态输出看过才填 resultState；以上示范未经视频生成验证。
