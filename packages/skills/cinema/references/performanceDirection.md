# 表演指导与人物调度

LITTO 适配版，2026-10-06。以 O-Side 的 higgsfield-acting、NolanX 的对白表演与调度技能为主要来源，参考 H3 分镜与表演项目的局部修复经验。固定版本、采用边界及 MIT 许可见 [来源与许可](performanceDirectionLicense.md)。这些是社区创作方法；本项目没有据此保证任何模型的表演或口型效果。

用于有角色表演、对白、无声反应或群像的镜头。无人环境、静物产品镜头不套人物表演模板；动画、动物、面具或机械角色按已确认的表现方式设计，不强加真人面部肌肉。

## 1. 先给角色任务，再写反应

读剧本、当前场景和已采用的角色设定，确定角色此刻知道什么、想从谁那里得到什么、阻力在哪里、正尝试怎样做。目标写成可执行行动，例如让对方留下、确认消息、掩饰迟疑。沿用故事已有冲突，不为“有演技”添加创伤、谎言、敌意或悲剧。

潜台词只在剧情有依据时使用：嘴上说的话与心里要达成的事如何不同，哪里出现了可见破绽。每个主要节拍落实“触发 → 判断或抑制 → 可见/可听行为 → 留下的状态”。反应可发生在一句话中途，但必须已经听到或看到触发信息；不能从开场就演出尚不知道的结局。

不按情绪词机械配动作：悲伤不必哭，愤怒不必吼，沉默不等于毫无反应，镇定也不等于凝固。强度数值只是描述，不能替代具体行为。动作数量和情绪转折次数按戏份决定，不强制每场 2–4 次变化或每镜 2–3 秒。

## 2. 身体、目光与景别一起设计

先选本镜最重要的一项行为，必要时加一项辅助反应；不要同时要求抬眉、眨眼、咬唇、落泪、颤抖、转头和迈步。近景让观众读到细微反应；远景用姿态、距离和行动变化表达，不在看不清脸时堆面部细节。

- 目光有对象与目的：观察对方是否相信、核对物件、避开某人的注视。写清什么时候转移、落在哪里，不能用固定眨眼配额、乱扫视或加强眼部高光代替注意力。
- 身体有任务：沿用剧本里的持物、整理或等待等行为；某个词让既有动作停住、继续或改变，可以成为转折。没有道具时用视线、呼吸或姿态，不额外塞杯子、香烟、伤疤。
- 习惯有触发条件，且适合当前姿势。坐着时不照搬走路姿态；并非每镜都必须展示同一个小动作。保持年龄、体型和自然比例，不用衰老、粗糙皮肤或劳损代替人物经历。
- 静止可以是有意识的倾听与等待；不要要求“整个身体一切不变”，也不要为了活动量强行摇摆。表演持续存在，不是台词结束就立刻恢复中性表情。

## 3. 对白、倾听和声音

逐句保留用户台词，明确说话者、画面正在看的人、声音来源和触发信息。听者可以在关键词之后反应，不必机械等整句结束；未获得线索的人不能同步知道。无对白戏用剧本已有动作或感知信息推动，不为了让模型动嘴新增独白。

声音身份与当场语气分开：沿用已确认的音色、口音和声音参考；音量、呼吸、语速和停顿随本场目的调整。疲劳或哭泣可以影响声音表现，但不能无故换成另一人的音色。关键对白保留可理解性，不把所有说话都变成低语、喘气或重叠抢话。

优先以实际录音时长安排镜头，再容纳反应与停顿；没有录音时标为估计。不靠字数估算声称口型已同步，不将字幕文本当作已有配音。音频/表演参考只有在实际模型接口支持并已绑定时才算送入；不支持时写明需要配音、口型处理或调整方案。

## 4. 双人和群像调度

用已确认的关系与空间安排接近、后退、转身、坐下或停住；人物路径与摄影机路径分别写。距离变化应有行动理由，不靠每句对白换机位制造表演。

同一事件中，每个人按自己获得信息的时点、注意力和目标反应，幅度可以不同。背景人物保持原有任务，不全部同时转头、惊讶或点头；明确要求的整齐表演例外。静默角色也要有当前注意对象，不能站着等轮到说话。不要把地位高低固定等同于安静/吵闹，也不按身份标签推断步态、口音或人格。

## 5. 写进实际 ShotSpec

复用当前工具支持的字段，不另造接口。按角色名称分别描述，避免一句反应被分配给所有人：

| 现有字段 | 落实内容 |
| --- | --- |
| action | 谁对谁做什么、触发事件和可见结果；必要的说话者与原句 |
| performance.emotion / intensity | 本镜情绪方向与适当强度，不能单独作为完整表演指令 |
| performance.eyeline / lookTarget | 已有空间里的目光方向与对象 |
| performance.gesture | 角色目的、当场策略与主要身体证据；必要的潜台词用可见行为表达 |
| performance.timing | 听到/看到什么后如何反应、台词与停顿先后、结束时残留的反应；声音身份和语气按需要写入 |
| blocking / camera | 人物与环境的相对位置；让关键反应可见的景别、焦点和有动机的运动 |
| constraints | 本镜真正需要防止的提前反应、串人、擅改台词或无故复位 |
| intendedStateDelta.emotional | 按实际角色资产 ID 记录计划中的情绪变化；未查看输出不能称为观测事实 |

跨镜读取已确认的上一镜实际状态；只有计划时明确为待核对，并把需要承接的呼吸、目光或未完成动作写进本镜 action/performance.timing。不能假定状态表中存在就已经进入模型请求。表演习惯、声音设定可保存在角色现有 attributes 或设定文档，情绪和表情不能作为永久身份锁定项。

通过 productionSpec 保存并 compile 后，检查实际请求的 PERFORMANCE、ACTION、BLOCKING 与约束是否保留人物归属、触发、顺序和声音意图。工具字段不支持的内容放入合适的现有文本字段，不能只写在聊天分析里。画布模式则将同一内容写入真实生成节点并核对引用。若只是无大模型的规则草案，标为基础草案，不称为专业表演设计已完成。

## 6. 审看与最低成本修复

审看完整表演段落及声音：角色是否在追求目标、是否听到了才反应、停顿里是否有判断、说话与听者是否串人、动作是否抢台词、结束情绪是否接得上下一镜。区分文字方案核对、模型执行符合度与表演是否可信；没有看听能力时说明未验收。

| 实际问题 | 优先处理 |
| --- | --- |
| 只有表情标签、人物僵硬 | 补具体目标和触发，减少互相冲突的动作，确认景别看得见 |
| 表情夸张或不停眨眼 | 去掉机械表情清单，让目光服务当场任务 |
| 反应过早、过晚或情绪无故复位 | 校正触发顺序与前后状态；已有合格素材可先调整真实入出点 |
| 群像整齐同动、听者没有反应 | 按人物分配注意对象、信息到达时点与不同反应 |
| 台词挤满镜头或口型不符 | 对照实际录音和嘴部运动检查，按真实能力修时长或配音流程 |
| 多个表演节拍都没执行 | 在保持剧情与用户镜头要求下减小单段任务，或把可编辑的段落拆开；不擅自破坏一镜到底 |

像素差或 PSNR 只能提示画面变化，摄影机运动和曝光变化也会影响数值，不能当作演技评分。静帧不能证明倾听、反应时序或口型同步。不能把冻结帧冒充自然停顿，不能为验证上游经验自动批量更换 seed 付费重跑。局部修改保留旧版，生成次数服从当前授权。
