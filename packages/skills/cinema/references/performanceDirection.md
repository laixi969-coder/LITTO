# 表演指导与人物调度

MILI MILI 适配版，2026-10-13。在原有 O-Side、NolanX、H3 方法上，对照 act-skill、ai-film-skills 与 director-craft-framework 补充适用范围、当场行为和摄影时机。固定版本、实际采用边界与许可见[来源与许可](performanceDirectionLicense.md)。这些是社区创作方法；本项目没有据此保证任何模型的表演或口型效果。

用于有角色表演、对白、无声反应或群像的镜头。无人环境、静物产品镜头不套人物表演模板；动画、动物、面具或机械角色按已确认的表现方式设计，不强加真人面部肌肉。

按当前段落选择重点，同一作品可以切换；只读取本方法，不为一次表演叠读全部上游技能或情绪知识库。已有表演具体且可执行时直接沿用，只有情绪标签或实际失败时才展开修订。

| 段落用途 | 表演重点 |
| --- | --- |
| 电影、剧情 MV、剧情广告 | 对手关系、信息到达、策略变化与镜尾余波；喜剧、温暖日常也按已有事件设计，不强加压抑或悲剧 |
| 演唱、舞蹈、时尚 MV | 歌词或乐句、目光对象、身体动作落点与造型活动范围；已有 musicVideo.timeline 承载时间，不另建情绪时间轴 |
| 产品使用、生活方式、口播广告 | 看见、选择、接触、使用及有依据的反应；兼顾产品可读性，不默认夸张惊喜、持续微笑或新增功效体验 |

干净、完整、清晰及既定体型继续沿用。紧张、疲惫或悲伤属于当场表演，不自动改变服化道维护状态、人物年龄、身体比例和场景曝光。

## 1. 先给角色任务，再写反应

读剧本、当前场景和已采用的角色设定，确定角色此刻知道什么、想从谁那里得到什么、阻力在哪里、正尝试怎样做。目标写成可执行行动，例如让对方留下、确认消息、掩饰迟疑。沿用故事已有冲突，不为“有演技”添加创伤、谎言、敌意或悲剧。

潜台词只在剧情有依据时使用：嘴上说的话与心里要达成的事如何不同，哪里出现了可见破绽。每个主要节拍落实“触发 → 判断或抑制 → 可见/可听行为 → 留下的状态”。反应可发生在一句话中途，但必须已经听到或看到触发信息；不能从开场就演出尚不知道的结局。

不按情绪词机械配动作：悲伤不必哭，愤怒不必吼，沉默不等于毫无反应，镇定也不等于凝固。强度数值只是描述，不能替代具体行为。动作数量和情绪转折次数按戏份决定，不强制每场 2–4 次变化或每镜 2–3 秒。

复用角色设定中已成立的行为习惯，但每镜只选当前目标、姿势和关系下有用的部分。例如习惯快步行走的人坐下后，不必补出抖腿来证明同一性。剧情需要掩饰时才区分“想让对方做什么”和“此刻不想被看见什么”；没有依据不虚构隐情。通用习惯不整段复制进每镜，也不锁成永不变化的身份特征。

## 2. 身体、目光与景别一起设计

先选本镜最重要的一项行为，必要时加一项辅助反应；不要同时要求抬眉、眨眼、咬唇、落泪、颤抖、转头和迈步。近景让观众读到细微反应；远景用姿态、距离和行动变化表达，不在看不清脸时堆面部细节。

先确定关键反应发生在哪里，再决定摄影是否需要移动。需要移动时，把开始的触发、运动路径与停止位置写入现有 camera.design；停点须能读到目标反应，不机械在情绪变化前推近，也不因出现情绪词就自动换光。剪点按信息或动作关系安排，保留观众理解反应所需的过程；明确要求的悬念遮挡和提前切走仍按导演意图执行。

- 目光有对象与目的：观察对方是否相信、核对物件、避开某人的注视。写清什么时候转移、落在哪里，不能用固定眨眼配额、乱扫视或加强眼部高光代替注意力。
- 身体有任务：沿用剧本里的持物、整理或等待等行为；某个词让既有动作停住、继续或改变，可以成为转折。没有道具时用视线、呼吸或姿态，不额外塞杯子、香烟、伤疤。
- 习惯有触发条件，且适合当前姿势。坐着时不照搬走路姿态；并非每镜都必须展示同一个小动作。保持年龄、体型和自然比例，不用衰老、粗糙皮肤或劳损代替人物经历。
- 静止可以是有意识的倾听与等待；不要要求“整个身体一切不变”，也不要为了活动量强行摇摆。表演持续存在，不是台词结束就立刻恢复中性表情。

### 造型与情绪演绎的接口

角色稳定的表演习惯只是基线，当场目标可使其克制、掩饰或改变策略。相互冲突的情绪先选本节拍可读的行动，例如想挽留却把递出的手收回；不把“又喜又悲”拆成同时出现的满脸表情清单，也不为增加层次虚构内心秘密。

按[妆造设计](../../workflow/references/methods/characterStyling.md)核对眼妆、面纱、发丝、领袖与鞋履是否遮住或限制主要表演。妆造影响可见条件，不能代替反应：花妆不是悲伤的证明，红唇不是强势的证明，卸妆后的脸仍能继续同一情绪。换装、整理发饰或擦妆可成为已有剧情的身体任务；触发、接触、迟疑和完成后的余波分别写入 action / performance.timing，不能每个人都安排同一小动作。

## 3. 对白、倾听和声音

逐句保留用户台词，明确说话者、画面正在看的人、声音来源和触发信息。听者可以在关键词之后反应，不必机械等整句结束；未获得线索的人不能同步知道。无对白戏用剧本已有动作或感知信息推动，不为了让模型动嘴新增独白。

声音身份与当场语气分开：沿用已确认的音色、口音和声音参考；音量、呼吸、语速和停顿随本场目的调整。疲劳或哭泣可以影响声音表现，但不能无故换成另一人的音色。关键对白保留可理解性，不把所有说话都变成低语、喘气或重叠抢话。

优先以实际录音时长安排镜头，再容纳反应与停顿；没有录音时标为估计。不靠字数估算声称口型已同步，不将字幕文本当作已有配音。音频/表演参考只有在实际模型接口支持并已绑定时才算送入；不支持时写明需要配音、口型处理或调整方案。

## 4. 双人和群像调度

用已确认的关系与空间安排接近、后退、转身、坐下或停住；人物路径与摄影机路径分别写。距离变化应有行动理由，不靠每句对白换机位制造表演。

同一事件中，每个人按自己获得信息的时点、注意力和目标反应，幅度可以不同。背景人物保持原有任务，不全部同时转头、惊讶或点头；明确要求的整齐表演例外。静默角色也要有当前注意对象，不能站着等轮到说话。不要把地位高低固定等同于安静/吵闹，也不按身份标签推断步态、口音或人格。

## 5. 写进实际 ShotSpec

复用当前工具支持的字段，不另造接口。按角色名称分别描述，避免一句反应被分配给所有人：

| 现有字段 | 落实内容 |
| --- | --- |
| visibleAssetIds / camera.design.start | 本镜实际出镜集合 / 首帧瞬间的占位、姿势和持物；稍后入镜写进行动时点，纯画外发声者不填画面站位 |
| action | 谁对谁做什么、触发事件和可见结果；必要的说话者与原句 |
| performance.emotion / intensity | 本镜情绪方向与适当强度，不能单独作为完整表演指令 |
| performance.eyeline / lookTarget | 已有空间里的目光方向与对象 |
| performance.gesture | 角色目的、当场策略与主要身体证据；必要的潜台词用可见行为表达 |
| performance.timing | 听到/看到什么后如何反应、台词与停顿先后、结束时残留的反应；声音身份和语气按需要写入 |
| blocking / camera | 人物与环境的相对位置；让关键反应可见的景别、焦点和有动机的运动 |
| constraints | 本镜真正需要防止的提前反应、串人、擅改台词或无故复位 |
| intendedStateDelta.emotional | 按实际角色资产 ID 记录计划中的情绪变化；未查看输出不能称为观测事实 |

跨镜读取已确认的上一镜实际状态；只有计划时明确为待核对，并把需要承接的呼吸、目光或未完成动作写进本镜 action/performance.timing。不能假定状态表中存在就已经进入模型请求。角色长期档案使用 attributes.characterDirection{speech,behavior,relationships}，导演按当场目的选用，生成请求不复制整份档案。发声习惯转成该句 dialogue.delivery，静默人物不附声音指令；情绪和表情不能作为永久身份锁定项。

通过 productionSpec 保存并 compile 后，检查实际请求的 PERFORMANCE、ACTION、BLOCKING 与约束是否保留人物归属、触发、顺序和声音意图。工具字段不支持的内容放入合适的现有文本字段，不能只写在聊天分析里。画布模式则将同一内容写入真实生成节点并核对引用。若只是无大模型的规则草案，标为基础草案，不称为专业表演设计已完成。

最终请求只保留本镜会执行的内容：有 musicVideo.timeline 时，把时间和先后顺序集中在那里，performance 补充未重复的行为质感与视线；没有时间线时用 action 与 performance.timing。发现矛盾先修原字段，不在尾部追加另一套表演。人物小传、候选反应、方法解释与验收清单留在制作记录，不设固定表演字数、占比或情绪条目数量。

## 按模型能力分工

同一段表演描述，不同执行器落得到的层次差别很大。先确认当前视频模型属于哪一档，再决定表演写在哪一层：

| 执行器 | 表演写在哪 | 不要写 |
| --- | --- | --- |
| 能做面部表演的模型 | 肌肉级：内眉抬、下眼睑收紧、嘴角单侧、喉结、鼻翼。可查[表演素材库](facialPerformance.md)的 FACS 与情绪链 | 只有「悲伤」「平静」这类概括词 |
| 只演动作的同生声模型（H3 一类） | 首帧把表情定住，提示词只写手、头、呼吸、视线、重心 | 面部肌肉细节——写了不执行，还会挤掉真正能执行的动作 |
| 只轻微动的图生视频、4 秒以内的短镜 | 一镜一个动作 + 首帧表情 | 镜内转折、多段情绪 |

三条在实践中验证过的规则：

1. **表情靠首帧，动作靠提示词。** 首帧只建立初始表情与姿势，镜内变化按当前模型能力和触发顺序设计。不能把尚未发生的被击中、理解或决定提前画到首帧；微动模型不能执行时应调整覆盖，不删掉必要因果。
2. **景别决定微表情是否存在。** 中景脸只占画面约八分之一，谈不上任何微表情；近景（脸占三分之一）才谈得上。要演技先改景别，不要先加形容词。
3. **按执行容量组织相连节拍。** 一镜可以包含触发、反应、选择与结果；仅当当前模型无法清楚完成、空间或信息需要变化时再拆镜。短时长和微动模型适当减少并发复杂度，但不把“一镜一个节拍”套给所有镜头，不按对白轮次或字数硬切，具体见[对白覆盖](coverage.md)。

写表演词时查[表演素材库](facialPerformance.md)选词，但只把本镜要执行的 2–3 个信号写进请求；整份词典抄进去会让模型平均化所有信号。

## 6. 审看与最低成本修复

审看完整表演段落及声音：角色是否在追求目标、是否听到了才反应、停顿里是否有判断、说话与听者是否串人、动作是否抢台词、结束情绪是否接得上下一镜。区分文字方案核对、模型执行符合度与表演是否可信；没有看听能力时说明未验收。

| 实际问题 | 优先处理 |
| --- | --- |
| 只有表情标签、人物僵硬 | 补具体目标和触发，减少互相冲突的动作，确认景别看得见 |
| 表情夸张或不停眨眼 | 去掉机械表情清单，让目光服务当场任务 |
| 反应过早、过晚或情绪无故复位 | 校正触发顺序与前后状态；已有合格素材可先调整真实入出点 |
| 群像整齐同动、听者没有反应 | 按人物分配注意对象、信息到达时点与不同反应 |
| 台词挤满镜头或口型不符 | 对照实际录音和嘴部运动检查，按真实能力修时长或配音流程 |
| 多个表演节拍都没执行 | 在保持剧情与用户镜头要求下减小单段任务，或把可编辑的段落拆开；不擅自破坏一镜到底 |

像素差或 PSNR 只能提示画面变化，摄影机运动和曝光变化也会影响数值，不能当作演技评分。静帧不能证明倾听、反应时序或口型同步。不能把冻结帧冒充自然停顿，不能为验证上游经验自动批量更换 seed 付费重跑。局部修改保留旧版，生成次数服从当前授权。

## 按场面选表演写法

| 当前场面 | 可填写的执行句 | 输出应检查什么 |
| --- | --- | --- |
| 特写中的消息到达 | {人物}正在{已有任务}，在{触发信息}之后把视线从{对象}移到{对象}，{主要行为改变}，镜尾仍{余波} | 注意力转移有依据，头/眼/手可错开但不强制固定先后 |
| 有依据的掩饰 | 继续{正常行为}时短暂{可见破绽}，为{已定目的}恢复{行为} | 不是全身同时演一串情绪；无隐瞒剧情就不套掩饰 |
| 双人回应 | 甲{行动}；乙获得{信息}后{反应}；甲因乙的反应{调整} | 听者有任务，未获信息者不提前反应；持物与距离连续 |
| 接触与释放 | {手/身体/物件}接近{部位}，接触后{受力反应}，释放后{恢复或持续状态} | 来手归属、接触可见、释放成立，不能从最后姿态推断全程 |
| 环境触发 | 已有{风/声音/光变}使{身体任务}改变，人物{应对} | 风向、遮蔽、衣物与受光响应相容，不凭空加环境事件 |

情绪词可保留为意图，但应有能被当前景别读到的行为。强度依人物与场面选择：克制、爆发、静止都可以成立，不禁用全部情绪词、不规定每镜眨眼或一至两个微动作。多张表情图只供目标形态参考，不能证明自然过渡；避免把身份锁定误写成表情冻结。

声音沿用采用音色，逐句 delivery 写说话目的、重音、停顿和力度；优先使用提供商支持的语音指令。标点不是通用时长控制器，不为了语气篡改原句。发声、口型、听者反应和字幕分别验，实际音轨未听就不填声音通过。
