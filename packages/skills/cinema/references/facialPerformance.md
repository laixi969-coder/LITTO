## 一、面部动作语言（基于 FACS 系统）

### 眉部
| AU | 动作 | 提示词语言 |
|----|------|-----------|
| AU1 | 内眉抬起 | 内眉端微微上扬，眉间形成浅竖纹 |
| AU2 | 外眉抬起 | 眉梢上挑，不对称时产生怀疑感 |
| AU4 | 眉间收紧下压 | 眉间紧锁，眉脊向下压，形成纵向皱纹 |

### 眼部
| AU | 动作 | 提示词语言 |
|----|------|-----------|
| AU5 | 上眼睑抬起 | 上眼睑抬起，露出更多虹膜，眼白可见 |
| AU6 | 脸颊抬起 | 脸颊抬高，外眼角出现细纹（鱼尾纹） |
| AU7 | 眼睑收紧 | 下眼睑绷紧上提，眼睛变窄 |
| AU43 | 闭眼 | 眼睑缓慢闭合/快速闭合 |
| AU45 | 眨眼 | 单次或连续眨眼；次数不证明紧张或撒谎 |
| AU46 | 单眼眨 | 单侧眨眼，配合嘴角不对称动作 |

### 唇部
| AU | 动作 | 提示词语言 |
|----|------|-----------|
| AU12 | 嘴角上扬 | 嘴角抬高，颧大肌收缩 |
| AU14 | 嘴角收紧 | 嘴角被拉向两侧，形成浅窝 |
| AU15 | 嘴角下拉 | 嘴角下垂，下巴肌肉紧张，下唇外翻 |
| AU17 | 下巴抬起 | 下巴向上推，下唇突出 |
| AU24 | 双唇紧压 | 双唇压成一条密封线，唇色变淡 |
| AU25 | 双唇分开 | 嘴唇微微张开，露出齿间缝隙 |
| AU26 | 下颌下垂 | 下颌下降，嘴张开 |
| AU28 | 吸唇 | 双唇向内卷吸，唇线消失 |

### 复合表情（可靠组合）

| 情绪 | 组合 | 提示词 |
|------|------|--------|
| 真实克制的愉悦 | 颧大肌+眼轮匝肌，无眉间紧张 | 嘴角上扬，外眼角出现细纹，眉间无任何收紧 |
| 隐忍的伤痛 | 眉间紧锁+嘴角下拉+颏肌紧张 | 眉间紧锁，嘴角下垂，下巴肌肉紧绷微微皱起 |
| 失望 | 嘴角下拉+下巴紧张+内眉抬起 | 嘴角微微下垂、下巴紧张凸起，内眉端抬起 |
| 愤怒 | 眉间下压+上唇提升+眼睑收紧 | 眉间向下压，上唇微微提起，下眼睑收紧 |
| 恐惧/警觉 | 上眼睑提起+内眉抬起+嘴微张 | 上眼睑充分抬起，内眉端上提，嘴唇微张 |
| 厌恶 | 鼻梁皱起+上唇提升 | 鼻梁上方出现横向皱纹，上唇向后上方提 |
| 蔑视 | 单侧嘴角收紧不对称上扬 | 一侧嘴角收紧向上翘，另一侧保持不动 |
| 情感麻木 | 整体张力低，所有动作幅度减半 | 面部各区域活动幅度明显弱于正常，眼神空洞 |

## 二、情绪表演链（精选 16 组核心模板）

> 中文表演词来自《AI角色表情动作与镜头表演提示词手册》

### 悲伤类

**1. 悲伤→压抑**
```
0-25%：目光空洞，焦点落在虚空处，呼吸变浅
25-50%：内眉端缓慢抬起，下眼睑微微收紧，泪光浮起但未落下
50-75%：双唇抿紧成一线，下巴肌肉紧绷微微皱起，喉结滚动——她在吞咽情绪
75-100%：目光低垂，嘴角缓慢下垂，肩膀微微下沉，静止
```

**2. 流泪失控**
```
0-20%：眼睑快速眨动，眼睛逐渐发红，鼻翼微微翕动
20-50%：第一滴泪从下眼睑边缘滑落，嘴角不受控制地抽动
50-80%：泪水连续滑过脸颊，呼吸变得不均匀，锁骨随抽泣起伏
80-100%：用手背擦泪但泪水不止，最终放弃，任泪流淌
```

**3. 思念崩溃**
```
0-20%：看着某样旧物，眼神由茫然转为聚焦——她认出来了
20-50%：手指无意识摩挲物件表面，呼吸开始加重
50-80%：眼眶泛红，下巴肌肉剧烈抖动，胸廓起伏紊乱
80-100%：紧紧抓住物件贴在心口，身体蜷缩，无声哭泣
```

**4. 绝望放空**
```
0-30%：眼睛睁着但不聚焦，瞳孔对光反应迟钝
30-70%：嘴巴微张但无气息进出——呼吸极浅极慢
70-100%：全身静止，只有眼角一滴泪自然滑落，不擦不看
```

### 温柔/爱意类

**5. 深情凝视**
```
0-30%：眼神从环境自然过渡到对方脸上，嘴角不自觉地微弯
30-60%：瞳孔微微放大，上眼睑微微抬起，眼神变柔
60-100%：外眼角出现浅纹，嘴角保持柔和弧度，静止凝视
```

**6. 心疼**
```
0-25%：眉头微蹙，眼神聚焦在对方的伤口/不适处
25-50%：手抬起但停在半空——想触碰又怕弄疼
50-75%：轻咬下唇，呼吸变浅，眼眶略微泛红
75-100%：最终轻柔触碰，同时深呼一口气——刚才一直在屏息
```

**7. 害羞的笑**
```
0-20%：与人对视后迅速低头，嘴角已不可控地上翘
20-50%：试图抿唇压住笑意但失败了，单侧嘴角先泄出弧度
50-70%：脸颊泛红，眼神闪烁看向别处又偷瞄回来
70-100%：用手背挡住下半张脸，眼睛弯成月牙，肩膀微微耸起
```

### 冷意/愤怒类

**8. 隐忍愤怒**
```
0-25%：下颌线紧绷，咬肌凸起，目光变硬
25-50%：双手缓慢握拳，指节泛白，呼吸加重
50-75%：鼻翼扩张，眉间深锁，上唇微提——牙齿轻咬
75-100%：强制自己松开拳头，但眼神依旧锋利，胸口起伏未平息
```

**9. 失望（高控制）**
```
0-25%：眼睛先亮（期待）后暗（落空），不到一秒
25-50%：嘴角向两侧轻微拉伸——一个不带感情的微笑
50-75%：叹气，胸廓下沉，肩膀随之下垂
75-100%：身体微微后退半步，目光低垂到地面，不再直视
```

**10. 冷笑自嘲**
```
0-20%：听到某个词后眼神骤变——从惊讶转冷
20-50%：单侧嘴角上扬，不对称的弧度，眼神却毫无笑意
50-70%：轻微摇头，幅度极小，像在否定什么
70-100%：转身或移开视线，笑意未消但眼神彻底暗下去
```

### 特殊状态

**11. 抽离/麻木**
```
0-30%：目光放空，焦点穿过面前的人和物，落在不知名的远处
30-70%：呼吸极浅极慢，嘴唇微张，对周遭声音不做出转头反应
70-100%：注意力完全从现实中抽离，静止，面无表情
```

**12. 微醺的笑**
```
0-25%：眼睑微微下垂，眼神慵懒，瞳孔略微放大
25-50%：嘴角缓慢上扬，弧度松散不克制
50-75%：头微微歪向一侧，肩膀放松下沉
75-100%：发出无声的轻笑，眼睛半眯，用手指撩开额前碎发
```

### 疼痛/医院场景

**13. 隐忍剧痛**
```
0-20%：突然睁大眼睛，瞳孔收缩——痛感袭来
20-50%：咬紧牙关，下颌肌肉绷出棱角，额头沁出冷汗
50-75%：一只手死死抓住身边物体（床单/扶手），指节泛白
75-100%：强行调整呼吸节奏，用鼻子深吸气，嘴缓慢呼出
```

**14. 苏醒恍惚**
```
0-25%：眼睑缓慢抬起，瞳孔对光线收缩——不适应亮度
25-50%：缓慢眨眼数次，眼球转动环视环境——在定位
50-75%：尝试吞咽，喉结滚动，嘴唇干涩微张
75-100%：试图抬起手臂但力不从心，手指在床单上无力蜷缩
```

### 双人互动

**15. 重逢拥抱**
```
0-20%：看到对方，瞳孔先放大后收缩——认出→震惊
20-50%：脚步先停顿再加速，呼吸变得急促
50-70%：一头扎进对方怀里，手臂紧紧环绕对方背部
70-100%：脸埋在对方肩窝，肩膀微微抽动，似哭似笑，手指攥紧对方衣服
```

**16. 诀别转身**
```
0-25%：眼眶通红，嘴唇紧抿，最后看一眼对方
25-50%：缓慢转身，动作克制，每一步都踩得极重
50-75%：走出几步后肩膀开始微微发抖，但脚步不停
75-100%：伸手想抹脸但手停在半空又放下，最终消失在画面深处
```

## 三、镜头语言——情绪驱动表

| 情绪 | 景别 | 镜头运动 | 光源 | 节奏 |
|------|------|---------|------|------|
| 隐忍伤痛 | 近景/特写 | 呼吸停顿时缓慢推近 | 柔和侧光，暖→冷渐变 | 慢→停滞 |
| 失望 | 3/4近景 | 轻微后退，增加人物周围空白 | 散射光，低饱和度 | 慢速后退 |
| 克制愤怒 | 正面近景/微低角度 | 下颌收紧时推进并锁定 | 硬侧光，阴影对比强 | 静止+突进 |
| 崩溃失控 | 近景+手持感 | 轻微不规则摇晃，一次反应抖动后静止 | 冷光为主，曝光略欠 | 不稳定 |
| 温柔深情 | 特写/极近景 | 不推不拉，固定机位长停留 | 暖光，浅景深 | 静止 |
| 恐惧警觉 | 中景→近景 | 从角色视角缓慢推近目标 | 逆光或不稳定光源 | 缓慢→突停 |
| 心动羞怯 | 近景 | 目光相遇后轻微靠近 | 柔和侧逆光，浅景深 | 缓缓→固定 |
| 麻木抽离 | 固定机位/侧面近景 | 不推进，长停留 | 平光，略欠曝 | 完全静止 |
| 对峙冲突 | 中景/双人中景 | 从侧面/过肩缓慢环绕 | 侧光，一明一暗 | 缓慢环绕 |
| 诀别分离 | 中景→远景 | 缓慢后拉，人物在画面中越来越小 | 冷光+单一暖色光点 | 极慢后退 |

### 镜头选择的适用范围
上表是候选摄影方法，不是情绪与景别、光色、运镜的一对一强制映射；沿用本场摄影、世界光源和已定媒介。
- 运动服务具体信息或情绪变化，停点由当前行动决定；持续跟拍不必在每个情绪节点停下
- 不要为了"让视频有动态感"而持续移动
- 手持、稳定跟随或固定机位按视点与动作可读性选择，不为某种情绪强制换支撑方式
- 静止镜头的力量往往大于运动镜头

## 四、身体动作与道具

### 手部动作库
| 动作 | 情绪含义 | 提示词 |
|------|---------|--------|
| 握拳 | 愤怒/隐忍/决心 | 双手缓慢收紧握拳，指节泛白 |
| 手捂嘴 | 震惊/压抑哭泣 | 一只手快速捂住嘴，指尖微颤 |
| 伸手又收回 | 渴望+克制 | 手抬至半空，指尖微张，停顿后收回紧贴胸口 |
| 摩挲物件 | 思念/焦虑 | 拇指无意识来回摩挲物件边缘 |
| 抓握他人手臂 | 恐惧/求助 | 手指收紧抓住对方前臂，用力到指尖发白 |
| 撩发 | 紧张/害羞 | 手指插入发间向后拨，露出耳廓 |
| 指尖触碰 | 心疼/温柔 | 指尖极轻地触碰目标，几乎不施压力 |

### 身体姿态库
| 姿态 | 情绪含义 | 提示词 |
|------|---------|--------|
| 后退半步 | 受伤/退缩 | 脚后跟先移，身体重心后撤，上半身保持朝向 |
| 身体前倾 | 愤怒/关切/施压 | 重心从脚跟移到前掌，上半身倾斜 |
| 蜷缩 | 崩溃/自我保护 | 双膝收向胸口，手臂环抱小腿，额头抵膝 |
| 转身不回头 | 诀别 | 动作流畅不卡顿，肩膀线条从松→绷→松 |
| 耸肩 | 无奈/自嘲/无所谓 | 肩膀快速上提放下，配合嘴角不对称 |
| 瘫坐 | 绝望/疲惫 | 脊柱弯曲，重心完全下沉，脖子后仰 |

### 双人关系规则
- **先定关系再写动作**：谁主动、谁回避、谁占据空间优势
- **拥抱四步节奏**：认出→奔向→接住→抱紧
- **诀别张力来源**：不追、不回头、伸手又收回
- **对峙视觉语法**：中间留白、明暗对照、不同身体姿态

## 五、表情控制词典（101 条完整分类）

> 使用时优先选择精确词，避免用概括性形容词替代

### 喜悦与积极情绪 (Joy & Positive)
微笑 / 露齿大笑 / 开怀大笑 / 喜极而泣 / 抿嘴笑 / 傻笑 / 狂喜 / 温暖的笑 / 得意的笑 / 苦笑 / 假笑 / 灿烂的笑 / 嘲笑 / 冷笑 / 甜美的笑 / 开心的眨眼 / 羞涩的笑 / 充满希望 / 安心 / 宠溺

**选词指南**：笑容的区别重点看嘴角幅度、牙齿是否露出、眼睛是否参与，以及笑意是真实、礼貌、得意还是苦涩。

### 悲伤与低落情绪 (Sadness & Melancholy)
流泪 / 无声落泪 / 嚎啕大哭 / 红眼眶 / 委屈 / 忧郁 / 心碎 / 绝望 / 疲惫 / 懊悔 / 沮丧 / 失落 / 楚楚可怜 / 麻木 / 强颜欢笑

**选词指南**：悲伤不只等于流泪。眼眶含泪、下唇颤抖、视线失焦、面部松垮和强颜欢笑分别对应不同强度。

### 愤怒与不满情绪 (Anger & Frustration)
皱眉 / 怒视 / 暴怒 / 咬牙切齿 / 烦躁 / 冷酷 / 怒吼 / 发脾气 / 杀气腾腾 / 气鼓鼓 / 凶狠 / 不耐烦 / 嫉妒 / 挑衅 / 愠怒

**选词指南**：愤怒可以从皱眉、咬牙、眼神下沉一路升级到暴怒；若需要高级克制感，优先使用下颌、眼睑和嘴角的细小变化。

### 惊讶与恐惧情绪 (Surprise & Fear)
震惊 / 睁大双眼 / 倒吸凉气 / 惊恐 / 害怕 / 呆滞 / 恍然大悟 / 受惊吓 / 惊奇 / 不可思议 / 恐慌 / 极度恐惧 / 屏住呼吸 / 惶恐不安 / 目瞪口呆

**选词指南**：惊讶通常是瞬时反应，恐惧则会继续扩散到呼吸和身体。关键词选择时先区分"意外"还是"危险"。

### 厌恶与轻蔑情绪 (Disgust & Contempt)
翻白眼 / 嫌弃 / 轻蔑 / 鄙视 / 撇嘴 / 作呕 / 傲慢 / 冷漠 / 嘲讽 / 不悦

**选词指南**：厌恶更偏身体排斥，轻蔑更偏地位判断。鼻部、嘴角和回避视线是这一类的重要信号。

### 思考与微表情控制 (Thinking & Micro-expressions)
沉思 / 歪头 / 单挑眉 / 眯眼 / 发呆 / 专注 / 困惑 / 咬嘴唇 / 舔嘴唇 / 嘟嘴 / 打哈欠 / 咽口水 / 深呼吸 / 眼角抽搐 / 吐舌头

**选词指南**：这类词适合做情绪连接和细节修正，例如挑眉、眯眼、咬唇、深呼吸，可与任何主情绪叠加。

### 暧昧、特殊风格与状态 (Romantic, Stylized & States)
抛媚眼 / 飞吻 / 脸红 / 迷离 / 含情脉脉 / 病娇 / 傲娇 / 微醺 / 沉醉 / 坚定 / 王者凝视

**选词指南**：这类表情往往需要同时控制视线、嘴角、脸颊红晕和人物气质，适合关系戏或强角色设定。

## 六、音效设计参考

### 环境音（具体化原则）
- ❌ "雨声" → ✅ "雨滴打在伞面上的闷响" / "雨水沿屋檐滴落水洼"
- ❌ "风声" → ✅ "风穿过树叶的沙沙声" / "风撞击窗户缝隙的低频呼啸"
- ❌ "城市噪音" → ✅ "远处模糊的车流引擎声" / "隔壁房间隐约的电视说话声"

### 表演音（微声音）
- 布料摩擦声（转身、抬手时）
- 呼吸声（吸气时鼻腔的轻微阻塞感、叹气时口腔的气流声）
- 吞咽声（喉部微弱的咕噜声）
- 脚步声（鞋底与地面的接触材质感）
- 心跳声（只在极度紧张/恐惧的主观镜头中使用）
- 泪水滴落声（极近距离特写时）

### 设计原则
- 环境音 = 场景信息（建立空间）
- 表演音 = 情绪信息（标记节奏变化）
- 不要所有声音同时播放——按时间轴分配
- 安静的力量：某些情绪节点应该完全静音

## 七、表演洞察（编辑补充精选）

> 来自 docx 手册中每个场景的「编辑补充」——方法论层面的底层洞察，生成提示词时作为指导原则植入

### 悲伤类
| 场景 | 核心洞察 |
|------|---------|
| 消息落地后逐渐失守 | 关键不是马上哭，而是从震惊→自嘲→彻底瓦解的递进 |
| 事实确认后维持体面 | 适合失恋/背叛/诀别——角色在努力维持最后一点尊严 |
| 道具触发情绪崩溃 | 食物/照片/信件触发思乡/委屈/生活压力，具体道具比抽象回想更有效 |
| 重大打击后麻木→冷笑 | 先用麻木建立防御，再用冷笑和骄傲撑起尊严，最后瓦解 |
| 想哭却笑着结束 | 克制型情绪——告别/错过/放手，想哭却要笑着画句号 |
| 突发噩耗后失去支撑 | 情绪从面部迅速扩散到全身——先是脸垮，再是身体塌 |

### 关系戏（双人/亲密）
| 场景 | 核心洞察 |
|------|---------|
| 受伤的是对方，疼的是自己 | 伸手又收回是非常有效的克制动作 |
| 无法真正触碰的关系 | 隔着玻璃/门/距离，隔阂本身就是情绪道具 |
| 重逢但不能相认 | 张力来自「不给对方看见真正的情绪」 |
| 心疼→幸福过渡 | 适合复合情绪，让泪光从心疼自然转向幸福 |
| 生活化亲密 | 依当场关系选择幅度与速度，关键是接触和回应成立 |

### 笑意
| 场景 | 核心洞察 |
|------|---------|
| 爽朗明亮 | 收尾及时回归自然表情，避免笑得过度表演化 |
| 被熟人打趣 | 「遮脸但眼神仍回看」是害羞笑意的核心 |
| 心上人甜蜜 | 眼神互动比嘴角幅度更重要 |
| 暧昧/久别重逢 | 比单纯甜笑更强调「想看又不敢看」的反复 |
| 慢节奏/柔光 | 迟缓、迷离和笑意缓慢扩散 |
| 成熟/从容 | 避免过度夸张，保持闭唇浅笑更高级 |
| 不能被人发现 | 道具遮挡是天然的表演装置——书/杯子/手 |
| 掌握主动权 | 不是狂喜，而是「确认之后的从容」 |

### 愤怒与权力
| 场景 | 核心洞察 |
|------|---------|
| 怒火高但不能失态 | 压低眼睑、收紧下颌比瞪眼更有力量 |
| 痛苦→讥诮→失控大笑 | 真正的崩溃点是笑声突然断裂 |
| 掌控局势的软刀子 | 语气可以温柔，眼神必须无温 |
| 公开场合嫉妒 | 越想保持笑容，细小的冻结和手部动作越泄露真相 |
| 职场克制嫌弃 | 不需要攻击动作，只用回避和眼神降温 |
| 谄媚假面剥落 | 笑容瓦解的过程比最终凶狠更重要 |
| 温柔表象失去温度 | 嘴角与眼底出现反差——嘴还在笑，眼已结冰 |

### 恐惧与接受
| 场景 | 核心洞察 |
|------|---------|
| 被威胁/无路可退 | 从瞳孔与呼吸开始，最终收缩到全身 |
| 突发证据/噩耗 | 震惊只需一瞬，真正可看的是后续几秒的消化 |
| 恐惧→接受命运 | 闭眼、叹息、再睁眼可作为气场反转开关 |

### 身体动作与镜头
| 动作/镜头 | 核心洞察 |
|------|---------|
| 走路 | 稳定感来自肩线、步频和视线方向一致。强化气场优先调整机位和速度，不堆叠过多肢体动作 |
| 追逐 | 先明确谁追谁逃、角色是否回头。适度手持增加紧张感，但肢体保持清晰可读 |
| 下跪 | 下跪速度、视线高度、手部支撑与背部是否塌陷共同决定含义 |
| 打斗 | 不要塞太多招式。用「接近→格挡/闪避→有效打击→停顿反应」形成清楚的动作因果 |
| 转身 | 肩、颈、头、视线按顺序变化；先停肩再回头比整个人同时转动更自然 |
| 手部特写 | 结合触发与关系解释握拳、颤抖、停手和交握，动作不与情绪一一对应 |
| 饮茶/饮酒 | 最有戏的节点不是"喝"，而是杯沿停在唇边或杯子落桌后眼神发生变化 |
| 拥抱 | 区分重逢/安慰/告别/控制：看手臂力度、持续时间、头部位置与是否挣扎 |
| 双人对峙 | 中间留白、明暗对照与不同身体姿态，比夸张动作更有效表达立场冲突 |
| 诀别 | 张力来自「不追、不回头、伸手又收回」——动作做少，距离感做清楚 |
| 重逢 | 四步节奏：认出→奔向→接住→抱紧，每步对应情绪升级，避免一开场就抱住 |
| 冲突 | 重点在动作前后的反应：扬手前的怒意、受击后的偏头停顿、回头时眼神变化，比接触瞬间更有戏 |

## 八、组合方法论（附录——三部分各取一层）

> 以下为通用表演写作方法，不是 Seedance 独占规则或模型原生控制能力。

### 1. 先决定「单帧」还是「动态」
单帧以表情关键词为主（见第五部分）；动态以情绪时间轴为主（见第二部分）。**不要用一长串静态形容词替代情绪变化。**

### 2. 给情绪一个明确触发点
人物看见什么、听见什么、面对谁——决定了表情为什么变化。**触发点越具体，表演越自然。**生成时每次都要补「触发事件」。

### 3. 选择当前景别与触发需要的可见信号
从**眼神、眼睑、嘴角、下颌、吞咽、呼吸、手指、肩背**中按需选择，不设固定数量。无关或互相冲突的信号会削弱表现；不能把作者的经验归因写成模型内部机制。

### 4. 用第三部分补「身体因果」
表情负责内心，动作负责外显。经典配对：
- 隐忍愤怒 + 握拳
- 诀别 + 转身不回头
- 心疼 + 伸手又停住
- 恐惧 + 后退半步
- 害羞 + 撩发

### 5. 双人镜头先写关系，再写动作
先确定**谁主动、谁回避、谁占据空间优势**，再写拥抱/对峙/挽留/冲突。能显著减少动作逻辑混乱。

### 6. 最后写限制项
常用限制：面部稳定不变形、五官清晰、手部五指正确、肢体不穿模、动作符合物理、背景人物不穿帮、镜头无无意义抖动。
