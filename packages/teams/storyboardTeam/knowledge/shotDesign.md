# 镜头职责与可执行设计

剧情镜头先写角色目的、策略、触发与可见反应，再写人物起点、目标位置、路径及摄影机怎样看清变化。每镜说明带来的事件、信息或关系变化；停顿有具体作用，不用微表情、衣发微动和慢推填满时间。允许有依据地拆合源节拍，不能丢事件或对白，也不按说话轮次机械切镜。完整原句逐句分配到 creativeBrief.dialogue，保留说话人、语气、时间与画内/画外通道；旁白不替代角色交锋。reviewer 对重复信息、无目的等待、只有摄影机动而人物无行为、对白只剩字幕逐项给出处和改法。

先通读原稿，再为全部场次分配镜头，不能把一场浓缩为一句台词后直接制作。source.sceneId/revisionId 只是来源索引，不是内容已保留的证明；逐项核对原文的行动主体、对象、证据、问答、反转与收束。开箱、夺物、攻击、递交等事件必须保留谁为何对谁做什么，不能因构图方便换执行者。镜数和时长由完整事件决定，不默认十镜或等长镜头。倒叙与平行线保留原稿结构，并设计可辨认的时间与状态线索。

每镜在已有 action/performance/camera.design/creativeBrief/intendedStateDelta 中共同回答：承接前镜哪个结果；谁因何对谁行动；台词在动作之前、之中还是之后；对手的可见反应；镜尾局面如何变化；为何切向下一镜。camera.design.cut 写具体表演或信息落点，不能只写“切下一镜”。反应镜头也须对应已发生的触发，不用空等填时长。将实际录音的屏时、句间停顿、视线与动作节拍一起调度；声音容量不足先重排或拆成有意义的行动单元，不加速删句、不拉慢动作。

多人对白明确每句真正的发声者、接收者与其在发声期的画面覆盖。专用口型不负责辨别剧情角色，也不能修复错位的表演；模型没有目标脸能力时优先设计明确的说话者覆盖，保留有动机的反应镜头，不把台词塞到另一人的正面画面。不得为处理方便将原本的当面对话改成画外旁白。无对白段落仍须有可见行动、信息或情绪变化，环境与关键动作声音按实际事件衔接。

导演先定义观众的信息变化，再选择镜头。master shot 是覆盖场面行动的主镜头，不是大师风格。推拉改变相机位置与透视；摇镜只旋转；zoom 只改视角；orbit 需弧线中间点；dolly zoom 需距离与视角联动使主体尺度近似不变。焦点转移、长镜头、手持、浅景深均为可选方法，不是电影感必备。

writer 为每镜填写 camera.design：technique、purpose、start、end、subjectPath、cameraPath、timing、cut、invariants（数组）、acceptance（数组）、fallback。保留 camera 景别、焦距、轴线和视线；表演放 action/performance，前中后景放 blocking，光源放 lighting。assetIds 保留叙事相关角色，visibleAssetIds 只列本镜出镜对象；画外说话人不进入画面参考。start 只写首帧已成立的状态，稍后入镜与终点写进 timing/end，不能提前摆在首帧。每个镜头须有原文依据或标成提案；按剧情节拍拆镜，不默认八镜，不为镜数添加无关道具特写。不按说话轮次机械左右翻转三人对话。缺少空间信息不编造轴线。

产品广告只选与卖点有关的职责：轮廓、材质、功能证据、使用关系、品牌收束；不是固定五镜。MV 用实际乐句/重拍/停顿事件，缺音乐分析时标记未对齐。导演向 writer 转交主 Agent 已读取的 cinema/adfilm/musicfilm 相关方法与项目约束，不能声称成员已读到未提供的全局技能。

reviewer 独立检查：删除一镜是否丢信息；对白动作停顿总时长；角色与相机路径是否混淆；透视和焦距描述是否冲突；轴线、屏幕方向、道具持有、情绪余波、光源一致；起止帧及剪点是否衔接；失败退路能否保住信息。逐条返回镜号、依据、严重性和最小修改。未见成片只审规格，不做“已看过”保证。

复用主 Agent 的既有 3D 导演台与动态分镜/FFmpeg 做低成本预演。团队只交文字规格。文字意图、视频参考、3D 预演、原生数值轨迹是不同能力。GEN3C 图像+数值轨迹不支持逐请求文字指导/声音，不是万能表演模型；只有用户选定且模型声明能力时才由主 Agent 执行。模型限制不足时给降级方案，不静默换模型。
