### 新增

- 新增多语言界面，支持简繁中文、英语、日语、韩语等 21 种语言，可在首次引导或设置中选择，并支持跟随系统。
- 首页和 Agent 支持将粘贴的长文本转为附件，可预览正文并还原到输入框继续编辑。
- 图像和视频生成节点支持展开提示词编辑窗口，保留参考素材标签、光标及撤销记录。
- 支持批量复制节点和完整分组，保留内部连线、分组层级及相对布局，粘贴后可整体撤销。
- Agent 新增 FFmpeg 媒体处理工具，支持查询媒体信息、转码、截帧、拼接和滤镜处理（需安装 FFmpeg）。
- macOS 新增原生编辑菜单，支持剪切、复制、粘贴、全选、撤销和重做。
- 新增更新重启后的版本核验，更新未成功时提供完整安装包下载入口。

### 优化

- 语言切换即时生效并记住选择，完善界面文案、系统提示和日期时间的本地化，适配从右向左阅读。
- 调整节点连线高亮设置的说明，使选项含义更明确。
- 从首页创建项目时，文本附件会一并带入 Agent；只有附件也能开始对话，历史文本附件支持直接预览。
- 优化文件保存、素材预览与下载同时进行时的占用处理，减少短暂文件锁导致的操作失败。
- 完善 Agent 和 MCP 的文件路径判断，加强对已打开画布和文档的保护。
- 改善 FFmpeg 下载、解压取消及临时文件清理的可靠性。
- 优化 Windows 和 Intel 芯片 Mac 的更新重启及失败处理；离开设置页后仍会跟踪更新状态，支持短暂断网后恢复查询。
- 补齐 21 种语言的项目介绍文档，统一文档入口与导航。

### 修复

- 修复桌面画布复制粘贴与文本编辑的快捷键冲突，并支持自定义节点复制快捷键。
- 修复 Windows 下仅修改文件名大小写时重命名不生效的问题。
- 修复部分文件已保存成功，却因临时文件清理失败而显示保存失败的问题。
- 修复部分参数校验错误被当作服务异常处理的问题。
- 修复部分更新未生效、退出后未重新打开的问题。
- 修复重复操作、切换更新源、取消更新或系统时间变化引起的更新状态异常，完善下载失败和异常更新包的提示。
