## 2. 对用户所需质感的理解

目标应继续沿用已确认的清爽真人方向，并同时覆盖身体、空间与运动。按本轮阅读和抽样观察，后续制作应分别落实：

- **人物可辨识**：面容、年龄、妆发和当前服装有稳定依据；转头、遮挡与变表情时仍需核对身份。
- **材料有区别**：肤面高光柔和，发束有层次，织物有厚薄与垂坠，金属反射集中；细节尺度随景别变化。
- **照明属于场景**：人物和背景共享实际光源；移动会改变受光，不能让脸始终挂着同一套影棚光。
- **行为能被理解**：先有注意对象和任务，再发生动作与回应；安静镜头也可以有持续倾听。
- **镜头知道看什么**：机位、清晰区域和遮挡共同突出当前信息，运动和剪点服从事件。

这是综合后的制作目标，不是已经验证的模型能力。干净肤面可以保留轻薄妆容，不借增加粗毛孔、油光、脏污、颗粒或全局柔焦来证明真人感。现有 [清爽默认](cleanPortraitIntegration.md) 与 [五条视频参考标准](videoReferenceAnalysis.md) 继续适用。

## 4. 可用于 MILI MILI 的提示词写法

以下为结合现有制作链路独立整理的规则，采用教程的方法，不复制案例人物和长段原文。

### 4.1 先区分三种信息

| 信息 | 写在哪里 | 需要说清什么 |
| --- | --- | --- |
| 固定依据 | 资产与真实参考绑定 | 哪个人、哪套衣服、哪个场地；每张图控制的内容 |
| 本镜执行 | action、performance、唯一时间线 | 谁注意到什么，随后怎样行动，对谁或什么产生结果 |
| 呈现方式 | camera、lighting、look、realism | 观众从哪里看、谁清楚、光从哪里来、材质如何响应 |

已有参考承载的外貌只作简短指认；剧情初始姿势、当前情绪和后续变化单独写。参考板不能同时充当剧情首帧、人物数量和背景的指令。只传本段用到的有效版本；实际输入数量和用途必须回读工具确认。

### 4.2 把情绪落到注意力与动作

写作顺序可用：当前任务 → 收到的信息 → 行为改变 → 可见结果 → 镜尾留下的状态。只有镜头需要的关键反应进入请求，身体停顿不等于视频慢放。

| 宽泛写法 | 本轮独立改写示例 |
| --- | --- |
| 她非常期待，演技自然 | 她核对街对面驶来的车辆，确认车次后放低手机，身体转向站台入口。 |
| 两人气氛紧张 | 甲把文件推到桌中央；乙看清签名处后停住翻页，目光转到甲脸上，甲的手仍留在文件边。 |
| 光影高级 | 窗外天光照亮画面左侧肩脸，右侧由浅色墙面反射补起，鼻侧留柔和阴影，背景比受光面暗。 |
| 材质逼真 | 棉布在肘弯形成宽软褶皱，包带随握持略微弯曲，金属扣只在转向光源时出现局部亮点。 |

这些是原创演示，不向现有作品添加车辆、文件或新剧情。正式改写只能取原剧本已有的事件与物件。

### 4.3 保留已有五板块，压缩重复

资产职责进入第一块；项目成像与布光进入第二块；先后、当前动作和结束状态集中在第三块；触发声与拟音进入第四块；具体高风险错误进入第五块。同一动作不在每个板块重讲，持续时间按任务与所选模型能力决定。

下面是独立创作的写法演示，假设模型支持 6 秒及所述参考模式。图片编号只是说明，实际使用前须替换成工具返回的真实绑定；本轮没有生成此样片。

```text
【故事前提与资产绑定】
6秒，16:9，一个连续镜头。人物在站台等待已约好的接车。
图片1只提供人物身份与当前服装；图片2提供站台结构、时间和用光。
开场人物左手提包，右手持手机，车辆位于画外道路方向。

【画面质感与光影】
清爽真人摄影。沿用人物肤色与妆发，近景纹理细微，皮肤、棉质衣物和包带各有不同光泽；焦点落在脸和上身，站台轮廓仍可辨。
阴天柔和天光来自道路一侧，面部另一侧接受站台浅色墙面的反射光，背景保留层次。

【镜头与动作时间线】
【镜头01｜0秒—6秒｜固定中景：确认来车】
摄影机位于站台内侧，与人物眼睛等高，构图同时包含头部、上身和双手。0—2秒她低头核对手机。2—4秒听到画右道路方向车辆减速的声音，目光先离开屏幕，头随视线转向道路。4—6秒确认来车后，右手把手机降到腰侧，左手继续握住包带，身体略朝站台入口转动，目光留在画外车辆方向。
光线：延续本场阴天天光，脸部转向时受光平顺变化。

【对白、环境声与BGM】
全段保留低声道路环境音，2秒处车辆减速声触发人物转头；无对白、无背景音乐。

【负面提示词】
身份或服装变化、手机与提包换手、对镜摆拍、反复回头、额外切镜、字幕、水印。
```

一段能读懂的要求仍需模型执行验证。不能因为文字包含先后、接触和光源，就声称视频已达到参考质量。

现有 `workflow/references/assets.md` 的前部“四视图定妆卡”写左侧全身，后部“角色”章节写右侧 90°；前部固定白底、16:9、4K，后部允许按模型能力选择。这些规则应在后续资产规范升级时统一，以已确认方向和真实接口能力为准。

## 6. 调整顺序与效果验证

1. **先核对请求。** 从已授权任务取代表镜头，检查真实参考、人物注意对象、触发与结果，以及空间光源是否进入实际请求；没有缺项便不追加模板。
2. **再补制作资料。** 优先处理表演方法的按需读取、资产规则冲突、侧脸信息与复杂室内空间依据；复用现有对象、裁切和编译入口。
3. **用实际片段判断效果。** 单人检查注意力变化；双人检查对方回应；走位检查受光与家具稳定；道具检查操作阶段和接缝。保留旧版与真实参数，每次围绕一个主要问题修改。

若做提示词对照，应尽量固定模型版本、参考资产、时长、画幅和支持的种子，记录所有差异。确定时长与预算后再进行真实生成；编译检查只能证明要求被表达，不能证明质量提升。

网站案例里的固定色板数量、表情网格数量、统一慢推、低清预览、多次重试及特定模型，不进入所有作品的默认。人物比例、题材、商品本色、原曲节奏与已确认风格继续服从当前项目。

本轮完成的是研究与升级依据。下一阶段若实施，先针对上述明确缺口做最小改动，再用完整看听结果验收。
