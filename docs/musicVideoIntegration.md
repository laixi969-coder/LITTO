# MV 故事与音画编排接入

## 目标与来源边界

2026-10-09：针对“MV 有剧情演绎，而且一开始就吸引人”的要求，补齐故事设计、短片音画编排与实际生成请求之间的链路。

评估了用户提供的 WUYIWU MV Prompt Director v1.0：参考图驱动、表演与音画联合规划、完整提示词交付对本任务有启发。交付包采用限制分发的商业授权，本仓库没有复制、翻译或打包其 Skill、模板、示例及配套文档。这里围绕 LITTO 的现有领域对象独立实现通用创作方法；不把该产品的单用户许可当作产品分发授权。

## 接入决策

| 能力 | 落点 |
| --- | --- |
| 第一幕提出可辨认的悬念，人物行动有因果，高潮回应开头 | musicfilm 默认剧情方向；尊重明确要求的纯演唱或抽象影像 |
| 歌者与故事人物的关系、可见演唱与画外歌声 | MV 导演编排，沿用 performance/action |
| 图片用途与叙事顺序分离，一图支持多个观看角度 | 复用 referenceBindings 与实际输入顺序，不新增图片标签协议 |
| 原曲、原创声音、无声素材分开 | musicVideo.audioMode/audioDirection；真实声音开关与编译前校验 |
| 歌曲位置与生成段局部时间分开 | sourceStart 与 timeline；记录不会冒充音频裁切或对口型功能 |
| 自包含的 Seedance 2.5 提示词 | 保存规格后编译进已有 A9.2 字段；真实引用映射并入 Reference binding |
| 特殊运动状态、动作时间预算、前后镜接点 | MV 方法补充，复用 cinema/continuity；不重复引入通用摄影模板 |
| 固定 30 秒、固定镜数、默认新增歌词、默认指定模型 | 不接入；沿用用户意图、原曲及现场模型能力 |

## 第一性检查与修复

1. **方案必须进入实际请求。** 工作区生成会覆盖自由 prompt；仅追加 Skill 文本会导致 MV 时间轴与声音方案丢失。新增可选 musicVideo 规格，保存在既有 shots.data，编译器消费同一份内容，无数据库迁移、无第二套编译入口。
2. **时间是有限资源。** timeline 从 0 连续覆盖生成时长；拒绝空段、倒序、重叠、缺段与超出使用/生成关系的时长。部分更新在合并旧规格后校验，失败不写入。
3. **音乐意图不等于声音已启用。** 原创声音方案与关闭音频的请求矛盾时拒绝，无声方案也检查输出能力；生成面板提供实际音频开关。音频参考能力与输出能力分别判断。
4. **身份参考不等于首帧。** 工作区多参考模式将已采用主图标为普通外观/构图参考；Reference binding 使用最终输入槽，不假造原生首帧控制。
5. **源事实与创作阶段不同。** Seedance 的剧情保真约束保护已确认 MV 方案，不能阻止上游故事创作，也不能把已确认非线性结构排回自然顺序。MV 不继承无音乐、禁止节奏快剪的普通剧情默认值。
6. **修改需要使旧审核失效。** musicVideo 参与规格指纹与已采用镜头修改保护，可显式清除，但不能静默绕过保护。

## 对抗式审查与验证

审阅开场是否只是风景、交换中段是否不影响故事、结尾是否没有回收；这些是创作检查，不是程序保证吸引力。还检查原曲起点与局部时间混用、歌词重复、参考未送入、冻结范围、音频开关及模板字段冲突。

通过临时数据目录启动本地 HTTP 服务，验证 MV 创建/读取、8 类非法输入返回 400、只改生成时长的合并校验、已采用镜头修改返回 409。内联验证规格往返、指纹变化、保留歌词原文、Seedance 2.5 与其他模型分流、静帧不带 MV 时间轴、缺失锁定参考拒绝，以及工作区实际输入编号与单一 Reference binding。用于编译门禁的审核记录为临时合成数据，不是实际媒体验收。

没有新增测试文件、测试框架或自动检查入口；未调用付费生成，未验证真实成片的吸引力、声音连续性或口型。内置技能继续沿用现有打包与同步机制，自定义安装副本保持冲突保护。

类型检查覆盖 cloud、server、web 与媒体工具；构建覆盖 server（含团队/MCP）、web 与媒体工具。检查 5 个相关技能文件的 52 个本地引用均可解析。新增音频开关仅作用于 MV，普通影片保持原来的请求默认行为。
