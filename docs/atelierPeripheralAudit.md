# Atelier 外围工具复核

2026-11-13。接续 atelierCanvasAudit.md，逐项查看上轮仅见菜单的外围工具。区分已观察到的交互、LITTO 的真实实现及仍缺少的后端，不将同名入口或相似提示词算作完成。

## 实际修复与复用

- **RH 远端任务恢复。** 复用已有 pollTask 作为 resumeMedia。恢复只允许 RH 官方同源精确 `/openapi/v2/query` 的 JSON POST，正文只能含与原任务匹配的 taskId，并禁止重定向。其它供应商或提交端点不放行。版本更新为 1.5.1，沿用已知官方源 hash 升级机制，用户改过的供应商文件不覆盖。
- **普通成员的视频采样权限。** 新增参数固定的 `/api/ffmpeg/sampleFrames`，复用已配置 FFmpeg、工作区路径授权、取消和文件操作。普通 EDITOR 可用，VIEWER、越权目录、符号链接、非法媒体及越界采样拒绝；原始 FFmpeg 参数仍仅管理员可执行。
- **真实帧时间与片尾。** 探测真实时长、尺寸、平均 fps，从解码 PTS 记录实际采样时间，处理原始时间戳偏移。仅当结束前已无后续帧时补真实末帧，不将任意采样列表的最后一项改成片尾。
- **画布到参考分析。** 视频节点与视频生成结果共用播放器工具。选中采样图直接复用已保存文件建立图片节点，记录原视频相对路径、实际时间、时长与帧率；同一来源加入故事参考时避免重复。分析仍走故事面板的原有模型、结构化保存与审阅流程。
- **取消及保存。** 客户端公用采样 helper 固定目录和 requestId；显式取消与先到取消标记按工作区和用户隔离。解码失败/取消等待进程结束后删除本次独占输出。服务端最多暂存 256 个成功批次的归属 125 秒，覆盖响应刚完成时的取消窗口；重复已完成 ID 返回 409，过期不删除已选用素材。关闭未采用预览清理临时批次，已经入画布的文件保留，刷新可重开。

## 实际验证

- Server、Web、FFmpeg、节点脚手架、视频素材节点和视频生成节点类型检查通过；Server、Web、两个视频节点构建通过。路由由 `bun run routes` 生成。保留已有 Web 大包和 Vite 配置提示，没有新增依赖、测试文件或检查入口。
- RH 实际供应商 loader 的受控验证：恢复只查询一次原任务并返回其素材 URL；14 项边界覆盖错 taskId、额外字段、别源、提交路径、查询串、Content-Type、Request/init 覆盖、重定向与其它供应商 POST。没有真实上游请求。
- 隔离多人 HTTP：非管理员 EDITOR 成功抽取互异 JPEG；VIEWER、越权目录、符号链接、非法参数与媒体被拒绝，原始 FFmpeg 仍返回 403。执行中取消清理输出；先发取消后提交返回 409；另一用户同 requestId 不能取消本用户任务。
- 真实解码：1920×1080 输出 960×540；2 秒、10fps 样片请求 0.333333 秒得到实际 0.4 秒，请求 0.9 秒仍为 0.9 秒，结束前 1.999 秒补实际 1.9 秒。原始 PTS 偏移 5 秒的媒体也返回正确相对时间。ffprobe 实现使用固定参数、超时、输出上限及 SIGKILL；未捕捉到极短探测进程的取消瞬间，不将其写作人工观察通过。
- 真实浏览器：4.042 秒、1280×720、24fps 样片显示 6 张采样图；下一帧时间从 0 变成 0.042 秒，上一帧回到 0；6 张图入画布后读取磁盘确认实际时间与来源，刷新仍保留全部图片及文件。
- 真实浏览器 → 故事参考 → 固定采样接口 → 既有模型桥接 → 结构化保存：本地受控上游两轮各收到 6 张实际图片，观察与采样覆盖范围写入 storyProject.json，声音与非采样画面保持未知。该验证证明链路，不证明真实模型分析质量。
- 关闭未采用的新采样预览后，目录数从 3 回到 2；已入画布及故事分析使用的文件保留。所有验证使用隔离目录与既有素材，不修改真实用户项目，未调用付费模型。
- 补充真实 HTTP 验证：成功后取消删除本批目录，另一用户批次保留；已完成 ID 再提交返回 409；执行中取消与先到取消仍有效。补查代码确认新图片的 540 列距、300 行距容纳内置图片节点最大 498 像素宽度。

本轮完成的是外围能力核查、RH 恢复和视频采样/参考分析接通。RH 动态应用/ComfyUI、生成式 3D 网格/世界、专用智能超分/质感处理仍是明确缺口，不能按已交付能力使用。
