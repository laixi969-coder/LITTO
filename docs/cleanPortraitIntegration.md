# 清爽写实人物默认接入

2026-10-22，用户确认此前 GPT Image 2 人物图与 Vidu Q4 回眸视频的效果符合需求，采用其清爽程度作为默认人物质感。没有追加付费生成。

## 固定的内容

自然均匀肤色、符合景别的细微纹理、轻薄妆面、克制高光、清晰毛流，以及皮肤、头发、衣料的材质区别。既定身份、年龄、肤色、特殊妆效、汗水和剧情状态优先。

固定的是方法和默认编译规则，不是某张脸、蓝衬衫、窗边构图、回眸动作或模型参数。已有合格资产继续复用；夜景、彩光、商品本色、音乐卡点、对白和演员动作保持其项目设计。生成有随机性，默认规则不保证每次像素级复现样片，也不自动批准所有后续成片。

## 接入位置

| 路径 | 生效方式 |
| --- | --- |
| 画布、独立图片及视频、Agent 媒体工具 | generation.withPhotographicBaseline 默认使用共享 skinFinishes.clean；明确 natural 时使用同一模块的自然肤质规则 |
| 正式剧情、广告、MV 镜头与工作区提示词 | compiler 及审看共用 cleanVisualDefaults，引用同一份 skinFinishes.clean，不按作品类型漏接 |
| 完整五板块生成段 | 仅在第二块补充默认真人肤面，重复编译不重复注入；明确插画跳过，资产、时间线和声音保持原文 |
| 人物资产 | assetSheet 肤面与布光模板、workflow 妆造方法与 cleanPortrait 方法一致 |
| 剧情入口 | story → cinema → 正式规格与编译，人物质感持续继承 |
| 商业广告入口 | adfilm，保留商品本色、包装与产品证据；无人产品镜不强加人物 |
| MV 入口 | musicfilm，剧情段与演唱段共用人物标准，保留舞台光色和音乐同步 |

肤质规则定义在 `packages/tools/mediaGeneration/src/runtime.ts`，独立生成与正式编译共同引用，避免各自维护一份逐渐不同的肤质文案。技能由内置资源同步机制安装；自定义冲突按原机制保留并提示。

## 验证与边界

验证采用临时配置目录的内联手工检查、类型检查与构建，不新增测试文件，不触发模型付费调用。检查正式剧情、广告、MV 编译产物包含同一基线，以及已指定的灯光、肤色、商品和音乐信息仍在；普通提示词、明确插画与完整五板块分别保持原有处理方式。

此前样片用户已认可，可作为当前项目的视觉方向。三类长片的实际表演、跨镜一致性、商品准确度、口型与音乐同步，仍由每个项目的真实成片验收决定。

## 自动调用与继承复核

系统提示中的“请读取技能”原先只是一条模型指引。本轮增加会话资源自动读取：明确的剧情、广告、MV 任务选择 story、adfilm、musicfilm，续作沿用已采用简报或唯一的制作序列类型；同时读取 workflow、cinema、videoPromptDirector 和 cleanPortrait 正文。题材匹配时再读旅拍、清新或园林入口。主会话和子会话共用这一入口；读取结果进入模型系统上下文，技能正文不依赖模型主动调用工具才可见。

自动读取沿用实际目录、工作区同名技能优先级、正文读取权限和 disableModelInvocation 设置。关闭读取、缺少文件或禁用自动调用时明确记录缺项，不绕过权限。仅载入适用制作任务，普通聊天不注入。

镜头编译补上资产 references 与资产级 IDENTITY / WARDROBE 等同职责绑定的继承。只取实际出镜资产及其当前服装；已采用权威定妆优先，已检查的视频主帧继续承载身份。镜头显式绑定继续保留；身份与服装参考不能因模型容量不足静默退回文字。HTTP 生成入口读取角色后继续保留此前的影调和年代说明。已有正式镜头的项目从统一入队入口要求 shotId 与编译指纹，独立素材须明确用途。

本轮用实际资源加载器核对三类任务、MV 续作、自定义技能优先级和关闭权限；用临时数据库检查三类作品连续两镜的真实参考计划、画外角色排除、主帧继承与容量不足拦截；核对五板块重复处理、明确画风、时间线和声音保留。验证不调用付费模型，视频请求核对采用 720P；本轮未新增收费样片。
