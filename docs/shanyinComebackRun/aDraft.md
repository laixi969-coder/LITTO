# 开席前到账

宴会厅的香槟塔刚摆好，主桌席卡上，“宴会主管许澄”被撕掉，换成了上司周启明的名字。

周启明站在空台前练致辞：“这场宴会能顺利办成，主要是我盯得紧。”他声音刚落，准备间里传来手机提示音。员工代表阿杰把屏幕递给许澄：团队群里，周启明刚发通知，原定奖金因“成本超支”暂停发放。

奖金一共一万二，四个人均分，每人三千。钱来自客户已经支付的服务增项款。公司内部的奖金确认单写得清楚：客户验收后，主管可提交分配；部门经理能暂时冻结，但必须填明超支项目并附凭据。财务工作台一旦解除冻结，奖金就能即时转账。

许澄手上还沾着香槟塔的金粉。她没去抢席卡，只把宴会流程表摊在备餐台上。最后一格是“客户验收”，还空着。

周启明进了准备间，抽走那张验收单。“你签了也没用。钱我说停就停。”他又把许澄排好的上菜顺序改掉，命令阿杰去搬酒。

阿杰看一眼宴会厅里已入座的宾客，没动。许澄把流程表递给客户代表林岚：“您说开席前要确认桌数和过敏餐。咱们先验这两项。”

林岚逐桌核对，许澄报菜名，阿杰对席卡。两张摆错的桌牌被换回原位，标明坚果过敏的专用餐卡也逐一核实。许澄没停下手里的活，周启明却已走到宴会厅中央，拿着删去她名字的汇报稿，向林岚介绍：“方案和客户沟通都是我负责，她们只执行。”

林岚没接汇报稿：“那十二桌里，哪桌有坚果过敏？”

周启明低头翻纸。许澄从准备间取出专用餐卡递给服务员，餐卡上的桌号和菜品一一对应。林岚看完，转向周启明：“验收我只签实际完成的。”

周启明把声音压低：“你现在签，奖金也到不了账。冻结权在我。”

许澄按住他伸来的手，把确认单转过来，指向“冻结理由及凭据”一栏：“可以冻结。理由和凭据要一起给客户看。”

周启明立刻抽出成本表，指着“宴会损耗”四个字。许澄把排班表、客户增项确认单和奖金分配页并排放在台面上。分配页上有周启明签过的字：四人平均，每人三千。增项款已到账，过敏餐和临时加席也都列在客户确认单上。

林岚签下验收页，推到周启明面前：“你说超支，具体是哪一项？”

周启明没答，转身打开财务工作台，输入冻结理由。许澄没有拦他，只把客户验收页放到屏幕旁。林岚看着他：“这笔已验收的服务费，你打算拿什么损耗抵？”

周启明删掉输入框里的字。许澄点了点奖金确认单：“撤销冻结，我现在提交。你也可以继续，但理由会留档。”

周启明盯着自己的署名，停了一下，按下“撤销冻结”。

许澄提交四人分配。页面刷新，四笔转账依次显示“成功”。她的手机震了一下：到账三千。阿杰也收到提示，举起屏幕给她看。

周启明拿起那份汇报稿，当着林岚和阿杰的面划掉自己的名字，补上许澄的。林岚收回验收单：“下次项目汇报，按实际分工写。”周启明没再争辩。他的本场奖金审批权限当场被收回，成本表须在次日更正提交。

宴会厅门打开，第一道菜准时落桌。许澄把流程表最后一格勾上。手机屏幕上，到账通知还亮着。
