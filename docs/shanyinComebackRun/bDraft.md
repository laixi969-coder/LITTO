# 开席之前

宴会厅里，四百人的庆功宴只差最后一轮检查。宴会主管林岚蹲在主桌旁，调整桌牌角度。相连的准备间里，员工代表阿杰盯着手机，团队群里那句“今晚结清奖金”还停在屏幕上。

经理周启举着酒杯走来，客户代表许曼跟在他身后。他笑着说：“临时改菜单、重排桌次，都是我带团队做的。奖金我会按表现重新分。”阿杰攥紧手机。周启顺手拿起林岚的流程夹，里面夹着改场记录和奖金分配表。

“开席前，把表还给我。”林岚伸手。

周启压低声音：“你现在闹，功劳和奖金都别想要。”

林岚没有去抢文件，只问许曼：“您要求的无坚果甜品台，最后是几点确认的？”

“四点二十。你当场划掉原甜品，换了独立制作和摆台。”许曼看向周启，“你刚才说是你安排的？”

周启立刻接话：“执行细节是林岚做的，方案是我定的。”

林岚从夹板里抽出订单复核页递给许曼。上面有许曼的签名、改菜单的时间，以及林岚与后厨的交接记录。林岚指向厅内尚未上桌的甜品牌：“最终版本在那儿，过敏原标识也按您确认的摆好了。”

许曼看完，转向周启：“那你刚才把谁的成果说成自己的？”

周启脸色一沉，抽走复核页：“客户不需要掺和员工奖金。林岚，去准备间待着，开席后再处理。”

他又看向阿杰：“这月排班我签。谁敢擅自转账，谁下周别来。”

阿杰看着手机，又看林岚。她朝他点头：“别碰工资账户，按约定的流程走。”

林岚打开宴会厅侧边的付款终端。屏幕上显示，客户预付的专项服务费已进入酒店内部奖金池：总额三万六千元，四名员工各九千元。周启和主管林岚双签放款；奖金分配表上，周启早已签过总额。款项入池后，林岚可以发起分配，经理复核一次即可付款。

“我没批准这次分配。”周启挡住终端，“你敢越权？”

“你签过总额，分配表也写明了每人九千。”林岚说，“我现在请你复核到账。”

周启伸手要关屏幕。许曼把订单复核页放在终端旁：“这笔专项服务费我确认过，也已经付进奖金池。你可以不签，但别说是我没付。”

周启盯她一眼，忽然抓起话筒：“各位，甜品台临时出了问题，开席延后——”

林岚按住话筒底座，没有抢夺：“甜品按确认方案完成，席位也复核好了。你要延后，请当着客户说清楚原因。”

阿杰把四人的排班确认和奖金分配表并排放到终端前：“钱是我们做完项目挣的。主管按流程发，我们都在。”

周启扫过已经落座的宾客，手停在话筒上。许曼没有替林岚求情，只问：“你要我确认她做完了，还是继续认领她的方案？”

周启放下话筒，在经理复核栏签了名。

林岚提交分配。终端逐笔亮起“转账成功”，四笔九千元，一笔不少。阿杰的手机接连震动，他把到账页面转给队友看：“真到账了。”

许曼将周启的名牌从主桌发言顺序上移开：“今晚项目复盘，你当着团队解释奖金为什么被扣。致辞由实际负责执行的人来。”

林岚接过话筒，向团队点头：“按计划开席。”

宴会厅灯光亮起，主桌宾客举杯。阿杰端着最后一盘甜品从准备间走出。宴会准时开席。
