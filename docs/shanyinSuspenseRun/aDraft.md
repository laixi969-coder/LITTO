# 晚十分钟

暴雨把办公楼的玻璃门冲成一片晃动的黑。卷帘落下，电梯停运，保安室只亮着一盏台灯。周启明的手机震了一下。

一条语音，发送时间是凌晨两点二十七分。墙上电子钟显示两点十七。

他按下播放。

“别让她碰门禁。老邵已经倒了。”

是他的声音，急促，尾音发虚。值班物业经理邵成坐在桌边，钥匙串绕在指上。相连走廊尽头，女租户许岚抱着一只湿透的帆布包，正看着他们。

“谁倒了？”她问。

邵成站起来：“假的。手机给我看看。”

周启明没递。他把手机揣进制服口袋，走到监控屏前。画面里，许岚站在安全门旁，红灯一闪一闪。楼里断网后，门禁切成了本地模式，刷卡记录存在保安室控制台里；这是邵成刚交班时告诉他的。屏幕下方的时间却停在两点零七。

“你说门禁主机没事。”周启明盯着他。

“我说过会断电。”邵成把钥匙串放下，“别拿一段破录音当指令。”

许岚从包里拿出一张门禁卡，卡角裂着一道白痕。“我办公室还有药，拿了就走。”

“先别刷。”周启明说。

许岚看他一眼，没收卡。邵成伸手去按控制台上的复位键：“我来。”

屏幕黑了。走廊灯跟着熄灭，黑暗里一声闷响，接着是钥匙落地的脆声。

应急灯亮起时，邵成躺在保安室门口，额角渗血。许岚站在两步外，手里攥着断成两截的门禁卡。

“别碰他。”她说，“他自己摔的。”

邵成的手指动了一下，又垂下去。周启明要上前，许岚抬脚挡住他，鞋底在地上蹭出一道水印。

“你早知道他会倒？”她问。

周启明没回答。他退到桌边，拿起旧对讲机，按住通话键：“地下值守点，保安室有人受伤，请求救护。”只有沙沙声。雨点砸窗，像一把没停过的豆子。

他打开控制台旁的值班电脑。那台电脑离线也能存录音，恢复供电后会把文件同步到手机；交班时他亲手试过一次。桌面上，录音软件还开着，队列里多出一条文件。

屏幕显示：系统时间两点零七，实际时间两点十七。

周启明点开属性。发送时间取的是电脑时间，排队任务则会在门禁复位后发送。录音文件的创建时间，早于这条语音十分钟。

“它不是从未来来的。”许岚说。

周启明按下播放。自己的声音再次响起，末尾有一下轻微的刮擦。他低头看向断卡：塑料断口蹭过控制台边缘，留下一道新白痕。

他把语音拖回开头，逐字听完。那句“老邵已经倒了”后面，藏着一声钥匙落地的脆响。

邵成睁开眼，伸手去够桌上的手机。

许岚先一步把手机拿走，放到周启明手边。邵成撑起半身：“那段不是我录的。”

周启明在电脑上调出本地操作记录。复位键按下前，管理员账号登录过，登录时间是两点零六。邵成的钥匙仍压在桌沿，金属齿碰着桌面，微微发颤。

“你把旧录音排进队列。”周启明说，“想让她以为我会拦她。”

“她拍了消防门的照片。”邵成抹掉额上的血，“我只想拿回来。”

许岚把帆布包放在桌上，拉开拉链。里面没有药，只有一部手机。屏幕上，是消防门闭门器被卸下的照片，拍摄时间清楚地显示在暴雨封楼之前。

周启明按下对讲机，将操作记录、录音文件名和照片时间一项项报出去。对讲机里传来断续回应：“收到，救援已到楼外。保持原地。”

邵成不再伸手。许岚收起手机，没有再看他。

雨势减弱后，门外传来敲击声。周启明打开保安室的内门，远处的应急灯沿走廊亮成一串。他回到电脑前，把慢了十分钟的时钟校正，又录下一句求救信息。

这次，他先听了一遍。

“保安室有人受伤。门口有人接应。”

时间显示正常。他按下发送。
