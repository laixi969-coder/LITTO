## 验证

- 仅使用隔离临时数据，通过标准输入执行原函数和实际本机 HTTP；没有新增或修改测试文件，没有调用真实付费模型、真实支付或真实 IdP。
- 验证了加号邮箱密码登录、Cookie 会话、创建项目和画布文件保存。
- 连续十次错误密码后，同来源被限制，另一来源正确密码仍可登录；state 重放、过期均拒绝。
- 使用本地生成的 RSA 密钥签名合法及非法 OIDC token，验证合法通过、discovery/issuer 替换、多 audience 缺 azp、空 subject 拒绝。
- 验证 0.1 + 0.2 精确得到 0.3；重复冻结、释放、结算不重复扣记；非法数字拒绝。
- 验证危险 CSV 文本不作为公式导出、敏感日志脱敏、无效支付配置不创建订单。
- 验证套餐到期在写入前同步免费配额，以及普通年、闰年、年套餐的月末 UTC 日期。
- 在前方放置五十一条满额供应商任务后，另一可用供应商任务仍完成生成和结算。

## 边界

- 原有积分数据库仍保留 REAL 列及历史不可变账本；本批修复运算精度与资金边界，没有重写历史账目或宣称已经迁移为整数存储。
- 定向锁号改为来源隔离；共享 NAT 的用户仍共享来源，多实例需共享限流存储。真实反向代理配置未核验。
- 已开启但尚未完成的 OAuth/SSO 流程需重新开始，真实 IdP/Apple 联调未进行。单次 state 只保存哈希和过期时间，不保存明文凭据。
- 本批没有增加批量注销 UI；现有重置密码撤销全部会话的机制保留。管理员、客户支持及企业组织流程不以新增界面代替实际需求。
- 日志修复针对已读 cloud 日志和供应商错误路径，不宣称所有第三方 SDK 和历史日志都已清理。
