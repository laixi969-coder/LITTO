# Seedance 2.5 / Seedream 5 Pro 接入与使用指南

> 面向 MILI MILI（LITTO）用户。本文说明如何接入文档《White Lang技能分享》主推的模型组合（视频 Seedance 2.5 + 图片 Seedream 5 Pro），以及如何用新增的视频提示词导演技能产出超逼真视频。
> 更新日期：2026-10-22

## 一、两条接入路径（推荐第一条）

### 路径 A：apiMart（推荐，无需方舟控制台）

apiMart 是 MILI MILI 已内置的聚合供应商，**已直接支持 Seedance 2.5 / Seedream 5.0 Pro / gpt-image-2**，无需创建方舟接入点，注册后填 API Key 即可：

1. 打开 MILI MILI「设置 → 模型供应商」；
2. 选择 **APIMart**（供应商说明里有官方注册链接 https://go.apimart.ai/gh-toonflow-app ）；
3. 注册/登录后获取 API Key，填入供应商配置；
4. 保存后，在视频生成节点 / 图片生成节点的模型下拉中即可选择：
   - 视频：**Seedance-2.5 (支持真人)** —— 4–30 秒，支持文字/首帧/图+视频+音频多参考
   - 图片：**Doubao Seedream 5.0 Pro** —— 出图作为人物三视图与场景资产
5. 在模型配置中确认时长与分辨率范围（2.5 为 4–30 秒，480p/720p）。

已内置的模型能力（代码内置，无需额外配置）：

| 模型 ID | 类型 | 时长/分辨率 | 参考能力 |
|---|---|---|---|
| seedance-2.5 | 视频 | 4–30 秒，480p/720p | 文生 / 首帧 / 9 图 + 3 视频 + 3 音频参考 |
| seedance-2.0 / 2.0-fast / 2.0-mini | 视频 | 4–15 秒，480p–1080p | 同上 |
| seedream-5-0-pro / lite | 图片 | 2K/4K | 文字 / 单图 / 多参考 |
| gpt-image-2 | 图片 | — | 文字 / 单图 / 多参考 |

### 路径 B：火山方舟（备选，BYOK）

MILI MILI 内置「火山方舟」供应商，本次已升级为支持 Seedance 2.5 与 Seedream 5 Pro 模板：

1. 打开火山方舟控制台（https://console.volcengine.com/ark），开通方舟、创建接入点；
2. 在方舟"在线推理"创建 Seedance 2.5 与 Seedream 5 Pro 的接入点，复制各自的接入点 ID；
3. 在 MILI MILI「设置 → 模型供应商 → 火山方舟」填入 API Key；
4. 打开模型配置，把内置模型 ID（doubao-seedance-2-5-pro / doubao-seedream-5-0-pro）**替换为你在控制台创建的接入点 ID**；
5. 保存后即可在节点中选择。时长校验已按模型动态生效：2.5 允许 4–30 秒，1.5 Pro 仍限制 4–12 秒。

## 二、推荐工作流（使用新增的视频提示词导演技能）

按「视频提示词导演（videoPromptDirector）」技能运行，完整流程：

1. **项目前期确认**：提供剧情构想（一句话/完整剧情/参考素材），技能通过弹窗补齐总时长、镜头数、画幅、资产范围、画面风格、声音方案；
2. **建立资产**：技能生成 16:9 人物三视图（五段式提示词）、场景图、道具图，绑定为画布资产（用 Seedream 5 Pro / gpt-image-2 出图）；
3. **标准横向分镜**：技能输出视觉规范与分镜表，统一确认后暂停；
4. **五板块提示词**：技能编译 final_video_prompt（故事前提与资产绑定 / 画面质感与光影 / 镜头与动作时间线 / 对白、环境声与BGM / 负面提示词）；
5. **自动建节点**：确认分镜后技能自动创建视频节点、绑定 @资产、写入完整提示词，设为可生成状态；
6. **你点击生成**：在节点上确认模型为 Seedance-2.5，点「生成视频」。

旅拍婚礼题材可用「旅拍影像提示词导演（travelWeddingDirector）」技能（默认每镜 2 秒，内置 40 镜镜头库 + 服装表）。

## 三、样片验证清单（真实调用后回填证据）

完成首次真实生成后，建议按以下清单验证并回写 `docs/outputQualityEvidence`：

- [ ] 30 秒文生视频一条（验证 2.5 时长上限）
- [ ] 15 秒 8 镜旅拍一条（对照文档示例《湖边草帽女孩》）
- [ ] 30 秒 20 镜中式园林一条（对照文档示例《古典之美》）
- [ ] 人物三视图 + 图生视频一条（验证资产绑定与身份一致性）
- [ ] 走完 QC 检测与最终验收，记录 SHA-256 与观察依据

## 四、注意事项

- **模型 ID 替换**：方舟路径下生成前须把模型 ID 换成控制台接入点 ID；apiMart 路径无需替换。
- **成本控制**：Seedance 2.5 为付费模型，样片阶段每条 30 秒约消耗一次生成额度；沿用"用最少的生成获得可用成片"原则，先做代表性样镜验证再扩展。
- **2 秒短镜**：旅拍题材默认每镜 2 秒，依赖 Seedance 2.5 对提示词内部切镜的稳定性；若某条样片 2 秒短镜不稳定，按模型实际能力调整为 3–4 秒并在镜头库注明。
- **图片替代**：文档图片侧主推 Midjourney V8.2；MILI MILI 暂未内置 MJ，可用 Seedream 5.0 Pro / gpt-image-2 替代（东方题材胶片质感请用 gpt-image-2 或风格化提示词）。
