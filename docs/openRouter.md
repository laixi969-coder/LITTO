# OpenRouter 接入

在「接入你的模型 → 剧本与对话模型」选择 OpenRouter，填入在 https://openrouter.ai/settings/keys 创建的 API Key，点击「测试并保存」。也可在设置的文字模型供应商中添加 OpenRouter。保存后在模型选择中选择需要使用的模型。

- 地址：`https://openrouter.ai/api/v1`；协议：OpenAI Chat Completions。
- 模型 ID 保留官方完整形式，例如 `openai/gpt-4o-mini`。目录动态获取，不固定整个模型列表。
- 使用 `/key` 验证密钥，再读取 `/models`；公开目录可读取不代表密钥有效。密钥有效也不保证所有模型都有调用权限或足够余额。
- 按官方模态筛选支持文字输入、仅输出文字的模型，读取名称、上下文长度及输出上限。图片理解和工具调用由具体模型能力决定。
- 剧本、分镜、节点与 Agent 复用现有调用链；图片和视频生成供应商不属于此次接入范围。
- 沿用现有账号配置存储与密钥脱敏，不在代码中嵌入密钥。

官方接口说明：[Quickstart](https://openrouter.ai/docs/quickstart)。
