# V3 实施计划

以 docs/prd.md 为需求依据，docs/prdAudit.md 为起点。复用当前 Vue Flow、供应商脚本和云端领域/任务模块。

## 第一阶段：持久化生成地基

- 用已有 AES-256-GCM 加密保护账号模式租户设置中的 Key；读取旧设置时迁移，运行时仅在服务端解密，客户端继续掩码。
- 工作目录与云端 Project 建立租户内映射，保留原画布与素材。
- 当前图片/视频节点及 Agent 生成创建持久化 Job，浏览器关闭仅停止观察；明确的停止操作取消 Job。
- 节点记录 Job ID，刷新后重新查询；结果继续写入原工作区目录，同时关联云端 Media/Generation History。
- 未知价格保持 null，不再伪造实际成本。已生成文件和已采用内容保留。

供应商脚本在嵌入式服务端运行，由云端队列通过适配器回调调用；回调使用 Job 的真实租户上下文，重新校验目录和成员权限。单用户模式保留现有直接执行路径。

## 后续阶段

1. 接入 World/Look、Asset、ShotSpec、参考用途、Hero Frame/Take 和连续性审批，统一当前工作台与云端领域链路。
2. 将通用电影规则与模型专用提示词规则分开；仅实际选用 Seedance 时执行其规则。
3. Music Film 独立项目、音乐与歌词输入、分析/对齐、方向选择、Music Timeline、镜头绑定与章节制作；在真实 Adapter 能力范围内推进完整歌曲组装。

每阶段先验证再提交 main。遵守 AGENTS.md：不新增测试文件；使用类型检查、构建、已有检查入口和隔离数据的手动 HTTP 验证。付费生成沿用用户明确授权范围，未授权时用接口及本地受控供应商验证任务机制，不把它当成真实电影质量验收。
