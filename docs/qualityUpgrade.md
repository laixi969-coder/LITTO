# 输出质量升级记录

日期：2026-10-06。依据：[原片检核](outputQualityReview.md)。范围为 LITTO 的生成约束、质检与成片验收链路；没有修改原片或付费重拍。

## 已修复

1. **空报告覆盖缺陷**：同一媒体的既有缺陷会延续到后续报告，改变规格或提交“无问题”不再自动清除。误报需要逐项排除并留下复核说明、检查者和前一报告关联。多肢及服装/商品形状漂移增加为严重问题，阻断采用。
2. **一键虚假全检**：界面改为逐项确认，视频另需完整播放确认；服务端也验证，旧视频记录没有完整播放证据时须重新检查。这是人工声明，不伪称播放器或系统能够证明认真观看。
3. **生成与视觉观察**：编译增加参考解剖结构、肢体数量、遮挡与镜面关系、动作准备/接触/收势，以及商品轮廓、缝线和长度保持要求。视觉辅助检查明确检查多肢及商品状态；短视频约每秒 4 帧，上限 48 个全帧，保留末帧和可选原尺寸局部图。长视频仍为稀疏抽样，模型费用可能增加，不等于全帧理解。
4. **最终文件检测**：“剪辑与衔接”的导出列表可对具体成片做完整解码、实际时长、声音低电平区间和逐接点电平分析。接点附近至少 0.25 秒低于 −50 dBFS，或前后半秒 RMS 差超过 12 dB，产生复听告警。阈值是筛查，不是通用艺术标准；静默、强音乐进入可说明依据，不自动删改声音。
5. **独立的最终验收**：文件导出成功仍显示未验收。皮肤材质、动作、光线、连续性、声音分别记录通过/返修/未验证；须完整看听并填写观察依据。解码错误、已知源素材严重缺陷不能在终审直接跳过；其余告警通过前必须逐项解释。生成成功、检测成功、人工通过是不同状态。
6. **验收绑定版本**：记录最终媒体 SHA-256、分析 ID、时间线与素材/规格/上游质检指纹、检查者和时间。剪辑、源素材、规格或相关源质检改变后旧验收标为过期；旧检测表单也不能覆盖新分析。保留旧导出文件供比较。

## 实际验证

- cloud、server、web 类型检查通过，server/web 构建通过；未新增测试文件、依赖或自动检查入口。
- 隔离临时数据库内用旧原片运行新检测器，报出 23.5 秒接点的低电平区间，以及 28.708 秒接点的电平突变等告警。检测结果保持 `unverified`，没有自动判好片。
- 人体严重问题经空观察复核仍保留，采用被阻断；缺少完整播放确认被拒绝；没有依据的误报排除被拒绝。
- 最终通过缺少告警解释被拒绝；显式返修可记录；剪辑变更后验收变为 `stale`。
- 实际 Hono HTTP 请求验证非法验收参数返回 400、VIEWER 发起分析返回 403。最初使用了错误测试路径得到 404，改用应用实际路由后上述验证通过。
- 浏览器打开升级后的本地剪辑页，确认最终验收说明加载。该界面验证项目没有成片；最终文件检测和状态转换在隔离数据库验证，没有把用户的旧片标为通过。

## 仍不能承诺

没有调用真实生成模型重拍对比，尚无新版成片证据可证明电影级/商业大片质感。提示约束不能保证模型遵从，48 帧抽样也可能漏掉瞬时缺陷；人工可能误判。RMS 与静音检测不能判断对白、情绪和口型。当前升级可降低漏检与误放行风险，不能保证所有问题不再生成。

下一次内容验收必须针对新生成并完成剪辑、混音的最终文件，尤其复核伸臂遮挡、手与布料接触、商品长度、服装切换，以及全部声音接点；不能用本记录或构建结果代替。
