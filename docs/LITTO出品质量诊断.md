# LITTO 出品质量诊断与修复

记录 2026-10-19 针对"成片不像电影、像 PPT 拼装"的一轮排查。问题按四层归类，每层给出根因、修复与验证数据。

---

## 一、提示词层：写的词本身就在要错的东西

### 1.1 「写实」被当成了「做旧」

**现象**：2026 年的年轻电工被拍成 1978 年的老工人，墙面灰暗、道具陈旧。

**根因**：提示词主动写了「旧书桌」「旧木柜」「搪瓷杯」「墙面有污渍与钉孔」。写实感被等同于"加磨损、加油渍、加颗粒"。

**修复**：

- `PHOTOGRAPHIC_BASELINE` 重写：删除「胶片颗粒」「边缘不做过锐」「色彩不过度饱和」「环境保留生活痕迹墙面磨损」；新增「曝光正常明亮通透」「色彩自然准确不降饱和」「画面干净无噪点无做旧痕迹」。
- 新增 `DISTRESSED` 词表拦截：提示词出现脏/旧/破/锈/污渍等词且未写 `DISTRESSED: 理由`，直接拒绝生成。
- `qc` 新增两项硬信号：`underexposed`（平均亮度 < 55）、`desaturated`（平均饱和度 < 8）。做脏做旧在数据上就是压暗 + 降饱和。

### 1.2 职业泛称本身就是年代炸弹

**现象**：物件换对（LED、铝合金窗、数显电笔）之后，人物仍是老厂工人。

**根因**：`工装`／`劳保服`／`工作服` 在模型里的视觉对应是**翻领宽松劳保服**；`水磨石`／`白炽灯`／`木格窗`／`铁皮` 同理。**词的年代暗示比形容词更强**，写「干净平整的工装」也救不回来。

**修复**：不用职业泛称，改用面料 + 剪裁 + 具体物件。

```
服装：深灰速干长袖、半拉链立领、修身剪裁、左胸小 logo、
      多口袋工装长裤带反光条、黑色低帮安全鞋
空间：浅灰瓷砖墙、PVC 卷材地板、嵌入式 LED 平板灯、
      铝合金内开内倒窗、白色吊顶
```

落在 `assets/world.json` 的 `garments`／`spaces`／`bannedWords` 三个字段，由 `eraAnchor()` 注入。

### 1.3 资产拆解自己在放大做旧

**现象**：`assetPlan` 生成的 26 条资产提示词里，**22 条带做旧词**。

**证据**：

| 资产 | 自动生成的提示词 |
| --- | --- |
| 陈砚 | 「额前碎发被汗粘在皮肤上，脸有灰尘与机油污渍」 |
| 祁 | 「短发凌乱沾着烟灰」 |
| 铁皮工具箱 | 「漆面大面积剥落露出褐色锈斑，提手缠着脏布条」 |

**根因**：剧本只写「磨得发白的工装」，`assetPlan` 的 system prompt 没有约束，语言模型把它扩写成汗渍、油污、锈斑。

**修复**：`assetPlan.ts` 的 SYSTEM 加三条硬规则（按年代写当代物件／默认干净完整／旧只属于建筑）。重拆后 22/26 → **15/29**。

## 二、约束层：规则写在文档里，没人执行

### 2.1 人物镜头没有身份参考 → 每镜重新选角

**修复**：无 `images`／`firstFrame`／`continueFrom` 的人物镜直接拒绝，只放行空镜与建资产用途。判定只取 `REQUEST:` 段作者原文，避免被编译模板里的 `face` 误伤。

### 2.2 时长按 5 秒一刀切 → 动作装不下，全部退化成摆拍

**根因**：MiniMax-H3 的真实区间是 4–15 秒，实际全用 5 秒。51 镜压 240 秒，一镜只有 4.5 秒，「绕到背后→蹲下→扳闸→站起」装不下，模型只能挑一个瞬间定格。

**修复**：未指定时长时取模型上限的 2/3（H3 即 10 秒）；技能里写明「生成上限是能力，不是每镜固定长度」。

### 2.3 影调没有项目级绑定 → 各镜各写各的色

**修复**：`assets/look.json` 存导演，生成时自动注入该导演的主色与占比、主光、高光/阴影偏色、对比度、avoid 清单。

### 2.4 资产后置 → 场景和人物全靠模型自由发挥

**修复**：`POST /api/ai/media/assets` 从剧本拆资产清单，`preflight` 核对覆盖率（清单 6 个角色 vs 实际 3 份档案）。

## 三、执行层：工程细节反复咬人

| 问题 | 表现 | 修法 |
| --- | --- | --- |
| **热更不可靠** | `bun --watch` 改完代码行为不变，一度误判成正则写错 | 用「改一处可观测输出（错误文案）看返回」验证，不能只看文件时间戳 |
| **自指误伤（三次）** | ①空镜被人物镜规则拦 ②「没有污渍」被判成要求做旧 ③`PHOTOGRAPHIC_BASELINE` 自己含「污渍/破损」，触发了自己的规则，全部生成被拒 | 检测前先剥掉系统注入段（`PHOTOGRAPHICBASELINE`／`LOOK:`／`ERA`／`CAST:`／`SHOTSPEC:`），只查作者原文；否定前缀表补「不主动／不添加／不做／不得」 |
| **异步拦截不即时** | 生成走队列，HTTP 仍返回 202，失败原因只写在 `generation_jobs.error` | 前端需轮询任务状态；文档里写明 |
| **合成绕过响度** | 走 `filter_complex` 时音频直接 `-map 0:a`，成片音量掉到 −47 dB | 音频也入滤镜链 `[0:a]loudnorm...[a]` |
| **静默写盘失败** | `writeWorkspaceFile` 收绝对路径，传相对路径写到了进程 cwd，还被 `catch` 吞掉 | 改用 `writeAtomic(join(cwd, ...))` 并让错误抛出 |

## 四、链路层：能力和执行是断的

**最根本的一条**：cloud 有完整制片链路（`compileShot`、连续性、`qualityReviewPlan`、`inspectFinal`、`nle-render`），但工作区那条裸生成链路一个都不用。

这一轮的修复都是在裸链路上补洞：

| 新增 | 作用 |
| --- | --- |
| `shotSpec` | 把散文拆成景别/焦段/运镜/调度/表演/光线/起止状态 |
| `cast` | 角色档案复用，按名引用定妆参考 |
| `styleReference` | 只借影调不借身份，且不能顶替身份参考 |
| `continueFrom` | 抽上一镜真实末帧作首帧，承接空间与光向 |
| `composeFilm` | 拼接不重编码（无黑闪）+ 调色 + 胶片响应 + 响度归一 + 自检 |
| `qc` | 黑闪/削波/静音/跳色/过曝/死黑/发灰/色板偏离 |
| `preflight` | 开拍前核对 look、cast、assetPlan、shotSpec、ffmpeg |
| `rules` | 规则覆盖率统计，用执行数据判断规则是不是摆设 |

## 六、仍然没解决的

1. **语义质检**：换脸、跑题、动作缺失需视觉模型，当前租户未配。
2. **台词配音**：`mediaProviderConfigs` 无 audio 模型。
3. **自我校正**：跑过的片子没有反馈回推荐与参数，每次从零算。
4. **UI 入口**：cast／shotSpec 等参数只能走 API 与 Agent，页面上没有入口。
