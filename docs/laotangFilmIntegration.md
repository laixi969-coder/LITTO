# 老唐电影技能在 MILI MILI 的取舍与实测

最值得引入的是三项导演判断。拆资产时能指回原稿，换机位时能说清同一间屋子的近远关系，拆对白时能说明听者究竟在哪个词之后才有反应。MILI MILI 已有采用稿、资产库、走位板、配音实测和剪辑时间线，这些判断可以直接改善写入现有工具的内容。

## 四组材料如何取用

| 桌面材料 | 它解决的创作问题 | 在 MILI MILI 的落点与取舍 |
| --- | --- | --- |
| 故事创作 S3.3，单文件及分模块版 | 把作者知道的事实、人物听来的消息、当场可见的结果分开。局部润色要保住肯否、消息来源和行动先后。 | 编剧已有场次目标、阻力、变化、知情和前因。改编指南补了“传言怎样落到听者行动”的例子，适用于既有稿、续写和局改。新故事继续按当前项目选定的类型和框架发展。 |
| 故事资产提取及角色资产板 2.0 | 实体身份、外观状态、展示角度与当场使用有不同作用。一把钥匙可以换手，多张图也可以指向同一件东西。 | 结构化拆解沿用场次表的实体编号。直接拆资产接口增加原文引句，使用摘要交代出场和状态，图像提示只表现其中一个时点。角色板吸收足底、肩膝对齐和人物自身左右的写法。MILI MILI 的正脸特写及正侧背全身图继续服务既有选角与参考绑定。 |
| 全能场景 3.0 | 提供总览转实景、室内两端平视和对角微俯三条路线。每条路线真正解决的问题都是换站位之后，原来近处、远处和偏在一侧的东西会出现在哪里。 | 场景有反拍需求时才推第二机位。用已采用的首图或已知布局确定门窗、通路和光源。已有坐标的走位板直接算出参照物的左右与纵深。补出的视角可用独立文件挂回同一场景，普通单张定场图仍可直接制作。 |
| 分镜 S10 至臻版与轻装版 | 完整版按任务展开表演、空间、声音和容量资料，轻装版把主流程和例子集中在入口。共同优势是先排事件，再分配视点，最后检查动作和原句能否在同一段时间里演完。 | 电影技能、分镜团队和导演提示词吸收了并行计时、信息触发与交接阶段。正式制作写入现有镜头规格。长对白可以用双人持续镜或有目的的反应镜；切点服从表演、已选镜型和真实口型覆盖。 |

老唐自带的茶室样例说明了这个区别。第一场老唐把青铜钥匙交给阿禾，第二场阿禾仍握着它。两场只需要一把钥匙，持有人要随交接更新。第二场只有门外三声敲门，原文没有揭示来者，分镜若直接切到老唐站在门外，就替作者提前给出了答案。

回查桌面原包时，故事的事实与视角看 `laotang-storycraft-zh/SKILL.md`，道具换手看资产提取包的 `references/continuity-workflow.md`，机位与地标看《老唐全能版场景skill3.0》第 4 节，覆盖与估时看 S10 至臻版的 `references/coverage.md` 和 `references/timing.md`。

有些约定适合独立聊天交稿。例如首轮确认卡、另交 HTML 时间表、首次挑选无头或有头三列板、按持续秒数切换视点。在工作台里，用户已有采用稿、选角、镜头表和声音窗口，再执行一遍会重复确认，也可能破坏有意保持的长镜头。因此这次沿用工作台的交付格式与模型档位；微缩图、对角视图和特定角色板只在作品确实需要时使用。

## 用同一场修伞铺戏核对

> 午后，南门正对北墙取件柜，光从西窗照到柜台。阿禾把封着口的蓝布袋递给林师傅。林师傅边接袋边说：“听说小乔明天回来。”阿禾听到“明天”才抬眼。下一场接上，林师傅解开同一只袋子的封绳，取出黄铜号码牌。小乔全程没有出镜。

**编剧和分镜的处理示例。** 第一句能支持林师傅转述消息，也能支持阿禾在听见“明天”后抬眼。开场先看两人之间递到一半的袋子，双人镜里可以同时看清林师傅接稳和阿禾的反应。若下一镜切袋口，手里的袋子已经交接完成，接下来拍解绳、露出号码牌即可。这样既保住原句里的不确定性，也给观众留下看清号码牌的时间。这段是导演示例。

| 实际核对项 | 调整前 | 调整后 |
| --- | --- | --- |
| 模型收到的剧本范围 | 在两场间填入空白，使输入达到 12,124 个字符。捕获到的旧请求只有前 12,000 个字符，第二场和号码牌都在截断处之后。 | 同一份输入完整进入请求。用可控模型回包返回“取出黄铜号码牌。”后，实际拆解接口将引句与道具一起写入资产清单。 |
| 新资产的出处 | 旧接口只筛类型、名称和提示词，没有原文依据检查。 | 引句须逐字出现在本次剧本中。伪造引句、缺少引句和截断回包均未覆盖已有清单。程序能核对引文是否存在，引文是否足以证明角色身份或道具用途仍要结合上下文判断。 |
| 南端朝北、北端朝南的两个机位 | 同一走位板只输出阿禾和林师傅的画面左右，已登记的门、窗、柜没有进入机位文字。 | 南端看过去是近处南门 1 米、左侧西窗 4 米、远处柜 7 米。北端看回来是近处柜 1 米、右侧西窗 4 米、远处南门 7 米。数值是物件中心沿镜头朝向的纵深。该例的两个机位跨过人物轴线，接口仍提示跳轴，直接对切前需要处理人物方向。 |

**时长算例。** 假设接袋与原句共同占用 3 秒，随后解绳见牌占 1.5 秒，计划剪入共 4.5 秒。在给定 5 秒、10 秒两个可用档位的条件下，现有规划器默认给出 10 秒素材、5.5 秒可剪余量。明确指定为独立短样时返回 5 秒素材、0.5 秒余量。两种方案的戏都是 4.5 秒。数字取自该规划输入，真实对白长度应以选定录音为准。

## 验证范围

- 在临时工作区通过实际 HTTP 路由验证了完整输入、合法清单落盘、无效回包后原清单保留，以及旧清单继续被制片预检读取。无采用稿时返回 400，采用依据过期或拆解途中改换采用稿时返回 409。直接传入剧本沿用现有 40,000 字符上限。
- 通过走位板路由保存上述机位并按输出名称读回反拍提示。无物件坐标时沿用人物调度，有坐标时只取有名称的近处、远处及偏轴参照。实际视场和遮挡仍需结合首图与成图复核。另用两个独立文件验证首图与补充视角可同时登记到同一场景。
- 无人环境图走场景资产与反拍提示流程。人物走位板计算对话轴线需要至少两个人物，无人空景可以直接依据首图和文字布局设计反拍。
- 通过运行时技能加载器核对故事改编、剧本拆解、反拍和仅拆分镜四条入口，并核对分镜团队包。服务端与媒体生成工具通过类型检查，服务端构建通过。

上述检查覆盖输入完整性、资产出处、机位投影和时长规划。拆资产接口使用可控模型回包。下面的表演、道具与反拍记录来自随后生成的实际影片。

## 修伞铺的实片对照

两版都在 MILI MILI 调用 Atlas Cloud 的 MiniMax H3 Developer 图片参考生视频，使用同一份剧本、同一张双人参考图、480P、16∶9 和模型原声，关闭供应商提示扩写。每版各拍三镜，南面双人镜 7 秒、手部插入镜 4 秒、北面反拍 5 秒。两片按同样入点截到 16 秒。优化前使用提交 `3e83b497` 的走位输出和技能说明，优化后使用工作区新版。两次都实际运行了机位计算，六条拍摄提示按各自版本的说明人工编排，具体输入保存在项目的 `atlasInputs.json`。接口未提供固定随机种子，每个镜头每版只生成一次。

| 看什么 | 优化前 · 16 秒 | 优化后首轮 · 16 秒 | 用优化后素材改剪 · 13.125 秒 |
| --- | --- | --- | --- |
| 阿禾何时抬眼 | 约 1.4 秒看向师傅，约 5.1 秒才听到“明天”。 | 约 2.1 秒看向师傅，“明天”约在 6.2 秒，仍抢拍。 | 保留师傅原声，把整句话放在阿禾的反应近景上。“明天”约在 2.3 至 2.8 秒，约 2.8 至 3.0 秒能看到她抬眼看他。 |
| 蓝袋怎样接到下一镜 | 师傅接到袋子后，下一镜在台面上解绳。袋口先露灰白方片，后镜取出黄铜牌。 | 师傅手托蓝袋解绳，持物状态接得上。但阿禾的绿袖和手又碰了一次袋子，袋口仍提前露出灰白方片。 | 手部镜从师傅已持袋处切入，在灰白方片露出前切走。观众第一次看清袋里的物件，是师傅在反拍里取出的黄铜牌。 |

眼神时间取自逐帧画面，词位结合普通话原声转写估计。单独观察首轮生成，能明确认出反拍空间改善，持袋动作只改善了一部分，关键词驱动的反应仍失准。第三版的抬眼和道具揭示来自剪辑。取牌镜最后两人把目光转向镜头，还有展示道具的表演痕迹。

早期试图的美术描述自行加入了旧街、旧木墙和旧围裙。正式拍摄前改用整洁营业中的当代店铺参考。两版六镜的浅木柜门、墙面、台面和衣服都完整洁净。这个结果说明本次共用参考维持了美术状态。工作台画布 `atlasReview` 可播放三版，对应 `exports/beforeMatched.mp4`、`exports/afterMatched.mp4` 和 `exports/afterEdited.mp4`。[Atlas Cloud 模型规格](https://www.atlascloud.ai/models/minimax/h3-developer/reference-to-video)

## 实片问题如何回到工作台

| 实片里看到的问题 | MILI MILI 的改动 | 本次如何核对 |
| --- | --- | --- |
| 师傅边接袋边说话，阿禾在“明天”之前就抬眼 | 拆稿保留动作中的说话人和完整引语。导演能把原词、听者和词前词后的动作绑定在同一句上。审片分别记录实际听清词位和首次动作的时刻，采用镜头与成片验收都核对当前素材的记录。 | 用原剧本只拆出林师傅的一句对白，小乔没有进入出镜清单。代入上表三版的实测时刻，前两版判为抢拍，改剪版通过该项。缺音轨或词位不明时保留为未验证。 |
| 蓝袋重复交接，袋口先露出另一块东西 | 镜头只执行本镜分到的交接阶段。分镜面板可把本镜后段才出现的资产标成“稍后入画”。生成首帧时排除其外形、专属参考和走位地标；视频按动作设计揭示。 | 通过分镜保存和编译接口核对同一个镜头。首帧没有黄铜牌的描述和参考，视频仍保留取牌动作及参考。没有该标记的旧镜头沿用原有出镜资产。 |
| 反拍只换人物左右，背景仍像正面 | 已有分镜调度时，正式提示仍从同一张走位板补入本机位可见的固定参照。 | 用原走位板调用实际接口，正拍算出西窗在左、北柜在远处；反拍算出西窗在右、南门在远处。旧走位板读回结果一致。 |
| 师傅的台词要延续到阿禾的反应镜头 | 剪辑和定稿检查共同读取原素材、音轨源入点与时间线位置。画外声可延续到相邻镜头，画内发声还须核对嘴部所用画面。 | 直接调用定稿检查。完整的同源声音桥通过对白检查；换源、断句、静音、画面空档和画内失步分别被拦截。 |

这里复核了既有素材与产品行为。本轮没有重新生成影片，因此没有新增样本可以判断模型下一次是否会一次演对。
