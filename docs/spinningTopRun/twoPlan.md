# 《盐灯亮着》

林砚回家的那晚，雨下得像有人把整座城泡进了水里。

他站在旧楼门口，先把鞋底在台阶上蹭了三下。门锁换过，钥匙插进去转不动。他敲门，里面立刻传来母亲的声音：“谁啊？”

“我。”

门开了一条缝。母亲看着他，没问他怎么瘦成这样，也没问这几年去了哪里，只把门拉开，说：“鞋放外头，地刚拖过。”

客厅里，妹妹阿澄正把一盏盐灯从纸箱里拿出来。灯罩缺了一个角，底座上还留着父亲用红漆写的“砚”字。林砚认得那盏灯。父亲做灯时总把盐块削得不对称，说这样光才不刺眼。

他从口袋里摸出一只铜陀螺，在茶几上转起来。

陀螺旋得很稳。

母亲看一眼，转身去厨房：“先吃饭。菜凉了。”

林砚没动。

四年前，父亲林柏舟失踪在北岸盐场。那天夜里涨潮，盐场的旧泵房进了水。父亲最后一通电话打给林砚，只说：“你回来一趟，灯坏了。”林砚当时在外地替剧团修舞台灯，手机没电，第二天才看到消息。搜救持续了九天，没找到尸体。母亲说父亲大概被水冲进了废渠；阿澄说那晚父亲根本没进泵房。

林砚没回家参加最后一次搜寻。他后来把那通没接到的电话存在手机里，听了很多遍。每次听到“灯坏了”，他都停下。

三年后，林砚在一场车祸里昏迷了七个月。醒来后，医生说记忆会有空缺。他没告诉家人，自己常常分不清某些日子到底发生过没有。他买了一只铜陀螺，带在身上。旋转时，它会在某个时刻倒下；只要倒下，他就相信眼前是真的。

眼前这只陀螺还在转。

母亲把饭端上桌，桌上四副碗筷。父亲的位置空着，面前摆了一只小碟，里面是切成薄片的咸柠檬。林砚盯着那碟子，伸手去碰。母亲把碟子移远了一点。

“你爸不吃这个。”她说。

“他以前吃。”

“以前是以前。”

阿澄把灯罩放在桌边，拿起一把小锉刀，继续磨缺角。她没看哥哥，只说：“你回来得挺会挑时候。”

“什么？”

“灯坏了。”她把锉刀放下，“妈明天要把泵房拆掉。”

母亲夹菜的手停了一下：“那地方早该拆了。”

“拆之前，我想去看看。”林砚说。

“看什么？”

“那晚的东西。”

母亲把鱼翻了个面，没抬头：“水都退了四年了。”

阿澄说，泵房的门一直锁着，钥匙在母亲那儿。母亲说钥匙早丢了。饭桌上没人再说话，只剩抽油烟机的风声和盐灯里一声轻轻的电流响。

林砚拿起钥匙串。母亲没拦他，只把一碗汤推到他面前。

“吃完再去。”

他没碰汤。

母亲把碗又往前推了一寸：“先吃饭。”

陀螺旋到桌沿，差一点掉下去，又被林砚用指尖拨回正中。

母亲看着他的手：“你小时候就这样。东西要是不听话，你就一直扶着。”

当晚，林砚和阿澄去了盐场。泵房的门上挂着新锁，锁芯却已经锈死。阿澄拿钳子夹住锁梁，林砚用肩膀顶门。门开时，一股潮湿的盐味涌出来，地面上还留着退潮后的白线。

里面没有尸骨，也没有父亲的工具箱。只有一张折叠桌，桌脚下压着一只旧收音机。阿澄拧开收音机，里面掉出一卷磁带。

林砚把磁带装进随身带来的录音机。父亲的声音先是几声咳嗽，然后说：“砚子，盐灯的线别接反。红线往里，黑线——”

磁带卡住了。

林砚按了几次，机器只吐出一段沙沙声。阿澄蹲在桌边，摸到桌脚上刻着一道浅浅的划痕。她说，那晚她也来过泵房。父亲让她站在门外，叫她别进去。她听见里面有人说话，像是在跟林砚争执。

“我那晚没来。”林砚说。

“我知道。”

“你听见的是谁？”

阿澄没回答。她从口袋里拿出一张折得很小的纸，放到桌上。纸上有一行父亲的字：**泵房钥匙，给砚。**

林砚盯着那行字。纸的背面还写着日期：失踪前一天。

阿澄说，母亲一直知道钥匙在哪儿。她把钥匙藏在厨房的米缸下面。父亲失踪后，母亲不肯让任何人进泵房，也不肯再修那盏盐灯。

“你为什么不早说？”林砚问。

“你那时候不在。”

“我现在回来了。”

“你是回来了，还是想把那天补完？”

阿澄把磁带收起来，先出了门。

回家后，母亲还坐在饭桌边。菜已经凉透，盐灯亮着，灯罩上缺掉的角被阿澄用透明胶粘住了。林砚把那张纸放在桌上。母亲看了一眼，没碰。

“你知道钥匙在哪儿。”他说。

“知道。”

“为什么不告诉我？”

母亲把桌上的鱼刺一根根拢到小碟里：“你回来就问这个？”

“我想知道爸那晚到底在哪儿。”

“你爸那晚在泵房。你妹妹在门外。我在家里等他。”

“那他为什么打给我？”

“他想让你修灯。”

“灯坏了？”

母亲没有答。她把鱼刺倒进垃圾桶，洗了洗手，回来把一只空碗摆到父亲的位置上。

林砚把陀螺重新转起来。它稳稳地立在桌面上。

“如果我那天接了电话呢？”他问。

母亲拿起筷子，把菜夹进他的碗里：“那你现在就会问别的。”

她说得很轻，像是在叫他多吃一口饭。

林砚把碗推开。陀螺快要停了，身子开始晃。他伸手想扶，母亲却把筷子塞进他手里。

“菜凉了。”

陀螺倒下时，发出一声短促的铜响。

林砚没有看它。他夹起那块鱼，慢慢挑刺。母亲把父亲那只空碗收走，擦干净，又放回柜子里。

第二天，泵房拆除前，林砚独自回到盐场。他带着那盏盐灯，把松掉的电线重新接好。红线往里，黑线绕过底座。灯亮时，潮水正从渠底退下去。

他把陀螺放在泵房门槛上。

铜陀螺旋了几圈，歪了一下，仍没有倒。

林砚提起盐灯，转身往家走。身后，拆除工人开始卸门。门轴发出一声长响，像有人在屋里挪开了一张椅子。

回到家，母亲已经把饭摆好。桌上只有三副碗筷。阿澄端来一盘咸柠檬，随手放在桌子中间。

“你不是说爸不吃这个？”林砚问。

“我吃。”阿澄说。

母亲给他盛了饭：“坐下吧。”

盐灯亮着。陀螺躺在林砚口袋里，没有人拿出来。

饭吃到一半，母亲问：“还要汤吗？”

林砚把碗递过去。

“要。”他答。

窗外的雨停了。厨房水龙头没拧紧，一滴一滴落进空盆里。
