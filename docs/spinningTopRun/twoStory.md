# 盐灯亮着

林砚到家时，雨正从旧楼的檐沟里往下倒。

他在门口把鞋底蹭了三下。锁换过，钥匙插进去转不动。他敲门。

“谁啊？”母亲在里面问。

“我。”

门开了一条缝。母亲看了他一眼，把门拉开：“鞋放外头，地刚拖过。”

客厅里，妹妹阿澄正从纸箱里取出一盏盐灯。灯罩缺了一角，底座还留着父亲用红漆写的“砚”字。父亲做灯时总把盐块削得不对称，说这样光才不刺眼。

林砚从口袋里摸出一只铜陀螺，在茶几上转起来。

陀螺旋得很稳。

母亲往厨房走：“先吃饭，菜凉了。”

林砚没动。

四年前，父亲林柏舟失踪在北岸盐场。那晚涨潮，旧泵房进了水。父亲最后一通电话打给林砚，只说：“你回来一趟，灯坏了。”

那时林砚在外地给剧团修舞台灯，手机没电。第二天才看见未接来电。搜了九天，没找到父亲。母亲说他大概被水冲进废渠；阿澄说那晚父亲根本没进泵房。

林砚没回来参加最后一次搜寻。

后来他出了车祸，昏迷七个月。醒来后，日子时常在记忆里缺一块。他买了这只铜陀螺，随身带着。转起来时，只要它最后倒下，他就相信眼前是真的。

如今陀螺还在转。

母亲把饭端上桌。桌上摆着四副碗筷。父亲的位置前放了一只小碟，里面是切成薄片的咸柠檬。林砚伸手去碰，母亲把碟子挪开一点。

“你爸不吃这个。”

“他以前吃。”

“以前是以前。”

阿澄把盐灯放在桌边，拿起小锉刀磨那道缺口。她没抬头：“你回来得挺会挑时候。”

“什么？”

“灯坏了。”她放下锉刀，“妈明天要拆泵房。”

母亲夹菜的手停了一下：“那地方早该拆了。”

“拆之前，我想去看看。”林砚说。

“看什么？”

“那晚的东西。”

“水都退了四年了。”

阿澄说泵房的门一直锁着，钥匙在母亲那里。母亲说钥匙早丢了。桌上只剩抽油烟机的风声，还有盐灯里一声细细的电流响。

林砚拿起钥匙串。母亲没拦他，只把一碗汤推到他面前。

“吃完再去。”

他没碰汤。

母亲又把碗往前推了一寸：“先吃饭。”

陀螺旋到桌沿，几乎要掉下去。林砚伸出指尖，把它拨回桌子中央。

母亲看着他的手：“你小时候就这样。东西不听话，你就一直扶着。”

当晚，林砚和阿澄去了盐场。泵房门上挂着新锁，锁芯却锈死了。阿澄用钳子夹住锁梁，林砚用肩膀顶门。门开时，潮湿的盐味涌出来，地上还留着退潮后的白线。

里面没有尸骨，也没有父亲的工具箱。只有一张折叠桌，桌脚下压着一台旧收音机。阿澄拧开收音机，一卷磁带掉了出来。

林砚把磁带放进随身带来的录音机。父亲先咳了几声，随后说：“砚子，盐灯的线别接反。红线往里，黑线——”

磁带卡住了。

林砚按了几次，机器只吐出一阵沙沙声。阿澄蹲在桌边，摸到桌脚上有一道浅浅的划痕。

“那晚我也来过。”她说，“爸让我站在门外，叫我别进去。我听见里面有人说话，像是在跟你争。”

“我那晚没来。”

“我知道。”

“你听见的是谁？”

阿澄没有回答。她从口袋里拿出一张折得很小的纸，放在桌上。上面是父亲的字：**泵房钥匙，给砚。**

背面写着日期，是父亲失踪前一天。

阿澄说，母亲一直知道钥匙在哪儿。她把钥匙藏在厨房的米缸下面。父亲失踪后，母亲不让任何人进泵房，也不肯再修盐灯。

“你为什么不早说？”林砚问。

“你那时候不在。”

“我现在回来了。”

阿澄把磁带收进口袋：“你是回来了，还是想把那天补完？”

她先出了门。

回到家时，母亲还坐在饭桌边。菜已凉透，盐灯亮着，缺角被阿澄用透明胶粘住了。

林砚把那张纸放到桌上。母亲看了一眼，没碰。

“你知道钥匙在哪儿。”

“知道。”

“为什么不告诉我？”

母亲把鱼刺一根根拢进小碟：“你回来就问这个？”

“我想知道爸那晚到底在哪儿。”

“你爸在泵房。你妹妹在门外。我在家里等他。”

“那他为什么打给我？”

“他想让你修灯。”

“灯坏了？”

母亲没答。她把鱼刺倒进垃圾桶，洗了手，回来把一只空碗摆到父亲的位置上。

林砚重新转起陀螺。它稳稳立在桌面。

“如果我那天接了电话呢？”他问。

母亲夹了一筷子菜，放进他的碗里：“那你现在就会问别的。”

她说得很轻，像是在叫他多吃一口饭。

林砚把碗推开。陀螺快停了，身子开始摇。他伸手想扶，母亲却把筷子塞进他手里。

“菜凉了。”

陀螺倒下，发出一声短促的铜响。

林砚没有看它。他夹起那块鱼，慢慢挑刺。母亲把父亲面前的空碗收走，擦干净，放回柜子里。

第二天，泵房拆除前，林砚独自回到盐场。他带着盐灯，把松掉的电线重新接好。红线往里，黑线绕过底座。灯亮时，潮水正从渠底退下去。

他把陀螺放在泵房门槛上。

铜陀螺旋了几圈，歪了一下，仍没有倒。

林砚提起盐灯，转身往家走。身后，拆除工人开始卸门。门轴发出一声长响。

回到家，母亲已经把饭摆好。桌上只有三副碗筷。阿澄端来一盘咸柠檬，随手放在桌子中间。

“你不是说爸不吃这个？”林砚问。

“我吃。”阿澄说。

母亲给他盛饭：“坐下吧。”

盐灯亮着。陀螺躺在林砚口袋里，没有人拿出来。

饭吃到一半，母亲问：“还要汤吗？”

林砚把碗递过去。

“要。”

窗外的雨停了。厨房水龙头没拧紧，一滴一滴落进空盆里。
