# 灶上的火

陀螺转了很久。

周既明站在玄关，盯着它黄铜色的身子在柜面上绕圈。陀螺边缘有一道磕痕，是他小时候从父亲的工具箱里偷来的。去年冬天，他在一间没有窗的病房里攥着它，靠它判断自己有没有睡着。

现在它在家里转，母亲在厨房里，桌上飘来糖醋鱼的香味。

“你还要看多久？”母亲喊，“饭都要凉了。”

周既明没有回答。他等着陀螺慢下来，等它晃动，倒下，给眼前这一切一个可以相信的理由。

它转得越来越慢，却总在将要倾倒时重新稳住。

“既明，洗手。”

他伸手按住陀螺。

“别碰！”母亲从厨房探出头，“你爸说过，转起来就让它自己停。”

周既明松开手。陀螺又转了几圈，终于倒下，撞在柜面上，发出一声轻响。

“它停了。”他说。

“那就吃饭。”母亲回了厨房，“菜都热三遍了。”

屋里的一切都熟悉得过分。窗台上的绿萝，墙上发黄的挂历，餐桌边缺了一角的椅子。连母亲走路时拖着左脚的声音，都和记忆里一样。

只有客厅的老钟停在七点十二分。

周既明脱下外套，走进厨房。母亲把一盘糖醋鱼端上桌，鱼背划着三道口子，酱汁里浮着几片姜。

“你怎么知道我想吃这个？”

母亲看了他一眼：“你每次回来都说想吃这个。”

“我以前回来过？”

“当然。”她替他盛饭，“你不是刚回来吗？”

她说得自然，像在纠正一道简单的算术题。

周既明坐下，没动筷子。

母亲把饭碗放在他面前。她的手比记忆里瘦，腕骨突出，虎口有一道浅浅的烫伤。那是他十三岁时打翻热汤留下的。她当年疼得直吸气，还是先问他有没有烫着。

“妈，”他说，“这次我回来，待多久？”

“你想待多久就待多久。”

“那我爸呢？”

母亲的手停了停。

厨房里的抽油烟机嗡嗡响着。窗外有车驶过，轮胎压过积水。

“你爸去买酒了。”她说。

周既明看向墙上的钟。

“七点十二分。”

“怎么了？”

“钟坏了。”

“坏很久了。”母亲坐下来，“你爸说哪天修，哪天修。一直没修。”

周既明拿起筷子，又放下。

他回家的理由，曾经简单得像一张车票：母亲摔了一跤，邻居打电话给他。他赶到医院时，她已经醒了，坐在床边数药片，嫌护士倒的水太凉。

后来她出院，他却没有留下。

他总说等手头的事忙完，等下一班车，等下个月。直到某个清晨，邻居再次来电，说母亲在浴室里摔倒了，这次没能醒来。

他赶到时，屋里桌上还留着半碗凉掉的粥。

那以后，他常常梦见自己回家。

每一次，母亲都在厨房里催他吃饭。

每一次，他都不敢吃。

“你怎么不吃？”母亲问。

“我怕你等我。”

“我等你不是很正常吗？”

“你等了多久？”

母亲笑了笑：“你这孩子，今天说话怎么一股怪味。”

她夹了一块鱼肉，放进他的碗里。

鱼肉上没有刺。

周既明盯着那块鱼，想起小时候父亲总把鱼肚子最嫩的地方留给母亲，母亲再把鱼肚子留给他。父亲自己吃鱼尾，说那里有嚼头。

“爸什么时候回来？”

“快了。”

“你知道他去哪儿了吗？”

“买酒。”

“外面下雨，他怎么去？”

“穿了雨衣。”

母亲夹菜的动作没有停，像在讲一件早已确定的事。

周既明站起来，走到窗边。玻璃上映出他的脸，身后是母亲低头吃饭的影子。他伸手碰了碰窗玻璃，指尖冰凉。

“妈，你今天摔过吗？”

母亲抬头：“什么？”

“你膝盖疼不疼？”

“好好的，问这个干什么？”

他看向她的左膝。旧棉裤上，膝盖处有一块深色补丁，是父亲缝的，针脚歪歪扭扭。补丁下面没有纱布，也没有血。

可在医院里，母亲的膝盖缠着白纱布。

周既明掏出手机。屏幕亮起，没有信号。日期显示在三年前——母亲摔倒前一个月。

他把屏幕按灭。

“你工作还顺利吗？”母亲问。

“还行。”

“你别总说还行。上次你说还行，后来连续一个月没睡好。”

“你怎么知道？”

“我不问你，你就什么都不说。”

母亲把鱼刺挑出来，放在碟子边。她的动作很慢，像是故意留出时间给他。

周既明坐回去，拿起筷子。

“我已经回来了。”他说。

“我知道。”

“我这次不走了。”

母亲看着他：“那就先吃饭。”

“你不问我为什么？”

“你肯坐下，我就已经知道了。”

他把鱼肉送进嘴里。

咸，甜，带一点姜的辛味。和记忆里一模一样。

他嚼了两下，眼眶忽然发热。

母亲没有看他，只给自己夹了一筷子青菜。

“慢点吃。”她说，“没人跟你抢。”

他低下头，一口一口把饭吃完。母亲也没再催他。她说起楼下新搬来的邻居，说起窗台上的绿萝，说起父亲以前总把袜子挂在阳台上，害她以为楼上在晒小旗子。

周既明接过话头，说父亲那双袜子一只蓝一只灰，穿出去也不肯换。母亲说他爸从来不记得自己穿什么。周既明说他记得，小时候父亲带他去河边，鞋里进了沙，回家后把鞋倒过来，倒出一小堆沙子。母亲说那是他爸故意的，想把沙留给她扫。

他们说着说着，窗外的雨停了。

桌上两只碗空了。母亲把剩下的鱼夹进小碟，说留着明天吃。周既明想起她临终前那半碗粥，忽然站起来。

“我来洗碗。”

“你难得回来，坐着。”

“我来。”

他端起碗，走到水池边。水流冲过碗沿，米粒一颗颗滚进滤网。他把碗洗干净，又洗了筷子，擦干手，回到客厅。

母亲坐在沙发上，手里拿着一件毛衣，正补袖口。针线穿过布料，她细细地拉紧。

“妈，”周既明说，“我明天早上走。”

母亲手里的针停了。

“你不是说不走吗？”

“我得回去。有些事还没办完。”

“那你什么时候再来？”

周既明看着她。

他想说很快，想说下周，想说等忙完这一阵。他已经说过太多次了。

“我不知道。”他说，“但我会给你打电话。”

母亲低头继续缝毛衣：“那你吃完饭再走。”

“好。”

“早上走之前，也吃点东西。”

“好。”

“别空着肚子赶车。”

“好。”

她把毛衣放在膝上，抬眼看他：“你爸呢？”

周既明没有回答。

母亲像突然想起什么，笑了笑：“他去买酒了。回来要是发现你走了，又要说我没留住你。”

“他会说什么？”

“他说你这孩子，走得太急。”

周既明坐到她身边。母亲的肩膀很窄。他伸手扶住她，掌心贴着她的肩，隔着毛衣，能感觉到她轻轻起伏的呼吸。

“妈，我那天赶到的时候，你已经——”

“别说了。”母亲说。

他低下头。

“我没来得及跟你说的话很多。”

“你现在说也一样。”

“你能听见吗？”

母亲看着他，眼神温柔得近乎责备：“你不是已经说了吗？”

周既明把脸埋进手掌。

过了一会儿，母亲轻轻拍了拍他的背，和他小时候发烧时一样。那只手停在那里，暖得真实。

“睡一会儿吧。”她说，“你累了。”

“你呢？”

“我把毛衣补完。”

周既明靠在沙发上，闭上眼睛。

他听见针线穿过毛衣的细响，听见墙上停住的钟，听见厨房里水滴落进水槽。远处传来一声汽车喇叭，像父亲从街口回来，按了一下车铃。

“既明，”母亲说，“明早想吃什么？”

他睁开眼。

母亲还坐在旁边，手里拿着那件毛衣。窗外天色暗了，屋里没有开灯。

“煮粥吧。”他说。

“好。”

“少放盐。”

“你小时候可不嫌咸。”

“我现在嫌了。”

“那就少放一点。”

她拿起针，继续缝袖口。

周既明把头靠回沙发，眼睛又合上。玄关柜上的陀螺安安静静地躺着，一动不动。

第二天清晨，他睁开眼时，自己坐在医院走廊的长椅上。

手里握着那枚黄铜陀螺。

它已经停了。

走廊尽头，护士推着空药车经过。窗外天刚亮，地上有一条淡淡的雨痕。周既明站起来，走到洗手间，把陀螺放在窗台上。

他没有转它。

他去街角买了一碗粥，坐在医院门口慢慢吃完。粥放得很淡，他还是吃得一粒不剩。

然后他回到母亲的旧屋，打开窗，把窗台上的绿萝搬到有光的地方。

桌上那只缺角的碗还在。

他洗了它，擦干，放回柜子里。接着拨通了姐姐的电话。

“我回来了。”他说，“今晚一起吃饭吧。”

电话那头安静了片刻。

“好。”姐姐说，“我买菜。”

周既明望向厨房。灶台冷着，日光落在地砖上。

他把门后的围裙取下来，系在腰间，打开了火。
