### 原先完成了什么，漏了什么

原有 videoPromptDirector、旅拍、清新、园林与东方奇境包，以及系统提示和 workflow 分发已存在。它们把五板块、镜头库、资产流程写进了技能，但存在以下断点：

| 发现 | 本轮处理 | 验证边界 |
| --- | --- | --- |
| 全局写实基底强调油光、毛孔、肤色不均和粉底边界，与清爽目标冲突；还会覆盖柔光、夕阳、DV 等成像设计 | clean / natural 分开，默认细微纹理、均匀肤色、克制高光，服从既定身份、年龄、妆容和光源；五板块不再叠加冲突基底 | 新人物图与短视频已生成；没有同种子旧版 A/B，不能量化提升 |
| “不要动漫”也可能触发跳过写实；负面段“污渍、破损”被当作正向做旧要求 | 正负表达分离，仅用于启发式检查，原始负面约束仍发送 | 内联手工验证通过，非完整自然语言解析 |
| Python 自检没接请求，实际引用与源包的纯 @名称 不同 | 新增服务端五板块/空块/时间码/总时长校验，接 preflight 与入队前校验；普通提示词仍可用 | 临时配置目录的真实 HTTP 验证通过；结构正确不等于画质正确 |
| 节点不能明确回读素材与引用编号，发模型的占位标记未翻译 | getConfig 返回 references 与 generationPrompt；setPrompt 检查连接，按真实输入顺序编译图片/视频/音频/文字标记 | 节点类型检查与构建通过；尚未覆盖所有模式的真实付费任务 |
| Vidu 单图节点的 images 与适配器 firstFrame 字段不一致 | Vidu 1.1.3 在公共适配器统一首帧入口，保留原有多参考能力；源码及运行版同步 | 内存请求验证通过，无追加付费任务 |
| 方舟运行目录还是旧版；新模板用了无法解析的动态数组、错误模型 ID，并缺少图片多参考 | 更新源码及运行适配器，修正 Seedance 2.5 / Seedream 5 Pro ID，使用可解析元数据；支持 2.5 最多 30 张图片参考；时长与精度须符合同一能力记录 | 适配请求离线验证通过；本轮样片用 Vidu，方舟尚未做付费验收 |
| Seedream 5 Pro 被误标为 4K、14 图，并发送不支持的连生参数 | 当前接入 2K、最多 10 张参考，去掉 sequential_image_generation；2.5 首帧使用 adaptive 画幅 | 按官方文档修正；图层、交互编辑及其它精度未接入 |
| 人物方法仍推荐黑眼圈、干皮、刻意不对称，并声称能“AI 感减半” | 新增 cleanPortrait 方法，调整资产模板、服装连续性、清新光色和分发；删除无实测依据的效果承诺 | data/skills 已同步，无自定义冲突 |

### 下载技能真正值得吸收的写法

本轮重点阅读用户本地女团选角 face-asset / model-adapters、复古日常 casting-aesthetics-and-styling、光感小清新等资料。关键是把**身份、妆发、成像、现场动作**分开写，再落实到同一份参考资产与时间线。细微皮肤纹理、清晰毛流和克制高光共同建立真实感；不是用“粗毛孔、干皮、黑眼圈”证明像真人，也不是堆相机品牌和 8K 标签。人物资产图要可辨识，剧情首帧要符合实际场景；三视图不能当作首帧让模型把三个身体一起动起来。

实现时使用 MILI MILI 的模型选择、真实引用和制作接口，没有照搬下载包的平台指令。原包中的固定妆面、镜头数、人物案例属于创作资料，不是用户对所有项目的指令。

### 本轮样片证据

- 样片、请求与回执保存在本机被 Git 忽略的 data 工作区，不随源码公开。
- 图片：用户确认从编辑版切换到 `atlasCloud / openai/gpt-image-2/text-to-image`，1152×2048，1 张。文件 `assets/generated/cleanPortrait.png`。
- 视频：沿用 `vidu / viduq4-preview`，上述图片作首帧，单镜回眸与浅笑，请求 5 秒、1080P、静音。实际 1080×1920、24fps、5.041667 秒，无音轨。视频文件保留在该本地验证工作区。
- 图片初始队列任务 遇服务重启，UI 历史可能仍显示失败。通过原远端任务 查询完成并取回唯一结果，**没有重新生成**。
- 视频由应用 generateMediaDirect 与现有 Vidu 适配器在隔离本地配置中执行，避免开发服务重启影响；未更改正在运行服务的鉴权。原远端回执已留存。因此本轮不是完整队列恢复能力的验收。
- 请求、结果、远端回执均保存在该工作区；视频按 2fps 抽查 10 帧，并查看 4 秒原尺寸帧。没有完成逐帧或连续播放审片，不以抽帧排除微小闪烁。
- 观感：图片的窗光、肤色、发丝与棉质衣料区分较好，符合清爽方向；视频保留了服装、桌面和窗光，完成转头浅笑，但正面脸更柔、更平整，有精修广告感，仍未达到可无条件称为“难辨真假”的水平。
- 没有旧版同提示词同种子样片，因此只能评估当前结果，不能宣称已证明因果提升、评分提升或百分比提升。
