# 3042｜表演过度：角色策略比情绪动作清单更有用

来源：[AI人物为什么总是演得太用力？](https://www.super-i.cn/info-3042.html)。作者 Loki，页面显示“2个月前”。2026-10-26 全文六章、逐组提示词及组合案例已阅读；本文笔记不将未观看的视频算作效果证据。

## 教程方法的独立摘要

作者将表演设计分为真实情绪、希望别人看到的样子、正在进行的正常行为和反应先后。情绪可在既有任务中短暂显露，而非将所有五官同时分配给同一标签。该方法适合含自我控制的关系戏；案例中的隐瞒目的并不是所有自然表演的必要条件。

## 为什么它能改变提示词的任务

“紧张”只指明方向；模型仍要自己选强度、对象与时间。“尽量让对方相信自己镇定”增加了行动目标和约束，身体行为开始有筛选条件。不过只给内心解释仍可能不可见，还需要决定观众能从哪个局部读到变化。

在 Milimili 中可用四个问题整理，不新增固定表格给用户填写：

1. 角色现在要完成什么，目标对象是谁？
2. 角色刚收到什么新信息，何时才能知道？
3. 哪个既有动作会因此停、改速或改变方向？
4. 本镜结束时，动作完成到哪里、对手读到了什么？

这是导演根据现有剧本做的判断，不能用模板虚构秘密、敌意或隐瞒。公开的欢喜、愤怒与直接表达同样可以真实。

## 身体任务与微反应怎样结合

身体任务必须在镜头开始前已成立，或由本场事件合理触发。既有“清点物件”被消息打断，可以让一次放置停在半途；如果原戏只有倾听，则无需为了自然凭空加喝水、抽烟或整理头发。

| 设计层 | 正确的编排对象 | 常见误用 |
| --- | --- | --- |
| 主要任务 | 把物件交给谁、完成哪一步、确认哪个信息 | 只写大动作，仍然没有目标 |
| 细微信号 | 当前任务的一次暂停、力度改变或视线转移 | 同时抖手、抿嘴、皱眉、乱看 |
| 时序 | 在信息到达后改变行为，完成后留下余波 | 从首帧就演出尚未知的结局 |
| 对手反应 | 对方依据实际看到或听到的信息回应 | 所有人同步理解并同步变脸 |
| 镜头 | 让相关手部、物件或面部确实可见 | 把关键手部藏在画外，却用手指变化传递转折 |

少写不是删掉必要因果。动作少但对象不明，同样可能僵硬；动作多也不必然夸张，要看是否承载同一事件、能否在正常速度完成。

## 原文自身的可复用与不一致

第一章两段完整提示词与前后关于“详细版”的说明有交错：标作第一组的正文反而包含更多表情。不能照标签建立优劣样本，应该比较实际文本。组合案例的回顾又提及拧瓶盖，而所展示的主要提示没有明确该动作。迁移时以选定的单一动作版本为准，不把分析文字中的新动作补进生成。

这两处说明了 Milimili 的审核重点：创作分析、镜头规格与最终请求须核对同一份行为。分镜里没有的动作，不能在总结段悄悄出现；反过来，必要动作也不能在编译时被丢掉。

## 原创写法演示

假设原剧本已包含“编辑把录用邮件转给同事，仍在校对稿件”的情节：她确认邮件标题后，手中的校对动作停在当前句，目光在同事脸上短暂停留；随后继续核对原句，字迹和身体节奏恢复。若剧本设定她愿意分享喜悦，可以直接笑；若已有不愿打断会议的目标，才安排压住笑意。不能单为增加层次编造隐瞒。

## 如何判断真正改善

先检查事件、知情、主要动作与镜头是否完整，再看反应幅度。未按顺序做事是执行问题；动作全对却像面向观众展示情绪，是表演组织问题；动作看不到则先调整覆盖。保留前版，只改一项主要问题。声音触发涉及对白时，必须对照实际语句和发声区间。
