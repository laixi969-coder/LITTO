# 2647 明暗、冷暖与虚实（正文及图片核对）

来源：[教程](https://www.super-i.cn/info-2647.html)，作者 Loki，页面显示8个月前。正文及17张独立内容图已看，无视频。

## 可用方法

情绪意图可以具体化为场景可信光源、方向、覆盖、软硬与明暗关系；色彩写明光来自哪里、作用区域、主辅关系和物体材质响应；焦点写焦平面与前后景层次、景别、主体距离与动态。三类条件要服从剧情、场景、参考和摄影机，而不是一律以形容词或相机品牌代替。窗光人像可说明窗在画左、柔光落在面侧、背部逐渐暗、暖色灯只落在桌面；需要眼神/动作时不能把主体虚到看不清。视线和焦点转移要有因果，动态模糊和失焦是不同机制。

## 纠错与证据边界

作者声称“dark vibe使所有RGB降低30%”“模型被迫关闭全局照明”“关键词触发电影打光引擎”“权重被规训”“90%/99%人出错”等未给依据，不能作模型机制或定量结论。情绪词可以是创作意图的一部分，明确可见光线描述帮助表达，但不是一律无效。强反差、死黑、单光源或青橙比例不是电影感必需：自然光、柔光、深景深和均衡配色同样可服务戏剧。把明暗对照直接等同伦勃朗光并不严谨；后者是特定人像布光方式，前者是宽泛的明暗对照。

景深由焦距、光圈、主体距离、成像格式和呈现尺寸共同影响；镜头焦段不是景深唯一决定因素。透视的近大远小与焦外模糊是不同现象，深景深画面不必然是监控风或无情绪；人眼看向目标时背景不一定必须模糊，注意力也不等于物理失焦。教程反例把“全部锐利”显式写入提示，正例换取景、镜头、空间内容与光，因此不是单变量实验。

网页将同一 rain street 文件用于全清晰反例及环境清晰/主体动态模糊正例的描述，需核实际图片是否相同；截图和示意图的标签、提示和展示可能有不对应，不能先按文案推断结果。Milimili 的 realism、lighting、camera 和已研究2899/2603布光知识可表达这些关系，需检查编译及参考职责，暂不新增通用固定滤镜。
