# 3097｜电影构图参考与自有角色场景

来源：[【AI影视】没有镜头思路？借电影构图，用自己的角色生成电影感画面](https://www.super-i.cn/info-3097.html)，作者 Lotus，页面显示约 3 周前。正文全文已读；人物板、场景、参考电影图及结果图待逐一核对。本课主要是静态图，不把图像写成动态镜头生成。

## 素材职责与提示词

先准备角色和环境，再明确当前镜头中的人、位置、行为、时间；按地点与动作寻找参考，重点拆解景别、机位、人物大小与裁切、前景遮挡、留白、前后层次及方向光。作者让视觉模型将参考镜头的拍摄结构、自有角色形貌/服装、自有空间与本次事件分别翻译成提示词：构图图负责构图，人物图负责身份和衣装，场景图负责场所特征，剧情要求负责动作与时天气氛，实际上传顺序必须与编号一致。

尤其有价值的是**优先级分离**：电影图即使是白天，若用户场景规定雨夜，不能直接照搬白天，需用夜间有来源的灯光重建近似的明暗关系。镜头可尝试不同视点，人物与门窗、桌椅按画面尺度协调，不能把“高挑”简单等同放大整个人。生成后比对人像占比、遮挡、留白、时间天气、空间尺度，而非只判断色调。

## 边界和冲突

单张场景图没有展示的背后/侧向空间是未知信息，“可从任意角度重建”只是创作目标，并不意味着能保持真实空间几何；固定地标、光源、窗门和动线须多视角资产或后续核验。参考中的构图也可能与原场地几何、叙事动作冲突，按用户明确要求优先解决。作者默认21:9仅是案例参数，不是所有项目强制画幅；参考影片或照片须按实际授权条件使用。

正文建议从所选视点重拍而不沿用场景原机位，不能把“不沿用原机位”当永恒规则：合适时原机位可以继续用，且换机位不能损害场景连续。示例提示写左上方台灯、后窗街灯，但又说“仅靠”台灯造成语义冲突，需分清可见光源、主光、辅光与色彩，不把描述当成严谨灯光图。正文将所用图片模型名称写成 seedance5.0pro，名称可能笔误，需核对页面截图而非自行纠正。

## Milimili 对照

已有构图、场景、人物和摄影字段/参考角色；在既有编译及容量限制内绑定图像角色，核查真实发送的编号、能力和降级。场景投影、构图参考与角色参考分别承担职责，不能把单张场景硬编码为三维几何、自动改变镜头时间天气，或仅凭提示宣称角色/空间一致。下一步看图片中的真实角色、参考与三张输出，区分原图、分析截图和生成图；带令牌的工作流链接不复制或访问。

## 图片核对

18 张引用包含目录图标和 3 个工具标识，14 张内容图已查看，无视频。两张开头超宽拼图分别是两幅场景并排，另有两个四格人物板、报社及茶室母图、检索界面、电影参考、分析界面和三张最终图；不是四条视频。角色板是正侧脸、裁头正装及背面，女记者戴帽和眼镜，男线人有正侧脸与正背服装。

电影参考是低机位仰看持纸男性及亮窗，结果报社图改为女性、夜间窗景和暖灯，同时保留低视角、桌面遮挡、纸张和人物/窗户层次；但原参考人物偏画面右侧、结果女主偏左且镜头结构并非逐项复制，正好说明“借拍法”不等于精确重放。茶室结果包含窗外取景、玻璃框遮挡和较大环境留白；交谈图有中景两人及左前景模糊人物。相较环境母图，新视角出现更多窗与内景，不能凭生成图证明原空间拓扑准确。人物比例和佩饰是否跨全部图精确一致需要原尺寸逐项验收。

生成界面的可见模型标签是 **Seedream 5.0 Pro**，正文所写 seedance5.0pro 与截图不一致；只记录实际截图，不推断其余节点所用模型。三张缩略图在界面上叠放，截图无清晰可见编号，不能仅按屏幕左右叠放次序断定实际请求顺序或已经正确绑定。没有动态视频、声音或生成控制实验。
