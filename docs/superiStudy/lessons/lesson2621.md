# 2621 环境决定真实（正文及图片核对）

来源：[教程](https://www.super-i.cn/info-2621.html)，作者西瓜，页面显示9个月前。正文及19张内容图已看，无视频。

## 空间、接触与因果

镜头设计可按前景遮挡、中景主体及接触、背景地形或空间边界说明观察路径；可见的支撑、受力及结果比罗列名词更容易构成可信场景。例：窗与叶片之间的遮挡让局部影子落在脸和沙发上，脚踩软泥产生下陷，雨水改变可见反射，锈迹从潮湿接缝沿重力流向下方，水平表面积尘多于经常接触的区域。光源位置、投射物和受光面必须同时合理，不是只加“阴影”“反射”。

天气是持续状态，要选择能由此天气产生的可见效应：风向/强度与发丝、衣服的运动一致；雨后道路湿度和积水反射与已有光源一致，衣物是否湿由时间和遮蔽决定。近中远层次与适合镜头的景深、环境遮挡一起设计，不是每镜都添加虚化叶片、镜头雨滴、薄雾或电影颗粒；过曝、色差、运动模糊需要具体成像原因和叙事目的，并非真实感必需。情绪同样不能简单由天气或光决定。

## 边界

正文声称动词会激活“物理模拟层”、模型能完美复原材质、简单名词必然导致背景平面/模型自动补光，是缺少验证的机制推断。体积光需要介质和光源条件，称为丁达尔是常见概括但并不等于所有体积光；次表面散射不是只有逆光可见。原文单光例又附加轮廓光，需核是否同一光源导致轮廓或实为额外光源。完整故事资产应维持合理空间位置和事件发生后的状态，不要因营造质感擅加雨、污渍与破损。

Milimili既有 realism.world/surface/imaging、lighting、blocking、interactions及场景资产；检查这些字段是否真正送入目标模型、环境变化是否跨镜继承，未实际生成就不说画面已达到要求。静图不能证明其提示必然产生所展示结果。


## 示例图核对

网页另有1个工具图标及19张内容图，包含景别/景深、空间示意、人物环境、灯光材质与天气；图中示意不是模型内部机制证据。中景例的文字要求靴子陷入深泥、手扶苔石，图上靴子落在苔藓岩石表面、手接触石头，靴子表面沾泥但看不见明显陷入深泥；不能据此证明模型完成重量下陷。

窗前植物与人物沙发图可见面部与座面斑驳光影，图片能说明关系设计意图，但无法仅凭静图确认遮挡物、准确光源和因果模拟。雨水/油膜图可见地面水坑、招牌映像与彩色纹路，不能据此证明动态雨滴与波纹同步或油膜物理计算正确。锈迹对比实际对象为阀门，不是正文机器人；图中后者有沿接缝向下的锈痕和顶面积尘，只可当视觉示意。

单侧强光人像示例左右轮廓均有亮边，画面左侧还有高亮光源；仅凭图片不能数出独立灯的数量，更不应称文字已验证单光与额外轮廓光如何兼容。风暴示例可见湿衣、翻折雨伞与雨天环境，静图不足以核对风向动态、受力或雨声。
