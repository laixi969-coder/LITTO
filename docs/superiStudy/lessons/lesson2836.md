# 2836 从角色创建到电影镜头（正文及素材抽样）

来源：[教程](https://www.super-i.cn/info-2836.html)，作者西瓜，页面显示5个月前。正文、10张内容图、5条生成片及5条参考片共95帧已核，音轨未试听。

## 方法

先固定主角身份和当前服装，再为具体镜头选择能服务情节和空间运动的环境；可将共同色彩和光源统一，同时按空间保留合理差异。参考影片时，拆镜头起点、被跟随对象、信息何时被揭示、相机路径、焦距与景别变化、结束状态，再结合自己的故事、人物和空间设计执行，不把导演名字当作技术参数。

五个具体意图：1 站台发现被监视，用推轨与反向变焦、人物大小近似不变的视觉效果表现空间拉伸；2 车辆停稳、开门、靴子受力落地、人物下车，然后低位上升环绕；3 固定机位由窄视角变宽揭示整个监控商场，人物画中变小；4 跟随路人穿过街区，再转向原先已在阴影里的主角；5 后备箱内仰视，盖打开→观察→取物→盖关闭至黑。场景前景、车门/雨伞、出入路径和物件应在空间中真实可通行，必要时拆段。

## 局限与矛盾

变焦/推轨耦合与单纯变短焦拉大全景是两种不同操作，不可把库布里克广义归结为任一镜头或将名字作为硬性模板。所谓人物保持相同画面大小需要视线、运动和焦距协调；视频是否实际做到待看，不能凭提示词认定。叙事跟拍提示先让路人向左离开，又写顺其视线与移动方向向右平移，需明确视线与机位相对关系；人物既在阴影里、又要求后揭示，须处理遮挡。后备箱要求“无声感台词”但又说出台词，是否要声应明确。镜头6秒多段需实际验证可用容量。评论提到雨伞穿帮，尚未独立确认。

本篇有五条参考电影片段与五个生成结果（播放重复待清点），应逐个对照，区分参考、创作提示和实际结果，未看前不承诺光学精准、一镜到底或稳定复刻。
