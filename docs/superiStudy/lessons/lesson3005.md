# 3005｜声音设计：以最终剪辑为依据，分清规划与混音

来源：[让AI自动完成一条视频的声音设计](https://www.super-i.cn/info-3005.html)。作者 Loki，页面显示“2个月前”。2026-10-26 全文四节、分析与生成提示词已读；未试听示例，因此不判断音乐或音效质量。

## 作者方法的独立摘要

先根据已剪视频整理情绪和节奏，再把观察转成音乐的力度、密度与收束要求；对现场声音判断保留、补充或强化，分别规划可独立调整的声音层，再回剪辑中试听。文中也承认生成音乐未必精确跟随时间，需要后续编辑。

## 为什么必须使用实际剪辑时间

分镜计划的落地时间，不一定等于最终使用片段的事件时间。镜头裁掉头部、改变排列或速度后，按原始秒数添加声音会错位。声音表应绑定当前剪辑版本、实际素材、源入点与事件位置；修改切点后需要复核相关声音，而不是只移动一份脱离素材的文字清单。

Milimili 现有 `EClip` 包含 start、in、speed、duration。普通事件的时间换算可理解为：成片位置 = 片段 start +（事件源时间 − in）÷ speed；事件必须仍在采用区间内。对白与原曲还受原速和完整性规则约束，不能用此公式暗中加速解决容量。

## 应区分的声音层

| 声音层 | 设计问题 | 原创示例与检查 |
| --- | --- | --- |
| 对白与演唱 | 谁发声、是否画内、原句和窗口 | 先让听者收到信息再反应，核对真实录音与可见嘴部 |
| 环境与空间 | 场地、远近、连续底声 | 连续室内场景切镜后，底声不无因归零或换空间 |
| 动作拟音 | 什么材质在何时接触、作用多大 | 同一木盒扣合时，扣件瞬态与箱体尾音各有来源 |
| 设计音效 | 哪个主观或非现实变化需强化 | 由影片既定风格决定，不能每次推镜都加扫过声 |
| 音乐 | 段落如何支持信息与情绪 | 关键台词出现时是否需要减弱，结尾是否有完整收束 |

作者的音效分类方便规划，但氛围底声与音乐性铺底容易交叉。保存时以实际用途决定所在轨道，不因叫 Drone 就自动追加一层低频。

## 提示词必须完成的转换

分析画面阶段保存事件证据、时间和声音来源；给音乐模型时转成音乐本身的变化，而非复述人物走了几步；给音效模型时写对象、材质、力度、空间及起落。生成的独立文件还需导入和排轨，文本中出现时间不等于音轨已定位。

原创独立音效提案：一个小型硬壳盒的金属搭扣在安静室内扣合，近距离、一次清楚的短促扣响，随后保留很短的箱体共振。该句不指定绝对成片时点，生成后裁取有效起点，再按真实扣合帧放置；若已有可用原声，则直接复用。

## 逐条生成的价值与成本边界

单独素材便于调时间、增益和淡出，不意味着每一个脚步或衣料声都必须重新调用模型。已有录音、可用原声或适配的素材优先；只有需要独立调整且当前缺失的关键层才补。生成 3–5 秒而实际只用短瞬态是素材余量选择，不是每个音效的固定长度。

音乐与音效的生成次数受任务范围和预算约束。课程中的工具名称、免费额度不作为当前可用能力或价格依据，实际执行前查真实模型和接口。

## Milimili 已有实现与明确边界

- `cloud/src/domain/nle.ts` 已有 dialogue、music、sfx 轨道角色，片段增益、淡入淡出、源入点、声画关联及 duck；可以承载独立层与对白让位。
- 同文件现有 Track/EClip 类型中未见声像字段。不能因为教程建议左右移动，就宣称系统已经能关键帧控制声像；真要实现须另核对渲染链或后期工具，本轮不新增功能。
- `cloud/src/domain/music.ts` 已检查原曲音轨的源位置、原速及覆盖。MV 要沿用原曲，不能按本页流程默认重新作一首背景音乐。
- `packages/skills/workflow/references/generationParams.md` 已要求后配音使用真实剪辑、实测句长与专用口型流程；此教程的音效设计不能替代对白容量和口型验收。
- `cloud/src/domain/nle-render.ts` 是实际混音输出链路。领域对象或剪辑表建立成功，只证明已安排，不证明可听质量。

## 完成标准

最终看听要同时检查事件同步、材质与力度、空间连续、对白可懂度、音乐遮蔽和片尾截断；不能只看波形、总时长或峰值便宣称声音自然。没有实际试听时明确保留“规划完成、效果未验收”。
