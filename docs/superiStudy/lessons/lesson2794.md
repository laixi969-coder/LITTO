# 2794 视频提示词优化三法（正文及素材抽样）

来源：[教程](https://www.super-i.cn/info-2794.html)，作者西瓜，页面显示6个月前。正文已完整阅读；5张内容图及8条独立视频75帧已核。用户评论指出时间线正例与内容可能不符、固定机位末段可能环绕，属于反馈而非已验证事实。

## 方法与边界

图生视频先考虑输入图的实际造型、构图与光照，让提示描述本镜所需改变：主体、身体、环境和摄像机在何时发生什么；过于笼统的“8K、顶级、质感”不如明确可见效果。强风可写发丝、衣角与雪的可见反馈，并根据景别挑看得见的动作。若需要明确换光、变景或摄像机运动，应明确条件、动作、参考职责与发生过程，不能一律删除视觉方向。

检查同一时间、同一对象、同一维度的要求是否互相排斥，如要求静止镜位同时又绕同一主体运动；“手持”描述稳定度而推轨描述机位路径，并非天然矛盾，但强烈抖动与极其平滑可存在风格或执行张力，应注明哪部分平滑、何时抖动。距离与速度可用画内参照辅助，但米、秒、焦距等数值对规划和承接仍有价值，是否精确遵循应看模型和测试。

雪信反例要求纸飞、起身追赶、360度环绕；正例则改成固定机位、纸受风移动及低头抬头，实质同时删除追赶和环绕，因此不是保留相同任务的公平对照，也不能证明分时间一定更好。其所谓数值效果分析中，正文说正例有迈步脚印，但给出的正例未写迈步或脚印。采用时间线时保持用户意图，写事件的因果、持物/位置、可并行动作与合理耗时，复杂动作超负荷时拆镜或具体调度，而非一秒只允许一件事或默认静态机位。

作者关于90%无效、首帧绝对决定所有内容、视觉词浪费80%算力、词语被强制屏蔽、分秒把算力专门分配给单个元素等机制与数字，没有给实验或模型文档；是作者解释，不是已证事实。普通参考图不一定等于真正首帧。模型、任务、随机种子和参数未完整交代，短示例不能证明普遍规则。Milimili已有唯一执行时间线与冲突复核，参照其实际编译和提供商能力而非新增教条。


## 图和案例核对

网页另有3个工具图标、5张内容图：示意图、雪地原图、20种运镜表、窗边读书、雪地信纸。8条视频文件哈希不同，5秒至8秒，合计抽取75帧；未听声音、未逐帧实时观看。

- 风格词冲突反例抽帧保留蓝雪风格，同时确实完成转身一圈并回看，不能认定动作被风格文字拖垮。正例一开始为侧身、再转向镜头，和原图正面站立的状态不同，不能仅据此证明真首帧稳定；未给生成请求和设置。
- 数值反例抽帧中风吹动头发、背景与人物大小变化，人物下半身未入画，无法测行走距离。视觉参照正例可见发丝运动及口前白雾，不能由此证明执行了指定风级、雪量或精确距离。
- 读书反例抽帧人物从中景变近景且书页位置改变；正例只抽到2帧，均为坐着翻页附近，不能证明全时段绝对固定。
- 雪地正例（第8条）开头抽帧只见信纸，后面人物蹲起并站立，人物与山线相对构图明显改变，后段出现近似绕人角度变化；与提示要求开头蹲姿、全程固定机位及后段保持蹲姿抬头存在可见差异。评论对内容不符的质疑因此有对应画面，但离散帧不能精确测量镜头轨迹或完整角度。反例（第7条）也可见纸飞、人物起身，后期大幅拉远；是否达到追逐或完整360度须全程观看。正反例任务本身不同，不能比较某一技巧单独带来的收益。
