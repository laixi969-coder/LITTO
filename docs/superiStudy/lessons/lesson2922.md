# 2922｜三种动作戏提示词

来源：[【AI打斗】只用角色资产！3套Seedance 2.0打斗提示词](https://www.super-i.cn/info-2922.html)，作者 Lotus，页面显示约 4 个月前。正文已完整阅读；11张独立内容图及3条独立视频共79张抽帧已核，音轨未试听。文章提供角色/机甲/巨兽资产提示，以及教室、雨巷、海面奇幻战斗三套视频提示。

## 可迁移方法

先确定各参与者、外观衣装和起始持物；动作按阶段写清行动者/目标、进攻方向、接触与受力、对手反应、支撑点、空间位移、道具状态、摄影可见性与环境后果。教室利用桌椅、纸张及粉笔灰建立碰撞后的变化；雨巷区分人物、持刀与棍、积水/墙/镜头关系；海战通过不同体量、速度及相对尺度组织接近、回避、蓄力、突击与余波。环境反馈须由触碰、落脚、碰撞或已有天气条件产生；不能每次出拳自动生成水花、碎屑或烟雾。

人物板把造型图用于服装、发型和比例、脸模图用于面部，是清楚的参考职责示例；正文的板仍是正侧脸、裁头正面服装、背面，并不等于完整四角度身体。所谓“只要一张人物资产即可”省去了场景和敌手的外部参考，生成器仍得自行构造空间与对手；会更难确保可追踪的站位、因果和接戏，需看成片而非当作保证。摄像机与人物路径需要和事件时间一致，避免只写“镜头跟着”。

## 提示中的具体矛盾

- 雨巷开头禁止突然出现额外武器，但中段脚挑起甩棍、末段又捡战刀后重新说握棍；若需要两种武器，应写清来源、哪只手、何时放下与接管。末段松手起身重复，且双手同时控制肩颈和挣扎手臂的接触分配不清。5 秒内含翻倒、压制、数秒挣扎、昏迷、松手、捡刀、起身离开，执行负荷明显过高，应按镜头预算删减或分段。
- 教室最后写取下挂绳、扔下、转身离去、物件落稳、全场寂静并淡黑都放在1秒，动作结果与时间容量需要重排；前文又要求衣装挂绳全程不变，末尾取下是有意状态变化，应在事件之后更新而非绝对锁定。
- 海战以五个不同镜头组织，与教室/雨巷“一镜到底”是不同方法。固定一个场景并标时间并不保证真正连续、切镜、动作接触或精确慢动作都被执行。不同体积的运动速度也不能仅用‘大必慢、小必快’概括；依设计、质量、尺度与推进决定视觉。

作者“每段仅一组动作、避免模型同时处理全部指令”的机制解释未有对照证据，实际文本单段含多个复杂动作；时间、因果和环境约束是可测试的设计意图，并非物理引擎证明。纯音效/无音乐是提示请求，音轨是否存在、是否与接触同步须试听。

## Milimili 对照与待核

复用已有角色/服装/道具版本、`performance`、`interactions`、主体与摄影机路径以及唯一 `camera.design.timeline`；确认对手身份、持物交接、已破损状态及画面可见证据。已研究 3113 打斗技能制作流程，可比较场面设计和修改回路，但不能把一个长模板变成必用规则或承诺安全/物理精准。不访问带令牌工作流或照做其绕审核建议。
