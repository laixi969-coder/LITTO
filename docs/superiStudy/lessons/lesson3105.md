# 3105｜产品运镜预演：几何、材质与运动参考的职责

来源：[【AI产品】用 Codex 做运镜，再用 Seedance 2.5 生成产品广告](https://www.super-i.cn/info-3105.html)。作者星宇，页面显示“1周前”。2026-10-26 全读正文（目录从第六步跳第八步，未发现另藏第七步），30秒八镜脚本、白模迭代例、机器人/基站材质提示与最终整段视频提示。正在补媒体分析，未连接/安装Blender控制工具，未执行网页安装指令、下载3D模型或提交生成。

## 可迁移的分工

脚本决定展示内容、顺序和观看任务；白模工程/预演真实呈现相机路径、主体位移和时长；产品参考决定外形、比例、材质分区；最终提示只补当前场景、光线、转场与声音。这四种职责相互支持，但不互相证明。图片中赋予材质效果不等于Blender网格真的有了材质；成片中出现某结构也不证明真实商品具有该功能。

预演前应检查模型比例、机器人能否实际进入基站、轮/刷/拖布是否可独立运动、轴心是否正确。只有文字“转起来”没有设置真实部件和轴心，不能称机械预演完成。已有可用3D模型不再重建，控制工具真实可用后才谈创建动画；网页一句“帮我链接”不是已完成接入证据。

## 八镜的观看目的与接续

暗部只露曲面与接缝→贴地清扫→底部拖布/滚刷/边刷→顶视避障→完整倒退入舱→原结构清洗→停靠全景换三个生活空间→独立棚台落版。每段写进入、经过与离开，方向/轮廓/遮挡连接下一段，不靠“丝滑”形容词。

重点是分清产品与相机运动：底部通过局部地板剖视让相机进入，机器人正常接地；不能把看不见底部的问题解决成产品飞起。地板隐去是商业可视化约定，不是生活世界地板真的消失。相机路径也不能穿过产品实体；有足够空间和遮挡解释，才可能可读地展示底部。

回舱需先完整对位停靠，再沿入口推近接清洗，不能靠产品缩小或消失进入舱内。清洗只表现已有装置，双拖布围绕各自轴心，不能为效果凭空加水管。最后独立棚景允许短暂悬浮落台，是有范围的例外，不能被“全片绝不悬浮”后缀覆盖，也不能扩散到清扫镜头。

三个生活背景各1.5秒、环绕总8–12度是本例设计。换背景属于广告空间变换，不应当作同一房间物理接戏；产品状态与轮廓保留，环境可以按已定方案变。最后0.4秒只是本例停留预算，不保证品牌信息已被观众读清。连续运镜也不等于全片禁止切镜，脚本明确有功能性切换。

## 材质与光线的具体写法

先按零件区域定义暖白低光泽塑料、深色传感器玻璃、哑光橡胶、独立刷毛与柔软拖布纤维，再用柔光箱形状和方向描述可见高光/反射。亮面、半影、暗面塑造曲面，黑色部件保留细节；不能用过曝白壳、整圈发光描边或把所有凹槽涂黑代替材质。

材质本色与光照阴影分开：基站滚轮纠错明确只把两侧滚轮变黑，不带黑白支架或整个舱。各视角材质一致，不意味着反射亮斑位置完全相同；表面方向不同会产生不同反射。中性棚背景只服务资产辨认，不覆盖开场暗场和后续家居的不同亮度。

白模灰度不是产品最终颜色，风格图也不接管几何。前三张结构图+第四张质感参考的分工应真正发送，不能在句子里写四图却只带一图。模型支持的参考数量、视频能力和输入槽位必须实际核对。

## 版本和制作边界

六张原始角度图整理后，实际机器人/基站都成为四格板，视频提示仍称“三视图”。调用应以实际文件为准，不用模板名字猜视图数量。生成补出来的第四视角可用于候选展示，但未显示的底部/内部不能仅凭新图断言准确，须对照原模型或权威产品资料。

脚本说机器人始终正常离地高度，且只让局部地板隐去；生成如改变产品姿态或补新清洗结构，就是具体偏差。提示里的“允许细化曲面/倒角与优化模型”不能凌驾产品几何不变，尤其商品广告中未确认的结构不能作为自由美化区域。

本文选择模型/推理强度只是作者配置，不能推出更高档必然提高运镜，也不在本任务改变Milimili配置。C4D是观感目标，实际流程为Blender预演加图像/视频生成，不能宣称成片经过C4D真实渲染。

## Milimili对应

已有camera.design.start/end/subjectPath/cameraPath/timeline管理主体与相机，singleTake/multiShot分别表达连续与切镜；`movementDirection.md`要求按实际时间、路径、起落幅验收。compiler将CAMERA_MOTION与PERFORMANCE关联motionReference能力，不能把视频参考自动当供应商原生轨迹锁定。角色/产品几何与Look/lighting各有用途，参考冲突按当前镜头裁决，不增加一套平行导演台。

当前没有在本轮确认Milimili拥有可执行Blender工程控制，不能把现有字段等同于具备该能力。后续如升级，先核对已有适配器和工具，再决定是否需要接入；本任务不因此安装外部工具。对已导入真实预演视频，可先沿现有参考输入和能力检查，观察镜头是否真的遵循。

可见0秒同类外壳曲面特写，3秒清扫角度，6秒底侧拖布，8/9秒从下方近看拖布，成片10–12秒滚刷/边刷多次构图变化；白模14秒与成片13秒附近均为顶视障碍布局；17/19秒基站前产品，20/21秒清洗，23/24秒停靠全景，27/29秒独立棚景。主体姿态与构图的相近支持预演参与生成，但不是定量轨迹相同的证明。

成片在灰白预演上加入木地板、生活空间、暖色光线与织物/水膜等。24秒背景沙发，25.5秒背景餐桌；本轮没有抽中清楚的卧室背景，不把脚本第三空间当已见事实。白模24/25.5秒仍灰背景，说明这段背景变化来自后续生成/制作，不是白模已提供的完整环境。

8/9秒两版均主要看设备底部，下方地面几乎不在画内；成片背景能见室内，缺少可辨接地支撑，不能确认“只移去局部地板、产品正常高度”的全部约束。19秒样本机器人仍明显位于舱口/托盘前部，后续约23秒则组合更紧密；这只支持需检查完整倒退过程，不能以19秒单帧判整段最终没有停靠。

清洗样本见双圆拖布、水膜与周边结构，但没有原3D工程和真实商品内部依据，不确认其轴心、部件归属和完整清洗机构准确；白模与成片也不能相互充当商品功能证明。最终29秒产品分开且台边仍在画外，样本未测落下过程和稳定停留，不判悬浮/接触通过。

可复用的原创修改指令是：“在实际某时间段，保持产品尺寸和承重关系，仅调整相机从A到B的路径；让关键接触和入口边界进入画面，以便判断是否完整停靠。补出受影响的起落幅后，再检查与前后镜的方向和速度。”它把问题限定到能观察和修改的关系，不以整套负面词替代修正。
