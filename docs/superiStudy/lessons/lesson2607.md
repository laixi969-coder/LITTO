# 2607｜UGC首尾帧接续：端点、持物、表演和声音一起检查

来源：[【电商美妆】这不是真人！AI生成的UGC视频已经进化到这个地步了？](https://www.super-i.cn/info-2607.html)。作者西瓜，页面显示“9个月前”。2026-10-26 全读工具准备及四步骤；已看A–E五张关键帧界面、剪辑界面，末尾39秒成片20张时序样本和8张近似接点样本。开头另一条视频未看，五段生成设置截图未逐一读，声音与完整动态未验收。没有调用付费模型。

## 工作流及其有效边界

先建立身份、当前造型、房间与摄影方式的基础图，再以图像编辑生成动作端点；A→B、B→C、C→D、D→E四段首尾帧，再用E作为第五段首帧，最后剪接。这是分段生成的连续长镜头效果，不能称一次生成的39秒一镜到底。共同端点降低了接点外观差异，但没有约束全部中间轨迹、速度、呼吸相位、声音、口型或身份细节。

端点应该包含本段真实可达的姿态、持物、人物距离和相机位置。先定动作链，再选能承接下一段的端点；不把每段起态重置为第一张惊讶脸。图片编辑时保存采用版，后续可以顺序编辑，但应与权威身份和原始场景比较，防止逐代漂移；前一张好看的候选也不自动成为最终资产。

## 图像实际内容比正文更完整

A为近距离捂嘴，B已靠桌前倾、手持半透明高瓶并指向瓶子，C手贴面颊且单眼眯起，D换成白色小瓶且捂嘴，E小瓶置于桌上、身体更近、手掌/指腹接触脸颊。五图保留红上衣、房间衣柜与置物架，但景别、可见下装、姿态和镜头距离均变化，不是固定机位像素相同。

B的实际输入含人物图和独立产品图；D的实际截图也含新产品图，提示词已写拿起精华并捂嘴。正文D却重复C的摸脸提示词，且正文把C、D、E部分标题都叫捂嘴。照抄正文会丢掉产品切换和正确动作，必须读实际输入。C正文称闭眼享受/涂抹，图中只是贴脸和单眼眯起，没有可见取液或涂抹过程，不能证明产品使用动作完成。

截图中的左右手还受自拍镜像语义影响，不能只凭画面左右判断解剖左右。当前采用版需要明确角色手、产品和屏幕位置，连镜核对；不能同时保留相互矛盾的手位文字。

## 真人观感怎样形成

近距离自拍构图、家中可辨生活物、自然受光、面部细微纹理、前倾/退让、触脸和看镜头共同建立博主交流情境。红衣、白肩带、白裤只是本例造型，法国口音与21岁只是本例声音/人物设定；不能移植给所有UGC或真人剧情。

“不完美越多越真实”不是通用规律。可见生活痕迹可成立，随机曝光抽动、噪点、模糊、过量脏污不必新增。此例全程反复瞪眼、大幅嘴形与兴奋语气属于夸张分享表演，也不能当自然表演的统一标准。真人感应服务人物当下交流对象与产品任务，而非每句话固定加眨眼、指脸和惊讶。

## 台词、产品与剪辑约束

作者每段都写“图1/图2”，这是段内上传槽位，不是全片A/B永久编号；实际绑定应明确本段首尾端点及供应商模式，不能用编号文字代替图片输入。首尾帧模式必须确认所选模型真实支持，不根据历史教程推定当前任意模型有同样能力。

原生声音的每段都重新要求兴奋、聊天和填充词，可能产生重复、语调/音色跳变或新增台词。已采用的原句需要保持；自然语气可用停顿和重音，不自动加词。产品功效台词只是案例文本，不能作为产品事实或真实使用证明移入新广告。实际使用方法、卖点与产品外形仍以用户提供的有效资料为准。

“剪掉1–2帧”仅适用于真实接点出现停滞且不伤对白/动作的情况。时长换算依帧率，不能机械每段删相同数量；也不能剪掉字音或关键接触来掩盖错误。位置一致仍可能速度不连续，面部一致也可能声音换人。当前没有试听，不宣称音色、语句和口型接续合格。

## Milimili真实链路

工具schema已有firstFrame/lastFrame及startEndRequired、endFrameOptional等模式。`cloud/src/workspaceMedia.ts`按模式声明startEndFrame能力，startEndRequired会要求实际END_FRAME；`apps/server/src/utils/media/jobs.ts`把已编译START_FRAME/END_FRAME转为真实请求firstFrame/lastFrame。应检查实际compiled.inputs的sent、角色和容量，不能只看提示词写了“首尾帧”。

`apps/server/src/routes/ai/media/generate.ts`的continueFrom仅在未传firstFrame时提取前视频接近结尾的画面为首帧；实现seek在duration−0.08秒，不能宣称精确最后一帧，也不包含速度与音频状态。显式首帧已存在时不会自动被continueFrom替换。对外解释应符合真实实现。

`state.ts`使用已采用take的observedStateDelta优先，帮助保存实际持物/状态；`coverage.md`、speechPlanning与nle继续承担真实声音窗口、可见嘴部和剪辑。已有这些入口，当前不新增接龙工具或重复Skill。

原创写法应描述本段真实起点、唯一动作和可达终点，例如“从已采用的桌前持瓶姿态接续，交流时保留产品可读；在既定台词结束后把瓶放到桌面，再靠近展示脸颊。摄影机保持在桌面支撑位置。”是否需要这一整链仍服从已定脚本与时长，不自动添加功效承诺或额外词句。
