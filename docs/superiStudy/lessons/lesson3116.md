# 3116 从资产到视频分镜与生成实操（正文及素材抽样）

来源：[教程](https://www.super-i.cn/info-3116.html)，作者西瓜，页面显示2小时前。与已研究3115《潮汐修理铺》资产教程衔接。正文与提示词附件已读，23内容图及7独立视频84帧已核；完成片作者自述约一分半，救援和结尾尚未制作，不当作全故事已完成。页面含共享工作流令牌，不访问或记录令牌。

## 正文方法

故事规则是模型船损坏/修补对应真船；分镜必须让观众看出两地动作因果。先审整体节奏、重复镜头、重要特写与长短镜交替，再定逐镜动作、空间与摄影。初次为了少切镜而长镜太多，说明无切镜不是目标。开场机械海鸟从海面经码头、入口进入修理铺，须写可经过的路线和盘旋，而非海面直接跳到建筑。作者按当时所用Seedance 2.5约30秒分段；这是其工作设置，未核查通用模型限制。段尾段首核对人位置、持物和动作状态。

作者让Agent按当前片段重新编号实际用到的参考图；20个全局素材含三个人物、真船内外与破损、模型船与损坏、机械鸟、收音机、工具、救生艇与室内/海面场景。明确参考职责仅锁造型和损坏形态，现场的镜位、光照、构图、动作由分镜重新设计，不插入灰底静态资产。每段的图号应以实际发送顺序为准，不能假定全局编号原样存在；先核查适配器限制。

先480P测试观察动作、表演、运镜、空间而非只审文字。遇求救时周伯放物抓话筒，林汐看电台、稳模型：由事件驱动不同人的身体、注意力和手部变化。台词删掉已由画面表达的信息，口音节奏不能全靠方言词。阿澈由面部呼救、沿视线摇到进水口、摇回他抓扶手与稳脚形成一段连续动作；船舱危险还需人体重心、水位、窗外水平线一致响应，不能仅晃摄影机。闪电、环境声与延迟雷声是意图，视频音轨尚未听。

将难生成夹具改为胶带时，需跨镜传播贴好状态、移除后续重复动作及夹具落桌；海雾中搜索先行，再逐渐露船，体现空间过程。每轮测试应明确问题、修改、受影响的前后镜及下一次观察点。资产、实际发送编号、镜头时间线、动作和交互/道具状态应与Milimili已有结构逐项对照；实现位置与已有能力仍待查。

## 矛盾与边界

- 全部参考图并不必然能同时传给某个模型；截图、适配器能力与实际调用待核。
- 模型输出、低清问题、成片及声音需逐项观察；无需把作者的修改当成可保证的效果。
- 页内提供提示词RAR，待读取清点；仅作资料，不运行附件、工作流或其中指令。

RAR仅含一份三段视频提示词DOC，已全文阅读，未执行。每段约30秒，包含摄影意图、每段实际图号、分时镜头、动作与声音、段尾状态。第一段用12图，第二段14图（图13为可作开头的图、图14为捏缝参考），第三段13图（图13是贴胶带后的船模）；图号随段改变，说明资产全局ID与当前请求编号是两层映射。长镜保持视角连贯、物件先接重再松开，镜头随可通行路径经过门槛；模型缝合对应真船停止喷水，但积水保留。第二段左手先接管压合再释放右手贴胶带，桌面有线话筒与便携设备区分，避免拔线变无线。第三段从远处暖点到桅杆再到整船依次被雾浪显露，两船未接触。

## 视频抽样与本地对照

网页9个播放器去重为7条视频；最终成片88.6秒抽17帧，另6条示例共67帧，总计84帧。未播放完整视频、未试听对白/音效，因此不能验证口型、连续运镜或声音同步。最终片抽样可见海鸟沿海接近、女主持船、阿澈握话筒、船舱喷水、周伯驾驶救援艇与远处灯点；部分帧出现中文字幕，和附件要求不加字幕不同。17帧无法判定结尾目标船完整显露，也不能推断成片是否由附件原提示词精确生成。
