# 2829｜画面结构拆解：观察、改编与真实执行分开

来源：[【提示词创作第五十二节】告别低效反推：掌握“画面结构拆解法”](https://www.super-i.cn/info-2829.html)。作者西瓜，页面显示“5个月前”。2026-10-26 全读五章与结语；另观察实际输入板、生成界面截图和15.1秒视频的12张时序样本。正文其余分析截图没有逐一读图，没有完整播放或试听。

## 方法真正解决的问题

只列人物、服装、地点与“电影级”词，未确定谁在何处、如何移动、摄影机如何观看、哪个事件先发生。结构拆解应先保留可观察的机位、景别、人物/道具关系、光源、遮挡与动作结果，再按真实切点或因果事件分段。切片的目的在于让信息可定位，不是强迫每秒换镜，也不是把每一帧改写成关节控制指令。

需要分开三类信息：源片可见事实、分析者推测、为了新作品增加的设计。没有真实视频、只有文字或单张截图时，不能推断其全部动作轨迹、精确时码、焦距、声源与后续镜头。作者允许文案/截图作为输入，但这最多能支持设计或局部分析，不能自动获得原片证据。

## 时间线不等于物理可靠性

先按切点和事件阶段记录相对时间：起态、行动、接触/遮挡、结果。主体路径与摄影机路径分别写；固定机位也成立。精确到小数的时码应有实际媒体依据，且不保证生成模型按小数秒完成动作。教程的分段示例包含推镜、拉远、转身、走远等，需要核对是否连续镜头、如何衔接以及当前生成时长，不能原样成为每个5秒镜头的配额。

接触只写真实发生的事件。衣服摆动、脚底支撑、水花扩散可用可见结果约束；不能因为模板要求环境互动就新增动作、道具或物理特效。光向须明确世界/画面坐标，反打不能让太阳在世界里换边。

## 正文与实际生成界面并非同一稿

正文列12个编号段落，终点37.5秒；其中多个“镜号”内部又写切镜，例如枪械特写切腰部、远景切顶视、脚特写再切跳跃。这些编号不能直接当成12个单一摄影镜头。固定宽银幕、35/50mm、浅景深与青橙色只属于本例风格，不是结构分析的通用前缀；没有画幅/真实参数，不能宣称器材测量。

实际生成界面播放器显示15秒，输入三图分别为人物、环境、武器。可读文本中第1段改为0–2秒，第2段改为2–5秒，并加了画外枪击导致女性入水；正文对应段落则为2–4.5秒步行、另段4.5–5.7秒入水。至少可确定执行稿与正文示范稿发生改写，不能把结果归因于37.5秒整稿逐字执行。

输入板真实可见：机器人正脸与三全身、枪械多角度/细节、海滨泳池豪宅。它同时提供身份、材质、造型与场景色光，并非只靠文字获得质感；附图不能证明所有角度的空间结构完整，也不意味着枪械板可自动约束持枪接触。

## 实际视频观察

- 0–3秒样本为低机位腿部近景，向泳池方向前行，背景建筑与地面杂物可见。
- 4–6秒背后女性中景向池边移动，8秒身体前倾入水、9秒水花；抽帧无法确认画外枪击的音画因果或受击细节。
- 10秒机器人向前持枪、另一手靠帽檐，11秒脸屏已呈绿色笑脸；13秒腰部枪套特写，14秒建筑航拍。

可见结果更接近正文前半部分的压缩/改写版本，没有覆盖37.5秒全稿。场景、反射与造型有连贯倾向，但这12帧不能确认枪械结构全程、脚步接地、入水中间形变、枪声或音乐同步。正文开头“一比一复刻”与末尾“原作者精心剪辑、全部还原不太可能”也存在承诺尺度差异，应采用后者的限制，不把方法包装成复现保证。

## 可复用的原创分析写法

“先记录能直接看见的切点、主体位置、动作起止与结果；把不确定的受力原因、器材参数和画外信息标为待核对。分开描述人物路径和摄影机路径。随后根据新作品已采用的身份、场景与实际时长改编，保留关键动作因果，删去源片专属品牌与无关风格词。”

生成稿复用Milimili现有五块，不增加第三套分析/执行时间线。分析表是证据与设计资料；执行时间线只保留当前采用版，不能同时塞入源片稿、压缩稿与修订稿。

## Milimili 对照

`cinema/references/shotLanguage.md`已有镜头职责、距离/焦段、调度与光源方法，`referenceQuality.md`已明确camera.design.timeline或musicVideo.timeline为唯一执行时间线，combat通过timelineIndex关联；`coverage.md`按真实声音与观看关系安排覆盖。应核对这些知识实际是否进入当前任务，而不是再装一份“超级提示词”。

camera的position/height/angle/shotSize及design路径承接空间与动作；lighting.worldSource与directionSpace承接光源语义；interactions承接真实接触。compiler仍须核对真实引用职责、容量、发送顺序与首帧，不把截图中的1/2/3自动套入本地请求。

验收要比较当前采用稿与真实视频，同一时长/版本下检查动作完成和空间关系。不能拿源片分析表直接给重写后的短段打分，也不能用生成成功或静帧风格接近证明动作因果正确。
