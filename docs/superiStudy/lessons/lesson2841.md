## 共用原则与四种方法

共用目标是给多个镜头同一空间依据，避免每镜重新想象。环境图约束空间/材质/光源，人物图约束身份/妆造，当前镜头决定机位/动作；不要让棚拍人物图白底或俯视构图进入剧情首帧。场景母版是采用的设计依据，不代表已有可碰撞三维场地。

1. **原地转向视频截帧**：由一张藏剑阁图生成15秒360度转头，截取门/桌案/书架/剑架/屏风，再放大修复当背景。这里“摄影机位置固定、摇360”是原地旋转看四周，不能误解成围绕房间中心移位的orbit；位置改变会产生视差。生成单图看不到的背面仍是补想象，需检查门窗/家具是否随转动消失重造以及回到原幅是否匹配。放大修复可能再造纹理/剑数，不是补回真实丢失信息。优点是候选角度快，代价是付费视频和后续截帧校验。
2. **俯视→九格**：先反推顶视空间，再以此换位置/角度生成平视候选，挑可用于剧情的单幅。适合用门窗/案桌/通道明确几何关系；单图反推不可见部分仍需采用确认。图像生成不同格可能各自改形，不能九格就叫已锁空间；同一底图/地标相对位置是验收点。
3. **场景图/九格/俯视+全能参考**：让角色与环境分别承担职责，可省去先把所有信息合成唯一首图。但模型数量/角色支持、图片顺序、引用内容与提示必须核对；仅全能参考按钮不能保证几何、角色、时间状态全被精确约束。参考越多也会冲突，先选本镜相关内容。
4. **全景生成/查看取景**：同一球面图旋转视角，便于找方向。720度是网站产品称呼，不能据此理解多绕一圈就新增空间或获得相机自由走位；同一观察点改朝向与移动到桌后是不同能力。球面展开图和正常透视视口分清：正确重投影先处理，不必所有截图都再用AI重绘。作者建议24–35mm观感、修垂线/边缘拉伸/清晰度且保内容；修复若生成新门窗、改桌长/剑架数量就应退回母版核，不能以“更漂亮”掩盖空间漂移。

四种可按当前信息和预算择其一，不机械叠加全做。至少先有能覆盖本镜的空间依据；只需正反打不一定先付费15秒环绕/全景，已有可靠相反角图可复用。

## 本例写法、状态和限制

人物为浅色古装年轻女与黑蓝袍男，藏剑阁夜内木结构、右圆窗、中央长案/剑匣、左书/剑架、后屏风门，蜡烛与月光。具体左右是原图屏幕方向，换机位仍须保持世界中原位置。人拿剑/鞘、古卷与剑匣开合属于当前状态，背景素材本身不决定后续人物站位与触碰。

人物稿有“手持长剑或背后”候选，衣色也列多色，正式采用时须收敛；不能把这些或选残留到最终镜头。灰尘/磨损/旧化和冷暖夜色来自本例历史室内风格，不推广到每个写实空间。器材名/柔光/胶片字样只帮助表达外观，不是已拍摄证明。

评论中“错误侧受损参考图反复垫会干扰新文字”的观察与现有参考职责原则相容，但无完整对照，先记待验证，不能把删参考当所有左右问题万能解。优先识别画面左右/角色自身左右/靠护栏等关系，采用正确资产或局部修正。
