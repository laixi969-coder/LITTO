# 一键自动成片

在项目上方点击「一键自动成片」，粘贴剧本或导入 UTF-8 TXT / MD，可选添加最多 20 张 PNG / JPEG / WebP 角色图，再点击「启动自动成片」。打开面板、进入项目和刷新页面都不会启动制作。

任务复用已配置的默认模型和现有制作工具，自动整理与采用剧本、登记参考、补齐资产、创建独立制作序列、规划声音和镜头、生成素材、选择候选、剪辑和正式导出。提供的角色图按实际内容登记到本项目媒体库，并保存输入快照。已有完整剧本保留剧情与对白，梗概由 AI 发展。项目中其他序列的镜头不会被本任务生成或重做。

故事、资产、音色、精度与剪辑选择由 AI 自主填写原有决定接口；任务保存选择及理由。自动授权只存在于这次任务的工具上下文。普通聊天、手动面板及其确认方式不变。剧本采用理由标记自动任务，制作选择事件标记 agent，不代填用户满意度。关键帧、镜头及成片继续走代理审阅和原有质量门禁。

视频审阅使用 `observeAutoFilmVideo` 把完整实际视频（含原音轨）交给「设置 / 管理后台 → 默认模型 → 视频审阅」选择的模型，再根据返回的真实观察完成代理检查。此选择独立于默认创作模型，留空时兼容原配置、跟随对话模型；不会自动选择其他供应商。创作模型可继续使用 DeepSeek 等模型调度制作，视频审阅连接须实际支持视频与声音输入。

「管理后台 → API 配置 → 视频审阅 API」可单独添加审阅连接的 Base URL、API Key、接口协议和模型列表；单机设置提供同名入口。复用现有供应商时直接在默认模型中选择，无需重复保存密钥。新增审阅专用连接标记 `purpose:videoReview`，不会出现在对话默认模型的候选列表；接口和密钥沿用现有供应商配置、掩码和加密流程。

每次启动或续跑先在内存中生成约六秒声画短片，通过实际视频输入核对随机画面顺序及随机朗读的三个数字。数字只进入音轨，不出现在画面或提示词中；逐字匹配，不能只凭自报“能听到声音”通过。内置数字语音为 CMU Flite `slt` 合成的 8kHz 单声道无符号 8 位 PCM，保存在 `reviewSpeech.json`，运行时由 FFmpeg 编成 AAC；运行环境无需安装语音合成器。纯音高低辨别不再作为对白理解的能力门槛。核验失败即保存具体原因并停止，不执行制作工具、不增加媒体生成次数。该检查会产生少量审阅模型用量，只核验接口读取能力，不代表正式镜头或对白已经验收。完整视频目前最多 100 MB，供应商也可能有更小的请求限制。正式素材仍须逐段真实观察，不以抽帧冒充完整看听；自动检查不保证模型不会漏判审美、身份或表演问题。

请求失败与声画能力检查分别报告。上游返回 403 时保留权限拒绝状态，提示检查 API Key 的模型权限、业务空间授权和 IP 限制，并明确声画能力尚未验证；不再把权限拒绝包装为 422 或建议更换声画模型。

阿里云 `qwen3.8-omni-flash` 使用 Chat Completions，可同时读取视频与原音轨；应用选择关闭思考时显式发送 `reasoning_effort:none`，包括业务空间专属域名，避免接口默认思考模式覆盖应用设置。`qwen3.8-omni-flash-realtime` 走实时会话协议，不能直接填入当前整段视频审阅的 Chat Completions 连接。

完整审阅的重试次数绑定当前媒体、镜头规格与审阅连接，修好连接或更换审阅模型后不会被旧失败次数锁死；已有有效观察继续复用。视频输入返回 422 不会停用仍可正常对话的模型。专用口型模型通过配音方案的 `lipSyncProviderId/lipSyncModelId` 独立绑定，不能替换默认视频生成模型；缺少原视频和已选配音的对应关系时返回具体绑定错误。

只有本任务序列正式导出成功、当前成片验收有效、完整声画观察有记录，并且采用剧本的全部场次已进入视频时间线，`completeAutoFilm` 才会记录完成。草稿、其他任务的成片、缺场次或无效检查不能交付为完成。

`selectModel` 收到专用口型模型时返回 `applied:false` 和 `configureVoice` 后续操作，不再把平台默认视频模型冒充为选择成功。口型通过配音方案独立绑定，生成使用 `purpose:standalone` 与已采用声音、人物原片；完整看听并完成 `inspectSpeech/importSpeech` 后，仍由 `reviewProduction` 采用。续跑重新注入当前执行规则，核对历史阻塞；无需放开人工 `approveTake` 或降低声画验收标准。

尚未登记为 Take 的口型结果也可完整观察，但必须来自本项目、本工作目录的成功视频任务，且仍匹配本任务镜头当前配音方案中的原片、声音候选、原句版本与口型模型。`importSpeech` 前核对实际文件哈希已有观察记录；导入后重新读取新候选的摄影清单，再观察和采用，旧的空清单不能代替逐镜检查。其他序列、未成功任务或失效声音不开放这条入口。

任务最多提交 120 次媒体生成，每个目标最多尝试 3 次（包含首次），每次运行最长 6 小时，最多 2000 次制作工具调用。失败后续跑沿用次数，不重置额度；次数是执行上限，不是金额报价，实际按已有模型服务计费。权限、模型、参考、声音及连续性检查仍生效。不会自动对外发布或修改跨项目角色库。

制作面板为非模态悬浮窗，可拖动标题栏，也可聚焦标题栏后用方向键移动（Shift 加速）。最小化后显示制作状态和生成次数，展开与最小化分别保留本次页面内的位置；窗口大小变化时自动限制在屏幕内。启动或续跑成功后自动最小化，展开时可操作其他画布区域，不锁定页面或键盘焦点。最小化、关闭面板或页面后后台继续运行；停止会取消本次 Agent 和正在等待的生成任务，已保存素材保留。服务重启后显示中断，只有点击「继续制作」才恢复。续跑复用独立对话记录、已存素材、序列和检查，媒体供应商已接单的结果仍按原任务核对，不盲目重新提交。

任务状态与自动决定保存在工作区私有数据目录的 `autoFilms/`，使用原子写入；输入和审阅快照在项目 `.agent/autoFilms/`，正式素材与可编辑时间线沿用现有制作系统。服务端提供 `/api/autoFilm/start`、`get`、`stop`、`resume`，同一项目最多运行一个自动任务，停止和续跑均校验任务 ID。

## 验证范围

### 叙事分镜与声画对应

自动任务在任何新媒体生成前先核对全剧分镜。`reviewAutoFilmStory` 从原始输入、当前采用剧本、角色资产与全部镜头读取数据；程序检查场次来源、逐场完整对白及顺序、说话人归属、发声窗口，独立文本检查核对原稿保真、事件因果、动作主体和对象、对白与反应调度、屏时及接戏。对白比较只忽略排版和标点，不用相似度放过删词。检查有缺项或未验证时先修规格，不能通过省场、改旁白或缩成预告继续生成。

分镜检查通过后，复用或采用真实角色录音，调用已有 `planSpeech` 实测并同步更新对白、动作及切点。镜头画面生成前还须通过现有声音容量与嘴部覆盖校验。检查结果按原稿、版本、资产和分镜内容缓存，制作状态更新不会使其失效；叙事相关内容变化后须重新核对。旧任务没有新检查记录时补检查，已有素材保留。

`observeAutoFilmVideo` 同时返回摄影观察与 `storyChecks`（叙事、表演、连续性、对白、口型、剪辑、声音）。逐句 `dialogueReviews` 保存实际转写、发声角色及时间；与系统映射到当前视频的对白窗口核对，不能漏句、重复或以总体评价代替。无声原片可进入视觉工作版，但不能当作对白已完成。口型导入、声画采用、成片代理验收和交付均核对当前观察，失败或不确定不能由制作助手改填通过。自动观察仍可能漏判，不构成艺术质量保证。

`readAutoFilmProgress` 从真实记录返回当前阶段、缺项和下一步。每轮继续制作时重新计算，不用模型文字总结判定完成；连续三轮没有工具操作时保留具体缺项并停止，仍遵守既有时间与生成预算。无需人工审核意味着系统继续自动检查与处理，不能把无声串片或草稿标记为完整交付。本次升级不迁移、重做或自动启动已有影片。

本次只读回放序列 `01M5SXZYTMXZV52Z369X6P9GXB` 的生产数据：14场、10镜，提前识别 s05/s07/s09/s11 未分镜，以及9个已覆盖场次的对白不完整对应。内联验证核对了删句、乱序、错角色、窗口越界、观察缺项、逐句转写与时间不符、旧检查拒绝、计划变化失效和真实阶段计算。视觉工作版、对白口型、整片混音分阶段校验，待补环境音不会阻断有效对白的导入，但会阻止整片交付。计划读取的集成验证使用内存替身，未调用真实生成或审阅模型；不代表模型创作质量已经端到端验收。未新增测试文件，也未修改这条片子的生产数据或视频。

升级后在原项目点击「继续制作」沿用原任务、序列、会话、素材及生成次数；兼容旧任务缺少试听记录字段。已有有效配音及同原句候选直接复用，不新增生成额度或计费记录；相同规格视频与资产沿用原持久化任务。以实际内存数据库核验了排队资产、成功资产和成功镜头的重复请求未创建新任务；配音重复调用未调用供应商。未完成的口型处理和确需补拍仍属于新生成，不等于续跑全程免费；须保留原数据库、私有任务数据及工作区文件。

自动链路补查：固定配音通过 `observeAutoFilmVoice` 交给已验证的声画模型完整试听（黑画面仅承载原声音，不登记为镜头），记录实际转写、结论与原句/文件指纹；未试听或不确定的候选不能由自动任务新采用。原片完成视觉检查并记录末态后，声音尚未核验时保留工作版，待口型结果完成才正式采用。整镜口型替换保留视频片段ID及其他声音关联，只移除已确认合入的同句独立对白；声音不一致则保留，撤销可恢复。自动推进不再受额外8轮上限限制，仍受6小时、2000次工具调用和生成次数限制。

本轮以模拟制作工具验证启动、自动剧本决定、专属序列、试听采用、连续10轮推进、成片观察及完成状态；未试听、不确定、跨序列、代填满意度、草稿、缺场次和未观察成片均拒绝。用实际SQLite验证原片工作版、重复审阅、定稿拒绝，以及声音替换、接点保留和撤销；用本地信号音核验试听输入发送、内容指纹和试听中修改失效。模型响应和导出状态为模拟，未调用真实视频生成或真实成片模型，不代表真实供应商服务及成片质量已验收。未新增测试文件。

口型通道补充验证：使用临时目录、实际 SQLite 数据库与 FFmpeg 生成的音视频，核验待登记结果观察、音轨匹配、候选导入、登记后摄影清单、代理采用与时间线同步、正式导出成功及 `inspectFinal`。跨序列、未成功任务与改词后的旧配音均被拒绝。审阅与口型生成任务记录为本地模拟，未调用付费模型；不代表真实人物口型质量或整个自动任务已经验收。底层专用口型输入仍为单句同长片段；多句、延迟发声和句间停顿由 syncSpeech 自动按原窗口裁片并合回整镜。该操作不改变镜头原句、总时长或剪辑速度，完整结果仍须实际看听。

多句链路补充验证：两名角色、三句声音（两句可见发声、一句画外音），首句延迟1.25秒并保留句间停顿。实际 FFmpeg 完成裁片、逐句合回、整镜声音、候选登记、代理采用、正式导出及 inspectFinal；核对8秒总时长、尺寸、发声窗口画面替换、非发声画面和原片间隙声音保留，逐句波形按原时间落位。模拟第二句已生成成功但响应丢失，续跑复用原任务，未重复提交或增加生成次数；缺句来源及改词后的旧声音被拒绝。口型供应商和审阅响应为本地模拟，未验证真实人物口型效果。整镜记录保存在私有 speechAssemblies/，逐句任务沿用持久化媒体队列；当前限制为正常速度的单视频片段、原片100MB以内、10分钟以内及最多40句，超限明确报错并保留原素材。

server、web、cloud 和工具脚手架类型检查通过；server 与 web 构建通过，前端仍有现有的 Vite 配置兼容性及大体积 chunk 提示。

使用临时数据目录、内存数据库、本地模拟模型和真实 HTTP 核验了显式启动、非法输入与路径、重复任务、过期任务 ID、停止续跑、自动风格与模型实际精度选择落盘、独立序列登记、虚假成片拒绝、默认模型选择不变、普通聊天仍等待人工回答、工作区隔离和只读权限。核验角色图片登记、输入快照不随源图变动，以及无活跃进程的运行记录显示中断而不自动恢复。用实际 FFmpeg 生成带测试音的短视频，核验完整视频输入的协议发送、媒体指纹和观察结果解析；模型观察响应为本地模拟数据。

浏览器实际检查了输入、显式启动、关闭后后台继续、重新打开、停止和恢复入口，并修正弹窗的窄屏宽度。未新增测试文件、调用付费模型或改动真实用户配置；这些验证不代表真实模型完整制作成片的质量已验证。
