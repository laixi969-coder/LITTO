# 最后一双 · A

修鞋铺门上的“明日起停业”被风吹得翻过来。林禾用透明胶压住纸角，胶带还没掐断，父亲在身后说：“留个口，玻璃要擦。”

她把整张纸揭了，擦玻璃。父亲又开始给桌上的黑皮鞋上油。鞋已经亮得能照见灯管，鞋口却有一道毛糙的补边。

“四点半来收桌子。”她说。

父亲嗯了一声，换了一块干布。

店里只剩这一双客鞋。号码牌是十七，取鞋单压在一罐鞋油底下，写着补鞋口，二十元。林禾把空纸箱推到父亲脚边。他把穿线针放进去了，又拿出来，插回桌沿的小软木块。

林禾去拆墙上的价目表。蓝色塑料板后面露出一块浅色墙皮，钉子弯着，怎么也拔不出。父亲让她拿钳子。她翻了三个抽屉，父亲手里的布停下来。

“右边第二格。”

“刚才不是都装箱了？”

他从围裙兜里掏出钳子，搁在桌边。

林禾没接，先看了他一眼。

老周来取鞋时，裤脚一边高一边低。他扶着门框换上黑皮鞋，在店里来回走了两趟。左脚落地，右脚拖过那块磨白的地砖。

“这儿还是刮。”他指着右鞋口。

父亲把鞋拿回来，用手指沿着补边摸了一圈，换一块更薄的衬片。林禾把已经打好的工具箱重新打开。

老周坐在矮凳上，穿袜子的右脚踩着自己的塑料袋。他想把袋口压平，脚掌一动，袋子便哗啦一声。

“以后上哪儿找你？”他问。

“不修了。”林禾说。

父亲低着头，剪下一小截多余的线。

第二次试鞋，老周仍说刮。父亲弯下身，要替他把鞋跟提正，林禾先蹲了下去。她将右脚袜口往下翻，脚后跟露出一道旧红印；袜子接缝正压在红印上。

她把袜子脱下来，翻到正面，再递给老周。

老周接着，没立即穿。他把袜尖展开，找那条缝。

“早晨急了。”他说。

墙上的钟快四点了。

这回老周走到门边，又回来，从裤兜里掏出二十元。父亲把钱压在鞋油罐底下，找出一只旧鞋袋。老周摆摆手，拎起自己的袋子，把换下的布鞋塞进去。

“我走着穿。”

他跨过门槛。父亲站起来，向外看。老周已经转过墙角，只剩塑料袋的响声，过了一会儿也没有了。

林禾重新把针收进工具箱。父亲没有再拿出来。

她蹲下贴箱底，胶带又粘住了手指。父亲把钳子放进去，盖子合上时碰到钳柄，没合严。

“换个方向。”林禾说。

父亲转了半圈，盖上。

林禾去锁后窗。父亲从鞋油罐下抽出那二十元，展开，抹平，放进围裙兜。他把围裙解下来，看了一圈，墙上的钩子也被拔了。

林禾拿过围裙，叠在箱子上。外面有人敲了敲玻璃，是收桌子的师傅，隔着门指了指表。

父亲拉开抽屉检查，里面空了。他摸到最深处，抠出一枚被卡住的鞋钉，放进掌心，又从工具箱的缝里塞进去。

两人抬起工作台一端，替师傅让出绑绳的位置。桌脚离开地面，底下那片浅色地砖完整露出来。

父亲往旁边挪，鞋底忽然吱了一声。

林禾低头。他左脚布鞋开了一小道口，脚一抬，鞋面和鞋底便分开。

“你的没修？”

父亲把脚放平：“不碍事。”

林禾打开工具箱，拿出针，又拿出线。父亲坐回尚未搬走的矮凳，脱下左鞋递给她。她把鞋托在膝上，线头戳了几次，没有穿过针眼。

父亲伸手。她把针递过去，鞋仍留在自己膝上。

师傅靠着门框喝水。父亲把穿好线的针递回来，手指在鞋边点了一下。

林禾落下第一针。
