# 《旗落之前》单集故事方案

**类型与时长：**架空古代武侠爽剧，单集约12分钟。  
**人物：**杂役少年阿砚；大师兄裴峻；总镖头沈震；委托人陆娘子。  
**空间：**镖局演武场及相连器械廊。  
**核心行动：**授旗大会散场前，阿砚须证明自己没盗镖、拿回被夺的镖银。  
**武艺来源与限制：**阿砚多年在器械廊磨枪、收枪，练熟短枪“压杆步”，擅借长兵器的杆身拨偏来招；枪法仅练熟三式，臂力不足，不能硬碰重刀。

演武场上，裴峻将一只空镖匣掷到阿砚脚边，指他偷了陆娘子托运的二十两镖银，还把护镖功劳写在自己名下。陆娘子确认匣中原该装银，沈震宣布授旗前查明；若阿砚不能自证，便交镖局处置。裴峻已把二十两银收在自己腰间的钱袋里，声称那是他的赏银。

阿砚不争嘴，只请陆娘子看匣盖。她指出封泥有一道细月牙缺口，是自己交镖时留下的。匣盖缺口还在，封泥却被从内侧挑开：银子不是被整匣偷走。阿砚又从器械廊取来一截断枪缨，缨头沾着蓝色封泥。陆娘子认出那是押镖途中用来补封的蓝泥；她记得当日只有裴峻拿过匣子，说要替她重封。

裴峻没认账，反抓起长刀逼阿砚“当众验手”。他知道阿砚不善近身，也知道枪在廊中。阿砚取一杆旧枪应战。裴峻先横刀压枪头，逼他退向廊口；阿砚不硬扛，沿枪杆向后滑手，侧身踏出压杆步，让刀锋擦过枪身。裴峻转腕削枪，阿砚松左手，枪杆落地滚进廊门，借门槛卡住刀尖。裴峻抽刀回斩，阿砚已绕到他持刀一侧，以短枪尾敲中其腕骨。刀落地，裴峻踢开枪杆，反手扯住阿砚衣领，将他撞向器械架。

阿砚肩膀撞上架子，几支木棍滚落。他顺势抓起一根短棍，横挡裴峻第二次劈来的刀背，手臂被震得发麻，仍借棍身一拧，把刀拨向空处。裴峻脚下踩中滚落的木棍，身形一歪，阿砚没有追打，只用枪尖抵住他的腰袋。钱袋被挑落，二十两银散在演武场上。

这场胜负只证明裴峻输了，沈震仍不准凭比武定盗镖罪。陆娘子当场取出交镖时的收条：二十两封在匣内，封泥缺口与断缨上的蓝泥相合；她又指明裴峻重封后，匣盖的月牙缺口方向倒置。沈震拆看空匣，确认银子从内侧取出，证据与陆娘子的交接记忆相合。裴峻先失镖银，再被沈震当众摘下腰牌，停授旗资格，押在器械廊里等镖局裁决。

沈震将二十两逐枚点清，交到阿砚手中，另把原定给他的护镖赏银也补齐。阿砚接过银子，却拒绝当场领旗：“先把我名字写进这趟镖的功簿。”沈震亲手落笔。大会鼓声再起，阿砚把银袋系紧，转身去收那杆旧枪。
