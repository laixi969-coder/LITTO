# 旗落之前

演武场上，新旗已挂到旗杆旁。总镖头抬手示意授旗，沈娘子却从席间站起：“我的十二两托镖银不见了。包口的双结也被拆过。”

大师兄陆骁将一个空油布包丢在地上：“从阿砺铺位搜出来的。他搬过镖，最有机会下手。”

杂役们低声议论。阿砺没有去捡包，只望着沈娘子：“交镖时，您称过银子？”

“十二两，亲手系的双结。”

陆骁接道：“包在他手里过，称过又如何？”

总镖头把一只钱袋按在桌上：“这是阿砺护镖应得的四两镖银，现下暂扣。大会散场前若查不清，他逐出镖局；授旗照旧。”

阿砺看向陆骁腰间的佩刀，又看向相连的器械廊：“我要重走搬镖的路。”

“可以。”陆骁提起长棍，横在演武场与器械廊之间，“不过你得先从这里过去。”

阿砺常年整理器械，练过贴墙步，也熟悉窄廊里怎样借架卸力；可他臂力不及陆骁，短棍也挡不住长棍硬压。他仍握起短棍，棍头斜挑，格开迎面砸来的棍梢，贴着墙侧身挤进廊口。

陆骁立刻转棍扫腿。阿砺用棍尾撑地，跃过扫击，落在兵器架边。陆骁不追他的步，长棍横压短棍，顺势锁住阿砺手腕。阿砺松手弃棍，贴身撞向陆骁肩口，趁他收棍的空隙夺回短棍，却没有再打，只用棍尖点向架底：“这里有新刮痕。”

陆骁一脚踢翻兵器架。刀枪哗啦倒下，阿砺失了借力的地方，被逼退回演武场。

“刮痕也能是你弄的。”陆骁将棍横在胸前，“你摸过镖包，正好栽赃。”

阿砺不再上前：“那就请沈娘子看架脚。”

沈娘子走到倒下的兵器架旁。架脚压着一枚铜铃，铃舌缠着半截断线。她脸色一变：“这铃是我系在银包上的，线打的就是双结。”

总镖头捡起铜铃递给她。沈娘子确认后，直视陆骁：“你接镖后，曾独自进过器械廊。那时包还在你手里。”

“他能把铃放在那里。”陆骁没有退，反而转向总镖头，“比武赢不了我，便拿一枚铃定罪？”

阿砺道：“比武不能证明谁偷了银子。我只想请总镖头看一眼陆师兄的刀鞘。”

陆骁手掌猛地压住刀柄。沈娘子盯住鞘口：“我的银包裹过油布。他鞘内侧有同样的油渍，我交镖时看见过。”

总镖头伸手：“刀交出来。”

陆骁握刀不放。总镖头上前一步，扣住他的腕子；陆骁挣了两下，刀终于落进总镖头手中。总镖头倒转刀鞘，夹层里滚出十二两银子，散在演武场地上。

陆骁被撤去大师兄职分，当场逐出镖局，并须向沈娘子赔礼。总镖头将十二两银子一枚枚点清，亲手交还沈娘子；随后打开桌上钱袋，把四两镖银交到阿砺手中。

“旗给你。”总镖头道。

阿砺收下银子，却没有接旗：“下一趟让我亲自护完，再谈授旗。”

总镖头将旗交到他手里：“好。”

阿砺握住旗杆，走到演武场中央。廊边那些倒下的兵器仍横在地上，他没有再退回去。
