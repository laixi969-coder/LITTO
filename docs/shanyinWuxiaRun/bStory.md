# 旗落之前

演武场上，新旗立在旗杆旁。总镖头正要授旗，沈娘子忽然起身：“我托镖的十二两银子不见了，封包的双结也被拆过。”

大师兄陆骁把空油布包掷在地上：“从阿砺铺位搜出来的。他搬过镖，最有机会下手。”

阿砺没碰那包，只问沈娘子：“交镖时，您称过银子？”

“十二两，亲手系的双结。”

“包在他手里过，称过又如何？”陆骁挡道。

总镖头按住桌上的钱袋：“这是阿砺应得的四两镖银，先扣下。大会散场前查不清，他逐出镖局；授旗照旧。”

“我要重走搬镖的路。”阿砺说。

“行。”陆骁提起长棍，横在演武场通往器械廊的窄口，“先过我这关。”

阿砺常年收拾器械，练过贴墙步和窄处卸棍；可他臂力不及陆骁，硬挡必败。棍梢砸来，他斜挑短棍格开，贴墙挤入廊口。陆骁转棍扫腿，阿砺以棍尾撑地跃过，落在兵器架边。陆骁不追他的步，长棍压住短棍，反手锁腕。阿砺松手弃棍，贴身撞开棍势，夺回短棍，棍尖点向架底：“新刮痕。”

陆骁一脚踢翻兵器架。刀枪倒地，堵住廊口；阿砺失了借力处，被逼回演武场。

“刮痕也能是你弄的。”陆骁横棍挡住他，“你摸过镖包，正好栽赃。”

阿砺没再上前：“那就请沈娘子看架脚。”

架脚下压着一枚铜铃，铃舌缠着断线。沈娘子走近看了看：“这是我系在银包上的铃，绳结也是双结。”总镖头捡起递给她，她确认无误，又道：“陆骁接镖后，曾独自进器械廊。那时包还在他手里。”

“他也能把铃放在那里。”陆骁没有慌乱，“比武赢不了我，就拿铃定罪？”

“比武不能证明谁偷了银子。”阿砺说，“请总镖头看他的刀鞘。”

陆骁的手立刻按住刀柄。沈娘子看向鞘口：“交镖时，我见过鞘内的油渍，和包上的油布一样。”

“刀交出来。”总镖头上前扣住陆骁手腕。陆骁挣扎不放，刀鞘撞上地面，夹层里滚出十二两银子。沈娘子认出油布包留下的油渍；总镖头当众点清银两，交还给她。

陆骁被撤去大师兄职分，当场逐出镖局，并须向沈娘子赔礼。总镖头打开桌上钱袋，把扣下的四两镖银亲手交给阿砺。

“旗也给你。”总镖头说。

阿砺收好银子，没有接旗：“下一趟让我亲自护完，再谈授旗。”

总镖头把旗递到他手中。阿砺走到演武场中央，握紧旗杆，没有再退回器械廊边。
