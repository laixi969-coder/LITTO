## 实际验证

没有新增测试文件；以标准输入执行原函数、临时隔离数据库和本机 HTTP 验证，没有调用真实付费供应商。

- 网络：内网目标在请求前拒绝；跨来源重定向不携带凭据；307 不转发带正文的 POST；没有 Content-Length 的超限流也拒绝；正常图片适配器输出通过。独立 Node 运行时使用实际本机 HTTP 验证 POST 流传输。
- 文本：模拟平台供应商成功生成和扣费；未知结果保留冻结额、明确拒绝释放预占；无单价拒绝，超时与输出限制传入适配器；其他项目、已删参考拒绝且未调用供应商。
- 数据：恶意 JSON 不能替换身份、归属和审批列；人为让第三步影调插入失败，验证项目创建整体回滚；过期会话清理保留有效会话。
- 密钥：四个独立进程同时初始化成功；后续启动不改已有密钥；非法环境密钥拒绝启动。
- 媒体：实际 ffmpeg 创建并读取缩略图；十次衍生请求最多建立两个任务目录，完成后清理。
- 回归：实际本机 HTTP 加号邮箱密码登录、Cookie、建项目、画布保存/更新、版本冲突保护、任务列表和退出通过；挂载模式媒体任务成功生成并扣费。

## 边界与使用影响

- 复用的 SSRF 防护仍有已有的 DNS 检查与连接分别解析的限制，未宣称已经解决 DNS rebinding；私有上游仍遵循原单用户模式/明确环境变量策略。
- 平台 runText 需要明确按次单价；成功但缺供应商成本时结算的是管理员报价，actual_cost 仍未知。超时或受理不明的任务需核对原供应商结果，不自动重发或退款。
- 200 MiB 上限与二十项输出为明确资源边界。衍生任务忙时可能只播放原素材，不影响原文件保存。
- 主密钥仍可按原方式存于数据目录，不因本批修改轮换真实密钥或宣称已经完成异地密钥管理。
- 任务列表仍保持最近两百条数组接口，本批修复数据库读取范围，没有新增分页界面或变更旧调用方协议。
