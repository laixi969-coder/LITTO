## 实际验证

全部使用临时隔离数据和标准输入执行原代码，没有新增测试文件，也没有调用真实付费模型或真实 IdP。

- 正文流等待期间将用户降为 VIEWER，Hono 和实际 Express HTTP 均返回 409，未执行旧权限写入。
- 非法 JSON 返回 400，已存模型策略保持原值；合法游标接受，其他结构拒绝；在线状态过期后清空。
- 八条 SSE 可连接，第九条返回 429，断开后可重新连接。全部会话退出同时撤销两个 token。
- 撤权后启动原排队任务，供应商提交次数为零，冻结额释放。正常媒体生成和扣费仍通过。
- 相同和乱序终态回调只保留一条事件并结算一次，非法签名/JSON/状态拒绝；不同远端任务尝试隔离，旧失败不污染新成功，失败回调允许空输出。
- 有活动任务或未结清冻结额的项目不能永久删除；模拟磁盘删除失败后数据库记录保留，核对结清和排除磁盘故障后可重试。
- 真实 ffmpeg 验证超配额时跳过衍生图、配额充足时正常生成，实际字节纳入存储统计。
- 模拟 SSO token 响应期间停用连接，返回 409 且未开户；连接稳定时正常建立会话。
- 实际本机 HTTP 验证加号邮箱密码登录、Cookie、项目创建、画布保存/更新/读取、旧版本冲突保护、正常媒体队列扣费及全部会话退出后的 401。

## 边界

- 撤权检查针对正文接收和付费新提交等关键边界，不宣称整个异步文件/供应商事务都能即时撤回。
- 已受理且费用未知的任务保留原回执和冻结额，需要核对；不会通过永久删除任务绕开结算保护。
- 磁盘删除跨文件不能原子回滚；失败明确报错并保留元数据，可能已有部分文件删除，需要重试清理。
- 同一次远端任务尝试以第一个有效终态为准，没有更改现有签名协议；历史事件与外部供应商实际投递机制未迁移或联调。
- 存储统计覆盖有记录的衍生文件，历史孤儿文件仍需独立核查。衍生任务为可选优化，超配额不删除原素材。
- 新增全部会话退出 API，没有添加未要求的 UI。真实供应商、真实 IdP、生产代理和多实例部署未验收。

## 最终复查

复核了撤权后的付费提交、慢正文身份变化、未结清任务删除、回调跨重试隔离、衍生文件配额和删除后不再写入。SSE HEAD 不建立后台流、不消耗名额，磁盘删除失败保留记录后可重试。三处类型检查和前后端构建通过；前端仍有大分包提示。没有新增测试文件。
