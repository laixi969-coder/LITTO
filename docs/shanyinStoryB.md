# 最后一双 · B

林禾把最后一个抽屉倒进纸箱，一张取鞋单跟着掉出来。十七号，补鞋口，二十元。

父亲从她手里抽走单子，压回鞋油罐下面。

“还有客人。”

“鞋修好了就打电话。”

“他说四点。”

林禾看了看手机。三点四十。四点半收桌子的车来，店门上贴着明日起停业，墙上只剩价目表没摘。

她把两只黑皮鞋装进袋子。父亲拿出来，右手伸进右鞋，摸了摸鞋口，又将它放回。

“要不你给他再打一个？”她说。

父亲没答，去扫地。

老周四点差三分进门。父亲迎着问：“今天袜子穿对了吧？”

老周抬了抬裤脚：“还说呢。”

林禾正卷胶带，停了一下。

“来过了？”

“上午。”老周说，“你爸说这里得再弄弄。”

他套上鞋，站起来试走。右脚刚落地，鞋带散了。他弯腰系，父亲已经蹲下去，把两边带子拉齐。

林禾看着桌角那张取鞋单，上面用铅笔写过“十点”，又划了。

“上午没修好？”

父亲系了个结：“得试。”

老周走到价目表下，再走回来，抬抬脚：“行，舒服。”

他把二十元放上桌，父亲又伸手去摸右鞋后跟。

“走远点才知道。”

“我回家就走远了。”

老周笑了一下。父亲的手停在半空，随后去拿鞋袋。

林禾拉开工具箱，把钳子放进去，声音很响。

“一双鞋，你让人来几趟？”

老周没接袋子：“我住得近。”

“近也不能这么来回折腾。”

父亲把袋子铺平：“还差一块衬。”

林禾从台面拾起剪剩的皮边：“哪块？”

父亲没看她，先看老周。老周的脚往后挪了一点。

“真不刮了。”老周说。

林禾把工具箱盖扣上。父亲按住盖子，她也没松手。两人隔着箱子站着，老周蹲下，把刚系好的鞋带解开。

“别脱。”林禾说。

父亲手上的劲松了。

老周站起来，重新踩实鞋跟。他指着右鞋口：“上午就是这儿。现在好了。”

父亲点了点头，把袋子递给他。老周装进旧布鞋，拿出手机：“以后还有小毛病，我给你打电话。”

林禾转头看父亲。他张开嘴，又看向那只已经扣好的工具箱。

“先穿着。”他说。

老周走了。父亲把二十元收进围裙兜，拿起扫帚。地上早已没有垃圾，他将扫帚尖伸到工作台底下，扫出一枚鞋钉。

林禾把钉子捡起来，放在箱盖上。

“下星期你还想在这儿修？”

“桌子不是卖了吗。”

“我问你。”

父亲把扫帚立好。它滑下来，他又扶了一次。

“家里放不下。”

林禾坐到矮凳上，用手机翻出工作台的照片。照片下面是她和买家的对话：桌子、钉鞋铁脚一并带走。她看看桌沿，铁脚用两颗螺栓固定着。

父亲说：“卖都卖了。”

林禾拨通电话，开了免提：“师傅，铁脚我们想留，桌子还给你。价钱怎么算？”

对方停了一会儿：“那少八十。照片里都说好了。”

林禾看父亲。他从围裙里掏出刚收的二十元，又摸了摸另一边口袋。她没有伸手拿钱。

“你要留吗？”

父亲将二十元放在桌上：“要。”

林禾对电话说：“行，少八十。”

父亲找出扳手，拆铁脚。第一颗螺栓带着锈，拧不动。他调整位置，林禾扶住桌沿。螺栓松开时，两个人一起往后晃了一下。

四点半，师傅把工作台抬上车。父亲拎着工具箱，林禾抱着包了旧围裙的铁脚。铺子里剩下两把扫帚和那张矮凳。

“阳台就这么大。”她腾出一只手，比了一小段。

“够。”

“别在饭桌上敲。”

父亲点头，伸手想接铁脚。林禾把它往怀里拢了拢：“你拿凳子。”

父亲提起矮凳，走到门外。她锁门，他把凳子放下，让她把铁脚先搁一会儿，空出手来拧钥匙。
